# W47→W48：从“局部搜索停滞”转向“正确反馈与真实闭环恢复”

执行规则以[最终W48计划](../../../../../../docs/S1_W48_STABILITY_PLAN.md)为准；本独立报告的建议经主审查整合，不另开并列实验。

审查日期：2026-11-13（Asia/Shanghai）。仓库结果基点：`6e9075f48718509d48f51d08d0a8f62a34edfb41`。这是文献与实验设计审查，不是新增服务器实验；没有执行 native solve、plant 或 PPO。

## 1. 新结果要求改变问题表述

仓库 `w47/task-c/planner-summary.json` 已统计全部1,944次原调用：1,601次正步安装，其中1,598次降低本次问题的J，另3次按r34风险优先降低违反量；内部停滞343次。四个旧保存上下文的540个正步不下降仍是有效局部证据，但不能再作为“全程都找不到下降方向”的解释。

`w47/task-a/paired-evidence.json` 中四对固定候选验证显示：旧版精确重现保存的alpha0；修正四元数自身/严格反号表示的状态差后，四例alpha0与各自nominal的状态、动作、时标、残差和J完全一致。B155/B158旧版J差分别为0.02347126250312126、0.01819062268719436，修正版均0。该文件同时明确：正步方向未重新求解；8条rollout、14,000子步不是8次优化或8次原任务。

这支持两个分开的结论：首次数值扰动来源已定位并有有限修复证据；真实非零状态误差下的反馈恢复能力仍未验证。修补只在四元数逐分量完全相同或完全互为负号时置零，不给邻域加容差，不能由此声称所有微小误差或接触失稳都被修复。

本轮Task B的结果是来源/上下文不可用：唯一指定R8原件未在执行服务器定位到，最新W46 A/B完整策略和同时间预测缺失，因此没有donor solve。这是干预未实施，不是donor机制失败。

**实验设计判断：R8缺失应关闭donor分支，不应阻塞已发现数值修复的正步和闭环验证。** 依赖历史上未保存的最新完整上下文作为所有后续实验的必要条件，会使采集所缺证据的实验也无法启动。

## 2. 一手文献：本轮优先读的六篇

以下每篇的内容归纳保持简短；“对本项目的判断”是根据仓库证据作的推论，不是作者对本项目的结论。未核定中科院分区，不把期刊名替代分区证明。

### 2.1 MuJoCo方法原文：保持与实际执行一致，反馈有效性需实验

**John Z. Zhang et al., _Whole-Body Model-Predictive Control of Legged Robots with MuJoCo_.** arXiv:2503.04613，已核v2（2025-10-18）；作者项目页当前仍标under review，不补写期刊接收。 [全文](https://arxiv.org/html/2503.04613v2) · [作者项目](https://johnzhang3.github.io/mujoco_ilqr/) · [部署代码](https://github.com/johnzhang3/mujoco_mpc_deploy)。

论文在模型内包含关节PD，以关节角目标为输入；全身iLQR与TV-LQR分频执行。它比较有/无反馈，明确反馈对接触计划稳定性的局限。作者采用前向有限差分，报告中心差分在其运动任务中不奏效；这是其经验结果，不是所有任务的定理。默认0.35s、100Hz规划离散与当前175个2ms held区间也不是同一计算量。

**对本项目的判断：** 优先核修复在求解与部署两条StateDiff路径都生效，随后测预测—真实残差与扰动恢复。不能根据“论文也用了iLQR”证明当前定制PD/H-QP/材料/步态链等价。部署repo只负责硬件接口，solver/task在MuJoCo MPC，模型在Menagerie；不能只比较部署Python。

### 2.2 ICRA 2025：线性反馈可能不具备接触恢复能力

**Yuki Shirai et al., _Is Linear Feedback on Smoothed Dynamics Sufficient for Stabilizing Contact-Rich Plans?_** ICRA 2025，11926–11932；DOI [10.1109/ICRA55743.2025.11127776](https://doi.org/10.1109/ICRA55743.2025.11127776)。预印本2024-11-10，已核v4（2025-05-14）。 [论文](https://arxiv.org/pdf/2411.06542) · [作者机构](https://rai-inst.com/resources/papers/is-linear-feedback-on-smoothed-dynamics-sufficient-for-stabilizing-contact-rich-plans/)。

作者在双臂接触操作的300多条轨迹上研究平滑接触模型上的LQR。一个关键机制是：线性模型的对称性会预测接触可“拉”，而真实接触只能单向推；因此可生成计划不等于线性反馈能恢复。多粒子优化有时改善结果，也有收敛困难。

**对本项目的判断：** 这支持在新记录中分离“nominal真实J下降”与“偏离nominal后的实际支撑/恢复”。只有观测到本项目也出现接触方向或活动面不一致，才可把它作为解释；文章研究操作，不能据此宣布Go2跌倒原因已找到，也不支持任意削K或取消反馈。

### 2.3 IJRR 2026：让局部模型的可信区域尊重接触力可行性

**H.J. Terry Suh, Tao Pang, Tong Zhao, Russ Tedrake, _Dexterous contact-rich manipulation via the contact trust region_.** IJRR，正式在线2026-01-05；DOI [10.1177/02783649251398875](https://doi.org/10.1177/02783649251398875)。预印本首发2025-05-04。 [出版社](https://journals.sagepub.com/doi/10.1177/02783649251398875) · [公开全文](https://arxiv.org/html/2505.02291v2) · [项目](https://ctr.theaiinstitute.com/)。

CTR把局部状态预测与接触力预测结合，用接触可行性约束界定局部模型可相信的区域。实现基于CQDC准动态模型，在双臂和灵巧手上验证，并研究准动态计划在二阶动力学下的执行。准动态状态不含速度，文中力矩约束主要是稳态约束，不能直接代表瞬态力矩。

**对本项目的判断：** 当新增记录显示接触切换后线性预测方向与真实恢复相反时，它比无条件扫输入惩罚更有针对性。当前不能直接把CTR套到Go2动态行走或把它当成一个现成MuJoCo补丁。本次未核到可直接复现的官方代码仓库；项目页面的论文宣传不等于代码已经可用。

### 2.4 RA-L 2024：优化精度、模型误差和闭环成功率分开测

**Charles Khazoom et al., _Tailoring Solution Accuracy for Fast Whole-Body Model Predictive Control of Legged Robots_.** IEEE RA-L 9(12):11074–11081，2024-09-09在线；DOI [10.1109/LRA.2024.3455907](https://doi.org/10.1109/LRA.2024.3455907)。 [全文](https://arxiv.org/html/2407.10789v2) · [MIT论文页](https://biomimetics.mit.edu/publications/tailoring-solution-accuracy/)。

作者以相同运动命令集比较求解精度、惯性误差、离散误差与计算延迟；高精度子问题解的收益会被这些误差限制。其SQP/ADMM与初步CBF方案在MIT Humanoid实机90Hz运行。这是有特定模型与任务条件的结果，不是允许任意放松物理约束。

**对本项目的判断：** 1,598次同问题J下降不能直接累计成闭环任务收益。应把native候选预测、实际执行、重规划导致的目标变化、物理失败分开记录。当前同步仿真的墙钟慢首先是吞吐问题，不能未经验证改写为实时延迟导致跌倒；r34接纳容差继续保持。

### 2.5 T-RO 2024：参考轨迹可以有用，但必须在当前动力学下评估恢复

**Simon Le Cleac'h et al., _Fast Contact-Implicit Model Predictive Control_.** IEEE T-RO 40:1617–1629，2024-01-09在线；DOI [10.1109/TRO.2024.3351554](https://doi.org/10.1109/TRO.2024.3351554)。 [作者公开全文](https://msl.stanford.edu/papers/le_cleach_fast_2024.pdf) · [官方实现](https://github.com/dojo-sim/ContactImplicitMPC.jl)。

方法沿离线参考构造时变接触模型，但保留互补约束以在线改变接触序列。论文单独验证受扰、模型失配和更高频仿真下的恢复；Go1硬件采用简化点足模型和低层力跟踪。官方仓库包含参考轨迹生成入口。

**对本项目的判断：** 它支持“生成当前问题可用的参考＋闭环恢复验证”，不支持强制依赖一个缺失的历史R8二进制。当前R8旧步态/模型与r35不同，直接借输入只有实验意义，不是已知可用的控制先验。当前首要工作仍是验证已证修复，而不是立刻迁移另一套接触求解器。

### 2.6 IEEE Access 2024：参考约束过强可能限制恢复，但不能混改目标

**Gianni Lunardi et al., _Reference-Free Model Predictive Control for Quadrupedal Locomotion_.** IEEE Access 12:689–698；2023-12-19在线、2024卷；DOI [10.1109/ACCESS.2023.3345157](https://doi.org/10.1109/ACCESS.2023.3345157)。 [作者机构全文](https://iris.unitn.it/retrieve/handle/11572/402849/771405/Reference-Free_Model_Predictive_Control_for_Quadrupedal_Locomotion.pdf)。

作者用与障碍距离相关的足速度代价替代固定摆足参考，使落足位置可调整，并在ANYmal B验证推扰恢复。仍有预定义接触阶段、接触面和基座速度等指导；“reference-free”不等于没有任务参考。使用Box-FDDP/Pinocchio/Crocoddyl，不是当前MuJoCo执行链。

**对本项目的判断：** 若修复后的同问题求解持续拒绝实际有益的运动，可据分项证据单独研究目标冲突或动作自由度。不能同时换步态高度、去参考代价和改求解器，再将结果都归为identity修复收益。本次未核到该论文专属完整官方复现仓库，通用工具开源不等于本文实验已完整开源。

## 3. 状态差的官方定义与修复边界

[MuJoCo 3.2.3官方API](https://mujoco.readthedocs.io/en/3.2.3/APIreference/APIfunctions.html#mj-differentiatepos)规定，`mj_differentiatePos`尊重四元数流形，输出nv维切空间量；`mju_subQuat`输出三维旋转差。四元数的4维表示不能直接逐分量减后塞进36维反馈。这是接口定义；文档没有承诺所有相同输入在浮点计算中逐位得到零。

W47的补丁在调用原函数后，仅对严格相同或严格反号的free/ball quaternion清零对应3维旋转差，其余真实差值仍走原函数。四个配对结果证明它消除了这些保存候选的零点注入。下一轮需要检查它的实际生产路径与正步效果；不必先要求一个从未记录的最新历史context存在。

## 4. 建议的有限推进顺序

以下为本审查的实验设计建议，由主计划冻结最终预算。

1. **先用现有完整问题验证修复后的正步。** 同一context、reference、预算、r34准则比较原版/修正版N；重用可证明同身份的旧baseline。保存dV、真实ΔJ、接纳与完整赢家，不只重复已经验证的alpha0。若旧baseline身份不足，则有限成对重算，而不是借不同问题比较。
2. **把“修复是否正确”和“修复是否使任务稳定”分开。** 数值一致性恢复可以成为有限闭环验证的依据；其本身不是稳定通过。若没有新的接口/物理硬条件问题，可以进行至多两条预先声明的修复版本原E30，用原任务判据给出成功/失败，并采集同时间完整上下文。失败照实保留，不换seed追成功。
3. **在同一回合补齐缺失记录。** 对实际安装策略保留policy id/hash、x/u/K/H/scale、完整初态、private gait、材料proxy、goal/mocap与冻结参考；把前一次accepted预测在当前时刻的节点与actual状态关联起来。先有这些资料，才能分离目标问题、模型误差与反馈恢复问题。
4. **同问题优化下降与跨epoch任务进展分列。** 不能把每次相对自己的nominal下降加起来当作持续稳定；应测预测/实际前进、高度和姿态、接触/支撑、投影前后动作及目标/力矩反转。
5. **donor可用性另列。** 如已授权服务器来源能恢复相同R8原件，可原位核验后另立种子实验；否则本轮关闭该分支，不改挑别的来源、也不阻塞主修复验证。
6. **CPU两流保持主要推进，GPU第三流只做新证据。** 不因显存空闲重复已知不等价长窗。若需要GPU扩大候选，将当前模型/动作/完整目标与CPU一致的必要条件明确后另立任务；现在先确保得到有用的稳定性证据。

## 5. 下一机制由什么证据决定

| 新证据 | 优先方向 | 暂不能宣称 |
|---|---|---|
| identity修复后真实正步下降恢复 | 数值执行一致性贡献成立，继续有限闭环 | 完整任务已稳定 |
| 正步本来就下降，但实际一步预测误差大 | 查当前预测器、状态/时间、PD/投影与材料更新一致性 | 算法只需更多迭代 |
| 同模型非零扰动触发接触方向/活动面不同，K恢复失效 | 接触一致局部反馈、可信区域、鲁棒方案 | 任意缩K或CTR现成可用 |
| 有益运动在J0/Jref某项被系统排斥 | 单机制目标/参考冲突研究 | 直接放宽r34即可 |
| 预测/恢复准确，但原路线切换失败 | 任务阶段/目标衔接 | 材料记忆已失败 |
| 修复版本仍失败且数据齐全 | 一次有限负结果，按首个机制分叉形成新问题 | 继续同配置直到成功 |

这些论文提供的是诊断思路和可选机制，不替代本项目的证据。W48最关键的新贡献应是把已证数值修复接到真实搜索与闭环记录上，避免再次只完成文件核验而无法回答它对任务到底有没有作用。
