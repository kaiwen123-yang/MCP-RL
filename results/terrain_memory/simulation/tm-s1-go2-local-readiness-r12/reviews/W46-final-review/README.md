## 5. 为什么alpha0端点必须先查

重建源码确认：新候选使用当前nominal的x/u中心、新K/H、scale=1，alpha只缩放前馈k；旧nominal通过时间插值ActionImpl评分，新候选用节点ActionIndex。alpha0不是旧策略在离轨状态上的同一个反馈映射。

但对同一模型、完整初态、时标与可执行nominal，若x=bar_x且ubar可行，标准iLQR的alpha0应逐节点再生nominal。B的显著J差不能仅用“换了K”解释。要找第一处分叉的状态、命令、投影活动面和接触，再判断是执行语义不同、微小误差被新反馈放大，还是局部模型/方向失真。模型已关闭warmstart；不能无证据指责qacc历史污染。

这比继续扫R更接近可验证的问题。K的绝对数值有单位和参考表示依赖，不单独用作新惩罚或成功标准。详细源码链、12行分支表和机制边界见[控制报告](control-report.md)。
