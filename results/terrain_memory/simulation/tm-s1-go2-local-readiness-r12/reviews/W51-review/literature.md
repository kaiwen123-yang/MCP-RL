# W51 后续工作的文献对照：从站立局部解到可执行的支撑交换

## 范围与结论

本记录对应仓库 `a621d7d35e6016634b388a3aef0d39d8d008aab0` 的 W51 结果，依据 `w51/phase.json`、`w51/D0.json`、`w51/D1.json`、`w51/paired-results.json` 以及 `experiments/terrain_memory/w51_seed.inc`。本轮只做文献和已有实现的对照，不运行新的实验。前轮已经研究的 MuJoCo whole-body MPC、HOUND、HiLQR、DIAL、BiConMP、CAFE 等结论继续保留；以下补足最接近本轮新现象的机制，避免再次罗列相同摘要。

W51 有两个不同问题。D0 的 refresh-only 在 5.814 s 身体跌倒；修正命令写入后的 D1 完成了 8 s 诊断窗，最低机体高度约 0.28577 m，但最终 x 为 −0.01245 m，4.3–8 s 的四足承重占比为 100%，计划摆动足仍承重比例全部为 1。后一结果证明了一段站立状态没有倒下，尚未证明正常行走已经恢复。以此进入长程路线、材料暴露或 PPO 比较，主要会再次测到起步失败。以上数字是本项目结果，不是文献实验。

文献对当前工作的共同启发是：**需要把“几何上存在一个抬脚姿态”，转成“当前真实状态出发、经过实际控制接口后能卸载并完成支撑交换的轨迹”；同时保留从现有可执行策略继续改进的搜索机会。** 几何 IK 收敛、native rollout 数值有效、相位标记进入 swing，都不能分别代替这件事。该判断是结合本项目的推论，并非声称下列论文已经解决本项目代码。

## 1. ROM-guided CI-MPC：为什么 IK 参考需要动力学修正和完整状态参考

**论文身份。** Sergio A. Esteban, Vince Kurtz, Adrian B. Ghansah, Aaron D. Ames, *Reduced-Order Model Guided Contact-Implicit Model Predictive Control for Humanoid Locomotion*, **ICRA 2025**, pp. 14735–14741，DOI `10.1109/ICRA55743.2025.11127605`。arXiv 初稿为 2025-02-21。作者出版页确认会议身份，项目页的 BibTeX 仍保留 arXiv 字段，不应据此误写成仅有预印本。

- [论文全文](https://arxiv.org/html/2502.15630v1)
- [作者项目页](https://rom-cimpc.github.io/)
- [作者出版目录](https://saesteban.com/publications/)
- [底层 IDTO 官方实现](https://github.com/ToyotaResearchInstitute/idto)

**论文实际做法。** §III 用当前 COM 状态初始化 HLIP，产生具有步到步稳定依据的名义落脚和运动；通过 IK 与差分得到关节位置、速度参考，平滑混合站立与行走参考。随后 IDTO 接触隐式 MPC 修正全身运动，并输出位置、速度、前馈力矩给低层跟踪。作者明确指出：混合后的参考未必满足完整动力学。其 CI-MPC-only 对照存在拖脚和不规则周期；组合方法允许偏离名义接触序列。验证为 Achilles 人形机器人仿真，作者也报告了相位建议可能不利于扰动恢复等局限。

**与 W51 的关系——本项目推论。** `w51_seed.inc` 能根据相位、锚点和当前足状态生成几何 IK，再把 `qIK − qB_joint` 作为 delta 加到旧策略，并保留原有反馈、PD、QP 路径。这是一个候选控制策略的构造，不能直接等同于该论文的“优化后的 q、v、力矩一致的全身轨迹”。尤其要区分三个对象：IK 希望看到的足轨迹、S 经真实低层接口得到的预测足轨迹、最后实际安装的控制策略。若三者不一致，继续微调 IK 步高或增加 IK 迭代没有触及主要原因。

应先用已有 W51 原件判断：S 的预测是否真正减少摆动足法向负载，原有反馈是否把新几何参考拉回旧站姿，S 的主要代价增量来自哪一部分，以及 S 的小幅改进为什么仍然无法优于当前 B。这里是解释本轮已有结果的必要读数，不是再增加一批诊断任务。若确认候选没有形成可执行的卸载，下一次实现应让构造的动作与其名义状态/速度保持一致，或利用当前 MPC 做动力学可行性修正，然后再使用原 native rollout 和原 J 比较。

**适用边界。** 不能把人形的 HLIP 方程、权重和接触时序直接移植到 Go2；也不能声称只要增加 ROM 就会稳定。该论文最有价值的是明确承认 IK 与动力学之间还有一层工作，而非给本项目提供一份可直接替换的控制器。项目页未公开本篇完整复现仓库；上面的 IDTO 是其底层方法官方代码，不等于本篇全部实验代码。

## 2. Reference-Free MPC：没有足轨迹参考，不代表没有接触安排

**论文身份。** Gianni Lunardi, Thomas Corbères, Carlos Mastalli, Nicolas Mansard, Thomas Flayols, Steve Tonneau, Andrea Del Prete, *Reference-Free Model Predictive Control for Quadrupedal Locomotion*, **IEEE Access 12:689–698, 2024**，DOI `10.1109/ACCESS.2023.3345157`，2023-12-19 提前在线发表。

- [作者所在大学的论文全文](https://iris.unitn.it/retrieve/handle/11572/402849/771405/Reference-Free_Model_Predictive_Control_for_Quadrupedal_Locomotion.pdf)
- [Heriot-Watt 官方出版记录](https://researchportal.hw.ac.uk/en/publications/reference-free-model-predictive-control-for-quadrupedal-locomotio/)

**论文实际做法。** §III-A 的 fly-high 代价把足部水平速度与障碍物距离耦合：高速时鼓励足远离障碍，接近落脚时允许速度减小。§III-C 仍使用预先规定的接触相位及时长；支撑相位足位置受约束，摆动相位释放足运动。自由落脚情形还用基座速度目标确定行进方向。全身 MPC 的力矩、状态、Riccati 反馈和关节 PD 参考共同下发。论文同时明确足速接近零时 fly-high 代价也最小。

**与 W51 的关系——本项目推论。** 不能从“reference-free”标题推出“给一个高度代价就能自然站起步走”。这篇工作的接触安排进入了求解问题本身；它不是只在日志里给仍在承重的足标上 swing。对本项目而言，参考相位、实际接触力、实际足离地三者需要分开理解。D1 的 100% 四足承重，说明当前完整执行链没有形成期待的支撑交换，不会因为相位计时器正常而变成正常步态。

这篇论文也反对直接把“距离地面近”一项无限加重：如果没有行进驱动或可行的接触交换，静止足同样可能满足一类避障/抬脚代理代价。应先定位现有机制为何没有卸载，再决定是否需要改变接触模型或目标。其方程 (18)–(19) 还提示了状态参考、反馈中心和关节跟踪目标需要协同；具体是否适用于 W51 的旧反馈，要由原件证明。

**适用边界。** 该论文是真实 ANYmal B 验证，并非 Go2 在本项目摩擦材料任务的验证。固定接触时序也会限制复杂接触的自由度。当前审查没有核实其完整独立复现代码，故不把 Crocoddyl/Pinocchio 的可用性写成论文全部实验可开箱复现。

## 3. Perceptive NMPC：卸载、摆动和接触事件进入同一动力学执行链

**论文身份。** Ruben Grandia, Fabian Jenelten, Shaohui Yang, Farbod Farshidian, Marco Hutter, *Perceptive Locomotion Through Nonlinear Model-Predictive Control*, **IEEE Transactions on Robotics 39(5):3402–3421, 2023**，DOI `10.1109/TRO.2023.3275384`，2023-05-29 在线发表。下述技术内容使用作者 2022-08-17 的公开稿核对，会议/期刊身份以 IEEE 记录为准。

- [IEEE 正式出版记录](https://ieeexplore.ieee.org/document/10138309)
- [作者公开全文](https://arxiv.org/pdf/2208.08373)
- [论文所指的官方 OCS2 实现](https://github.com/leggedrobotics/ocs2)

**论文实际做法。** §IV-G 明确要求摆动足接触力为零、支撑足速度为零，并约束摆动的法向运动。§VI 将优化的接触力、关节速度和前馈加速度经全身动力学转换成关节力矩。§VI-A 将实测与计划接触不一致的事件反馈到 MPC：晚触地执行向下重新接触，临近预期触地的早触地则从实际接触状态重规划。作者也明确固定步态与硬编码接触反应的局限；该方法不是任意扰动下的全局稳定保证。

**与 W51 的关系——本项目推论。** 这补全了仅看 IK 会遗漏的一环：摆动不是在支撑动作上叠加一个足端位置意图，还需要改变受力分配并让低层执行与该意图相容。控制审计已从原件发现 S 的若干 native 预测仍全足承重，因此不能把拒绝这种 S 解释为原 J 错拒了一段正常行走。若原有支持偏置和新的几何摆动意图互相抵消，就应改进可执行候选的构造，而不是降低接受标准。

另一个需要处理的情况是：时钟已进入 swing 后半段，真实足却还没有离地。对当前位置连续续接一条“剩余摆动曲线”并不保证剩余段仍有向上的净间隙；它甚至可能主要要求水平移脚。此时数学连续性和几何可达性都无法代替一次新的、受力可行的起步过渡。应使实际接触状态参与候选生成，同时保留名义相位的意图，避免把“只要检测到承重就取消摆动”写成新的死锁规则。这里所建议的是修复当前候选生成中的不一致，不要求整体移植 OCS2、增加外部接触监督控制器或改变原任务。

**适用边界。** 论文的零摆动力约束属于其预测模型及 WBC，不是可以直接写入 MuJoCo 真实状态的指令。真机或仿真里的法向力只能由实际运动和受力改变，不能通过改日志或强行指定接触标记实现。本文仅核对论文对 OCS2 公开代码的说明；没有在本项目运行该实现。

## 4. 全局采样加局部接触优化：不要让一个差初值占据唯一搜索通道

**论文身份。** Sharanya Venkatesh, Bibit Bianchini, Alp Aydinoglu, William Yang, Michael Posa, *Approximating Global Contact-Implicit MPC via Sampling and Local Complementarity*, **IEEE Robotics and Automation Letters 10(11):12117–12124, 2025**，DOI `10.1109/LRA.2025.3615030`。官方项目页注明于 ICRA 2026 展示。

- [论文全文](https://arxiv.org/html/2505.13350v2)
- [作者项目页及出版信息](https://approximating-global-ci-mpc.github.io/)

**论文实际做法。** §IV 展示局部接触几何近似如何让控制器陷入无进展的解。方法对少量不同末端位置并行求局部接触优化，再选择无接触重定位或接触操作；候选集合始终包含当前状态，也保留仍在执行的重定位目标。切换采用成本和进展信息，避免噪声导致反复改目标。实验证据来自 Franka 机械臂操作，所用无接触阶段近似依赖准静态假设。

**与 W51 的关系——本项目推论。** W51 r39 的结构是“有效 S 成为 Q，即使 J(S)>J(B)”，最后仍以 B 作为接受基线。如果从 S 出发的局部方向都只比 S 好、却仍比 B 差，算法可以保持 B 很长时间，同时每轮继续计算没有实际改进的 S 附近方向。因此，“B 被保留”和“B 附近仍能继续优化”不是同一件事。

若逐调用原件确认这一结构导致长期停滞，最有解释力的一种改动是同时保留 B 与 S 两个起点的独立改进路径，使用同一当前状态、同一原 J、同一真实 rollout 和既有约束做最终比较。并行计算的是不同、有解释的局部搜索方向，而不是只把同一差初值重复随机化。这样既不会为了移动而强制接受更差 S，也不会让较差 S 阻断从 B 继续改善的机会。但 D0 已证明 B-only 路径本身没有取得成功：恢复它的搜索机会不能被宣传为稳定性修复，也可能重新引出 D0 的失稳。因此是否先做这项改动，应与候选动作/反馈一致性审查合并决定；不能凭文献把它宣称为已证实修复。

**适用边界。** 四足的支撑足不能像机械臂末端那样随意无接触重定位，身体也不会在重定位时自动静止。这里借鉴多起点覆盖与并行评估的结构，不移植论文的接触自由阶段、准静态假设、切换阈值或完整求解器。文献不支持为了找更好解而放松本项目真实执行链的约束。

## 5. RL-augmented MPC：后续 RL 必须具有与问题相匹配的控制权限

**论文身份。** Yiyu Chen, Quan Nguyen, *Learning Agile Locomotion and Adaptive Behaviors via RL-augmented MPC*, **ICRA 2024**。采用 2024-03-19 的 arXiv v2 核对技术内容。

- [论文全文](https://arxiv.org/html/2310.09442v2)
- [USC 实验室出版目录](https://sites.usc.edu/quann/publications/)
- [官方实现](https://github.com/DRCL-USC/RL_augmented_MPC)

**论文实际做法。** 基础控制已经有支撑力优化、落脚启发式和名义摆动轨迹。RL 在 33 Hz 提供线/角加速度补偿与摆动关节偏移，并观察计划接触和真实接触等历史信息。官方代码说明还包括落脚偏移版本，论文报告的是名义摆动轨迹上的关节角偏移版本。它并非仅通过调节一个速度上限来获得障碍反射与足部摆动调整。

**与 W51 的关系——本项目推论。** 本项目外层低频 scalar cap 适合风险保守程度和速度调节，不能直接表达哪条腿卸载、摆动轨迹如何反射、如何补偿身体力矩。若低层在非零命令下仍长期四足承重，继续增加 PPO 步数没有充分的因果依据。应先恢复原任务所需的稳定移动基线；其后若实测剩余问题确实属于足端反应或动力学补偿，再决定是否扩展 RL 的观测和动作。扩展动作是研究方案变更，不能在本轮偷偷加入并把结果算成既有 cap-only 方法。

**适用边界。** 论文的策略频率、动作范围、训练场景不能直接当成本项目默认值。它支持“权限应能作用于要解决的物理问题”，不支持“现在立即换成整套残差 RL”。

## 6. 对下一轮的收敛建议

1. **当前目标是恢复可持续的行走与任务进展。** 保持 S1 的原始路线、材料和长期目标；8 s 站立结果不能替代完成任务，也不应因为未倒而作为胜出控制器直接进入训练。
2. **从已有原件定位一条最短因果链并修复它。** 对照 B、几何 IK、真实 S rollout 和最终安装结果，判断卸载/支撑交换在何处消失。当前原件已支持几何 IK 不等于可执行摆动，优先处理原有支持动作、新参考和实际接触状态之间的不一致；恢复 B 的独立搜索分支可作为第二种可解释改动，不能用它代替卸载问题的解决。不要把这一步扩展成新的大规模诊断矩阵。
3. **并行资源用于可比较的工作。** 两个独立实验可以针对不同、预先明确的机制；同一实验内独立候选方向也能并行。二者都需要独立可变状态与足够的 CPU 配额，不能因多开进程就把较慢、资源争抢的结果解释为算法差。第三任务可以同步处理成本分项、原件/视频分析和交付。论文没有证明当前 native MuJoCo/FD 路径能因 96 GB 显存而自动加速；GPU 适合的候选生成或批处理仍应按已存在、已验证的链路使用，最终结果以原执行路径核验。
4. **不先扩大权重、步高、horizon 或随机初值搜索。** 当前结果首先暴露的是初始化、执行一致性和搜索覆盖问题。改变太多因素会再次失去解释能力；若后续成本分项证明目标本身偏好站立，再单独讨论目标的修改，而不是未经证据先默认加大某个权重。
5. **保留有界的科学预算，取消任意后台墙钟杀进程。** 自然终止、既定仿真任务长度、数值异常与明确资源故障可作为停止条件；实验所需真实时间会受当前求解开销与并行负载影响。任务结束后核对 GitHub 提交和 Release 原件即可；不额外安排用户电脑归档。

以上是文献对本项目的适用分析，不是对尚未实施修复的性能承诺。具体下一轮唯一主变更及并行实验组合，以 W51 逐调用日志、成本分项和视频的联合审查为准。
