# W51 控制实现、全部运动种子与原生候选审查

审查基点：`a621d7d35e6016634b388a3aef0d39d8d008aab0`。前轮计划基点：`354b14bf5313332ae167f02c84ce6b68ef6bae90`。本审查只读取已经完成并发布的 W51 数据，使用 NumPy/XML 和记录数组复算；没有加载 MuJoCo 模型，没有新 physics、native solve、动力学 FD、PPO 或 GPU 积分，也没有修改运行控制代码。

## 1. 结论

**W51 已把“刷新参考”和“新增运动种子”真正接入正常运行，但尚未解决正常步态。新证据已经把一个具体错误定位到运动种子的当前摆动段接续公式：它在真实脚仍落地、原相位已向前推进时，会生成往地下走的足端目标。** IK 数值求解很准，却忠实求出了这个错误的几何目标。与此同时，未来完整摆动段即使给出约 5 mm 的几何抬脚目标，S 的原生动力学 rollout 也经常没有相应卸载和抬脚，说明几何目标与实际受力执行仍有距离。

D0/r38 从正常 t=0 连续刷新，5.814 s body_fall；D1/r39 修复命令传递后完成 8 s，身体高度保持约 0.286–0.290 m，却最终后移 12.45 mm，后半段四足共同承重，不能选择为正常行走版本。D1 的改善应写成“避免本次早倒、形成稳定驻足”，不能写成已经稳定行走。[实际阶段状态](../../../w51/phase.json)、[结果线独立原件审查](../results/review.md)

下一轮有明确、有限的机制推进依据：首先修正当前摆动段的几何接续；保留原绝对时钟、固定 apex/touchdown、原 5 mm 高度、原风险/J 和原接受条件。可以用两个并行 D8 比较“修正后只沿 S 搜索”与“同一修正下保留 B/S 两个独立方向”，而不是立即重开正式 A/B E30。旧 PD 承重偏置是否进一步阻碍卸载仍需区分，当前证据不支持同时硬改全部反馈或直接降低 R35 权重。

## 3. 实际实现与真实使用：不是只有配置标签

### 3.1 D8 与 command repair

D8 是真实正常 plant/Agent/RPC/query/hold 入口的 8 s 诊断阶段，有专门的 protocol 提前返回分支，`qualification_usable=false`。它没有通过墙钟 timeout 截断 E30，也不是训练时长改成 8 s。最终 phase 是 `paired_D8_ended_pending_scientific_selection`，不是 README 中残留的 running。

首个 D1 因 `userdata[78:84]` 没有填入 mission 世界速度，在 3.12 s 被作为技术无效尝试停止。原因是旧 runtime 只在可选 `r11_body_twist_reference` 存在时填写命令槽，但本轮未启用该成本。`463e91b` 让 W51 contract 也填入原 `mission.v/mission.w`；**修复没有启用额外 twist 成本**。D0 原进程连续保留，修后 D1 才是本报告的有效配对流。[runtime](../../../../../../../scripts/s1_go2_r11_runtime.py)、[phase](../../../w51/phase.json)

本线打开修后 D1 留存的全部 68 个事件 context，原生 `userdata[78:84]` 与同事件记录的世界命令最大差为 0；不是只接受“修复完成”的文字说明。

### 3.2 B/S/Q 的实现语义基本正确

每个 epoch 先按原 R35Freeze 和 nominal screening 得到完整 B。r39 的 S 复制 B 的 reference、K/H、feedback scale 和既有 delta，追加 `q_IK − q_B_joint`。一个有效 S 即使 J 高于 B 也可成为 Q，但不能因此被安装。导数与正 α 家族围绕 Q；接纳仍比较不可变的原 B 和全局 archive。

本线打开关键 B/S 对象逐数组检查：reference、K、H、Qu、Qxu、active、semantics、provenance 均保持一致；IK 增量相对于原 B rollout joint 的误差为 0；delta 合并最大差为浮点舍入量级。301 个记录中 Q 的完整内容身份全部等于 S。call 121/128 的安装 reference/K/H 对应各自正候选；call 216 的已安装完整策略身份等于其 S；call 231 与末次 call 421 的安装身份等于 B。

因此，现有证据不支持“生成 S 却没有真的用作 Q”“S 只比自身改善就绕过 B 安装”“IK 被直接覆盖成 projected action”这些接线错误。`ClearDelta()` 发生在将真实 Q rollout 的动作转为局部导数 nominal 之后，原动作已经包含 delta；不应把它单独判作丢失种子。

实现：[w51_seed.inc](../../../../../../../experiments/terrain_memory/w51_seed.inc)、[w51_native_source.py](../../../../../../../scripts/w51_native_source.py)、[r39 patch](../../../../../../../experiments/terrain_memory/s1-go2-r11-S5-r39.patch)。W50Transfer 中关于隐式 α=0 的旧注释仍写 construction base；r39 的真正接受底线由保留的全局 B/archive 实现，不应仅据陈旧注释判错。

### 3.3 世界锚和相位没有每次任意重置

Native 顺序是 FL/RL/FR/RR，日志足顺序是 FL/FR/RL/RR。Trot shifts 恰好都是 `[0,.5,.5,0]`，但 IK 与足数组仍在复算中显式换序。

301 个 active call 的 100 个足段身份中，同一 segment 的 anchor、touchdown 和 end 没有漂移，最大差为 0。相位按原 2 Hz 绝对时钟推进；stance anchor 在实际新 stance 段开始建立，当前 swing touchdown 在该段开始/接入时固定。当前异常不能归结为“每 20 ms 偷换落点/重置 gait clock”。

## 4. 已定位的具体错误：连续接续不等于可行足轨迹

### 4.1 当前公式为什么会向地下走

原种子把当前段的实际位置/速度连续地接到固定端点，再叠加原绝对 gait 高度并减去初值误差：

\[
z_S(t)=z_{end}+H_0(u)(z_{actual}-z_{end})+T H_1(u)\dot z_{actual}
+h_{gait}(t)-H_0(u)h_{gait}(t_0)-T H_1(u)\dot h_{gait}(t_0),
\]

其中 `H0=1−(10u³−15u⁴+6u⁵)`，`H1=u−6u³+8u⁴−3u⁵`，`u=(t−t0)/T`。公式确实精确匹配当前位置和速度，并在剩余段末端接回原 touchdown。**它没有任何不穿地或保留抬脚峰值的性质。** 当参考已在上升、真实足却仍在地面且速度接近 0，减去 `T H1·原参考速度` 会把后续目标压到地面以下；当原 apex 已过，当前位置误差校正还会把剩余原高度一起消掉。

这不是 IK 求解失败：全部 301 次 `S_valid=true`、`IK_failed_node=-1`，最大 IK 位置误差 `9.9994e−8 m`，远小于允许的 `1e−5 m`。IK 正确地解了错误目标。

### 4.2 全量数据，不是一个末帧推断

全部 301 份 IK 目标的世界 x 范围为 `[-0.230583, 0.306469] m`，在材料起点 0.8 m 之前。模型平面 z=0，原足半径 0.022 m。因此下表的“足底高度”就是 `target_geom_z−.022`，不是未观测材料表面或沉陷。

| 全量当前摆动段快照统计 | 数量/数值 |
|---|---:|
| 当前 swing 足 × replan 快照 | 650 |
| 已保存的剩余当前段目标节点全部不高于地面 | 360 |
| 最低保存目标节点比实际初始压入更深超过 1 µm | 362 |
| 有保存目标节点低于地面超过 1 mm | 96 |

这里的 650 是重规划时的足段快照，不是 650 次独立摆动，更不是物理失败次数。统计基于保存目标节点，不声称已求连续曲线极值或排除节点之间的微小抬高。负节点已经充分证明目标下穿，无需为强化措辞再开实验。1 µm 是区分当前实际几微米接触压入与人为继续下探的描述口径，不是新增运行资格阈值。

### 5.1 不能遗漏大 α 的向前候选

部分大 α 候选确实向前，不能写成“任何候选都不向前”。例如 call 220、α=.177828，0.35 s 前移 84.162 mm，但最低身体 z=.241775 m，各足最高 10.8–64.3 mm，J=.791964，而 B=.015326。call 231、α=1 前移 68.752 mm，但各足最高 107–208 mm，J=.813719。它们表现为明显偏离原低幅 gait 的激烈运动，尚无正常连续步态证据。把这些被拒候选强制安装无法由现有证据辩护。

### 5.2 旧 PD 偏置的证据与限度

S 确实保留了 B 的支持偏置。call 121 的 `S held action − q_IK`，四个 calf 的时域均值约 0.0984–0.0992 rad；在“关节恰位于 IK、速度为 0”的代数条件下，这对应约 5.91–5.95 N·m 的 PD 项。call 421 相同差值约 0.0883–0.1033 rad。实际 S 的足高误差则可达到约 5 mm，即目标完整摆动抬高而原生足仍贴地。

这些事实支持“站立承重偏置不能自动等同于 swing 合适的受力”的机制疑点；**没有做隔离偏置的原生对照，所以还不能断言去掉某个 bias 就会走好**。实际扭矩还取决于真实 q/v、反馈、投影和力矩限制。下一轮先修已确定的目标下穿，保留 PD60/5 和现有完整反馈；继续直接读 native S 的卸载/脚高。如果几何修正后仍不卸载，再进入相位承重分配/动力学参考问题，而不是本轮同时改全反馈。

为排除“其实是旧 feedback 或 QP 把 IK 全抹掉”的混淆，本线还对已保存的同节点策略做了纯数组分解：

\[
u_S-q_{IK}=[c_B(x_B)-q_B]+[c_B(x_S)-c_B(x_B)]+[u_S-c_S(x_S)].
\]

第一项是保留的 nominal PD 偏置，第二项是 S 状态改变产生的 B 反馈差，第三项是 clamp/QP 改写。call 121 的 calf 保留偏置均值为 .0984–.0992 rad，反馈差最大仅 `1.09e−6 rad`；call 421 的 calf 偏置为 .0879–.1029 rad，反馈差最大 .003466 rad。121/128/131/231/416/421 的第三项均不超过 `2.22e−16 rad`，说明这些 S 的几何失配不是被投影截掉。分解本身在保存节点闭合到浮点精度，但仍不能替代一次偏置改变的物理因果对照。

## 6. J 究竟在优化什么，为什么不能先盲调权重

当前 moving 目标没有启用额外 body twist 跟踪项。`StandLinearVelocity`、`StandAngularVelocity`、`StandFootPosition`、`StandFootVelocity` 是 Stand 语义，Trot 时不能把它们当作已经生效的速度跟踪或支撑足不滑约束。

Position 是 r26 的局部 head reference：每次重规划以实际 base x 为锚，根据原 mission 速度、cap、0.35 s horizon 和原 lead 构造前方参考，再加 head offset。任务层要到 3 m 不等于 residual 直接承受 3 m 误差。它奖励局部前移，但不会让静止成本随远端未完成距离无限累积。

Gait 仍主要是四足竖直高度误差：原 2 Hz、duty .45、5 mm C2；没有移动脚的世界 xy 落点 residual，也没有直接要求摆动足法向力为 0。单足漏掉 5 mm 峰值在 `weight=2, SmoothAbs p=.03` 下约为 .0008276。它对“钟相位正常但脚还承重”的区分能力有限。[原 task 基线与后续 r26 patch](../../../../../../../experiments/terrain_memory/s1-go2-r11-S5-r26.patch)、[r20 原高度曲线](../../../../../../../experiments/terrain_memory/s1-go2-r11-S5-r20.patch)

R35 的 InputReference 以**当前实际 incumbent 的 rollout**为共同输入参考，constant 分支保持原支持正则，不因 S 改变。它对探索有代价，确实值得审查，但本轮不能把所有问题归给它。

例如末 call 421 的 S 相对 B：

|---|---:|
| InputReference | +.001916710 |
| Position | +.001480050 |
| Effort | +.000983317 |

| Upright | +.000428677 |

纯代数扣去 InputReference 后，S 仍比 B 高约 .002821628，并且实际预测倒退 29.476 mm。26 个已阅 call 的 S 中，只有 call 128 和 416 属于“原本较差，单扣 InputReference 后变较好”的例子；二者也没有正常足腾空/换支撑。这个消项仅是对已有残差做的排序解释，不是新控制器运行结果，也不是重新优化的结果。

## 7. 参考为什么又过期：有效机制没有持续被接受

| D1 时段 | 调用数 | homotopy 安装 | 其他安装/保留 |
|---|---:|---:|---|
| Stand 至 2.000 s | 120 | 92 | 其余 bootstrap/nominal/保留 |
| 2.002–4.280 s | 115 | **2**：121@2.002、128@2.140 | S 直接安装 1 次：216@3.900；nominal 18 次；保留 94 次 |
| 4.300–8.000 s | 186 | **0** | 全部 incumbent retained |

301 个 moving S 全部作为 Q，299 次 J(S)>J(B)，2 次较低。最后一次新 reference/K/H 来自 call 128 的 `[2.14,2.49] s`。call 216 的 S 安装只是追加 delta；call 231@4.2 的 nominal 安装只是更换 feedback scale，并没有生成新 reference。到 8 s，策略 generation age 为 3.8 s，但 reference 尾部过期为 **5.51 s**，这两种年龄不能混淆。

结果线独立检查了每个实际 held 查询：D1 积分口径中 2,754/4,000 条已经越过末控制参考，首个为 2.492 s；D0 实际 2,907 条没有真正尾部过期。`reference_covers_query=false` 中还有 float32 query 比起点略早的情况，不能全部计作“参考过期”。[结果线复算](../results/analysis.json)

因此 W50 的参考生命周期机制确实实现了，W51 却因移动段缺少被接受的新完整反馈而重新陷入长期保留。这不等于应强制安装较差解来刷新年龄；应先修正候选的可行性和搜索范围。

## 8. D0 的对照：参考新鲜仍然可以倒

D0/r38 的原任务失败不能全归到 S，D0 没有 S。它在持续更新 reference 的条件下仍出现以下实测先后关系：

- 2.976 s 首次数值上的 PD 超界，也是首次 QP 修正；该次仅超界 `8.39e−7 N·m`，不能叫明显饱和。超过 .01 N·m 的首次时刻为 3.4614 s。
- 3.016 s 首次 raw target clamp，raw feedback `Kδx` 从早段小量跳到约 1.968 rad；2.002–2.976 s 的该量最大约 .030054 rad。
- 3.170 s 首次身体 z<.28 m，3.564 s 首次 z<.27 m；5.2304 s 首次非足 >1 N，5.814 s body_fall。
- 全程按原“超边界即计入”口径有 1,557/29,070 子步，其中超界超过 .01 N·m 的 996、超过 1 N·m 的 619；648 个 query 存在 raw actuator target clip。708 是包含 QP 的 before→after 总改写，不能误报为纯 raw clip。37.867 rad 的 feedback 极值发生在 4.05 s，是后期极值，不能当作首因。这些幅度分组只是解释浮点小量与明显动作异常的差别，不改原运行阈值。

D1 则无这些饱和/clip，raw feedback 最大约 .004046 rad，但稳定驻足。这个对照说明单独追求 reference 更新次数不能保证闭环稳定；同时也没有充分证据据一个反馈极值直接增设任意 K clip。短 horizon 的 native J 严格下降、一次反馈曲率有效与长时正常行走不是同一判断。[结果线事件/反馈原件分析](../results/review.md)

上述 PD 超界指由已发目标与真实 q/v 按 PD60/5 算出的**未限幅请求**；实际 `actuator_force` 仍在原力矩限幅内，不能写成电机实际突破了原硬上限。

## 9. 下一轮最小修法：固定事件时刻的有界曲线

### 9.1 修曲线本身，不能简单 clip

移除当前 `h_gait−H0·h0_ref−T H1·v0_ref` 的误差追赶构造。改用从真实当前高度/速度到**固定原绝对事件时刻**的分段五次曲线：

1. 原 swing 时长 `.275 s`，rise `.075 s`，descent `.20 s`。每足 `t_apex=t_liftoff+.075`、`t_touchdown=t_liftoff+.275` 都从原绝对相位得到并跨 replan 固定；最大高度仍 `.005 m`，原 touchdown xy 与 stance 世界锚不改。
2. 若当前仍在原 apex 之前，从真实 `(h0,v0)` 接到原 apex 的 `(.005,0)`，再接原下降段。可以用五次 Bézier 控制点
   `P0=h0, P1=h0+Tv0/5, P2=h0+2Tv0/5, P3=P4=P5=.005`，明确这是选取 seed 初始加速度 0、apex 加速度 0 的确定性构造；不新增高度/速度/phase 网格。
3. 若已过 apex，只在当前已经离地、可按原剩余时间下降的条件下，从当前高度/速度接固定 touchdown `(0,0)`；对应 `P3=P4=P5=0`。不补造新的 apex，不把剩余时间重新延长。若足仍落地而还需水平移动到原 touchdown，原抬脚事件已经错过，应明确记录 S 不可用，并由原 B 分支处理。
4. 可用控制点凸包的充分条件，必要时直接求曲线导数实根检查真实极值与单调段；不靠采样网格寻找一个“看上去没下穿”的曲线。不可行就报告具体足/相位/原时间，不退回旧的下穿 S。

这使曲线拼接处有 C2 性质，且不通过 `max(z,ground)` 引入折角。**真实初始足加速度未被当前入口提供**，所以不能写成已匹配真实位置/速度/加速度三者；`a_seed=0` 是明示的种子边界选择。当前实际穿入接触面的几微米必须保留为初始条件，不允许借所谓连续性主动继续下探数毫米。

还有一项必须诚实处理的数学边界：若 `h0≤0` 且真实 `v0<0`，精确保留速度与“后续一点也不比 h0 更低”无法同时满足。不能暗中把负速度清零，也不能加一个没有尺度的 `vz>=0` 硬门。应使用原几何/IK 数值精度解释接近舍入的小量，以完整曲线极值为依据；真正不相容的状态应显式不可用。已有原 IK 容差不是增加物理允许穿透的理由，更不能把它改成毫米级容差。

### 9.2 初始切换与 S 可用窗口必须写清

在 call 121@2.002，FL/RR 已经是 swing 的下降段：原 apex=1.9385，touchdown=2.1385；RL/FR 为 stance，其下一 swing=2.1135、apex=2.1885。因此上述诚实可行性处理会使最初 S 不可用，首个“当前摆动足全部仍在原 apex 前”的重规划窗口是 **call 128@2.14**。

在已经记录的 W51 旧轨上，301 个 moving call 只有 60 个满足“全部当前 swing 尚在 apex 前”；241 个至少有一脚已过 apex 而仍在地面。这个数组统计描述旧轨，不是预测修复后的可用率。一旦脚真正完成抬升，后 apex 的连续下降分支也可用。如果实现再粗暴要求实测 `vz>=0`，微小负数会把这 60 个机会压成 11 个，属于不合理的数值门槛，不应采用。

### 9.3 双线 D8 比直接正式 A/B 更有信息

建议两个并行新诊断臂，使用相同完整初态与 seed1，唯一比较差别写清：

| 臂 | 几何修正 | 搜索方向 | 接受基准 |
|---|---|---|---|
| D2 | 同一确定性修正 | S 有效时只沿 S；无效沿 B | 原 B 与全局 archive |
| D3 | 与 D2 完全相同 | S 有效时 B/S 各一个 first-valid backward 与原九个正 α；S 无效只沿 B | 同一原 B、同一 risk/J/roundoff |

D3 检验是否因唯一 S 线性化起点夺走了 B 的局部探索机会；它不会自动修正受力，也不保证比 D2 稳。D0 已经说明 B 方向本身可以失稳。两线均不得通过降低接纳要求、强制安装、换 seed 或改物理来制造优势。

最大常态完整 rollout 为 D2 **21**（freeze1+nominal10+S1+positive9），D3 **30**（再加 B 的 nine positives）；几何/IK 不可用而没有评分 S 时退回原单 B≤20，若已经消耗一次 S rollout 才判原生无效则为≤21。导数/FD、两次 backward、候选来源与真实工作量必须单列。B/S 每个方向的 immutable snapshot 与 worker 数据须隔离，不能让第二方向改写第一方向的 k/K/H/μ 或 R35 reference。全局 B 只建立一次，原 R35 reference 同 epoch 只冻结一次。

两条 D8 复用已完成 W51 作背景，不重复 D0/D1；第三线继续已有证据的代数/GPU 工作即可。先看修正后 S 的实际卸载、支撑交换、脚高/水平足速、身体姿态和前进是否成立，再决定是否固定同一个实现做正式 seed1/2 E30。完成 8 s、J 下降或者足端 IK 很准，都不足以直接进入完整任务资格判断。

## 10. 当前能排除与尚不能归因的边界

已有证据可以排除把本轮问题简单归结为“没有真跑 r39”“有效 D1 的世界命令仍全零”“301 次 IK 都没解出来”“世界锚每次重置”或者“只能靠强制刷新参考年龄”。有直接源码与全量原件支撑的首要修复是当前摆动高度的错误接续。

尚不能排除后续还需处理 PD 支撑偏置、接触力分配、局部搜索在接触切换处的导数质量、短 horizon 的闭环反馈问题以及目标对真实换支撑的约束不足。当前最合理的顺序是先修正已确定的几何错误，再由同对象 native rollout/真实 plant 的差别定位剩余问题；不能用增加论文式术语、更多资格门槛或单纯堆 GPU 显存来替代这个机制修复。
