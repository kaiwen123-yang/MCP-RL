# W41 CPU：从“能完成采样”推进到“能稳定完成材料任务”的文献机制审查

日期：2026-11-08。审查基线：`9cc42d5a9189a2bfd7e1e6cd99b9300045a16724`。范围：W41 两路 `S5-r30` 的控制机制与下一次真实 MPC+PPO 联合实验；不改动仍在运行的 GPU 作业。本文的论文事实来自原文/作者页面，项目事实来自仓库，迁移建议是待检验设计，不把论文成功当成本项目的根因证据。

## 本轮接触新证据更新：W42 先保持原生前向，只在反向使用平滑导数

**新原件改变了本轮实施优先级。** A635、B712/713 在同初态、近同动作的首个 2 ms 子步中，预测 ground Fz 约 0.007–0.013 N，而实际约 114–247 N；关节速度已经出现约 0.39–0.44 rad/s 差异，之后反馈项可被放大至约 1 rad。这里有先于后续大反馈的零阶状态转移/接触响应失配，不能只把末端现象解释为 K 太大或扭矩饱和。`MakeDifferentiable` 将 `solimp[0]` 置零是需要用同快照反事实核实的候选来源；这些局部记录尚未证明全部跌倒都由该项造成。

因此，**W42 首选机制是 native forward + 在原生 nominal 上作零阶锚定的 smooth Jacobian**。由实际 plant 契约生成 nominal、十个物理子步、候选成本和约束记录；平滑模型只提供优化导数。原生 MuJoCo 接触仍是本项目采用的接触模型，不能因引用下文硬接触论文就把它称为严格刚性互补模型，也不为追求这种称谓改动材料物理。此前“参考/步态代价冲突、多模式初值”的建议保留为：**修正前向后仍然欠推进时的后续分支**。

历史 r17 仅恢复 native geom/pair 的 d0，E30 在 15.36 s 非法接触；它早于 r26 的十子步执行、r28 和 r30。该结果不能证明单独恢复 d0 就足够稳定，也不能替代当前架构下的“前向与反向分离”实验。W42 不能把 r17 改一个编号再跑，也不将 clip K 作为本次接触失配的解释。

### 更新 A：HOUND CI-DDP / CI-FDDP，IJRR 2025

**已核原文机制。** §4、§5.2/5.3 保留硬接触前向，只在反向使用松弛互补梯度；§7.2.7 专门比较前向也松弛的版本，其非物理接触会增大计划—执行偏差。§6.3 的实际执行是前馈扭矩加 PD，期望关节状态来自优化轨迹；不能据此声称 relaxed Jacobian 得到的时变 K 已有稳定性证明。§8.1 还指出过强松弛可能使方向不再下降。

### 更新 B：DiffMJX / CFD，ICLR 2026，arXiv 2506.14186v2

**已核原文机制。** §4 式(4)以 straight-through estimation 保留原始前向值、替换反向导数，并明确在未被修改的前向轨迹上评价 surrogate 导数。这是 MuJoCo 系列中与 W42 分离设计更直接的依据。论文的 CFD、自动微分和自适应积分不等同于当前固定步长 C++ FD；它没有证明任意软化参数都适合控制。

[原文 §4 与附录 C/D](https://arxiv.org/html/2506.14186v2)；[ICLR 2026 正式会议记录](https://proceedings.iclr.cc/paper_files/paper/2026/hash/44039e59aaf6a41b16f1fc5b27bcd409-Abstract-Conference.html)；[作者项目](https://sites.google.com/view/diffmjx)。

**迁移边界。** W42 可先沿用已有 FD 和执行积分，只分离模型职责；不为引用该文而额外改成自适应积分、MJX 或 CFD。下面的 soft-to-soft FD 是本项目对该分离原则的实现设计，不是声称已经复现该论文。论文也讨论了 surrogate 梯度的非凸局限，因此“导数平滑”不等于“一定能离开四足驻留”。

### 更新 C：DiffContact，arXiv 2610.35852v2，2026-11-02 预印本

**已核原文机制。** 同 KAIST 方向的最新扩展保留硬接触前向，只松弛反向的完整摩擦互补关系，涉及 separation、clamping、sliding 及法向—切向耦合。§VIII 的比较固定前向、目标与初值；只松弛法向的 Signorini 方法仍可能让脚保持 clamped。抗拉恢复实验使用 joint PD，仍不是本项目 TV K 的稳定性证明。

[原文（重点 §IV–VI、§VIII、结论）](https://arxiv.org/html/2610.35852v2)；[作者项目](https://diffcontact.github.io/)；[版本与日期](https://arxiv.org/abs/2610.35852)。本次没有核验正式会议或期刊发表。

**迁移边界。** 该文支持后续检查足端卸载/滑移方向是否在导数中缺失；不是 W42 立即更换摩擦求解器的理由。其方法实验采用平地四个点足，任意形状碰撞、非点足和不平地面仍列为后续工作，不能直接覆盖我们的材料模型。作者抗扰指标不照搬为本项目收益；其 BPTT 策略训练也不是本项目 2 Hz cap PPO 的直接替代。

### W42 实现必须保留的边界

令 `F_native` 是实际执行契约下的单步/组合转移，`F_smooth` 是仅用于求导的模型。两者都从同一个原生 nominal 状态、相同因果动作与材料/参考数据出发：

- **零阶值归原生模型。** `xbar`、候选 rollout、实际 `(v,J)`、约束与部署所用参考都来自 `F_native`；求导副本的下一状态不能写回 nominal 或实际预测缓存。目标投影、PD、饱和及十个子步必须与执行契约相符。
- **FD 两侧必须使用相同求导模型。** 在欧氏坐标下，导数的示意是 `[F_smooth(x+eps,u)-F_smooth(x,u)]/eps`。禁止 `[F_smooth(x+eps,u)-F_native(x,u)]/eps`：后一式会把零阶接触偏差除以 eps，伪造巨大 A/B。零阶锚定可在局部切空间中理解为 `F_native(bar)+F_smooth(z)-F_smooth(bar)`，不是把未锚定的软模型下一状态充当真实 nominal。
- **四元数不能直接按数组相减。** 状态扰动、输出差分和反馈误差使用现有 MuJoCo 切空间工具及一致基准；上述加减式仅是欧氏/局部坐标示意。保持 r30 的固定 target、边界和组合导数定义，避免通过更换 FD 语义另造失配。
- **平滑导数给搜索方向，原生前向决定是否采用。** 候选要在同一实际反馈、投影、PD 链中评价。soft Jacobian 是有偏 surrogate，不应报告成真实 plant Jacobian；预测 dV 也不能替代原生 rollout 的实际改善。若之后另算 native tracking K，最终候选必须用实际部署的那个 K 重评，不能优化时一种反馈、部署时悄悄换另一种。
- **K 稳定性单独保留为未证明项。** 局部误差可分解为 `e_next ≈ (A_native+B_native K)e + r`，其中 `r=F_native(xbar,ubar)-xbar_next`。修正前向针对零阶残差 r；这不自动证明闭环矩阵或接触切换稳定。若 r 已明显缩小而反馈放大仍在，再用原生动态敏感性检查 tracking K，不能只把 K clip 小后宣称根因已解决。

同输入记录应同时保留首个 2 ms 和十子步的 ground force、速度/状态残差、计划/实际接触、Kdx、投影与饱和。其用途是辨认“前向偏差消失但仍不迈步”与“仍有响应失配”，不是新增纯 MPC 或刚地面准入流程；最终仍以真实联合训练及严格合法材料任务评价推进效果。

## 1. W41 进度与仍成立的观察

**当前首先修正前向接触响应与求导模型混用的风险；推进欠跟踪、参考/步态和接触局部最优在原生前向修正后继续检验。** 两路都完成了新的 2048 transitions / 8 updates，累计各 11665 / 45，说明这次采样、更新和退出链可以走完。但 130 个训练回合中，99 跌倒、19 材料域退出、9 非法接触，合计 127 次物理失败；其余 3 次为训练边界/会话截断，不能计作通行成功。结果级技术异常为 0，也不等于所有中间技术问题都已消失。

最终 E30 中，A 在 14.100 s 跌倒，最大 base x 约 0.692 m；B 在 28.408 s 跌倒，最大 base x 约 0.821 m。二者都没有到达远端，没有进入转身/返程阶段，合法材料往返仍为 0。全轮最远训练 base x 约 1.05 m，相对材料东界 2.2 m 仍有明显距离。A 评价中“base 尚未进入材料带”和“部分足端已加载材料”可以同时成立，不能将两个口径混写成从未材料加载。

源码明确给 PPO 的动作是 2 Hz 的单标量：`cap = 0.215 + 0.035*a`，范围 0.18–0.25 m/s。**该策略可以调速度上限，不能主动将上限降至零，也不能直接改变摆动/支撑相位、落足或载荷分配。** 四足长期接触、指令持续要求前进、实际不再推进时，继续输出另一个正速度上限未必能产生纠正动作。这是已确认的权限边界；“这正是全部失败的充分原因”尚未得到证明。

**原始窗口补充（与主审查同步）：** A/B 在材料接触前均出现四足长时间着地，命令约 0.22 / 0.208 m/s，而实际前进速度仅约 0.0145 / 0.0098 m/s；这些窗口的实时动作 QP 全部 inactive、投影没有改变动作、heading 正常。A 停在 C2 风险带附近，B 则远在其前方，因而风险 gate 不能单独解释共同停滞。在完成上述前向/反向分离后若仍欠推进，再依据位置/步态/effort 成本分解处理短视野接触过渡；不能据此先修一个尚未出现的航向或投影错误。训练中当前 PANN 特征仅 229/4096 非零；两次 E30 将当前特征清零后，即时 cap 差最大约 2e-6 m/s。这是局部输出敏感性结果，不是闭环 memory 消融，但当前没有闭环记忆收益证据。数值以本轮原始窗口审查最终汇总为准。

### 2.1 SNS-MPC：先查优化器到底在惩罚什么动作

**原文事实。** Fig. 17 给出了一个非常相关的失败：由 trot 代价构成的 standing 代价过度惩罚迈步、对姿态和高度约束不足，减速时不愿多迈补偿步；重新调代价后才稳定。论文也显示，一步误差较低的普通 MLP 不必然带来更好的梯度控制，平滑性和导数条件会影响闭环。[原文 Fig. 17 与模型/优化比较](https://arxiv.org/html/2601.12169v1)；[作者代码](https://github.com/generalroboticslab/SNS-MPC)。

**本项目迁移。** 这不是“照抄 SNS 网络”的理由，而是 W42 前向修正后仍有驻留时可检查的具体控制机制：在首次 command nonprogress、尚未严重倾斜的窗口，查看相位是否持续推进，计划中有没有摆动足、实际足是否离地，向前一步究竟增加了哪些代价。把基座高度/姿态/角动量和摆动足/落地速度/接触代价放在同一实际候选轨迹上解释。只看总 J 或最终饱和率，无法分辨“没有生成迈步”与“生成了迈步但执行失败”。

若修正原生前向后计划仍压制补偿步，后续变更才修正具体的参考或代价冲突，使低速前进时仍有可执行的支撑转换；若计划已经合理而实际始终四足着地，应转到执行响应/足端卸载，不能继续盲调 cost。`runtime.py` 已对 gait 参数进行实际读回，不应无证据地再宣布“gait 设置根本没有生效”。

**需要的权限。** 首先使用现有全身 MPC 的基座/足端参考与动作权限，不急于增加 PPO 维度；让控制层可以选择必要的补偿动作，同时保留材料边界、躯干接触和终止规则。论文不能证明本项目某个权重就是错的，也不能证明把全部接触统一平滑或重训动力学就会成功。

### 2.2 ROM-guided CI-MPC：全身接触优化也需要能引导迈步的参考

**原文事实。** 本文明确把接触隐式 MPC 的局部极小与调参困难列为问题，用 HLIP 生成 nominal gait，再由全身 CI-MPC 修改接触。§III-B 把质心/躯干/摆动足参考经 IK 嵌入全身状态；不是只给质心一个前进速度。**Fig. 5 还明确报告：小速度命令下，最低代价行为可能就是原地站立，且低速时 standing reference 占优。** 验证对象是 Achilles 人形机器人的仿真，不能当作 Go2 实机或材料验证。[原文 §III](https://arxiv.org/html/2502.15630v1)；[作者项目](https://rom-cimpc.github.io/)；[ICRA 2025 作者发表记录](https://saesteban.com/publications/)。

**本项目迁移。** 这比“换另一个 optimizer”更贴近当前四足驻留：给定正速度，并不保证局部轨迹优化愿意跨越卸载、离地、摆动和再落足的中间代价。需要让参考或初值本身含一个物理可执行的接触转换。如果当前 nominal 长期驻留，上一解平移再做小范围反馈/线搜索可能持续落在同一个解附近。这里的“可能”是本项目待检验假设，不能仅凭论文定案。

W42 前向修正后仍欠推进时，依据成本分解只选一项：**参考修正**，或**接触模式不同的少量结构化初值**。后一项可以保留旧 warm start，并增加一个与既有 gait 相位相容、确实带卸载/摆动动作的初值，经过同一真实动力学 rollout 与当前 `(v,J)` 规则选择；这是我们提出的最小多初值试验，不是论文原算法的逐项复现。只有生成不同控制/接触轨迹才叫增加候选；复制旧解再改名称没有作用。不同时改求解器、reward 和 PPO 维度，也不要为了容纳新初值放松材料/躯干约束。

**需要的权限与局限。** MPC 的参考/初始化层要能提出支撑转换，接触优化仍可修正它。无须立刻给高层 PPO 12 维关节动作。双足 HLIP 的支撑/碰撞假设不能直接用于 Go2；可借其“可行运动参考 + 全身修正”的组织方式。多初值也无法修复一个本身奖励驻留的目标函数，更不能保证跨越所有局部极小。尤其不能照搬其低速 standing/walking 混合阈值：本项目整个 cap 范围只有 0.18–0.25 m/s，如果这个区间落在驻留偏好的区间，混合参考反而可能固化当前问题。

### 2.3 ReCo：建模“实际能做到的响应”，恢复时不要追逐不可跟踪的参考

**原文事实。** ReCo 用 MPC 指挥低层 RL，和本项目的层次并不相同。其低层训练采用受速率限制的临界阻尼参考，处理步态相位条件响应，并在外力扰动及恢复区间暂停严格响应匹配；MPC 再辨识这个闭环。消融并非所有指标都改善：文中明确报告过位置误差降低但姿态误差增加、高度重复性未改善。[原文 §III-B/C、消融与结论](https://arxiv.org/pdf/2610.01612)。

**本项目迁移。** 将其原则用于我们的真实执行链：`MPC reference → TV feedback → target projection → PD → actuator saturation → contact → base motion`。在同一个真实联合回合中，按步态相位、四足接触、足端是否材料加载，记录参考速度/姿态与实际响应，并比较 20 ms、100 ms、350 ms 的响应。这里 350 ms 对应当前预测长度，前两个尺度用于分开单次执行与更慢的响应；它们是本项目提出的观察尺度，不是 ReCo 给我们的参数。

需要回答的是：基座参考继续向前，但实际接触系统是否进入了另一个局部状态？参考累积或相位继续推进后，是否让方向/高度跟踪与维持支撑互相冲突？若存在明确响应滞后，就在同一实际 rollout 中约束参考变化、维持可恢复的支撑转换；不能把任务完成的要求改为永远站住。仅在不同 integrator、MakeDifferentiable 或材料 proxy 上比较终点，不能自动认定为真实 plant 模型误差。

**需要的权限。** 参考生成层可以整形速度、基座姿态或步态参考，且 MPC 必须接收与实际执行一致的因果参考。是否让 PPO 主动选择暂停/恢复状态，属于之后的显式动作契约变更。ReCo 不提供可直接替换本项目的控制器，也不证明给现有预测器增加一个简单时间常数就足够。

### 2.4 Residual MPC：有纠偏权限的联合学习，与只学速度上限是两类实验

**原文事实。** 该论文在 MIT Humanoid 上将 MPC 与残差策略均以 100 Hz 放入训练和部署闭环，比较关节目标与扭矩混合。§IV-B 特别指出：网络输出为零，不必然意味着残差扭矩为零；若相对默认姿态生成 PD 扭矩，初始影响需要混合系数控制。[原文 §IV](https://arxiv.org/html/2510.12717v1)；[作者 T-RO 2026 条目](https://seungwoo-hong.github.io/publications/)；[IEEE 原始记录](https://ieeexplore.ieee.org/document/11644391)。

**本项目迁移。** 当前 PPO 不是这类残差控制。它在跌倒前不能直接减少某条腿的压载，也不能发出纠正落脚或身体姿态的动作。因此“再训练八次更新仍跌倒”不能直接推出 PPO 不适合 MPC；只能说明当前速度上限策略没有使这一固定底层闭环产生成功通行。

若原生前向修正及必要的后续参考/步态修正后，仍确认需要学习纠偏，建议另立阶段，只添加一种小权限：例如相位条件的落足偏移，或支撑卸载/摆动幅度修正。先由事件证据选择一类，不同时加落足、载荷、姿态、reward 和材料参数。新增 residual 的零输出应严格恢复旧控制；进入同一目标投影和真实 PD 链，不能在投影之后任意加一个扭矩再声称保留旧约束。如果其因果动作没有进入预测/候选评估，就应明确这是带未建模残差的试验，而非原 r30 的匹配预测器。

**需要的权限与边界。** 这是动作维度/执行语义变化，必须标为新阶段，不能把旧 actor 的 cap 输出直接重解释。即使仅把区间从 0.18–0.25 改为 0–0.25，`a=0` 的含义也从 0.215 变为 0.125 m/s，不是无损续训。允许停车只是新能力之一，不能代替合法出带、等待、返回的科学目标。MIT Humanoid 的机器人、接触和任务均不同，论文没有验证 Go2 的湿草、沙、雪材料或 PANN 记忆收益。

## 3. 下一次最小真实联合实验

### 第一优先：W42 原生前向与零阶锚定的平滑导数

1. 在已采集的同输入首子步与十子步证据上核实原生前向的零阶残差，实施顶部所述模型职责分离、soft-to-soft FD 和切空间差分。该分析是本轮结果审阅和实现核查的一部分，不新建纯 MPC、刚地面或 smoke 准入关卡。不得将局部前向失配直接升级为全部跌倒的唯一根因。
2. W42 只推进上述前向/反向分离机制。保留现有材料物理、PANN、PPO cap、reward、域边界、非法接触和合法路线口径；不同时引入参考调权、多初值、residual、动作维度变化或新的接触求解器。候选的最终判断使用原生执行链，不能用 surrogate 的预测收益充当实际收益。
3. 继续真实 MPC+PPO 采样/更新，采用现有的一块 2048 transitions / 8 updates 作为本轮预声明训练量，而不是设置后台完成时间。当前工程推进默认两路各继承自身 W41 父点，同一机制在两个续训状态上复核，不额外重跑已完成 r30。未来若另立严格因果对照，则需要预先声明同父 checkpoint、同评价条件的分支关系，完整继承 actor、critic、optimizer、normalization 与 RNG；这不是当前已完成的对照。
4. 现有 W41 A/B 是共同历史祖先上的不同工程续训流。若选择各自父 checkpoint 同时推进，必须分别报告相对各自基线的结果；不能把它们当作完全匹配的单变量对照，或声称两个从零独立训练 seed。可在后续一块中对第二父状态复核同一修正。
5. 先报告原生前向的接触力/速度残差、Kdx 与实际轨迹是否对齐，再比较首次 nonprogress 的发生时间/持续时间、实际摆动/触地转换、基座姿态先于饱和还是后于饱和、首次材料加载与真正东向出带。训练和最终评估继续严格报告合法出带/等待/返程/往返。少跌倒却停在原地，或拖得更久仍不过带，不构成主要目标改善。

### 后续分支：原生前向对齐后仍欠推进，再处理参考或接触局部最优

若首子步及十子步的零阶响应已对齐，而真实联合回合仍出现四足驻留，才回到 §2.1–2.2 的代价/接触模式分析。依据实际成本分解，在参考修正与少量结构化初值中只选一种；不把两者与 W42 首要修正捆在一起。这样可以区分“预测的支撑根本没有对应实际执行”与“模型已经可信，但优化目标或局部解偏爱站住”。

### 后续分支：只有问题确实超出 cap 权限时，再给一类残差动作

如果修正使底层可以持续推进，但在材料变化处仍需要状态相关补偿，就优先采用 Residual MPC 的“真实控制器在训练环内 + 零残差保持旧行为”，给 PPO 一类与事件对应的接触/姿态权限。不要一次将当前层次改成高维直接扭矩策略；也不要把提高频率本身当成稳定性证明。具体频率、残差限幅和观测应由本项目响应时间及控制预算决定，不能照搬论文 100 Hz。

两路 CPU 的 workers 依实际空闲 CPU 与仍在跑的 GPU 主机负载声明，Torch/BLAS 单线程，具体分配以 W42 计划为准；文献没有给出在 25 核主机上再开第三组 12 workers 的理由。GPU 支线保持运行，不因本次 CPU 机制审查而重启或改配。

## 4. 与长期科学目标的关系

当前证据支持“工程联合训练已经能够完成，但闭环材料任务仍未达到可重复成功”。先让稳定推进、材料出带和完整往返成为真实可观察结果，再检验 PANN 的历史记忆是否改善材料适应与再次经过的表现，才有可解释的消融基础。上述论文能帮助决定模型职责、控制设计和学习权限；没有任何一篇替我们证明 PANN 因果收益、TM02 接触参数正确、或 r30 已具备全局稳定性。

**本轮文献给出的具体推进顺序：先以原生前向和零阶锚定的平滑导数修正模型职责，在真实联合训练中测量接触/闭环响应；若对齐后仍欠推进，再依据成本分解选择参考修正或结构化初值之一；确有需要时才扩展一种纠偏动作权限。** 不扩大无关论文清单，不将恢复到站立偷换成通过材料，不用新的准入流程替代实际实验。
