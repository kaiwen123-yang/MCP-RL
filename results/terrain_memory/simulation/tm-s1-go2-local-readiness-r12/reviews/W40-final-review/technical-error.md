## 3. 新根因：把最终允许误差误当作自由面已被最小化

需要对上一轮修复的边界说清楚：**qp1 新增的工作集 refinement 有一个数值逻辑缺陷。** 上一轮两例故障和相邻九例查询没有触发它；A314 提供了一个新的真实反例。

qp1 在 `max(abs(g_F)) <= gradient_tol` 时认为当前自由面 F 已经最小化，可以释放错误乘子的活跃边界。这里的 `gradient_tol` 实际来自最终 KKT 证书：

`gradient_tol = 1e-7 × max(1, max_i Σ_j |H_ij c_j|)`。

该容差适合回答“整个候选解是否达到既定精度”，却不足以回答“当前自由面已经求完，可以安全决定下一个工作集”。病态且强耦合的 H 会将小自由梯度放大为明显的自由面位移，并改变活跃乘子的符号。

A314 的实际状态直接给出完整循环证据：

1. 容差为 **0.00720090199**，自由轴 `[2,4,5,6,8,11]` 的最大梯度为 **0.00641401446**，qp1 因而跳过当前自由面的 Newton 求解。
2. 轴 3 位于上界 1.0472 rad，梯度为 **+0.0969351882**，属于错误符号的上界乘子，qp1 将它释放。
3. 在扩大的自由面上，实际 MuJoCo Cholesky 解给出轴 3 的 Newton 方向 **+0.02208530123 rad**，朝上界之外，而非回到区间内部。
4. 它已经恰在上界，因此最大可行步长 **alpha = 0**；同一轴立即再次进入活跃集，位置不变。下一次又满足步骤 1，重复释放和锁回，直至 608 次上限。

数学上，释放一个边界轴 j 后，其 Newton 步满足

`p_j = -(g_j - H_jF H_FF⁻¹ g_F) / (H_jj - H_jF H_FF⁻¹ H_Fj)`。

若当前自由面确已最小化，`g_F≈0`，正定 Schur 补使错误符号乘子产生回到可行域的方向。qp1 提前释放时，`H_jF H_FF⁻¹ g_F` 不可忽略，方向便可能相反。本例无需推测接触参数或再运行物理即可确认。

所以增加迭代上限只会延后相同报错；放宽 KKT 阈值、直接返回逐轴 clip 或忽略异常则改变了验收或控制定义，都不是此次修复。

### 数值和退化边界复核

- 完整 Newton 步恰好落在边界时，该点仍是旧面的驻点，限制到新面后其自由梯度仍满足同一驻点条件；下一轮先做完整证书再考虑释放。
- 零步或部分步不再设置 `face_minimized`。相等界/恢复轴保持固定，不能被错误乘子释放。
- 浮点求解无法达到原证书时，仍明确返回 `stationary_precision_limit`、非正定/非有限或迭代失败；没有以“跑满次数”默认成功。
- 原 4n²+32 是数值算法的有限保护，不是用户取消的后台实验墙钟期限。本次不扩大它。
- 十二个真实记录的回放足以验证本次具体修复及已有回归样本，不能证明对任意未来 SPD 条件数都无失败，更不能当作机器人长期稳定证明。
