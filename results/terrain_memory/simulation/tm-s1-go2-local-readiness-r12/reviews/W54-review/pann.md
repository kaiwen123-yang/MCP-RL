# W55 材料/PANN 独立审计（截至 W54）

审计仓库：`1ae25272c86f551f8c6b3a65073bc05b24e3d8f6`。本文只涉及材料施力、PANN、材料观测、PPO 的 cap 接口以及对应证据；未执行机器人动力学、MPC rollout、训练或修改机器人控制/材料实现。原始 W54 记录取自已发布 release，所有实际提取成员逐个与发布 sources.json 的 SHA256、长度匹配；这是选择提取成员核验，不是未下载 native 二进制或整个 ZIP 压缩包的哈希核验。本次额外从历史 release 提取了当前 PANN 权重和它的真实 B 组训练数据，并分别核对 SHA256。

## 1. 对“PANN 出问题／参数锁定过早”的直接结论

当前证据支持进一步审计材料训练与接触加载的适用域，但**不支持把 W54 的普遍不稳定直接归因于 PANN 权重过早冻结**。理由不是“以前已经验证过”，而是当前代码和九条原始动作依赖记录共同限定了它的作用路径：

1. 机器人脚下实际施力是解析的 `ReferenceColumns`。`JointMaterial` 构建 `Ground` 时没有传入 PANN 权重；当前 PANN 不生成真实 plant 力。
2. PANN 的网络权重冻结，但世界地块的 `e/q` 内态没有冻结。每次新任务从 virgin 状态开始，任务中每 2 ms 依据真实可见足端边界独立更新，跨脚、释放和重访保留同一世界地块的历史。
3. PANN 输出四脚 × 三个时间点（2/200/500 ms）的“假定从现在起零载荷”恢复量，作为 PPO 最后 12 个输入通道；PPO 仅以 2 Hz 输出 `.18–.25 m/s` 的单一速度 cap。它没有直接修正每 2 ms 的支撑力和落足力矩。
4. W54 九条原始 `pann-action-dependence.json` 显示：把当下最后 12 个 PANN 通道置零，五条没有材料加载的 F 任务输出完全不变；有材料加载的四条最大 cap 差只有 `3.49e-6–1.39e-5 m/s`。这不是完整闭环消融，却直接说明：这次运行中，当前恢复特征经“当前 actor → 当前 cap”的即时影响极弱。
5. 上述证据不能排除冻结 PPO 历史训练已经吸收了有偏材料特征，也不能排除更换 F 底层之后，旧 actor 的动作—回报关系和观测分布发生改变。应分别验证这些路径，不能把“当下特征效应小”改写成“PANN 与整个学习过程绝无关系”。

当前最优先是修正已定位的低层执行/运动学问题；材料线应并行做实载路径审计。只有量化发现冻结材料模型在相关路径上确实有明显、决策相关误差，再做定向重训练和独立版本评估；不应先解冻全部参数再观察任务是否偶然好转。

## 4. 历史工作量与验证范围：不是只训了一次，但也不是全域有效

第三轮 memory study 保存了 60 个模型（10 复用、50 新训练），每个 20000 次更新；B 组有 1000 条完整随机历史，每条 100 个增量。最终 12 个选中模型在 600 个物理条件、700 条完整参考历史上共完成 8400 次模型历史积分，保存的最终失败数为 0。这些是材料积分与拟合证据，并不是 Go2 完整任务通过证据。

当前 B ideal 在历史最终表 `final/family-model-summary.csv` 中：F1 原始随机路径的平均/最坏应力 RMSE 为 `.0473931/.1575173 MPa`；F2 幅值/速率组合为 `.0471949/.2843662 MPa`；F3 应变保持为 `.0719555/1.1947611 MPa`，最坏法向分量 RMSE `1.6896474 MPa`。F4–F6 应力控制历史的最坏整体应变 RMSE 分别约 `1.5483e-5、1.0820e-5、1.3933e-5`。因此仍有快速全幅随机路径、最大体积应变保持的误差，不能只引用较好的 F4–F6。

训练中用辅助 LSTM 推断隐变量并与势函数共同优化；部署时不运行这个 LSTM，而是由冻结势函数做隐式积分。因此“训练拟合误差低”和“部署自由积分误差低”本来就是两个验证对象，后者应直接在实载历史上检查。

历史材料研究本身明确没有验证：实际脚接触面积/厚度的力—位移映射、未知初始内态/未知参数、真实传感器噪声、真实地形以及机器人 MPC/RL 闭环收益。它提供冻结 ideal 模型进入下一阶段的依据，不是这些后续假设已经成立的证明。

## 6. 真实 plant、observer、candidate 的职责不同

真实 plant：每 `.0002 s` 用真实 foot-bottom 的法向位移除以 `H=.05`，并解 lateral stress=0 的轴对称混合边界。自由地块零应力恢复，接触满足单边压缩。法向压力 `-sigma11 * 1e6 * gamma`，再乘精确重叠面积成牛顿力。两个脚印覆盖同一地块时较低脚拥有该地块，力不重复计数；材料越域的候选步在 `mj_applyFT` 前停止。

还应限定模型物理范围：当前是法向轴对称独立柱，材料不积分脚底摩擦引起的剪切历史；切向力另由 `-.5*N*v_xy/sqrt(|v_xy|²+.01²)` 给出。全张量材料训练包含剪切，不等于此接触桥接已实现三维地面剪切变形。

Observer：每 `.002 s` 以最新观测足端边界推进自己独立的 learned `e/q`；这不是使用解析 plant q/e 校正。2 ms 窗口内的真实 0.2 ms 激活/释放可能被跳过，是公开配置中的已知近似。它查询未来脚印上的零载恢复，不预测候选 GRF 下的完整加载—卸载轨迹。

N r48 候选模型：`experiments/terrain_memory/w54_e_core_r48.h`、`w54_e_native_r48.h` 的材料规则是已知未变形表面上界、gap/vz/当前状态的执行修正和 `−.001m` 脚底域代理；没有携带 PANN e/q。它能约束脚的局部入地代理，不等于保证 body height 或接触可支撑性。

F r52：`scripts/s1_w54_f_r52_backend.py` 明确使用测量力、局部因果刚度锚和当前法向速度；声明没有 future material state propagation。PANN 的恢复状态不直接进入其候选支撑力预测，仍只有上层 cap 通道。

因此现在不能描述成“PANN 已准确进入 MPC 的每个候选，所以剩下只是把权重练好”。当前实际架构中，这种候选材料传播还没有实现。

## 8. 接触桥接确实值得独立检查，但没有证据说单位写错了

当前源码由 MPa 乘 `1e6` 成 Pa，再乘 `gamma=.025` 和实际面积成 N；位移除 `.05 m` 成无量纲应变。面积、厚度、单位在这一调用链中一致。`e22=e33`、侧向自由的精确各向同性子空间不是把 3D 任意缩成单轴固定横向应变。

该桥接是独立柱状材料的合成测试床，未标定为草、沙、泥等真实地面。根据配置解析计算，平衡 Young 模量为 750 MPa，瞬时 Young 模量为 2454.545 MPa，折算整脚局部刚度分别 375000、1227272.727 N/m。约 15.2064 kg 的机器四脚/两脚静支撑，平衡压入约 `.09945/.19890 mm`；瞬时约 `.03039/.06077 mm`。所以 1 mm 行程并非连静态体重都支撑不了，但它要求非常好的冲击和接触控制。不能把这组线性局部数值当成动态非线性可行性的证明。

S0 曾验证的是支架支持的力控压头、相对温和的下压路径，不能以 S0 的通过自动推出自由机身的步态稳定。硬地—软区完全脚印进入后切换、移动脚印激活全新世界柱、单柱拥有整个面积块的位移等离散桥接也会产生变化；这些需要用实际事件、速度和能量对齐分析，而不是先把 PANN 权重解冻。

## 9. 可以立即做的等价效率改进

F r50 的 15000 次 observer 更新、60 次 query 中，真实和 observer 世界地块数始终为 0，query 却花了 `57.7141493 s`（含首次编译 `8.4389 s`）。原因是未来查询脚印进入材料地图，私有副本创建 virgin 地块并做 250 次零载积分，即使没有任何材料历史。

势函数零应变/零速率校正使 virgin `e=q=0` 在零载下保持为零。可对**查询并集内每个地块的 e、q 都严格为零**的情形直接返回零恢复量，同时保留 query mask、调用计数、时序和归一化。不要仅凭“现在没有接触”或“当前 stress=0”缓存：卸载后仍有 q 历史时会有恢复，必须照常传播。若还做一般缓存，键至少包括权重 SHA、地块状态版本、query area 和 horizon；先用当前权重零状态输出检查数值等价。

本次已直接计算当前真实权重的零状态本构导数：最大残差 `1.8189894e-12 MPa`，低于线上 Newton 不更新状态的 `1e-8 MPa` 门限，因而在同一数值规则下 `e=q=0` 保持为零，恢复输出为零。该检查保存在 `pann-virgin-cache-check.json`。

这是减少无信息计算的工程改进，不是已经证明会修复稳定性的问题。用户的 96 GB 显存也不意味着把大量已知零状态重复积分是有效并行。

## 10. 本次已经完成的实载自由积分，不再只停留在下一轮建议

### 10.3 采样误差与本构误差的分拆

保持解析材料完全相同，仅把真实 .2 ms 边界换成 observer 的 2 ms 端点边界，F52/N48 的最大瞬时地块力差分别达到 **7.47165 N / 45.26916 N**；应力最大差分别 `.750840 / 5.928930 MPa`，大于相同 dt 下 PANN 对解析材料的应力差。这包括 2 ms 窗口内边界变化、激活/释放遗漏、端点时钟和积分 dt 的共同影响，不是纯 dt 收敛试验，也不是实际控制 force-error 指标。

对卸载恢复，参考 2 ms 对 .2 ms 的最大位移差在 N48 六格中约 2.753 µm，模型恢复误差某些格反而更大。因此不能说“所有材料误差都由采样导致”。合理的结论是：**当前冲击峰值估计更需要处理端点/采样一致性；高速加载后的自由恢复仍存在需要定向校准的本构误差；这两项都不能替代已有低层稳定性根因的修复。**

当前 PANN 力预测并不直接进入 plant 或 MPC 候选，而上述真实 actor 的即时 cap 效应只有几微米/秒至十余微米/秒，所以这些恢复误差目前没有建立“导致整机反复摔倒”的因果链。将来如果把 PANN 真正用于候选支撑/恢复规划，这个误差及其不确定性需要纳入设计。

### 10.4 CPU 复现过程的技术边界

最初的 CPU 长 scan 和本次离线异构 8 列批调度在 N48 约 7.312 s 的候选加载调用出现计算阻塞；没有输出 NaN 或残差失败，不能把它计作本构失效。保留同一输入后，原 `LearnedColumns` 源码只将设备切为 CPU、逐地块 batch=1 调用，新加载格在原容差下返回 `sigma11=-4.493118614 MPa`、残差 `4.2388e-11 MPa`；其它同刻地块也收敛。随后按独立柱逐格调度完整跑完 N48 两种时钟，约 73.1 s。未改变本构参数、归一化、Newton 迭代/回溯上限或容差，也没有设后台自动结束时间。

因此本次结果是冻结势函数在指定实际路径上的有效材料回放；不是 GPU 整批 kernel 的性能验收，更不能从 CPU 批处理技术问题推断线上 GPU 材料错误。若 W55 需要全网格高吞吐审计，仍应在实际 GPU 环境复核批处理调用。

文件：`pann-replay.py`（支持 `--repo/--originals/--weights/--output`，可选保存数组）、`pann-replay-short.json`、`pann-replay-summary.json`、九地块 `pann-replay-cells.csv`。大训练原件继续使用原 release，不需要另行归档到用户电脑。

## 11. 对 W55 第三条并行线的具体建议

已有证据足以让三条线各司其职：低层先修已被定位的执行/运动学错误；任务验证维持同一个解析 plant 和原 E30；材料线做部署时钟一致性与短时加载—恢复的定向改进。无需让材料线等待所有机器人实验完成，也无需先把 PANN/PPO/plant 全部解冻。

材料线现在可以围绕已测出的 N48 恢复峰尺度约 19–22% 偏差，准备短时加载、卸载、重复脉冲与跨足时间间隔的数据族，比较冻结 B ideal、仅改 observer 采样、定向再训练候选三者。训练仍以可用边界/应力观测及自由积分损失为依据，参考 q/e 可以用于离线误差分析，不能作为在线控制输入；合成材料监督应明确标注，不冒充真实地面测量。

划分保留集时不能只按邻近世界格：F52 (41,4)/(42,4) 有相同法向应变历史，只是面积不同，单按 world key 拆分会泄漏同一脚加载路径。应按完整 episode/脚加载事件族/相似完整历史分组，保持真正独立的加载与恢复条件。当前被审计的 N48/F52 应保留为已知诊断集，另外设置未看过的路径条件，避免在同一九格上反复调参然后宣布泛化。

W54 没有成功返程，目前没有可声称“真实返程”的新数据。真实返程覆盖要等稳定任务产生；可先使用明确标注的合成重访/延迟恢复数据，不能把它计作原任务完成。

新模型是否值得上线，应同时报告加载应力、峰值/积分力、恢复绝对误差与相对峰尺度误差、激活/释放一致性、实际 actor/candidate 的决策敏感性以及旧 F1–F6 检查。针对恢复误差的小批量 GPU 学习有实际理由，但它承担材料精度与后续研究准备，不能被描述成已经找到这次反复摔倒的主要解法。
