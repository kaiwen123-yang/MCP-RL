# W50 控制实现、候选原件与下一步可识别性审查

审查结果基点：`09bd55e0cb70244938ad82db7dd202a31ac70f77`。本文件是对已完成 W50 的只读审查，不是新实验结果。没有启动 MuJoCo 模型、native solve、动力学 FD、plant/predictor 积分或 PPO。

## 1. 结论与证据范围

**W50 修复了一个真实的反馈参考生命周期问题，但没有证明机器人已形成正常步态，也没有取得进入完整原评价的实质早期改善。** 三个保存问题有真实严格成本下降，两个早期问题的赢家依然在预测内坍低、后退。另一个问题保留旧 nominal。两条短部署存在 shared-library ABI 错误，不能用其力、力矩或物理变化证明 native 等价或恢复成功。与此同时，W50 没有测试从正常初始化开始持续采用 r38，因此它的有限负结果不能否定“从起步即刷新可以预防失效”。

审查包含当前 r38 正式 patch、生成器、完整策略序列化与控制查询路径、r37 对照、原比较器、当前 gait/cost 和 r26 reference 语义、W50 计划与 task A/B/部署记录。已实际读取 Release 解压出的四个问题的 `input.json`、baseline/backward/direction/raw-centers、76 个完整候选对象与 76 条原始候选轨迹，独立重算全部 36 个正候选的完整 J 分项、运动与足部摘要，而非仅接受 `policy-construction.json` 内的布尔断言。

可复算产物：[recompute.py](recompute.py)、[analysis.json](analysis.json)。脚本只使用 NumPy 与原始数组；不 import MuJoCo。对 231 个 W49 历史事件策略的全量生命周期结论来自已执行的 [task-a.json](../../../w50/task-a.json)，本控制复算没有声称重新打开全部 231 个历史对象。四个有限问题的原始对象则已重新读取。

## 3. 已确认的旧问题：时钟在走，反馈参考未滚动，真实换支撑未形成

### 3.1 参考冻结已经由实测支持

task A 检查了两流共 3,042 个调用/边界、30,002 条 held 查询、300,000 条物理子步，以及保留的 231 个事件完整策略。各流保留对象中的 reference states/actions/times、K/H 都仍等于最初有效 Stand bootstrap 的数组；reference 范围为 `[0, 0.3499999999999941]`。

每流 15,001 个真实 held 查询中有 14,825 个越过 reference 末端，即 **98.8267%**。越界查询实际落在 `[174,174]` 的末控制节点；首次越界约 0.352 s，30 s 末端超过 reference 约 29.65 s。安装 plan ID 递增并不能证明 K/H 或 reference 已更新。W49 中原先只能由源码推断的冻结，现在有 task A 全量记录支撑。

### 3.2 Trot 的相位推进正常，但目标摆动大部分时间仍在承重

实际首次 Trot 为 call 121、`t=2.0019999999998124 s`。private gait 为 Trot，phase velocity 为 `12.566370614359172 rad/s`，对应原 2 Hz；phase origin 保持正确，后续时间推进。没有发现“配置写 Trot，实际一直执行 Stand”或 gait clock 被每次重置的证据。

从 2.002 到 4.30 s、首次明显坍低之前，按记录的 FL/FR/RL/RR 顺序：

| 真实诊断 | A | B |
|---|---:|---:|
| 目标摆动时足仍 >1 N 受载 | 88.09%–94.11% | 87.81%–93.53% |
| 四足同时 >1 N 受载 | 85.7180% | 86.7363% |
| 真实 PD 请求饱和占比 | 0 | 0 |
| 2.298 s 内前进 | 0.061337 m | 0.054970 m |
| 同窗口平均前进速度 | 0.02669 m/s | 0.02392 m/s |
| 高度目标 RMSE | 约 2.22–2.33 mm | 约 2.22–2.32 mm |

这些比例不是新增资格阈值，>1 N 是已声明的分析定义。它们说明“几毫米高度残差不大”和“真正卸载、摆动、落足、承重交换成立”是两件事。目标 gait phase 正确也不代表物理 gait 已成立。非足受载在随后窗口出现，符合视频中的下蹲、顶起和低伏挪动，且 A 根本没有进入材料；材料模型或 PANN 不足以单独解释最初失效。

四个 W50 问题的实际初始状态应分开读：A237@4.32 s 的 z 为 0.290605 m，B236@4.30 s 为 0.267324 m；它们不是都已贴地。但它们已走过从 Trot 切换开始约 2.3 s、约 4.6 周期的换支撑失败。A328@6.14 s 为 0.141877 m，B625@12.08 s 为 0.131105 m，才是明确的低位恢复问题。

## 4. 四个有限问题：J 下降是真的，正常行走改善没有成立

以下数值由原候选 residual/state 数组重新计算；J 是同 epoch native 完整成本。位移为各自 0.35 s 预测起终点差，不是随后持续重规划的 plant 位移。

| 问题 | B 的 J → 赢家 J | 选中 α | 最低 z，B → 赢家 (m) | 前进位移，B → 赢家 (m) |
|---|---:|---:|---:|---:|
| A237 | 2.481990810 → 2.448853506 | 0.0316228 | 0.153080287 → 0.153228868 | −0.004296775 → −0.018140685 |
| B236 | 2.871753627 → 2.871425118 | 0.0133352 | 0.140918898 → 0.140935246 | −0.018832771 → −0.019024125 |
| A328 | 7.249398635 → 7.096721999 | 0.0749894 | 0.137754981 → 0.141382837 | −0.000248406 → −0.023342556 |
| B625 | 8.109798457 → 保留 nominal_8 | 无 | 0.130552658 | −0.001585485 |

严格改善数依次为 **4/2/4/0**。A237 的最低高度只改善 0.1486 mm，却多后退 13.8439 mm；B236 最低高度改善 0.01635 mm，多后退 0.1914 mm。A328 有更大的低位高度恢复，但仍多后退 23.0942 mm。因此 `finite_negative_no_substantive_early_support_or_forward_progress` 符合所见，不能把 10 个严格改善改写成步态已经解决。

成本变化解释了“为何下降却不走好”。A237 的 MaterialSupportHeight 降低 0.099491，而 Effort 增加 0.037835、InputReference 增加 0.031650，Gait 也略升；净 J 下降 0.033137。A328 的支撑高度项降低 0.323082，抵消 effort/input 增加后 J 降低 0.152677。原优化器确实抓到了当前目标下可评分的改进；这些改进尚不等于站高、前进与正常换支撑同时成立。

### 不能遗漏被拒绝的向前候选

仅看赢家会误说“整个候选族从未产生前进”。原 76 条记录证明这不成立：

- A237，α=0.421697：前进 17.506 mm、最低 z=0.153064 m，但 J=2.649958 高于 B 的 2.481991。
- A237，α=1：前进 35.626 mm，最低 z=0.148926 m，J=2.843138；trunk risk 为 0 也不能把坍低称作正常步态。
- B236，α=1：前进 25.942 mm，最低 z=0.138244 m，J=3.396530；各足最大间隙约 58–93 mm，远高于原 5 mm 参考，同时身体仍坍低。
- A328、B625 的部分大 α 也有正位移，但伴随更低姿态、非零 trunk risk 或很高的 impact cost。

因此，现有证据既不能证明“根本没有任何向前候选”，也不能证明“原目标错拒了正常步态”。后续应先产生具有可解释换支撑、落点与身体前进关系的运动候选，再判断原 J 对其怎样排序。

## 5. r38 数学与实现核查：未发现能解释坍低的 rebase 接线错误

正式实现见 [`scripts/w50_native_source.py`](../../../../../../../scripts/w50_native_source.py) 第 124–269 行及 [`S5-r38.patch`](../../../../../../../experiments/terrain_memory/s1-go2-r11-S5-r38.patch)。关键对象语义为：

\[
b_i=c_B(\bar x_i,t_i),\qquad L_i=\partial_\xi c_B(\bar x_i\oplus\xi,t_i)|_0,
\]

\[
u_{\alpha,i}=b_i+\alpha k_{N,i},\quad
K_{\alpha,i}=(1-\alpha)L_i+\alpha K_{N,i},\quad
H_{\alpha,i}=(1-\alpha)H_B(t_i)+\alpha H_{N,i}.
\]

`c_B` 包含已安装 feedback scale 和旧 delta，并在 clamp/QP 之前获取。`L_i` 是当前 MuJoCo tangent 坐标中的 raw map Jacobian，已吸收旧 scale。候选 reference 为本次 B 的真实预测轨迹；新 scale=1，delta 清空。k/K/H/μ/active 从同一次首个有效 backward 捕获，四例均为 μ=1、rate=1、attempt=1。未发现把首 k 与末 μ 拼接、重复乘 alpha/scale，或把已投影 action 当作 raw center 的错误。

独立数组复算结果：

| 复算项目 | 最大误差或结果 |
|---|---:|
| 独立四元数/切空间公式求 raw center | 4.44×10⁻¹⁶ rad |
| 独立 tangent central raw-map Jacobian 对照保存 L | 2.22×10⁻¹⁰ |
| 36 候选 K/H 混合公式 | 精确相同 |
| 前馈减法核对 | ≤2.22×10⁻¹⁶ rad 的算术消去误差 |
| reference state/time、Qu/Qxu/active 来源 | 全部吻合 |
| 最后 K/H 行重复最后控制行 | 全部吻合 |
| 实际安装对象匹配 | A237 记录15、B236记录14、A328记录16、B625记录9 |

安装匹配包括 feedback scale 等语义 header 和全部数组，只有安装后合法改变的 plan ID 不作等同要求。不能仅比数组忽略 header；B625 的多个 nominal 对象数组相同，但 scale 不同，实际装入的是 nominal_8。

### 5.1 局部表示与 α=0 分支必须分开

精确 α=0 是缓存的完整 B，未 rebase、未新增 rollout、未重装。正 α 家族的 α→0 只具有局部一阶意义：四元数状态差的非线性、时间插值和最后动作节点语义，使它不保证在所有状态上与 B 恒等。

本次额外用原数组检查了这项风险：在 B 当前轨迹归一化四元数的中点，前 174 个控制区间内 hypothetical zero-limit center 与旧 B raw center 最大差仅 **1.18×10⁻¹¹ rad**。最后 174→175 区间中，u/K 已保持末控制节点而 state reference 继续走向终点，中点最大差 **2.88×10⁻⁷ rad**，终点最大差 **5.76×10⁻⁷ rad**。终点不是新增控制节点。这些数值不支持把本轮厘米级后退与十多厘米下沉归因于 rebase 网格接线错误；也不证明远离轨迹后两映射全局等价。实际 native rollout 仍是正候选的判据。

### 5.2 大 α 的主要变化不只是小前馈

旧 reference 已过期，实际查询到的有效末端 K 最大绝对值约 0.009097；B236 还乘旧 scale，只有 0.00005116。新 backward K 的最大绝对值分别为：

| 问题 | 新 K 最大绝对值 | 新 K 首节点最大绝对值 |
|---|---:|---:|
| A237 | 192,278.25 | 485.71 |
| B236 | 131,998.10 | 16,108.95 |
| A328 | 259,834.92 | 35,154.80 |
| B625 | 360,439.80 | 11,213.23 |

不同状态坐标单位不同，这个数值不能单独证明 K 错误，更不能直接推出应再加 K clip。它说明正 α 正在把几乎末端开环的旧响应转成很强的新反馈及其 QP 投影，不能把 alpha 仅理解成 0.09–0.19 rad 前馈方向的步长。大 α 的接触变化与投影改变足以让局部二次模型的效果失真，原 rollout 排序保留了这一现实。

B625 的 J 急剧升高也不是 NaN。α=0.013335 时 J=52.5524，ImpactMargin 为 44.4419；α=0.031623 时 J=5101.9736，ImpactMargin 为 5093.8321；α=1 时 J=1,523,733.1328，ImpactMargin 为 1,523,721.7634。候选数值有限、没有 failure flag，但实际完整成本拒绝它们合理。把这类候选失败都记作“求解器崩溃”会误导下一轮。

### 5.3 原 strict 比较器语义没有发现错置

原 R34Better 先比较 trunk risk，再在 risk 完全相等时比较完整 native J，要求超过双方可计算的浮点求和误差预算。kind=1 的正候选还必须先胜过同 epoch 的 best nominal B，再与全局 archive 比较。本轮候选与被装入对象一致；未发现新轨迹评分、旧完整 policy 部署的偷换。J 独立重算最大绝对差为 2.33×10⁻¹⁰，发生在约 1.52×10⁶ 的大成本候选；正常候选差为 10⁻¹⁵–10⁻¹⁴ 级。

当前动力学导数仍是 **FP64、one-sided、1e−6、10 个 0.2 ms 子步复合**；`fd_mode=0`。只有 W50 raw-center 控制映射 Jacobian 使用 central 1e−6 且零物理。这两者不能混称“已按 MuJoCo 论文改为中心差分”。没有充分证据在 W51 同时切换 FD 方式。

## 6. 步态参考为什么不足以给出正常迈步的明确方向

当前 quadruped Gait 残差本质上是四个足的**竖直高度误差**。原 2 Hz、duty .45、5 mm C2 step 保留；升段约 75 ms、降段约 200 ms，用五次平滑多项式保证端点连续。没有发现这段曲线本身的明显相位或连续性错误。

该移动 Gait 残差没有逐足的世界 xy 目标，也没有直接的支撑足水平速度目标；StandFootVelocity 是 Stand 语义，不能把它当作 Trot 已具备防滑/迈步参考。当前 `Gait weight=2, norm=6, p=.03`，单足漏掉 5 mm 峰值只产生约 0.0008276 的成本。实际四例 Gait 项约 0.0005–0.0009，而支撑高度项通常占 B 总 J 的 95.6%–97.6%。这种局部目标不能独自说明如何卸载、向前落脚并轮换承重。

这支持“搜索种子缺少接触与运动结构”的工作假说；**它不证明把 Gait 权重直接调高就会成功**。5 mm 来自已有慢着地设计，不应无证据提高步高。Position 项也不能按“目标3m而残差小”判错：r26 用的是有方向/速度积分的局部 head reference，含 .3 m head offset；任务远端目标不是直接的 native body Position 残差。四例 input 中的真实 userdata packet 与此一致，未发现可直接归咎的 .3 m 偏置错误。

相关当前源码是 r25 task baseline 经后续 patch 累积，审查时使用已还原的 r35 task 源（r37/r38 未改该 task），并核 r26、r20 等正式 patch；不要仅以某个早期 baseline 文件当作当前全部逻辑。

## 7. 短部署的工程错误与科学负结果分别处理

两条 40 ms 短部署确实经实际 RPC 做到单次 FP32 cast，20 ms 中点重新规划，并消费 INPUT_POLICY / R34_CONTEXT / R35_REFERENCE 等一次性导入。新 reference 分别为 `[4.34,4.69]` 与 `[4.32,4.67]`；可用于检查策略对象和新 epoch 生命周期。

但 bridge 当时通过已有 Python 进程加载，同 SONAME `libmujoco.so.3.2.3` 复用了不同构建的 wheel 库。wheel SHA 前缀为 `78f5455…`，冻结原生库为 `235066ca…`；`mjData` 相关字段偏移差异导致记录的 actuator/support 字段出现非物理值。**该 bridge 的力、力矩、support 与物理改善不能用来宣称正确 native predictor 等价。** 四个 standalone native agent 的有限候选评分使用独立进程和冻结库，不因此作废。

现有 [`w50_deployment.py`](../../../../../../../scripts/w50_deployment.py) 第 11–20 行已改为 `dlmopen(LM_ID_NEWLM)` 独立 namespace。已执行证据仅证明库映射修复，无新模型/积分重跑；不能把代码已修等同于修复后物理已验证。下一轮有意义的连续真实控制运行可同时覆盖实际接口正确性，不宜再把“原样重做两条 40 ms”作为整个下一轮科学目标。

## 8. 下一步建议：从起步的配对诊断，只有一个新增候选机制

### 8.1 首先区分预防性刷新与缺少迈步搜索初值

推荐两条 CPU 线从**同一个 seed1/full-init、t0 正常初始化**开始连续运行到 8 s（原任务失败/技术失败语义仍保留）：

1. **refresh-only**：当前 r38 正式在线逻辑，检验从起步持续刷新是否能避免过去 2.002→4.30 s 的换支撑失败。
2. **refresh + one phase-aware seed**：仅增加下面的运动种子，原 cost、物理、gait、horizon、风险排序与接纳规则不变。

W49 既有结果作为历史背景，不重跑第三条 r37 原轨迹。两条诊断控制器不同，不能拿它们冒充正式 A/B seed1/2 评价；后续正式原 A/B 必须冻结为同一个版本。8 s 是足够观察 Trot 切换、最初承重问题和已知低伏窗口的**物理观察工作量**，不是后台墙钟截止。若 refresh-only 已建立正常换支撑，便不把它的贡献误归因于新 seed。

### 8.2 一个完整候选 S 与一条导数方向，保留 B 的接纳基准

新增机制宜为一个相位与当前状态决定的运动 seed，而不是新增成本、另一套 MPC 或 alpha×beta 网格。

- **因果脚锚与相位**：使用实际 private gait 的 FL/HL/FR/HR 顺序，再明确映射记录的 FL/FR/RL/RR。支撑段保持该足本次 stance 开始时的实际世界 xy 锚点；摆动段从实际离地/相位边界的锚点，转移到由原 body 速度命令、原周期与名义脚相对位置决定的前方落点。跨 epoch 的锚点/端点必须因果继承，不能每 20 ms 任意重置使轨迹跳变或永远追不上。原 Gait 的 5 mm C2 高度成本参考不改。若已有摆动的实际足位置不等于该参考，seed 用原剩余 swing 时间确定性接续到原 touchdown；不能同时声称第一节点等于实际状态又强行等于不同的高度参考，也不能借接续新增步高。
- **几何求解与支持偏置**：在当前姿态和 MuJoCo tangent 中做受原关节边界约束的确定性 IK，得到相对于 B 原几何轨迹的关节增量 `Δq_IK(t)`。构造 `c_S(x,t)=c_B(x,t)+Δq_IK(t)`，保留 B 的全部 pre-clamp/pre-QP 中心、既有反馈和 PD 承重偏置，之后只走一次原 clamp/QP。不能用裸 `q_IK` 覆盖整个中心，否则会删掉支持身体所需的 `q_target−q` 偏置。
- **实际动态打分**：IK 输出是种子，不能把几何路径叫作可行动力学轨迹。单个 S 必须在当前 native 状态、时刻、任务目标下做一次完整原 rollout，得到实际接触、足受力、身体轨迹和 J。有限/可执行是其可作搜索起点的必要条件；是否可安装由原 strict comparator 决定。
- **只保留一条 backward 路径**：正常 nominal screening 得到 B 后，评分一个 S；若有效，可围绕 S 的真实 rollout 执行同样一次首有效 backward、同样九个正 α。不再从 B 与 S 各衍生九候选。若 S 在原 J 下较差，仍可以是寻找另一接触区域的 linearization seed，但不能因此抹掉 B 或降低最终接纳要求。
- **显式拆开搜索基线与接纳基线**：B 保持不可变的原 incumbent/archive。S 和其后候选最终都须胜过原 B，并按原风险/J/roundoff 逻辑胜过 archive；不能仅胜过一个更差的 S 就安装。r33 的 nominal 对象当前同时承担多种角色，实施时必须明确 `acceptance_baseline_B` 与 `search_seed_S`，并记录各自 score/reference/source。

这类 seed 可作为接触结构候选与 warm-start 的最小结合：先多一次 native rollout，随后沿 S 做原单方向搜索；不隐藏另一整轮优化。正常新 epoch 的 full rollout 预算从 control 的 `freeze1+nominal10+positive9=20` 变为 seed 线的 `freeze1+nominal10+seed1+positive9=21`；FD、raw-map 计算另记，首次无有效 metric 的 bootstrap 仍按原路径处理。单一 seed 应当完全由当前状态、原命令和原 gait 参数确定，不能在现场按成败加入不同步高、多个落点比例或额外 β。

这里给的是边界与识别方案，不承诺 IK 种子必然成功。若种子根本不能产生真实卸载和受控前移，结论指向 seed/运动可行性；若已经出现机械合理候选而原 J 一贯拒绝，才有依据进入**单项目标结构**审查；若刷新与 seed 都从未改变真实接触，才再追导数/接触可达性。不要把文献中的防滑项直接单独加上：无移动落点与足腾空目标时，它可能更奖励四足停住。文献依据与限制见 [literature.md](../literature.md)。
