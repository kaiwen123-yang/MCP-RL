# W56 后的文献与研究目标审查

检索截止：2026-11-21（Asia/Shanghai）。这是本轮审查记录，没有运行新物理、QP 求解、native rollout 或训练。仓库证据来自本轮最新 main；本文件先供整合审阅，提交基点由主审统一填写。

## 1. 目标已经进入新阶段

项目主问题是：**从可观测载荷与运动估计同一世界地块的持久材料状态，并利用这种状态改善后续跨足、跨步和返程支撑。** “机器人稳定走完原任务”“接通 PANN 到执行器”“证明材料记忆改善决策”是三个不同结论。

W56 的 r55 A/B 和 r60 A/B 已各自通过 E600；r57 的真实 12 维恢复特征置零 A/B 已通过 E60。因而后续不应继续把所有工作归为寻找可走 baseline，也不宜原样复跑稳定基线去增加成功次数。应保留 r55 为更简单的稳定参考，保留 r60 为已通过同任务的材料接口平台，转向材料状态的因果作用、步态质量和计算吞吐。

依据：`docs/TERRAIN_MEMORY_PLAN.md` 顶部、`w56/index.json`、`w56/f/F-{A,B}-r57/E60-paired.json`、`w56/f/F-{A,B}-r60/E600-paired.json`。

## 2. 现有证据实际说明什么

### 2.1 有真实重访曝光，但 actor 的直接反应极小

`w56/exposure/A-E300.json` 与 B 对应文件给出：2400 次足查询中，A/B 各有 462/447 次查询先前受载地块；既往受载、被查询、后来重载且与下一触地共享覆盖面积的地块分别为 652/655。不能再解释为“没有任何记忆机会”。不过，两份原 E300 中已记录足恢复特征最大量仅约 24.45/22.96 微米，同状态对最后 12 维置零引起的 cap 差最大约 1.46e-5/1.89e-5 m/s。这与 r57 置零仍能完成 E60 相符，表明原 cap 通道对当前显式材料恢复特征依赖很弱。

这不等于所有历史无效。原 540 维近期运动/受力历史仍然输入同一 actor；此消融只针对最后 12 维显式恢复预测，而且只有两份冻结 nominal case。

### 2.2 r60 是稳定接通，尚未显示统一的性能收益

在 E600 配对表中，相对 r55，r60 A/B 的 slip_integral 分别增加 0.0004446355/0.0025339723，材料峰值应变分别增加 0.0001098845/0.0001521316；任务都是十圈完成。闭环轨迹分叉之后，一些阶段到达时间稍提前，但没有统一支配 baseline。r55→r60 同时改了观察窗口、材料执行参考、材料计算后端，因此这个配对本身也不能唯一归因于“材料记忆”。

### 2.3 差分法向参考可能消掉主要的记忆偏置

`src/tm02/s1_material_prediction.py:normal_reference` 采用

\[
\Delta z=\delta(F_{\mathrm{measured}},\hat s)-\delta(F_{\mathrm{target}},\hat s).
\]

如果当前同一接触集合、小应变区内逆本构近似为 \(\delta(F,\hat s)=a(\hat s)+bF\)，历史主要影响的偏置 \(a\) 会在两次相减中抵消。这个推导只是解释候选，不能当成全程实验结论。

但仓库已有对应的局部证据，毋需重做旧单点：`w56/c/interface-qualification.json` 的 5.420 s 状态，当前力 22.670807 N、目标力 34.220451 N，r58 与 r55 的法向参考差为 1.11917e-7 m；r58 有历史与 zero-current-history 的参考差只有 8.85888e-11 m、映射输入差 5.89135e-11 rad。相同 14 节点材料预测里，有历史与零历史的绝对沉陷差最大却有 6.68139e-7 m。材料内态影响预测，不保证现有接口保留足够的决策影响。

应当在既有全程真实重访样本上测量这个差分消去效应的分布，并分开报告：绝对沉陷、相对执行增量、法向切线、最终 WBC 输入、候选选择和实际任务指标。不能通过软化原 plant 或改动应变域来人为制造效果。

## 4. 下一轮能合并完成的实质工作

这部分是给总计划的建议，具体身份与实施范围以主审发布的 W57 计划为准。

### 工作 A：把“能走”固化成可解释的步态与任务基准

复用已发布 r55/r60 A/B E600 全部轨迹及视频，按起步、材料去程、远端停车/转向、材料返程、回家停车与最终保持分段。统计实际而不是名义的支撑时序、对角交替、摆足离地高度、早/晚触地、足底归一化滑移代价、脚步长度/周期、roll/pitch、载荷交接与速度追踪。步态“好看”不宜先用主观观感作唯一判据；必须区分低速短步但正常交替与拖脚/全程四足承重。这个工作不需要新物理资格链。

机械能指标可以在已有力矩/关节速度中计算，但区分绝对功、正功与净功，避免用正负抵消掩盖耗能。只有适当解释的机械 CoT，不能冒充实测电池能耗。

### 工作 B：同后端的材料历史干预，给出因果结论

在 r60 相同 CPU FP64 后端、相同窗口观察、同一冻结 actor 和归一化、相同原 plant/初态下，对照只改材料执行参考是否使用持久历史。默认基线数据复用；新 case 各自走原 E30→E60。干预必须真的进入执行器并记录 mode 和输出，不再用 shadow actor 作为闭环消融。

保留 observer 完整更新和记录，只在声明的查询/参考分支改变历史信息；不要清空真实 plant q，也不要顺带更换材料弹性参数、gait 或 actor。若采用 zero-history，必须明确如何构造可解释的查询状态，以及这个干预与相同当前力/几何之间的关系。若只使用固定 k 作为对照，则报告为“本构参考 vs 固定 k”，不声称它单独隔离了历史。

至少输出两个层面的证据：同一真实状态下的成对参考/动作差；闭环独立分叉之后的任务/滑移/接触事件差。不能把后者所有差异都解释为同状态直接作用，也不能将两个冻结 nominal case 算成很多独立成功率试验。

### 工作 C：一次完成材料状态→预测→决策的链路定位与有用并行

用现有首次触地、同足重访、跨足重访、返程重访四类样本，按 episode/事件族分组，测量 full-history、预声明 history ablation、仅诊断 oracle 的预测与输出。训练/调参组和保留组以整条历史分开。先报绝对沉陷和 force residual，再报差分参考的变化、最终动作和候选排序。

已有 5.420 s 的单点与 14 节点传播已完成，不应重复当作新成果。新的增量是全程与真实重访覆盖、误差量级、分布和可改变选择的案例。若差分参考在真实样本中普遍消掉历史作用，应在同轮转向现有 `rollout_candidate` 的未来承载/落点几何传播，让材料状态进入预测和选择，先选一个决策接口，不同时重写所有 gait/MPC/actor。

同一候选的地块时钟、覆盖面积、foot ownership、loaded/free 更新和硬域检查保持一致；world map 和候选分支隔离。oracle 仅作诊断上界，不能控制机器人。若只发现模型有微小数值差而选择没有改变，就直接报告当前 nominal 任务的可辨识性不足，不靠放大权重或改软 plant 制造正结果。

GPU 用于真正独立的多个历史/地块/候选批次；每条历史内部时间递归顺序不能伪并行。W56 已证明 174 个历史批次可以有收益，而单历史 GPU 慢，因此不强迫 500 Hz 在线小批次迁移到 GPU。GPU 核函数计时与包含装配/传输/同步的端到端吞吐都应报告；不要再次泛称 GPU 一定慢或已经全链路加速。

### 三线如何同时推进

两个物理槽用于成对新干预 case 或经证据选定的一个新方法 A/B；第三线做已有数据的步态/材料辨识与独立候选批处理。共享构建、数学线程和发布串行整合，避免三个大型物理任务争用主循环。N/r59 既然仍未贯穿，应作为独立未解决分支保留证据，不再占据稳定材料主线的固定主要物理槽，除非出现直接针对其失败机制的新改动。

| RL 模块贡献 | 既有 658D actor 确实训练过；冻结 scalar cap 真正执行；r57 消融真实进入闭环 | 没有新的材料长程决策接口、跨重访 credit 分配或相对通用 residual 的模块比较；显式 12D 依赖弱 |
| 联合贡献 | 三部分已共同运行，已排除许多接线/稳定性问题 | 尚未证明“较好的估计→较好的未来预测/选择→学到对后续重访有益的行为”；全系统能完成任务不能替代各环节与联合消融 |

因此不必再从头“找一个能走的控制器”；下一步应把既有稳定系统作为固定实验平台。也不能仅把它换名为“PANN+MPC+RL 联合创新”。工程工作并没有白做：它给后续因果比较提供可解释的起点，降低了“新方法看似有用，其实只是修了旧 bug”的混淆。

### 6.2 材料/PANN 模块：从能更新状态到可辨识、可迁移的世界记忆

合理研究对象是每个世界地块的**动态材料状态与其可信程度**，不是再泛称“用网络估地形软硬”。同一个地块被 FL 加载后，另一足重访时仍应读取同一因果历史；新地块与已经恢复的旧地块应区分。状态演化、载荷/几何观测和跨足数据关联必须共享物理时钟与有限 footprint，接触 overlap 不能重复累加反力。

可以重新开放材料估计模块，但先回答以下问题：

1. **可辨识性**：仅由已经发生的力/位移/速度，是否能区分弹性、未恢复耗散态和观测误差？若短暂载荷下多组状态解释相同，诚实保留区间/协方差/集合，而不是输出看似精确的单点 q。具体不确定性表示由可观测残差和保留组校准，不把真实 plant q 当在线输入。
2. **状态与参数分离**：W55 的两参数拟合候选训练 loss 下降但保留组恢复误差增加，说明“解除参数冻结”本身不是解决方案。可以比较固定物理势+改进状态估计、有限参数适应、两者联合，但每一种都必须用同事件族/同保留组检验。原 B ideal 基准保留，不能改写原已成功合同。
3. **跨足/空间迁移**：与最近窗口 encoder、每足独立记忆、当前接触状态、卸载后忘记的 world map 对照。根据真正新增模块选必要比较，不机械堆全套。检验在同一世界 cell、部分面积重叠、先前加载者不同、观测稀疏以及重访时间变化时的预测误差与校准。
4. **误差在哪个量上减少**：预测下次接触的法向力/位移/恢复曲线、耗散与切线，并报告绝对误差、相对误差、覆盖率和拒绝/回退比例。不能只优化训练本构 loss，或只报 q 的数值变化。真实内部 q 可以用于离线标签/评价上界，进入控制器须用估计。

PANN 结构的物理约束、不确定性估计和在线参数适应分别都有大量先例，本轮所查文献不足以证明任一单独技巧“首次提出”。可主张的候选贡献应更具体：**接触有限面积与持久世界地块关联下，跨足加载–恢复状态的因果估计，并能证明这些估计改善了后续决策。** 最后是否创新还需围绕最终精确定义继续排重，不预先保证论文新颖性。

### 6.3 MPC 模块：保留稳定内层，用材料事件层覆盖实际重访尺度

当前 350 ms force MPC 读到历史，可以对当前/近未来做出响应；这与主动优化“这次踩踏怎样影响下一只脚/下一次重访”不同。已发布 exposure 表中，A/B 同圈跨足 **prior_event_age** 中位约 1.3563/1.3750 s，跨圈同足约 47 s；前者表示查询时过去事件的年龄，**不能直接说成当前动作到下一次加载的未来时距**。下一轮应从 source-load→next-load 的真实事件对重新计算所需覆盖范围。

如果目的确实是跨足协同，一个成本合理的方向是保留原 50 Hz/350 ms 内层 force MPC 与原 WBC/PD，将较长的材料状态预测放在低频事件层。该层按实际接触/卸载/重访事件传播候选的世界材料状态，而不是把所有内层 20 ms 节点机械拉长数倍。预测时域需覆盖被声明要优化的重访事件，并报告覆盖率和最长未覆盖间隔；例如探索 1.5–2 s 只能是依据真实分布验证的初始设计范围，不是本次已确定合适的常数。

候选可先只改变一个有实际权限的变量：一次支撑间的载荷分配偏好、有限的落脚选择，或有限的接触时序。每个候选从同一 observer 快照建立独立地块状态，完整传播加载/卸载、共享 footprint 和恢复；若短 horizon 看不到相关重访，可明确使用终端材料状态代价/近似价值，但其定义和校准成为新增模块，不能隐藏在旧 J 中。所有候选必须以同一模型/同一目标重算成本与原约束，不能把不同模型原始目标值直接比大小。

**下一轮最小实现应更小**：先用现有 `rollout_candidate` 把材料状态真实接进一个被消费的预测接口，在保存事件族上判断是否改变未来预测、候选排序与首动作；确认有意义后才做新原物理 A/B。若仅 moment arm 的微米级变化不足以改变选择，应明确承认该通道无辨识力，不再盲跑相同 E600。研究主动跨步负载/时序属于下一阶段，需明确的新目标和新实验身份。

本轮实测材料历史量级也限制了可证明范围：同圈跨足存在更明显残留，跨圈大多已恢复。因此有限范围内先研究同圈/短时重访，比给原 47 s 一圈任务无限增加圈数更有信息。补充短重访任务应保留原 plant/材料/硬界，独立声明路线/phase，不能把其通过算成原 E600 资格。

### 6.4 RL 模块：学习有材料后果的决策，给延迟效果真实 credit

目前 scalar cap 只能在有限速度范围调节，不直接控制卸载、法向载荷分配、落点或接触计划。继续盲目增加 PPO 更新，未必能从一个低权限通道学出跨足材料策略。新 actor 最好从一项明确、有界、可回退的低维决策开始，由原 MPC/WBC 检查与执行；同时保留匹配动作空间、匹配训练样本预算的“无持久材料记忆”学习对照。

与 AugMPC 的差异不能只写“RL 输出 gait 参数”，与 Residual MPC 的差异不能只写“RL 与 MPC 相加”。更有针对性的研究问题是：**RL 是否能利用地块状态及其不确定性，选择当前载荷/落点/接触时序，以改善下一次同地块重访，而冻结短时控制层保持稳定与约束？** 如果动作经过可行性投影发生变化，必须同时记录请求动作、被接受动作、原因与实际执行，否则策略可能主要在学被拒绝的命令。

奖励与 credit 也要对应这一问题。训练 segment 至少要真实覆盖相关加载–重访链，价值估计不能每次接触就把该地块的后果丢掉。接触事件索引可以支持按真实重访组织奖励或 auxiliary prediction；是否使用 recurrent actor、terminal value、事件级 return，需和相同信息/预算基线比较。不要用任意重权重让微小材料指标压过稳定与原任务，也不要只奖励预测模型认为更好而实际地面没有改善。

一条可执行的训练路线应包含：冻结 r60 低层与原 actor 参考；单独新增 actor/head/normalizer/optimizer 身份；明确新动作界与回退；指定采样单位、最大更新数或已定义实验预算、保留集和自然终止规则；完成后由未训练的冻结 A/B 与新的独立种子/初态测试。**更新/样本预算不等于墙钟完成期限**，用户要求不设置后台截止并不妨碍预声明科学实验规模。

### 6.5 最小模块消融应服从接口依赖，不机械枚举 2³

记 `M0` 为现有因果世界材料估计，`P0` 为现有 r60 规划/执行层，`R0` 为冻结 cap；`M1/P1/R1` 分别是未来明确的新估计、材料规划与学习决策模块。这些名字仅为下表记号，不代表已经实现三个新方法。

| 条件 | 用途与可解释比较 | 前置条件 |
| --- | --- | --- |
| **B = M0/P0/R0** | 已成功工作基准；保留 r55 作为更简单稳定参考 | 已存在，不必反复原样跑 E600 |
| **M1/P0/R0** | 检验估计模块本身；首先看未见事件预测/校准，当前低层不敏感时不能要求步态必然改善 | M1 用因果输入、独立事件族保留组；无真状态泄漏 |
| **M0/P1/R0** | 隔离新的材料未来规划是否有贡献 | P1 已消费状态、候选隔离和原约束核验；M0 已足够支撑接口 |
| **M1/P1/R0** | 看改进估计能否在有权限的规划里发挥作用 | M1、P1 单模块与交叉接口通过；对照 M0/P1 与 M1/P0，而非只对 B |
| **M0/P1/R1** 与 **M1/P1/R1** | 分别比较 RL 增益和新估计在学习系统中的增益 | R1 动作若由 P1 才能执行，P1 是必要依赖；两者匹配训练样本/动作界 |
| **M1/P0/R1**（有条件） | 只有 R1 在 P0 上有同语义动作接口时，才是有意义的学习单模块比较 | 若 P0 根本不能消费该动作，不应造一个永远失效的“RL-only”对照 |
| **oracle / history-reset / history-shuffle 诊断** | 分别检验预测潜力、持久状态必要性、信息语义；有合理状态构造与时间因果性才使用 | oracle 离线或明确特权上界；reset/shuffle 只能改私有查询状态，不改真实地面 |

并不是第一轮就运行全部条件。先用 oracle/估计/无记忆的同状态保存事件检验：即使理想材料状态进入同规划，也不能改变决策或指标吗？若答案是否定，应先改任务/决策权限/预测时域的研究定义，不能指望更复杂 estimator 或更久 PPO 自动创造效应。

“联合协同”也不等于 full 条件比 B 好。若 M1→P1→R1 的接口依赖严格存在，应该报告逐层增量和适用条件；若接口允许独立 M、P、R 组合，可预声明交互项，例如全系统增益是否超过已有单模块增益，附不确定性。相同两份 nominal 成功记录无法估可靠交互效应；需要少量预声明独立场景/种子与成对配对，先做有信息量的短任务，再决定是否推广长资格链。

### 6.6 哪些通用做法已不够构成新颖性

以下是从本轮实际读到的一手来源得出的排重提醒，**不是全面文献不存在性证明**：

- **MPC 加低维 RL residual / 改 gait**：AugMPC 已有 twist/flight contact 注入；Adaptive RL-MPC 有 dynamics、swing、gait 多模块；Residual MPC 有策略与 MPC 融合。因此“RL 调 MPC 参数”只是架构描述。
- **从最近接触历史估地形后调步态**：Terramechanics-aware Go2 的官方摘要已这样描述；MILD 摘要也已有 terrain latent/proprioception 估计。我们不能把这类一般能力作为首创，也不能从没读到的全文推断它们缺少 world memory。
- **在线模型参数估计再做 MPC**：Online Learning MPC 和 Adaptive-MHE 已覆盖相近方向。新贡献需要精确到稀疏、跨足、持续地块状态及其如何改变未来接触决策。
- **GPU 批并行与更多环境**：已有成熟方法，项目目前可以把它作为实现效率与可复现基建；除非提出并严格比较了新的数值/调度方法，否则不把“使用 96 GB GPU”当方法创新。
- **Terrain memory / 返回时记得走过的地形**：LF2WB 已利用前行视觉与本体感知记忆服务无后视的后退行走，且有实机摘要。项目应准确限定为材料加载–恢复状态及其跨足未来影响；“有世界地形记忆”这个宽泛口号不足以排重。
- **有物理结构的材料网络、因果状态更新、隐状态或不确定性**：这些一般概念本身不足以证明新颖性。本轮没有完成对所有相关材料建模/过滤文献的全文排重，不能给出“世界首创”之类结论。

项目最有希望提出且可证伪的主张，是**同一世界地块的可观测历史，经可校准的材料状态估计和候选内加载–恢复传播，改变跨足/重访决策，并在物理与任务条件不放宽的情况下带来可重复收益**。若当前 TM02/原任务效应太小，研究结论可以是该组合在这个条件下无显著收益；之后独立设计仍物理可信、有辨识力的任务或材料域扩展，而不能悄悄改变基准让方法赢。

### 6.7 下一轮有限范围与长期路线分开

**下一轮应承诺能够实际交付的内容**：完整步态/接触审查与真实事件日志；同状态材料记忆强度及接口衰减分布；一个真正消费材料候选的规划接口与成对私有历史干预；两个物理槽做严格选择后的 A/B；第三线完成已有数据辨识、GPU 独立批次与按天工作日志。在负结果出现时给出清晰决策，不自动扩成若干周无边界重训。

**长期路线**：若现有状态有预测信息但接口压掉它，先做 P1；若 oracle 有潜力但 M0 误差/不确定性太大，先做 M1；若 M/P 已稳定产生可控制差异但短时目标不善用它，再做 R1 与长程 credit。新 PPO 可以在明确阶段获得执行权限，应该让每次训练回答一个具体问题。最后用必要模块/联合消融、保留场景与原长任务复验，逐步支持最终论文主张，而不再把每一轮都限制为修一个小 bug。
