# v1 历史书目快照（2026-10-13）

此目录保留改版前的 100 篇清单，包含正式发表于 2024–2026 的 25 篇及 2024 年以前的 75 篇。它是历史记录；当前主清单见 [新版索引](../../INDEX.md)，改版依据见 [修订说明](../../../docs/library-v2-revision.md)。

- [papers.json](papers.json)：原公开书目与当时的阅读、访问状态；新增本归档说明及路径语义说明。
- [papers.ris](papers.ris)：改版前公开 RIS 的原样快照。

JSON 中 `reading_note` 按**仓库根目录相对路径**解析。例如 `notes/MR004-survey.md` 指向根目录下的 `notes/`，不相对于本归档目录解析。笔记正文继续放在主仓库的原位置，不随此归档重复复制。

v2 保留其中 29 篇并补入 71 篇新条目；退出主库的 71 篇仍可在此追溯。稳定的 `MRxxx` 编号没有重新分配。保存历史条目不表示它们继续占用当前主库的近期或经典名额，也不表示这些论文已被精读或复现。
