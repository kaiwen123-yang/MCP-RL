# 四足机器人地面记忆辨识与跨步协同控制

**最终研究问题（用户于 2026-10-21 确认）：机器狗在会被自己改变的软地面上，怎样决定当前加载、落点和重访时间，为后足及返程留下可用的支撑条件？**

同一空间地块的材料状态跨腿、跨步、跨返程持续演化；后续支撑需求反过来约束当前踩踏。第一版从具有可测恢复过程的黏弹性材料开始。

## 三个待实验验证的贡献

| 贡献 | 实际要解决的问题 |
|---|---|
| 跨足材料记忆辨识 | 从加载、卸载、无载恢复和不同腿重访中，估计能预测后续支撑的材料状态；用物理关系约束演化 |
| 后续支撑约束当前决策 | MPC 将后足需要的支撑转成当前加载、落点和时间的可行选择 |
| 远期重访价值学习 | RL 评价 MPC 时域外的地面后果；与普通价值函数及长时域/事件规划比较 |

它们是待验证的机制假设，不能把 PINN、MPC、RL 三个名称本身当作三个创新点。研究问题保持不变。
