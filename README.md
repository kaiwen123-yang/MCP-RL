## 研究约定

- 创新可以沿已有问题推进：明确重要的未解问题及其原因，再通过方法改进和匹配证据证明收益。
- 区分作者结论、作者明确的限制与展望、阅读者推断和待检验假设。
- 当前以方法、理论和仿真认识为中心，不急于指定最终算法、求解器或机器人平台。
- 同时关注样本、训练时间与在线计算，但不提前把整个课题限制为加速求解。
- 仓库存放公开书目和原创笔记；通过出版社、会议及作者公开链接访问原文。
