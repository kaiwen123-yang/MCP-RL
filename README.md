# 四足机器人地面记忆辨识与跨步协同控制

**最终研究问题（用户于 2026-10-21 确认）：机器狗在会被自己改变的软地面上，怎样决定当前加载、落点和重访时间，为后足及返程留下可用的支撑条件？**

同一空间地块的材料状态跨腿、跨步、跨返程持续演化；后续支撑需求反过来约束当前踩踏。第一版从具有可测恢复过程的黏弹性材料开始。

### 冻结第一轮

[第一轮原方法结果](results/terrain_memory/reproduction/material/tm02-rnn-20261023/index.json)、[重访结果](results/terrain_memory/transfer/material/tm02-rnn-20261023/index.json)和[可下载归档](https://github.com/kaiwen123-yang/MCP-RL/releases/tag/tm02-r2-evidence-20261023)已包含 50 次实际训练的最终模型、完整曲线与 36 条重访推演。这里的 50 次自由预测来自 **50 个模型对同一条独立路径**，不是 50 个独立评价工况。

按最终训练损失选出的 ideal seed 13、noisy seed 0，在该独立路径上的 RMSE 为 **2.513、3.536 MPa**；同一训练历史的自由预测 RMSE 为 0.093、0.352 MPa。评价路径的 231/250 个增量超出训练体积应变范围，误差集中在静水/法向应力；优先检验完整加载历史覆盖不足。材料方法链条已运行，不宣称达到原文预测效果或整机收益。

第一轮重访峰值压缩误差中位数为 ideal **2.31%**、noisy **7.43%**。排序是 6/6、4/6，但六组参考都偏好早加载，恒定 always-early 也有 6/6；noisy 的另外两组是微小差异被预测成平局。第一轮模型、归一化、实际数组及历史判定保持冻结。

## 最新论文怎样用于当前课题

本轮的直接复现对象来自 TM02 自己的 **§5.2.2 / Fig.14：100×100 多历史训练**。增加历史覆盖所带来的改善属于原方法能力验证，不包装为新算法创新。

- [SuperMimic，TM07](https://arxiv.org/abs/2610.28480)：完整自由推演和动作后果评价；明确长期漂移出现后才讨论新的多步训练。
- [全场数据标定黏弹性神经模型，TM08](https://arxiv.org/html/2609.03645v1)：从可测反力/位移识别材料，为 S/H 标定提供路线；本轮不扩成 FEM 系统。
- [低预测误差为何可能误导规划，TM09](https://arxiv.org/html/2610.05550v1)：分开候选共同偏差与动作响应差，加入恒定策略和决策遗憾；指标改善不直接等于闭环控制改善。

固定来源与范围见 [资料清单](literature/terrain_memory_sources.json)。已有 PDF 复用，只准备本轮涉及的论文：

```bash
python scripts/prepare_terrain_memory_sources.py --papers-only --paper-id TM02 --paper-id TM07 --paper-id TM08 --paper-id TM09
```

不新增人形模仿、整机世界模型或新的全文复现支线，不以调研代替训练。

## 三个待实验验证的贡献

| 贡献 | 实际要解决的问题 |
|---|---|
| 跨足材料记忆辨识 | 从加载、卸载、无载恢复和不同腿重访中，估计可预测后续支撑的材料状态 |
| 后续支撑约束当前决策 | MPC 将后足所需支撑转成当前加载、落点和时间的可行选择 |
| 远期重访价值学习 | RL 评价 MPC 时域外的地面后果；与普通价值函数及长时域/事件规划比较 |

它们是待验证的机制假设，不能把 PINN、MPC、RL 三个名称本身当作三个创新点。当前 R2 学习固定参数、已知初态的合成材料，尚未解决真实地块未知状态、跨足共享和力/位移接触映射。S 仍需充分辨识的经典本构、同信息历史网络与充分规划强对照。
