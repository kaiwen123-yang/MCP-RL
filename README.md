# MPC 与 RL 融合方法研究

从融合方法与理论出发，理解学习经验怎样进入预测控制，再通过有判别力的通用测试选择研究问题，最后考虑机械臂或四足机器人验证。

本仓库是研究资料与阅读笔记的起点。目前已整理 **100 篇正式发表文献**，并为第一轮阅读建立了原创中文初读笔记。**尚未实现融合算法、运行复现实验或确认最终创新点。**

## 从这里开始

1. 阅读 [当前研究思路](docs/research-brief.md)，确认目标和阶段安排。
2. 阅读 [融合方法地图](docs/fusion-map.md)，看清模型、策略、价值、优化器和训练数据的不同接口。
3. 按 [第一轮阅读路线](docs/reading-plan.md) 阅读四组核心文献。
4. 在 [100 篇文献索引](literature/INDEX.md) 中展开相邻工作。

## 研究约定

- 创新可以沿已有问题继续推进：明确尚未解决的原因，改变关键机制，证明实际收益。
- 不因残差、终端价值或策略初值已有研究而直接否定方向；也不把换网络、换平台或增加模块自动算作创新。
- 区分作者的结论、作者明确的局限与展望、阅读者的推断，以及未检验的假设。
- 当前以方法、理论和通用测试为中心。实时计算与训练预算需要考虑，但不提前把课题限制为求解器加速。
- 论文原文通过出版社、会议、作者机构或公开作者稿链接访问；仓库存放书目和原创笔记。
