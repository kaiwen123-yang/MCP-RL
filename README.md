# MPC 与 RL 融合方法研究

从近期融合方法与理论出发，理解学习经验怎样进入预测控制，再通过有判别力的通用仿真选择研究问题，最后考虑机械臂或四足机器人验证。

**当前主清单为近期优先的 v2：90 篇2024—2026年正式发表论文，加10篇经典奠基文献。** 已完成的是书目筛选与组织，并有少量原创中文初读笔记；没有完成100篇精读、算法复现或创新点确认。

## 从这里开始

1. 阅读 [当前研究思路](docs/research-brief.md)，确认方法理论、通用仿真、机器人验证的阶段顺序。
2. 阅读 [融合方法地图](docs/fusion-map.md)，看清模型、策略、价值、优化器与训练数据的不同接口。
3. 按 [近期优先阅读路线](docs/reading-plan.md)，从最新综述、价值与规划协同，再到学习优化和安全理论展开。
4. 在 [100篇主清单](literature/INDEX.md) 中查找相邻工作；经典在遇到具体理论问题时查阅。

## 研究约定

- 创新可以沿已有问题推进：明确重要的未解问题及其原因，再通过方法改进和匹配证据证明收益。
- 区分作者结论、作者明确的限制与展望、阅读者推断和待检验假设。
- 当前以方法、理论和仿真认识为中心，不急于指定最终算法、求解器或机器人平台。
- 同时关注样本、训练时间与在线计算，但不提前把整个课题限制为加速求解。
- 仓库存放公开书目和原创笔记；通过出版社、会议及作者公开链接访问原文。
