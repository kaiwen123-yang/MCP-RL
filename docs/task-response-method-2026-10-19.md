# 任务驱动的闭环响应与反馈共同学习：本轮方法与实现

日期：2026-10-19（Asia/Shanghai）。状态：**候选方法、条件理论和代码已形成；训练参数更新分支尚未执行，没有学习有效性或独立算法优势结论。** 本轮不训练、不开自动检测。必要的只读前向/求导验证与服务器计划分别记录，不能替代方法效果。

## 本轮要解决的核心问题

自由追求任务回报的反馈可能不容易被小模型预测；固定简单响应又可能牺牲任务行为。本候选让任务改变响应目标，策略学习实现该目标，再用新策略的真实执行数据校准模型。研究假设是：这能在一定模型容量和计算预算内改善完整任务与预测可用性的取舍。

本轮把这条关系落实为一套神经策略、神经响应模型、MPC、完整任务采集与交替训练代码。没有再用标量反馈r或准确闭式响应替代神经共同学习。优化器沿用成熟PPO与Adam；候选的潜在价值在响应表示和共同训练对象，不在新的优化原理。

其实际形式是**任务敏感度加权的双向响应塑形，加上新策略下的预测再校准**。它仍可能被普通共同训练、已有任务相关建模与标准PO解释；四组比较专门让这些解释有机会成立。

## 1. 具体表示：真实执行与预测记忆分开

实际二维惯性对象状态为位置、速度和执行器状态x=[p,v,a]。actor从实际状态、MPC命令和公开任务上下文产生二维动作，动作经过所有方法共有的输入范数限制。环境只推进执行滞后、耦合阻力及扰动，没有解析跟踪器代替actor完成控制。

响应模型g的状态z=[p_hat,v_hat,m]保留位置与速度，末两维m是学得的有效响应记忆；它由编码器从真实初态初始化，不冒充实际执行器a。g以已知运动学组织位置/速度传播，神经函数决定响应记忆的演化，另预测实际输入平方范数的条件均值。模型内部有界不等于真实行为可实现。

每个宏段从真实初态编码一次，g开环预测四个微步的位置、速度和输入资源。真实actor在每个微步根据实际状态反馈。两者使用相同的任务上下文；未知未来扰动不进入控制器。学习期间模型同时作为MPC预测器与响应匹配目标，部署保留MPC和actor。

首版actor是前馈网络，真实执行器状态可见。模型的“记忆”是动力学状态而非已实现的历史观测RNN；本轮不声称已经解决部分观测或机器人接触记忆。

## 2. 任务如何进入共同学习

每个宏段开始时，MPC用当前g选择命令计划。为判断哪些响应误差更影响后续任务，将该计划以末命令保持的方式延长到任务终点，并计算位置、速度及资源方向的后段成本敏感度v。

先构造A=I+αvvᵀ/(1+||v||²)，再令W=5A/tr(A)。α固定为4，每个W的迹固定为5，与均匀W=I具有相同总权重。其作用是重新分配不同误差方向的重要性，避免把候选的区别混成单纯增大惩罚系数。

W来自固定计划代理，不是整个闭环MPC的精确任务梯度；它也没有覆盖模型隐藏记忆方向。所有尺度、代价和权重在正式小试前固定。后续实际模型误差和任务表现负责检验这个选择是否有用。

策略的训练奖励包括真实任务回报，以及实际段内响应偏离g目标的加权代价。因为奖励来自实际执行，actor必须改变真实反馈行为才可能改变这部分代价。模型则同时接受实际响应拟合与预测任务代价的梯度，使响应目标能够被任务推动，而不仅跟随当前策略。

这里采用**软一致性罚项**。它不保证响应可实现，不保证输入之外的状态约束，也不保证每次更新改善任务。实现损失还包含响应方差惩罚，可能让行为更可预测，也可能压制有用探索；两种可能均需按实际任务评价。

## 3. 完整一轮由三批新数据连接

| 阶段 | 执行内容 | 为什么需要这一批 |
|---|---|---|
| A：提出响应改变 | 当前确定性部署actor与MPC执行完整任务；g按实测响应及固定已执行命令的任务代理更新 | 让任务影响模型目标，同时保留实际实现数据 |
| B：学习实际反馈 | 冻结新g，重新运行带探索噪声的actor与MPC；真实任务回报＋固定响应目标/度量形成PPO回报，更新actor | 改变真实反馈；不拿旧模型下的数据冒充新模型下的PPO批次 |
| C：校准新反馈 | 新确定性actor重新执行完整任务；g只做新策略数据拟合，随后进入下一轮MPC | 使下一轮规划依据更新后真实反馈的数据，而不是仅保留乐观目标 |

A/C辨识的是确定性均值actor的实际轨迹，B用于随机PPO探索。非线性对象上，随机轨迹均值不等于均值动作轨迹，本方法不作这种替代。各组均采用相同三批规则，不能只给候选额外数据。

模型数据项包含局部四步开环拟合与整段完整任务的连续预测拟合，避免只靠每宏段重新初始化掩盖长预测漂移。模型任务项使用本批实际执行过的命令序列，计算完整模型任务代价；不把CEM排序假装成可微最优解。

这仍是一个交替代理优化程序。W所用的持尾预测计划，与模型任务项所用的完整记录命令序列不同；重新规划和数据分布还会随更新改变。目前没有证明它是同一固定总体目标的精确坐标下降。C校准也不能自动保证新查询区域可靠，这正是实际评价要检查的内容。

## 4. 与普通共同训练、同信息PO/TO的实质差别

| 对照 | 实际实现 | 能区分的内容 |
|---|---|---|
| ordinary | actor只优化真实任务；g监督拟合实际反馈 | 增加双向响应塑形及任务设计是否有价值 |
| uniform | actor真实任务＋均匀响应匹配；g数据拟合＋同样的任务项 | 候选的任务方向加权是否优于普通双向共同训练 |
| weighted_id | 与候选同样的任务加权匹配，但g只辨识 | 任务推动g目标移动是否必要，还是重加权就解释了效果 |
| codesign | 任务加权的响应实现＋模型任务步＋新策略校准 | 完整候选，仍待实验 |
| 同目标标准PO | 给相同PPO相同奖励、数据和更新规则 | **可以完全等价**，候选不拥有独占梯度或新求解器 |
| 同信息命令TO | 在同一个g上优化相同合法命令，使用投影梯度与多初值 | 检验已有反馈能否被更充分规划；它不更新actor，不能冒充共同策略优化 |
| 更强的同变量PO/TO | 若同时优化同θ/φ并获得相同目标与信息，可求相同解 | 本轮不声称优于这整个方法类；充分最优或更多信息的oracle另列 |

普通共同训练组没有被刻意限制任务信息、网络容量或训练步数。uniform也保留模型任务步，避免把“任务加权”和“模型目标设计”混在一个主差异里。

最重要的结论是：**本候选有具体的目标、表示和数据流程区别，但没有建立不可由标准PO/TO实现的优化原理。** 若未来收益只来自已知的任务重加权、更多计算或普通共训，则应按这一归因收尾，不能另取名称包装独立贡献。

[直接近邻比较](../notes/task-response-2026-10-19/related-work.md)覆盖SPlaTES、ReCo、GPS、costate-focused RL和TaskMet；这些机制的已有覆盖已明确保留。

## 5. 必要理论为哪项设计服务

[数学定义、证明及LaTeX片段](task-response-theory-2026-10-19.md)给出：

- 固定迹W的谱界：α=4时特征值介于5/9与25/9，既保留所有可观测方向，也不无限放大某个方向。
- 响应损失的均值匹配＋方差惩罚分解，说明actor究竟受到什么学习信号。
- 潜动作score的合法使用条件；固定动作映射不要求真实环境可微，PPO多epoch仍只是局部代理。
- 后段任务的Taylor误差解释，明确曲率、敏感度误差、遗漏记忆和重新规划差距。
- 同一有限候选集合下的2ε+δ规划比较，以及完整新旧pair的双侧任务误差条件。

这些属于必要的标准数学实例化，不当作三个原创定理。没有获得实际可用误差常数，也没有证明机器人安全、稳定、全域实现或共同学习优势。权重的理论界不等于实际任务改善界。
