### 六条工作包的算法内容

使用隔离分支/工作区和唯一整合者。首先核对每条最近邻的正式正文与官方关键实现，复用已完成阅读，不为数量重复检索；之后直接实现具备条件的完整算法及对照。

**A：材料模型。** 主线实现材料族条件PANN、受约束低秩条件权重、support/query适配与响应空间更新尺度；并行研究可恢复慢记忆、不可逆压密和耗散一致隐式更新。非局部算子先做双压头/间距/加载顺序数据与强独立柱对照，有真实作用再扩展。材料身份、历史内态、几何与观测误差分开；模量和松弛时间从明示参考状态的响应提取，不把latent分量直接当物理参数。对比ME-PANN型embedding、普通元学习、HANO/强RNN及相同积分器组合，不只赢原模型。

**B：步态。** 主线实现受控周期轨道族、真实闭环返回映射、横向反馈及可行过渡桥；完整生成周期、足轨迹、接触窗口、落足和躯干运动。并行保留非周期接触程序生成、跨形态/能力协调技能迁移两个独立问题。位置/速度/加速度来自同一时间参数化；前进轨道在平移/航向商空间处理。不要把固定gait选择或CPG调频当全部创新。对照PROMO、LoComposition、Gaitor/轨道库和相关非周期方法。

**C：MPC。** 在同一个预测问题上实现拓扑保留的GPU采样、多材料场景、局部GN/SQP/DDP精化和残差/信赖域分布更新；控制候选、模型场景和精化计算分配。不要平均互斥接触拓扑；proposal变化要有正确权重，材料场景按共同信念风险聚合。另建有限K步学习热启动/预条件器/终端价值支线，以及风险/信息协同规划支线。学习有限步算法需unroll实际K步或黑箱外层，不能拿收敛KKT导数训练已被消掉的初值依赖。前馈包括材料加载和驱动可实现性。

**D：WBC。** 主线实现接触约束下自然任务惯量与可实现部分解耦，同时研究相位相容内模/复合自适应控制。浮动基欠驱动行严格保留；约化坐标带连接项，接触秩变化按局部chart/过渡处理。第三支线是材料储能、功率和任务推进联合优化；内部接触功率不要重复计外部供给，松弛有界。HIM表征、经典IMC和内模原则分别说明。对照现有WBC、层级逆动力学、IMC/WB-DRC及匹配的自然动力学方法。

**E：策略学习。** 主线实现事件级接触模式、连续变量和持续时间策略，真实事件critic，完整混合Fisher与执行映射共同定义的自然梯度更新；纯score版本先可独立工作。条件允许再接可信模型导数，包含连续动作影响未来离散模式概率的交叉项及事件时间导数。另保留尾风险/推进约束学习和实际命令空间离策略联合学习。与同动作空间PPO、SPO、HPO/TRPO及合适off-policy基线比较。控制器和动力学Jacobian是链式因子，不作为三份独立回报梯度相加。

**F：联合与评价。** 建立共用任务、数据和真实执行响应接口。物理转移、observer belief和controller内部记忆分开；WBC响应算子条件化当前版本/参数/预算并校准。主联合目标是固定部署计算/风险预算下，减少未见材料×运动×能力组合的适配阶段累计控制代价；比较相同模块分别训练与共同训练。query来自当前适配候选的真实rollout或明示合法off-policy估计，不能换动作后仍用旧query next state。固定support策略版本先做给定数据适配；学习主动探测时另算support分布梯度。更新G/MPC/WBC/延迟后重新评价轨道和过渡有效域。
