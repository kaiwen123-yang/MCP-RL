# NeuralActuator 对 MPC+RL 的价值、源码边界与接入设计

研究日期：2026-11-26，Asia/Shanghai。

**结论：值得纳入，优先作为“因果执行器模型＋外力/承载观测”的研究依据。它有助于补齐实机链路，但不能直接替代 PANN、MPC 或现有世界模型，也不能证明当前 S1 的数值问题来自执行器。**

本文是论文与官方源码审阅及研究设计，没有运行该方法的复现实验，没有启动 S1 训练或硬件控制。研究依据不含用户个人 SuperMimic 复现记录。

## 2. 最有价值的思想

论文把执行器历史、可微刚体传播和外力感知结合起来：历史网络给出用于轨迹传播的等效力矩，另设外力、接触概率和受监督关节状态输出。力矩头通过运动轨迹训练，不依赖关节力矩真值；外力头仍使用力标签。实机示范主要来自机械臂，Franka 部分是离线验证，不是直接迁移到四足机器人的部署证明。[论文方法与实验](https://arxiv.org/html/2607.11734v2)

对本项目的启发是：此前把“给出的命令能否正确执行”主要交给 PD 与残差模型处理；面向实机，应单独表示驱动链的迟滞、饱和、负载依赖及历史状态。与之对应，地面模型负责接触后的形变、恢复和重载。这样才能讨论某次承载晚了究竟来自运动命令、执行器、接触几何，还是地面响应。

这不是说当前所有误差都应拆成可唯一识别的物理原因。有限测量下，多个解释可能同时成立；合理的模型应保留这种不确定性。

## 3. 官方代码中直接影响接入的细节

以下是对锁定版本代码的审计结论，不是对所有神经执行器方法的泛化判断。

| 审阅位置 | 发现 | 对本项目的接口要求 |
|---|---|---|
| [train_actuator_diffsim.py](https://github.com/Frank-ZY-Dou/Dynamics-Modeling/blob/541a93aac4368e73883e86a51f31a7add6bde059/NeuralActuator/train_actuator_diffsim.py) 的模型初始化与外力开关 | 默认关闭模拟器接触，显式施加外力为可选项 | 默认等效力矩可承担交互效应，不能直接再加一份 PANN 接触力 |
| 同文件 loss_fn 的特征构造 | 展开时替换模拟位置、速度及误差，电流等通道仍来自对应记录 | 记录条件下的轨迹预测不能直接充当候选命令的反事实预测 |
| [models/transformer.py](https://github.com/Frank-ZY-Dou/Dynamics-Modeling/blob/541a93aac4368e73883e86a51f31a7add6bde059/NeuralActuator/models/transformer.py) | 历史编码后有不同输出头 | 可借鉴共享历史，但应分别核验各头的监督、物理含义与可信范围 |
| 训练器中的非有限状态处理 | 训练保护路径可使用目标位置恢复状态 | 本项目的候选评估必须将非有限结果计为失败，禁止借未来真值“救活”预测 |
| 训练/配置的验证与恢复逻辑 | 存在按命名为 test 的指标保存/恢复权重的工作流 | 本项目显式分开训练、开发选择与封存测试，不直接照搬其数据命名和选模规则 |

论文附录还暴露了时间对齐、离线代理目标及平台条件的重要性。接入时必须自行规定信号时间戳：输入是什么时刻可得，输出对应哪个物理区间，监督是否偏移一个采样步。不能把微小的对齐错误学成“材料迟滞”。论文所报单网络推理耗时也不能代替完整观测—估计—规划—控制周期的尾延迟测试。

## 4. 为什么不能直接与 PANN 相加

希望使用的物理分解是

\[
M(q)\dot v+h(q,v)
=S^\top\tau_{\rm act}
+\sum_i J_i(q)^\top\lambda_i
+J_{\rm ext}(q)^\top f_{\rm ext}.
\]

这里：

- \(\tau_{\rm act}\) 是作用于关节的执行器输出；
- \(\lambda_i\) 是已经通过接触模型计算的各足作用；
- \(f_{\rm ext}\) 是不属于已建模足地接触的其他外部作用。

在固定基机械臂上，接触的关节空间作用可能被等效力矩吸收。对于浮动基，只看驱动坐标投影时，混淆可示意为（\(S\) 为标准驱动坐标选择矩阵）

\[
\tilde\tau
\approx\tau_{\rm act}+S\sum_iJ_i^\top\lambda_i.
\]

这不吸收未驱动六个基座方程中的接触 wrench；完整浮动基作用不能只由关节力矩头替代。若整体模型吸收它，需要全维等效广义力或完整状态转移表示。再把已经吸收的 PANN 接触作用加进去，仍会造成相应分量的重复计算。即使短期状态拟合很好，内部归因也可能错误；换地面、载荷或命令后可能失效。

这说明我们需要明确的“每项作用只出现一次”的模型契约。可以研究以下两个独立基线：

1. **整体等效模型。** 网络直接预测完整命令到运动响应，不再叠加同一份已吸收的接触力。它可做性能基线，但不据此宣称材料参数被正确辨识。
2. **可分解模型。** 执行器只预测驱动输出，PANN 负责地面，其他未建模效应用受限制的残差表示。它更适合解释与控制，但需要额外辨识证据。

PANN 本构势还需经过接触几何、面积积分、边界和历史状态求解，才得到 \(\lambda_i\)。同一足地作用也不能同时由物理引擎原生接触与 PANN 各加一次。其他外力头需要物理作用位置、支持范围或数据锚点约束，不能成为任意抵消所有误差的自由项。必须通过自由空间、已知接触与未知材料试验限制各头互相抵消。

## 5. 必须分开“观测器”和“候选动作生成模型”

### 5.1 观测器：解释已经发生的运动

\[
q_\varphi(a_t,c_t,\xi_t\mid y_{\le t},u_{<t})
=O_\varphi(\text{截至当前可用的历史}).
\]

\(a_t\) 为执行器隐状态，\(c_t\) 为材料参数信念，\(\xi_t\) 为材料记忆状态。历史中可包含编码器、IMU、命令、可读取的电流/力矩反馈、电压和温度。没有的通道不能假设硬件会提供。

这个接口可以使用实时测得的电流辅助外力/承载判断。它适合估计已发生的事件与当前状态。

### 5.2 生成模型：预测尚未执行的命令

\[
(a_{k+1},\tau_{{\rm act},k})
=A_\phi(a_k,u_k,q_k,v_k,\zeta_k),
\]

其中 \(\zeta_k\) 是已建模的供电、热状态等；未来值必须由相应模型推进，或明确作为固定/有界外生量处理。初始状态只用当前及历史观测初始化。

MPC 改变候选命令 \(u_k\) 时，未来电流与输出力矩也必须随之变化。若仍回放原轨迹的未来电流，就没有回答“换一个命令会怎样”。因此要增加命令到作用的因果建模，或直接训练命令条件下的执行器状态转移。

第一版候选展开只传播当前信念，不进行假想测量校正。因此它仍是实际部分可观测闭环的近似，不是完整真实 Bayes 闭环的精确导数。若以后预测未来学习收益，可以由生成模型采样假想观测并传播假想后验；但不得使用未来真实接触标签、力或电流，也不得把假想后验当作已经获得的真实证据。

### 5.3 两个接口可以共享编码器，但评价必须分开

观测任务看已发生状态/力估计误差；控制模型看候选命令的干预响应、方向导数与多步稳定性。观测精度高不推出反事实精度高，反事实状态预测准也不推出梯度准。

## 6. 执行器状态与材料状态应放在哪里

执行器的记忆跟随机器人和关节。例如同一电机走到另一块地面，热状态、命令延迟缓冲和传动迟滞不会留在上一块地面。

在当前固定基底、独立柱近似下，材料记忆跟随世界坐标中的物理地块。同一格被不同足接替踩踏，应继承加载、卸载和恢复状态；足离开后仍按材料模型演化。若引入侧向流动或柱间耦合，需补充材料输运/耦合关系。M1 已有世界坐标共享历史和零载恢复，不能记为本次新增创新。

因此扩展状态可写为

\[
z_t=(x_t,a_t,\{c_j,\xi_{j,t}\}_{j\in\mathcal C},
h_t^{\rm obs},s_t^{\rm ctrl}),
\]

其中控制状态包括相位、接触确认、持有命令、MPC warm start 与 WBC 内部状态。材料身份 \(c_j\) 与其历史内态 \(\xi_{j,t}\) 必须分开。固定未知材料的估计变化，不等于真实物性在变化。

训练不能默认所有真实隐态均已知。仿真真值可用于教师监督和 oracle 上界，部署排名只允许可取得的观测。

## 7. 怎样避免把执行器误差错认成材料参数

### 7.1 需要数据锚点

建议依次建立三种数据：

1. 自由空间或悬腿运动，辨识命令—输出链，尽量减少未知地面作用。
2. 已知刚性接触或可测外力台架，检查执行器模型在负载条件下的迁移。
3. 未知柔性材料上的加载—卸载—等待—重新加载，交叉改变执行器条件。

自由空间辨识不代表负载下也准确；这正是第二类数据必要的原因。开发阶段可临时使用力台或外部传感器产生监督，再测试部署时移除这些传感器的版本。不能把“部署无力传感器”写成“训练无需力标签”。

浮动基的六个未驱动方程能提供净外部 wrench 的独立信息，因为关节驱动项不直接进入这些行。但它不能唯一分离四只脚各自的作用，且惯量、基座加速度、接触位置和其他外力误差都要进入噪声或不确定性模型。

### 7.2 检验条件信息，而非只看拟合误差

对观测模型 \(y=H(c,\eta)\)，将未知材料初态、执行器状态与参数、接触几何和传感偏置归入 nuisance \(\eta\)。对白化 Jacobian，先检查数据本身提供的局部信息：

\[
F^{\rm data}_{c\mid\eta}
=J_c^\top(I-J_\eta J_\eta^\dagger)J_c.
\]

它仍是依赖当前线性化、量纲和噪声模型的局部诊断，不是全局唯一性证明。先验加持后得到的后验曲率要另报，不能把强先验制造的稳定估计当成数据已经识别了材料。

只在有效信息方向更新；其他方向保留区间/后验。若条件信息不足，控制器应按多种可能情况作决策，而不是强行宣布唯一材料参数。

### 7.3 参数发布必须保留能量与历史的一致性

候选展开内冻结材料参数版本，允许材料内态正常推进。参数更新后，用可得历史重放或有约束的状态转换得到新内态，并按材料参考体积记录模型储能变化 \(\Delta E_{\rm est}\)。短窗口重放不能恢复不可观测的完整历史；该能量变化不属于真实材料耗散。记账与重放也不是被动性保证，后者还需要明确供给率或更新预算；执行器模型若更新，另记其储能变化。

同样，接触事件可以触发观测器的模式切换；不能清零执行器延迟缓冲、真实热状态或世界材料记忆，只为让估计曲线更平滑。

## 8. 对五个模块的具体价值

| 模块 | 建议接入点 | 独立研究对象 |
|---|---|---|
| PANN | 将执行器模型作为观测链 nuisance，交叉辨识材料身份与历史状态 | 有限观测下能否避免“驱动误差被材料网络吸收”，提升跨加载协议适配 |
| 步态 | 估计触地、有效承载、离地及其时间不确定性 | 在执行延迟与软地接触延迟混合时，能否正确调整相位、承载时长和恢复序列 |
| MPC | 候选命令先过因果执行器，再进接触/刚体传播 | 在同算力与约束下，能否改善候选排序、前馈预测和实际可行性 |
| WBC | 名义模型包含执行链与材料响应，观测器只补未解释部分 | 能否减少过补偿、冲击与饱和，同时满足浮动基欠驱动约束 |
| RL | 将执行器及其记忆加入完整闭环导数 | 能否减少模型给出错误策略更新方向，而不是只降低状态 MSE |

可能形成的联合贡献是：**可分解的驱动—接触状态估计与因果预测，让同一份可审计的状态同时服务于步态、规划、执行和学习。** 目前这只是研究假设；添加一个 Transformer 或连接几个现有模块不足以证明它。

## 9. 最小可行实验：先验证价值，再扩大架构

### 实验 N0：接口与数据审计

确认真实可读取的命令/遥测、时钟、采样频率、掉包与限幅；画出每个特征的可用时刻。仿真端列出真实执行映射，区分理想 PD、显式延迟和其他执行器效应。此阶段不启动大训练。

### 实验 N1：因果预测

固定一组完整起始状态，对同一状态施加不同候选命令。比较理想 PD、经典延迟/摩擦模型、历史黑盒、可分解因果执行器。分别测自由空间与已知负载，报告多步状态、输出作用及方向响应。禁止未来电流回放。

### 实验 N2：交叉归因

最小设计使用“材料固定/变化”与“执行器固定/变化”交叉；训练与测试按组合整体划分。再单独留出恢复间隔，验证模型能否区分驱动变化和材料恢复。使用 oracle 只做上界，不给部署策略。

比较整体等效模型与可分解模型，既报告总动力学误差，也报告各物理分量误差和错误归因比例。若无法识别分量，应承认模型只适合整体预测。

### 实验 N3：闭环收益

保持 gait、MPC、WBC 权限和奖励相同，只替换执行器表示；看承载时序误差、冲击、滑移、饱和、任务成功率与端到端尾延迟。之后再测加入自适应 gait 或新 WBC 的交互收益。

### 实验 N4：梯度与实时性

先冻结 actor，审计完整闭环 1/3/5 子步方向。每个分支恢复相同的观测历史、延迟缓冲、材料世界状态、控制器内部状态与随机数。逐层区分模型自身 AD/FD 不一致、对高保真系统的导数偏差，以及接触切换导致的非光滑性。

方向未通过就不把该模型送入解析 actor 更新。实时测试包括传感输入、编码、模型、数据搬运、求解和动作发布；报告 p50/p95/p99、超期率及最坏观察值，不能只报神经网络均值。

## 10. 与当前 S1 的关系及实施优先级

已有稳定仿真基线，可以开展受控分支实验；尚无证据把新模块描述为已稳定落地。上一轮审计中的结构世界模型多步发散、冻结刚体映射和可信梯度时域为零的问题，不能用引入 NeuralActuator 绕过。

推荐并行推进：

1. 修复与验证现有结构预测的数值推进及完整闭环导数。
2. 做执行器/材料分离的接口和最小交叉实验。
3. 用固定低层控制器开展本体感觉自适应步态研究。

只有 N1/N2 显示明确收益，才把执行器模型作为联合架构默认组成。若目标平台上的简单执行器模型已足够，保留它做强基线，研究精力转向材料与接触；不为“模块数量”强加神经网络。

## 11. 工作流约束

六个研究工作包可以并行设计、实现和做小规模验证。重训练与高保真物理作业的并发数量必须由同组合吞吐、RAM/VRAM、CPU 和尾延迟实测决定，不以占满 96 GB 为目标。

后台任务按实验步数、迭代数、自然结束、数值失败与磁盘/资源保护条件管理，不设置任意墙钟完成时间或聊天结束 kill。控制周期的 solver deadline 仍保留，它与训练任务到点终止不同。
