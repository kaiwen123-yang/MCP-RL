## 1. 目标与当前距离

长期目标是：从可观测接触估计同一世界地块的可恢复材料状态，预测当前加载对其他足和后续重访的影响，让这个预测真正改变支撑、接触或落点决策，最终证明相对于无记忆/短历史方法的任务收益、泛化与部署价值。

当前已成立的是 **r55 与 r60 两个稳定的联合方法基线及材料执行接口**。四条原 E600 均完成十次合法往返，并保持到 600 s；两份冻结 nominal case 的任务稳定性已过关。r60 尚无一致的滑移/应变收益；世界材料历史尚未进入实际 MPC 候选选择；旧 frozen PPO 主要输出 scalar 速度 cap。工程正确性修复、CPU 后端替换与接口接通不能直接算作核心科学贡献。

| 层次 | 当前状态 | 后续可验收证据 |
| --- | --- | --- |
| 原任务与可比较基线 | 已有 r55/r60 A/B E600 | 复用资格和原件，避免原样重跑 |
| 步态质量与接触机制 | 对角摆动成立；有约 2 mm、约 100 ms 的前足再离地 | 原计划/测力/足边界/执行的事件对齐，确定是否非预期失载及首因 |
| 材料模块 M | 有因果持久状态与冻结本构 | 保留事件族上的未来响应预测、可辨识性和校准误差 |
| MPC 模块 P | 当前 normal reference 已接通；候选传播仍离线 | 历史改变未来预测、候选排名和实际首动作，且闭环有益 |
| RL 模块 R | 旧 cap 依赖显式恢复特征很弱 | 新低维动作真有权限，新策略确实学习；记忆盲对照另行匹配训练 |
| 联合方法 | 尚无独立和联合增益证据 | 冻结模块组合、必要消融、等预算联合适配与重复实验 |
| 泛化/实时/实机 | 本轮未验证 | 保留场景、扰动/传感条件、墙钟延迟与 Go2/NX 分阶段验证 |

不报没有定义的“完成百分比”或保证几天内完成创新。也不强求三个模块各自都必须产生一个新算法：主贡献可以是世界地块材料状态促成的跨足协同，其余模块以必要性和效果证明价值。新方法优于旧方法需要实验，不预写正结果。

## 3. 三条可并行的模块工作

### M：测力校正的持久世界地块状态估计

**问题**：冻结权重不等于材料状态冻结。当前 e/q 持续推进，尚不能把失败归因于“PANN 参数锁得太早”。需要区分本构失配、隐状态估计偏差、采样/面积/ownership 错误和决策通道不敏感。

**实施内容**：

- 在 CPU observer 上维护与因果 packet 同步的自身加载/卸载 history mask、owner transition 和 event ID。目前 `log=False` 时既有 `ever_loaded/last_owner/last_release` 没有可靠更新，不能直接使用它们，更不能在线借真 plant 的 q 或加载历史。
- M0 为原冻结本构的前推 observer。M1 保留该本构作为先验，利用已完成时间窗的足法向测力，对**可辨识的低维足印/事件状态方向**作物理一致的校正；自由地块按同一本构恢复。足总力不能唯一反演足下每格全部内态，不把同一残差随意平均灌给所有 cells。状态更新必须保持原应变域、非拉力条件与势能/耗散结构。
- 先在已发布完整历史上建立首次加载、释放、同足重载、跨足重访、长恢复的分组预测误差。训练/调参与保留按完整 episode 和事件族划分，不能把相邻子步/同一载荷曲线随机切分造成泄漏。已被用于诊断的 A/B 不是未见场景泛化集。
- 只拟合当前测力不算成功，必须评估之后真实接触的力、沉陷/恢复、切线及其校准误差。报告单位、分位、极值、事件数、独立 episode 数和决策敏感度。真 plant 状态仅用于离线误差/诊断上界。
- 只有保留数据证明本构权重误差是主要剩余原因，才启动一个独立的参数/PANN 校准候选；不与状态校正同时变成不可归因的大改。候选保持原物理结构、完整历史保留组和历史迁移检查，允许不采用新模型。

**交付**：M0/M1 的可复现保存输入结果、误差/可辨识性报告、状态接口、选择理由。若 M1 无独立改进，冻结 M0 继续 P/R；不以强行采用新模型作为完成条件。

### P：从当前材料参考到未来接触与载荷规划

**第一项同时推进的质量工作**：用已发布 r55/r60 再离地事件，按同一物理时钟对齐实际接触/足速度/Fz、名义与确认接触、目标 Fz、交接门、材料状态、normal inverse、WBC 和实际 PD 输出。先判断计划是否本就要求卸载，再定位第一个偏差。不能见到小跳就调刚度，也不能把 r55 已有现象说成 r60 新缺陷。

**P1 的最小真实决策入口**：

1. 保留 r60 标称 gait 和 xy 落点，先取得原 force-QP 候选。
2. 从同一已发布 observer 快照为每个候选独立复制状态，真实传播未来 footprint、owner、受载与恢复；将预测的 loaded sole z、法向响应和接触可用性进入未来几何/线性化/执行参考，产生一个材料修正候选。
3. 原候选和新候选都在**同一材料+质心预测模型**上复评同一原代价和原硬界后选择。不能比较两个不同模型下的 J，也不能把任意材料惩罚、force cap 或低 q 偏好藏进“原目标不变”。
4. 记录状态差→未来响应差→候选排名→选中 force/reference→实际 mapped input→下一接触结果。仅 rollout 日志非零或 QP warm start 改了，不算材料有实际决策权限。
5. 给定 F 反演位移再正算相同 F 只是本构一致性，不保证机器人可实现足轨迹；需要与实际运动学、WBC 与下个物理窗口的误差核对。

**同轮的升级方向**：如果仅法向几何通道在真实事件族中仍普遍过弱，不继续加同版本长跑；在同轮构建低频材料事件规划层，以真实 source-load→next-load 配对延迟覆盖下一次目标重访，保留内层 .35 s MPC / 500 Hz WBC。不能把 `prior_event_age_s≈1.36 s` 当成未来触地延迟，也不能直接把整个高频全身 horizon 盲目拉到数秒。比较候选有限且各自完整传播，不做盲扫。

事件层可以比较有限的载荷/接触交接请求；若要改变代价函数，必须另立公开的研究目标、单位、权重、版本与同目标对照，不能把它归因成纯历史效应。本轮优先完成一个有真实消费路径的规划接口，复杂 xy 足点搜索留待已有机制证据后。

### R：新的材料条件交接策略，首版只增加一个动作

旧 W44 A/B 速度 actor 始终 deterministic evaluation，新 head 独立训练。**不能把旧 `stream.training=True` 当成启动新 head 的办法**，否则会进入旧 PPO、target 和历史 deadline 分支，污染旧基线。

首动作固定为下一对角支撑交接的请求时刻残差：`a∈[-1,1]`，`Δt_request=a×0.050 s`，尺度来自已有 50 ms load-transfer ramp。`a=0` 对应原请求；所有原 confirmed/load-bearing、测力/求解支撑比例、release、body/angular residual 和已提交摆足完成条件保留。请求只能影响何时申请交接，不能强制在没有支撑时抬足。运行调度和 `_future_contact_feet` 必须消费同一请求。

保存请求动作、可用 mask、预测请求时刻、实际接受/生效时刻、延后原因、被零动作覆盖的原因。零动作一致性、非零请求确实有权限及控制约束核验用必要的保存状态和首条真实任务完成；不增加一套 mock/smoke 入场流程。如果所有动作都被门条件消掉，先修接口或说明无权限，不继续用学习曲线掩盖。

**事件顺序必须固定**：在 `walking_requested` 初始化好下一pair之后，以及每次真实liftoff完成pair切换之后，才为下一次交接采样一次动作；把本事件的 `nominal_due+Δt_request` 锁存到实际交接或自然终止，不每2ms叠加或重新后移。原runtime的旧 `joint.control` 早于F调度更新，不能直接照搬其hook读到上一pair。观察只使用已发布因果状态，记录publication、采样、请求和最近已完成WBC residual各自时刻；首次合法决策前不把尚未初始化的inf residual输入网络。若P事件层也提出timing，固定为“P先给base请求，R只对该base加一次残差，然后规划与实际调度消费同一最终请求”；候选评估必须按最终请求进行，P/R不能轮流覆写。P0时base就是原nominal请求。

新 head 使用独立、首条采样前冻结的 59D schema：每足 Fz/法向速度/confirmed/load-bearing/next-pair/planned-stance 共24维；四足×三个时距的因果恢复预测12维；请求时距/transfer fraction/body/angular residual 共4维；请求速度/COM速度/角速度共9维；上一动作1维；9个原 phase one-hot。尺度、排序、缺失语义见模块路线第5节；不复用旧658D normalizer。若实际实现需变更维数，先建立独立 schema 身份并写清原因，不能静默变换。

首版沿用标准 PPO 作学习基线，不把“timing residual + PPO”本身称作创新。潜在新增贡献在于世界地块材料状态提供的跨足决策信息，以及后续可独立比较的跨接触 credit。

#### W57 的有限新 PPO pilot

- **一个共享新 head，一个预声明学习 seed，8次 update ×256条，总2048条 distinct 真实 on-policy transitions。** 两条 collector 使用旧 A/B 速度 actor 作为明确环境 case；A/B 不是两个新训练 seed。
- 训练环境明确为**固定选定M、P0、原路线E60任务**，两collector仅旧A/B case不同；每个episode从其原virgin初态自然开始，原失败/60s终止条件保持。16个短重访episode是后续冻结评估，属于任务分布变化，不冒称同分布训练成功或已验证泛化。原速度cap的action_change继续明确为旧cap项，不能改称timing平滑罚。
- 每次两 collector 在相同 policy/normalization version 各收128条，收齐256后暂停采样，只更新一个共享策略，再同步。4 epochs，minibatch64，hidden64×64、learning rate3e−4、initial std .35、clip .2、value .5、entropy0、max_grad_norm .5，继承已有 PPO 参数含义并在 spec 冻结；新 actor/critic/optimizer/RNG 独立保存。
- 按实际事件 `Δt` 积分原任务 reward 的组成；折扣和 GAE 以原0.5 s决策基准换算 `γ(Δt)=.99^(Δt/.5)`、`λ(Δt)=.95^(Δt/.5)`。正确区分原物理失败终止与采样截断 bootstrap，不跨 episode 串接优势。
- 新建事件时长适配器：现有 `src/response_ppo/ppo_backend.py` 的Rollout无dt、tensor_gae仅标量折扣且默认action_bound=1.2，不能直接复用。新head显式 `action_bound=1`，有界动作与log-prob一致，避免实际变成±60ms；GAE保持两collector的 `[T=128,B=2]` 时间序列和各自终止mask，逐转移dt折扣，算好优势后才flatten为优化minibatch。只复用适用的上游PPO learn，不改旧W44适配器身份。
- 首 pilot 不同时新增不透明材料奖励；步态失载/冲击先独立记录。如确有必要新增质量 reward，则先独立声明身份、单位、权重及同 reward 对照，不能事后把收益全归于记忆输入。
- 2048是总真实转移预算，mask、实际作用动作及可用策略梯度样本另计；被完全 mask 的动作不冒充有效探索。旧数据、teacher rollout和重复 epoch 都不算新增 on-policy samples。
- 该预算只判断接线、学习方向与机制可行性，不承诺收敛或论文显著性。保存全部8次学习曲线与checkpoint，最终评价使用预声明最后checkpoint，不能按保留任务挑最佳。如动作完全无效，在本轮按证据修复并明确新身份；已花样本不重新算成可用预算。

## 4. 原任务与短重访机制任务分别验证

已发布 r55 actor 查询存在同圈跨足历史，跨圈约48 s的查询残余极弱；这不等于已经测过 r60 所有查询。原路线继续作为稳定回归，另建立**独立的短重访机制任务**，仍用原 plant/材料/硬界，从 virgin 原起点实际走入材料后交替踩踏同一地块，再返回。

每 episode 预声明12个目标重访周期；两类条件为“下一次可行交替踩踏”与“充分恢复后再踩踏”。间隔和总物理观察时长在第一次真实运行前，用已有原材料恢复曲线和真实 load→reload 配对一次确定并写入 spec；之后不因结果阴性反复调间隔、软化材料或改域。目标必须由实际卸载、下一次加载、同 world cell 面积重叠确认，持续静站不算重访。若无法实现目标重访，报告任务构造失败，不能把虚构接触用于评价。

独立 `task_mode` 保留原9phase/旧actor观察形状；实际目标从任务读取，原默认3/0保持。`home_hold` 之类 Stand phase 会禁用踏步，不能错误复用它来声称原地交替踩踏。局部零平移阶段若旧速度cap不被消费，应说明它是材料/接触机制任务；新 timing head 的作用仍需实际记录。短任务通过不继承原 E60/E600。

## 5. 先分模块，再联合：本轮就推进第一批可解释组合

M0/M1 用独立预测保留组选择；选定一个 M 后冻结，避免每个组合悄悄换材料。以下 B/P/R/PR 用同任务、同初态定义、同 hard limits、同一冻结 R1：

| 组别 | 规划 | 新 timing head | 比较目的 |
| --- | --- | --- | --- |
| B | P0/r60 | R0，零新增动作 | 相同研究任务的控制参考 |
| P | P1 | R0 | 前瞻规划独立作用 |
| R | P0 | 独立训练后冻结 R1 | 学习动作的独立作用 |
| PR | P1 | **同一冻结 R1** | 直接组合的互补或分布失配 |

本轮条件满足后，做这四组 ×旧A/B case ×短重访/充分恢复两条件的首批 **16个独立 episode**；真实 episode 身份各自保留，但两个名义 case 和大量事件不构成充分泛化统计。相同任务已有合格可复用结果不重复运行。若某模块无可用输出/原硬界下不能实施，不伪造其一组，交付可用组、明确阻塞和同轮已做的定向修复。不要为了凑满矩阵放宽物理限制。

材料历史因果干预作用于**候选私有副本**：保留当前实测接触/受载足的**完整几何footprint及共享ownership组**内全部cells状态、即时观测与主observer；不能只保护 `loaded=True` cells，因为同一足印内暂时零压力的cell也可能被相同足边界重新压到。只对当前真正脱离上述组、过去曾受载且未来候选会查询的cells，将完整 `(e,q,stress)` 设为 virgin。两组随后正常演化，不在 horizon 每步反复清空。当前 WBC normal reference 和 actor保持不变。该对照识别的是未来规划使用脱离当前接触足印的跨接触记忆作用，不是“所有记忆”。先做同状态完整事件族，再仅对确有执行差异的方案做必要闭环。

原任务中实际改变控制的候选，各自按原 E30→E60 取得基础回归资格；只有有新增科学信息且准备作为最终联合候选的版本，才继续自己的 E300/E600。资格仅复用实际未改动的r55/r60完整身份；若采用M1或改变在线observer/法向参考，B组也建立新控制身份、取得自己的E30→E60，表中P0/r60只表示规划器结构沿用r60。新策略、新任务同样不借旧资格。不能对所有离线消融盲目运行四级笛卡尔矩阵。

可报告描述性交互 `I_PR=(Y_PR−Y_P)−(Y_R−Y_B)`，但本轮小样本不能写成已证三阶协同。零新增动作不是“同权限无记忆学习策略”；后者需要独立训练。

## 6. W57 以后：论文所需的证据，不能提前宣称完成

**下一证据层**：多个独立学习seed、预声明扰动/保留任务；同权限、同网络、同训练预算的 history-blind 策略；full/private-reset、短残余/充分恢复负对照；固定 M 下 P×R 四组重复。若主张 M 改进必要，再以相同 P/R 比较 M0/M1。未实施 MR/MP/PR 等全部必要组合时，不声称三因素交互都已证。

**联合适配**：第一次先冻结组合。之后在固定 M/P1 环境中训练 `R_joint`，与 P0 环境继续训练的 `R_ind` 匹配新增样本和优化预算，祖先数据只计一次。这样区分联合适配与单纯多训。新 PPO 扩展预算需在对应计划/spec先声明；W57不默认无限延长2048 pilot，也不把它当永久训练上限。

**泛化与部署**：模型参数/载荷/传感噪声/延迟、路线和材料任务保留集，报告失败边界与episode级区间；按真实热点优化。500Hz逻辑控制不等于2ms墙钟实时，174历史GPU吞吐不等于单实例实时。Go2/NX还需核对足力/定位/边界采样的实际可获得性，不能把仿真0.2ms完美观测直接当硬件传感器。

## 7. 25核CPU、96GB GPU的执行组织

| 逻辑线 | 可同时做的工作 | 资源安排 |

| M/数据与材料批次 | 独立历史、预测保留组、observer/PANN候选、GPU批次 | 共享批处理/装配最多14 CPU核，GPU按真实batch需求 |
