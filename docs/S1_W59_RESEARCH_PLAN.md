## 1. 本轮要解决的主问题

长期目标保持为：在同一世界地块反复受载、释放、恢复和跨足重载时，从可观测信息估计历史，通过未来动作改变接触过程，并取得可重复的任务或效率收益。Go2/NX 轻量化与实机是后续目标，不把仿真稳定等同于实机能力。

当前已经有可用的稳定平台：旧 r55/r60 与新 W57 PR 的 A/B 均有自己的原 E600。当前缺少的是**材料记忆对实际决策与任务的增益**，以及能高效训练这类决策的预测器。W58 的主要新证据为：

- G1 自己通过 A/B E30/E60，早触后离力时间下降，但四组 slip 指标均恶化，故选 G0。
- M2 改善 release→reload 误差，却损伤短时预测；自由恢复误差与初态误差会相互抵消，不能只优化末端 MAE，故选 M1。
- P2 的候选只有 0/2/6 ms 等待，使用相同既定落点、触地时刻和预设加载场景；八条 P2-full 正式机制回合中 3,413 次非空私有历史干预没有一次改变候选赢家。
- W58 结束 56 个 attempts，其中 53 个自然终局、3 个技术中断；联合准入未通过，新联合训练样本/更新为 0。

因此 W59 的主假设为：**持久材料状态与真实执行模型必须成为同一套动作条件预测；在真实可用的动作空间中，模型必须同时预测历史如何影响承载，以及 MPC/WBC/硬门会怎样兑现请求。** SuperMimic 用来增加真实数据的学习价值，不用它替代这两个物理前提。

## 3. 要融合的是一个预测系统

令状态为 `s=(x, b, c, g, κ)`：

- `x`：机器人本体、足端运动和当前可观测接触量。
- `b`：按真实世界格点编号保存的材料估计、释放时间、已观测来源和不确定性；未观测格点沿用先验。
- `c`：控制器记忆，包括当前支撑/摆动、待执行请求、confirmed bearing/release、已承诺参考、held PD 命令与必要 MPC/WBC 缓存。
- `g`：路线、往返、回家与保持计时等任务状态。
- `κ`：控制器、模型、actor、动作接口和数值后端版本。

忽略 `c` 会把控制器相位造成的后继差异误学成材料随机性。`κ` 不同的数据可以用于预训练，但必须显式区分；当前版本校准不能由旧版本的平均 MSE 替代。

统一世界模型 `F(s,a,Δt)` 包括三个可检查部分：

1. 从当前 `x,b,c` 和已发布请求预测本子步真正执行的负载/命令/事件。
2. 用同一份负载推进材料恢复/受载状态与机器人动力学，更新下一 `b,x`。
3. 更新控制器与任务记忆，得到下一步输入。

不先用未知未来负载更新材料后再预测这份负载。若采用 predictor-corrector，先冻结迭代次数与一致性准则，所有对照同预算。

已知刚体关系 `M(q) qdd + h(q,qd) = Sᵀτ + Jᵀf`、PD 映射、坐标旋转和原数值离散规则用于结构化更新。网络补未知/不准确的执行与接触项。总预测 force/torque 受原约束检查，不能仅约束 residual 后任由总量越界。用模型预测的真实负载推进材料，而不是把名义 QP 力当作一定被实现的力。

`F` 对世界格点的位置、历史与动作条件保持一致；MPC、actor imagination、模型评价使用同一版本。模型不是视频生成器。视频继续用于检查真实行走和接触现象，无需给当前任务添加视觉大模型。

### 时间尺度

保持原 plant 0.2 ms、WBC 2 ms、force MPC 14×25 ms / 20 ms replan 的执行语义。模型训练采用多尺度记录：连续运动可按 20 ms 建模；触地、反弹、bearing、release 和 held-input 极值保留 2 ms/0.2 ms 的事件证据。宏步的端点正确不能替代区间内接触与保持正确。

官方 32×20 ms = 0.64 s 不是当前约 1.2 s 跨足恢复的全部时间。先验证 0.02/0.10/0.35/0.64 s；对真实 release→reload 分布单列约 1.3–2 s 的预测。以模型校准决定可相信的展开长度，超出部分由真实数据训练的 value 承接；不能因目标更远就直接对 20 s 宏事件想象做 BPTT。

## 4. M3/WM：模型工作必须一次做完整

### 4.1 现有数据与三套模型对照

从 W56–W58 已发布原件抽取带版本的连续片段，优先使用已在 D57 的原件或已迁移清单指向的存储位置。冻结 E600、训练 rollout、原资格、机制 development/validation、技术中断尾段各保留来源；中断不当成功，也不伪装物理失败。W58 validation 已经参与本轮分析，之后只能作为 W59 开发资料，不再宣称它是 W59 未见保留集。

建立同输入、同数据的三套对照：

- A：现有 M1 + 解析/原执行预测，不训练新的大网络。
- B：相同因果状态与动作输入的通用 learned execution WM，作为黑盒结构对照。
- C：M3 材料记忆 + 已知动力学 + 执行残差的结构化 WM。

B/C 使用相同回合划分和拟合预算。每套可学习结构采用三个 model seed 5901/5902/5903，作为 ensemble 与拟合重复；这三个 model seed 不冒充三个 RL 学习 seed。episode、同一材料历史链及相邻片段不能跨训练/验证划分。

初始每个拟合身份 10,000 个优化步；若预先固定的验证损失与事件误差仍改善，按 30,000、50,000 的累计节点继续，B/C 使用相同规则并记录实际计算量。公平主表只比较 B/C 共同累计节点；某一结构额外训练单列成本，不叫同拟合预算。这是计算量边界，不是墙钟结束时刻。对任务收益的判断仍使用独立真实执行。

### 4.2 M3 要修的是恢复链，而不只是最后一个误差

分别拟合/诊断 release 初态、无载恢复律、重新加载接触解。当前单足合力不足以唯一辨识每个格点的完整内部向量；保留原物理先验，只学习可观测的低维校正和区间。可使用保持凸能量/非负耗散结构的参数修正或有界恢复时间尺度，不能向每一隐变量自由回归却称完成辨识。

真实 plant 的材料常数、应变域、摩擦和终止判据不变。学习器可以改善自己的材料预测，不得改 plant 来制造更强历史效应。真 `q`、真材料恢复状态只用于明确标记的离线误差分解，不进入在线观测、actor、planner 或公平模型训练输入。

训练目标覆盖当前力/深度、20.2 ms 短预测、释放后的多个无载时距及首次真实跨足重载。同时检查误差符号和分项抵消。已知初态上的 free-law 改善与未知初态上的端到端改善分别报告。新 M3 的晋升必须保持旧短预测质量；若仅某一事件域有效，可做有根据的域内模型与不确定性回退，不把全域版本强装上线。

### 4.3 执行 WM 必须输出的量

至少包括：下一本体状态、请求/实际交接时刻、touch→rebound→bearing 过程、实际载荷和压陷、接触滑移、正机械功、区间最低高度/最大姿态或力矩、任务进展、失败与数据截断标志。不以数据量很大的静站/平稳帧淹没接触事件。

动作记录保留四级：requested、reference、solved、measured。必须学习“请求变化但硬门挡住、真实结果不变”的区域；不能把每个 proposal 都算一次已实现动作。自由恢复与执行残差使用不同可解释输出，防止网络把触地偏差吸收到材料状态里。

材料及微小历史差的基准复算保留 FP64；神经训练先 FP32。BF16/TF32 只能在关键物理量、候选排序和梯度方向等价证据支持后使用，不照搬官方速度配方。GPU 内存按实际模型需要分配，不通过复制无用 batch 占满显存。

## 5. P3：给予历史有意义的动作通道

第一版宏动作在每次真实交接请求处一次发布：

`a = (due offset, transfer ramp duration, pair load preference)`。

初始设计范围为 due offset ±50 ms（沿用已存在的 timing 权限）、ramp 40–80 ms（零动作对应原 50 ms）、两条有效支撑足的载荷偏好参数 `rho∈[-0.10,0.10]`。它表示等量反向法向偏置：按原leg ID排序的incoming pair第一足参考加 `rho*m*g`、第二足减同量，保持总法向参考不变；仅两足实际可承载时施加，否则记为未兑现。它不是乘法权重。偏好统一经原QP/WBC可行集求解，不能分别截断两足后破坏合力。load preference 是 QP/WBC 的偏好，不是强制真实力；总支撑、摩擦锥、总力矩、mapped input、关节与原 bearing/release 判据均保留。若当前可行集合拒绝偏好，记录未实现及原因。正式采集前用当前真实可行集冻结物理有效范围，禁止用测试结果事后扩权。

具体接线位置：W57 `_new_handover_request` 发布结构化请求；`_update_schedule` 与 `_forecast_events` 消费同一 request-specific ramp；`_redistribute` / force horizon 对实际 active contacts 施加偏好；`select_force_plan` 为每候选推进自己的负载历史。禁止只改计划里的时刻、只改实际执行一侧，或在 PD 映射后再加一份 residual torque。新接口零动作必须还原共同内核：nominal due offset=0、ramp=50 ms、load preference=0。

P3 保留原稳定 force MPC/WBC 作为执行内核，新增事件层候选搜索。第一版用名义候选及三维正负邻域检查动作有效性，之后以同一固定候选预算（初始 64 个候选、2 次迭代，含原名义解）开展模型搜索；这是算法的动作搜索，不是按最终分数反复搜超参数。候选必须分别产生自己的触地/加载/恢复后果。原 0/2/6 ms 同载荷打分不能改名当 P3。

同一状态比较 full、private、无历史网络，以及固定等待/固定载荷偏好控制。private 只在预测副本中去除已释放、目标相关格点的历史；保护当前完整受载足印及共同拥有关系，真实 plant 不重置。所有臂具有相同候选、动作边界、代价、数值精度和计算预算。

初版不在已承诺摆动中突然换 XY。几何工作线可以同时开发**起摆前**的小范围落点选择：只有已有证据表明重复落点不交叠是阻塞时，将可达足域内的前后向 landing offset 作为明确新身份加入全部对照，先从原内核的真实可达集合推导边界，不能靠搬足/重置材料保证成功。该身份重新取得自己的资格，且不能把它与旧固定落点控制的差异全部归因历史。

## 6. R3 与联合算法：明确哪里有梯度

采用官方 SuperMimic 的循环思想：真实闭环采集 → 多步拟合 WM → actor 更新时固定 WM 参数 → 短 rollout 回报加 critic → 回到真实闭环校准。冻结参数不等于切断对状态、动作的导数。

R3 使用上述同一三维高层请求。旧 W44 speed actor 固定；新的 R3 替换 W57 一维 timing head 的这一职责，不能让旧 head 与新 head 在同一次请求上叠加两份 timing residual。P3 给出共同的事件计划；R3 输出有界修正，实际内核只消费最后一个规范化 request。

唯一合成式为 `a_request = Project_A(a_P3 + Scale * tanh(r_theta(s,a_P3,margin)))`；`Scale=diag(0.05 s,0.03 s,0.10)`，`Project_A`对总请求统一应用上述绝对边界/可行域；ramp用绝对秒表示，50 ms零点与40–80 ms非对称余量通过该最终投影处理，并记录饱和比例。R3零输出严格还原P3，P3的名义ramp为50 ms，但R3零残差不会强行把已选P3 ramp改回50 ms。Actor观察P3 base及有效裕量，不能把两份分别有界的动作相加后越权。

P3/R3只在合法事件请求处产生新macro action；20 ms模型子步持有pending request并更新 `c`，32子步仍是0.64 s，不是32次宏动作。下一合法事件才重新调用P3/R3；force MPC仍按原20 ms replan，不能将事件层与力层时钟混用。

WM 学习的是最终请求经 force MPC/WBC/硬门之后的后继；BPTT 通过这个可微近似传播，不声称对 MuJoCo 求导。QP 活动集、candidate argmin、clamp、脚切换、world-cell寻址/足印所有权切换和硬门不是自动可微。固定连续分支内可固定寻址/事件身份或验证插值；跨格点/接触模式用候选分支及真实排序检验。第一版对 P3 的离散选择停止梯度，保留其前向调用；这是有偏的局部/半梯度近似，必须通过真实更新方向检验，不称整个控制器端到端精确求导。需要完整连续 MPC 梯度时另立有明确可微条件的身份，不把它混进第一版。

critic 先用真实 executed transitions 训练并校准，再加入有独立权重和来源标记的想象 λ-return。使用实际 `Δt` 的连续时间折扣，例如 `exp(-βΔt)`，不要把不同事件时长当相同一步。reward、done、truncated、mission complete、qualification observation continuation 分开：完成任务后的价值按任务定义吸收；原 E600 剩余观察仍真实执行，但不继续给虚构进度奖励。保持计时用原细粒度信号，不能用 20 ms/宏事件端点漏掉内部违规。

策略更新记录实际 accepted steps、参数变化、触发 KL 与最终 KL。普通 PPO/混合参照若使用 KL 界，检查更新后的解析 KL，并用独立参数及 optimizer 快照回滚/缩步；不能重复 10 月 20 日“先检查后一步越界，剩余只训 critic”的旧问题。模型梯度不可信时，其权重为零；可以保留真实 PPO 或候选规划继续推进，但必须如实报告该分支未获得路径梯度收益。

联合训练是交替协调：控制器源码、动作接口与plant在整个身份内固定；actor在封口的128×2事件batch内固定，两个stream到达合法请求同步边界后可按合同更新版本并继续同一episode，不能在held PD中段更新。WM可后台拟合，但发布到collector仅在共同自然episode边界，旧/新版本transition分开标记。WM发布采用非阻塞待发布：仍有未封口batch就继续旧WM，不让先到episode-end的stream等待新WM而堵住另一stream的128屏障；到预定采集节点、batch封口及两个自然尾均完成后共同发布。不能要求actor必须等E60自然结束、同时又让满128的collector原地等待它更新，否则形成死锁。WM只由数据拟合，actor loss不反向修改WM来制造回报。P3 搜索、R3 想象、M3 更新共享状态与误差口径，三者不各用一个矛盾的未来。

## 7. 本轮完整实验顺序与并行工作

### 阶段 A：立即并行，主要复用已有资料

1. 数据与 M3：形成可重放的因果 episode bank，拆分恢复误差并训练 B/C 模型。
2. 执行 WM：拟合接触事件与请求兑现，进行不同时间长度的开环校准。
3. P3/R3：完成新动作接口、真实任务 critic、候选搜索与官方训练循环的适配，准备版本化控制器。
4. 步态/几何：复核接触点滑移、早触冲击、四足相位与漏目标，设计独立机制任务与保留集。
5. 真实数据：在新接口有完整因果接线后取得自己的 A/B 原 E30/E60，并收集缺失动作覆盖；不重复旧 PR E600 证明能走。
6. 整合/交付：统一数据身份、资源、日记、结果和 GitHub 直交。

模型训练和 learner 实现不必等待材料历史已有正收益；大规模物理训练必须有可用动作和可信模型依据。某一分支失败时，其他独立问题继续完成，不因 G1/M2 未晋升而整轮只交一次探针。

### 阶段 B：有限但充分的真实行动检验

预选24个完整状态，全部位于合法 `_new_handover_request` 边界。按不扰动参考接下来出现的刚地/平稳、早触或搜索、材料跨足重载分别预分8个，标签在看候选结果前冻结。中途早触/search快照只用于事实预测；若从它续跑，必须先按完全相同前缀到下一合法请求再扰动，禁止热改已承诺宏动作。每类预先分4个开发、4个封存准入，合计12开发+12准入，二者互斥。每状态执行2条完全相同nominal用于重放噪声底，加三维±扰动6条，共8条；每条最多2 s模拟窗口，至多192分支/384 s物理，其中准入集96分支/192 s。按原失败条件提前结束。冻结状态、扰动幅度与归类后才看结果；WM、动作范围、超参冻结后才解封准入集。使用两个扰动幅度时在固定预算内预分配，不按方向挑幅度。准入集一经用于改模型即成为开发资料，不能继续称未见；新模型需新登记且独立的准入证据，否则路径梯度分支保持未准入。

需要完整 robot/plant material/observer/controller/task/RNG 状态和时间。只有 qpos/qvel 不足以恢复；旧快照缺状态时，在上述新资格回合中一次性补采，不伪造反事实。所有额外物理都计费，分支不充当完整 E30/E60 资格或独立学习样本。

比较预测与真实的请求有效性、事件时刻、负载、接触点滑移/功、任务回报；固定模式内报告方向导数，跨模式报告候选排序。nominal 重放误差与不同微扰尺度给出噪声底。预注册 bootstrap 单位为初始状态/完整回合；不把同一状态多个方向当独立证据。

模型进入策略梯度阶段至少满足：在未用于选择模型的行动检验中，预测改善方向的真实配对效果高于重放误差；方向正确率的回合/状态 bootstrap 下界高于 0.5；真实 hard failure 不增加。小于误差的变化记为不可分辨，保留在完整分母：同时报告全部方向、可分辨方向的正确率及不可分辨比例，不把删去无效请求后的条件正确率冒充总体能力。各接触阶段分别报告，不能用大量刚地好样本淹没材料/换脚失败。

### 阶段 C：先证明可执行规划，再比较学习效率

固定共同版本后比较 B3（共同内核）、P3-full、P3-private、Fixed action 四臂，A/B × short/recovered：16 条完整开发机制回合。为M3晋升进行固定execution predictor/planner/R下M1/M3配对：P3-full×A/B×short/recovered，共四对；复用开发矩阵中同身份M3的四条，另外补M1四条。未通过M3离线候选准入时，不启动其物理；通过离线门后，以候选身份取得原资格并完成配对，再决定闭环晋升。若声称M3闭环泛化，保留集同样另外补M1四条，与已有M3四条配对。新增身份的资格另计。B3、Fixed action、P3两臂中每个真正新身份，在正式机制前都各自取得A/B原E30→E60；未改变且有完整相同身份资格的对照可直接复用。若动作接口改变，旧版本资格不继承。

原 12 目标 protocol 保留旧判。新协议先根据实际足印和足序建立机会分母，保持区域/源释放/重载/同格交面积的逐条记录。开发几何与独立保留几何在看候选算法结果前冻结；若固定路线无法提供充分正交叠，应明确设计同几何、同历史干预的踏步/重复足印子任务，再由原往返验证任务意义，不能把子任务成绩当原任务成绩。任务收益与严格机制覆盖分开报告，缺失目标仍在分母里。

有可用模型和动作时启动 R3。主比较四臂：

- `PPO-full`：普通真实数据 PPO、同新动作权限与完整材料信息。
- `Diff-full`：使用官方启发的短 WM rollout/BPTT，完整材料信息。
- `Diff-private`：同Diff-full，但在模型/规划/actor新增历史通道执行对应私有历史消融；当前接触测量与硬门不变。
- `Diff-fixedWM`：与Diff-full相同初始WM、actor、动作、数据预算与BPTT，但WM参数始终固定；材料观测状态仍因果演化。它用于检验交替适配超过冻结模型拼接的增量，不能用“R不训练”替代这个对照。

private消融除释放格点查询外，还应遮蔽/重建新execution recurrent state及actor输入中可直接携带这些被移除格点历史的通道；保留当前测量及共同控制记忆。因此结论限定为新增持久材料历史的增量，不声称系统完全没有任何历史信息。

每个学习seed使用相同mean/residual网络初始化与初始执行行为、相同奖励、真实采集预算及模型准备规则；PPO std/entropy与Diff采集噪声在正式采集前固定并公开。PPO保留原采样变量/logprob，WM使用最终规范化request，不能对clamp后的动作套原Gaussian密度。

各arm/seed的在线replay、WM、actor、critic、norm、optimizer独立；可共享同一离线准备bank并公开其共同成本，不能暗中共享其他学习臂的新物理数据。若改用共享在线池，必须让全部方法访问同池并按全池真实交互成本重新定义比较，不能继续称每臂只用了8192。模型训练计算、想象步和真实步分别计数；不能把几十万想象步算新真实交互。保留无梯度/冻结 R3 的规划控制，以区分 P3、动作权限与新学习的收益。

先执行seed5901的四臂各2,048条去重事件转移；当前版本有有效动作、模型方向可信且没有不可接受退化时，同轮推进 5902/5903，并按累计 4,096→8,192 结点完成三个学习 seed。最多12 heads×8,192=98,304条实际用于优化的去重事件转移；相邻转移并非统计独立。自然尾回合、开发分支、资格和评价都另外计入真实总交互/墙钟成本，不能把98,304写成总物理量。尾数据若用于WM/critic，也须计入该head学习数据预算；公平主表不暗用未计费尾数据。分别报告observed/used/tail-excluded计数，实际预算和未运行原因逐head记录。学习 seed 与 A/B 环境 case 分开。不得挑 held-out 最好 seed 作为主结果，长测展示 seed 预定 5901。

每seed最终预算 `N_s` 根据Diff-full预注册开发准则在共同节点选定，并在保留评价前锁定；PPO-full、Diff-private、Diff-fixedWM均独立到同一 `N_s`，主表只比较共同完成节点。不得因对照效果差而少训；未完成head记不完整。WM/actor 更新边界不热换旧 collector 身份。每个 two-collector campaign 原子持有两个物理槽，直到两个自然尾回合完成，不能每个 campaign 各占一个槽互相等待。

首次策略参数更新另设真实方向检查：每learning seed预锁8个不同于上述开发/准入集的合法request状态，比较更新前/后各一次完整2 s continuation，未来合法事件重新真实调用P3。每head16分支/32 s；12heads最多192分支/384 s，全部计入真实成本。该检查回答actor参数更新是否兑现，不能用action局部Jacobian代替。数据不能回流调参后仍称未见；若更新拒绝，回滚参数和optimizer并保留提议/拒绝计数。

独立保留评价：若四臂×三seed均执行，学习身份12×4=48条A/B×short/recovered，加B3、P3-full/R0、P3-private/R0、Fixed action四个共享规划对照×4=16条，共64条。若同时宣称M3闭环泛化，再补M1/P3-full四条与已存在M3配对，合计68条。若只完成P3为16条，含新增M1材料对照则20条。上述数量只计机制回合，不含资格、方向检查和训练。每个新冻结learned head在其正式保留机制前先取得自己的A/B原E30→E60；符合长测门后按预定展示seed5901继续。所有保留路线、任务变体、完整分母与选择规则先冻结。A/B 不是两份泛化分布；新材料参数/速度泛化另列，不从两 case 推断广泛鲁棒性。

每个要晋升的 controller/actor 身份取得自己的原资格，按 E30→E60→条件 E300→E600。已通过的同身份资格直接复用；稳定性/效率门不通过则不加长，继续完成可回答的模型、动作和算法比较，不靠无限延长旧负版本追正结果。

### 结论分叉必须明确

- 材料历史显著改变实际动作且带来收益：推进主线与多 seed/泛化。
- WM 改善执行/步态，但 full/private 无差：保留执行预测与学习效率结果，不称材料记忆收益。
- 可用动作不同但历史效应低于误差：明确当前 plant/任务的效应上限；不放大材料常数、缩小噪声估计或改阈值制造结论。
- 模型梯度失败、候选排序有效：继续模型辅助MPC/CEM/PPO。仅当局部导数可信而长展开前向漂移是主要问题时，才将DMO式真实前向列为备选；它仍需要可信局部Jacobian。Diff回退到PPO/混合更新必须建立带fallback标志的新算法身份，不能将其收益计作纯BPTT。

## 8. 资源与六路并行

W58 已测到 scratch 六物理流的总速度 0.14347 模拟秒/墙钟秒，比可比四流约 +47.7%，并非只能运行两路。但混合存储的旧四流扩容失败，后续六流也有一次每流低于阈值，不能固定宣称六路总是最好。

沿用统一共享租约。物理核池至多18核，数据/材料/构建至多4核，系统/交付/其他项目至少3核；所有值受现场其他项目实际占用约束。数学库线程1，显式 native workers 和子进程另计。W58 当前身份 native workers=1，不能把旧 W57 四 worker 约定机械复制。

| 阶段 | CPU 物理槽 | GPU 工作 | 其他并行工作 |
|---|---|---|---|
| 已有数据拟合 | 2–3 条新接口资格/缺口采集 | M3/WM 三成员批量拟合；B/C 对照 | 几何、真实任务 critic、数据与交付 |

六个研究工作流不等于六个双 collector campaign 同时运行；后者需要12槽，超出本合同。单 GPU 优先批量化/统一调度，若两个独立 GPU trainer 的合计有效更新吞吐增加再并行开两个。不给每进程硬凑固定显存。记录 GPU 活跃率、显存、有效更新/秒、数据等候，以及真实模拟秒/墙钟秒、各流速度、P95、RSS/I/O、其他项目占用。缓慢 I/O 不能靠加 CPU 解。

重用 W58 合格六槽证据作为起点，在当前自然运行窗口确认；有新存储、模型负载或其他项目变化时按3→4→6实测。降并发只停止接纳新任务，让现有有效任务自然结束。不得因为回合结束间隙、训练同步点或对话结束杀进程。

## 9. 步态与证据质量

将稳定、接触质量和效率分别评价。保存：四足相位/周期变异、占空比与对称性、抬脚高度、早触冲击/反弹/重新触地、确认承载后失载、身体高度/姿态、实际接触点滑移、正机械 CoT、全任务完成时间与末段保持。

W58 矩阵的 `loaded_center_slip_per_m` 包含球足中心运动，与 G1 使用的 `slip_s_per_m` 不是同一个指标。W59 新主接触滑移从真实接触点切向速度计算，明确球足转动、接触法向和地面速度；旧指标保留并列，不事后换指标撤销旧选择。模型与各臂使用相同定义。CoT 指正关节机械功/重力/路径，不是电池效率。

视频提供全程及起步、材料进入、直行、换向、重载、回家保持的固定片段。帧率与物理时钟对应；几十毫秒接触事件由原始接触/足速日志确认，不能以视频看起来平滑代替。
