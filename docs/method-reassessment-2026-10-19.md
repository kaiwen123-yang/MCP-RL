# 负结果后的核心方法重审：预测事实、响应设计与真实反馈

日期：2026-10-19（Asia/Shanghai）。依据：776cdb5保存的固定服务器实验、既有评价分析、原始A/B/C日志和当前源码。本轮仅作既有数据统计、源码/数学推理与直接近邻核查；**没有训练、新环境采样、模型或actor前向、参数更新、服务器连接或自动检测**。原方法与冻结实验配置没有改动。

## 1. 核心判断

此前把“同一个闭环响应既供规划、又作为策略需要实现的目标”具体化成了：**先允许预测器直接降低自己的任务成本，再让有限次PPO追赶这个预测目标。** 这没有把响应目标的变化充分绑定到真实反馈的变化，是应当撤回的具体实现选择。

已确认大问题和MPC规划、RL执行结构继续保留。需要共享的是一项由真实反馈支持的闭环响应关系；学习过程中尚未实现的期望，不能直接冒充当前可用的预测事实。

这次负结果不是只有“指标不好”：可以从目标函数说明一种不需要真实行为改变、却能让模型自评变好的下降通道；日志和末轮预测偏差与这一机制一致。但当前数据没有证明所有失败只由这一条通道造成，也没有排除有限优化、状态表示和任务设计的影响。

推荐的结构改法是：**在实际策略所诱导的响应集合中做任务设计，预测器学习描述它；任务不能通过自由改写预测器的输出实现“改善”。** 这是改变优化对象和信息流，不是提高拟合权重、增加校准次数或外加发布检查。

## 2. 为什么模型会变乐观：目标函数确实允许这样做

原模型块为

\[
L(\phi)=L_{\mathrm{ID}}(\phi;D_{\theta_k})
+\lambda J_g(\phi;\bar C),\qquad\lambda=0.1.
\]

在这一块内，actor、真实数据及记录命令序列\(\bar C\)固定。第一项希望模型描述已经发生的响应，第二项却希望模型预测一个任务更好的未来。代码直接相加，见[learning.py](../src/task_response/learning.py#L149)。

### 一个与训练量无关的局部机制

假定\(L_{\mathrm{ID}}\)和\(J_g\)在某内点\(\phi_0\)附近二阶连续可微、局部Hessian有界，且

\[
\nabla L_{\mathrm{ID}}(\phi_0)=0,\qquad
g=\nabla J_g(\phi_0)\ne0.
\]

沿\(d=-g\)移动小步\(t>0\)，有

\[
\Delta L_{\mathrm{ID}}=O(t^2),\qquad
\Delta J_g=-t\|g\|^2+O(t^2).
\]

因此任意正\(\lambda\)下，足够小的步长都可降低总模型目标，同时固定反馈、固定命令下的真实行为没有改变。若原来对该记录任务已校准，这就引入了乐观偏差。有参数约束时，结论限于存在相应可行下降切向方向的情形；不可微切换处不能直接套此展开。

这只证明目标允许这种下降路径，不证明本轮Adam每一步都沿它走，也不否定后来改变命令或actor可能产生实际收益。

### 更直观的目标偏置

真实响应恒为0，任务目标为1，模型自由输出q：

\[
\min_q q^2+\lambda(q-1)^2
\quad\Rightarrow\quad q^*=\frac{\lambda}{1+\lambda}.
\]

真实任务成本仍是1，模型自评却变为\(1/(1+\lambda)^2<1\)。即使数据完全正确且无噪声，这个平均损失的最优点也偏离事实；增加相同分布的数据不会自动移除偏置。

这个例子只解释目标语义，不是新实验、创新定理或另一条标量研究路线。它说明：**不能先把期望响应优化好看，再把有限次策略学习等同于已经实现该响应。**

### 不应误伤所有任务相关模型学习

任务可以决定“哪些预测错误更重要”，也可以通过模型引出的真实决策损失学习模型；这些不等于降低模型自己的预测成本。[TaskMet](https://proceedings.neurips.cc/paper_files/paper/2023/hash/91a5742235f70ae846436d9780e9f1d4-Abstract-Conference.html)和[VAML](https://proceedings.mlr.press/v54/farahmand17a.html)保留真实预测关系作为误差锚点。不能由本轮失败推出“任务梯度不能参与模型学习”或“只能最小化普通MSE”。

## 3. 既有训练数据支持到什么程度

[日志统计](../notes/method-reassessment-2026-10-19/log-analysis.json)只读取原来的15份阶段日志和已生成的评价分析，没有再运行模型。

| 既有证据 | uniform | codesign | 可以支持的解释 |
|---|---:|---:|---|
| proposal中任务项占已记录model loss的平均比例 | 84.93% | 87.57% | 模型优化的数值目标主要是完整预测任务项 |
| 任务项/辨识项中位数 | 6.21 | 7.73 | 两种目标值的尺度明显不同 |
| PPO B批匹配罚/真实任务成本总和 | 0.323% | 0.188% | actor实际接收的匹配罚在总回报中占比很小 |
| proposal对自身A记录命令低估真实成本 | 47/48轮 | 47/48轮 | 乐观并非只在末轮单个case出现 |
| calibration记录对自身C命令低估真实成本 | 47/48轮 | 47/48轮 | 切换为ID损失不等于已经恢复可靠预测 |
| 最终校准后评价：实际成本−模型成本 | +4.4364 | +5.7202 | 真实最终pair仍有明显整段乐观 |

需要准确解释这些数值：

- 目标值占比不是梯度范数，更不是因果份额。0.188%不能直接证明响应项完全没有梯度作用，也不授权把下一轮变成调大β。
- local与long-fit被归一到平均宏段尺度，任务项保留完整4秒成本；actor匹配是四步局部响应。时间尺度和语义不一致，不能只按系数0.1/0.2比较。
- 日志只保存第四次模型optimizer step之前算出的loss，即已经做过前三次更新；没有同批更新前和最终第四步后值。因此不能重建每次更新造成了多大变化。
- A/C数据、命令和actor版本不同，不能直接将两行之差称为校准改善。
- “辨识误差一路恶化”不是已知事实。uniform三个seed的跨轮ID记录反而都下降；codesign两seed上升、一seed微降。数据分布也在变化，不能用跨轮值推出单步因果。

结果与目标函数的结构风险相互支持，但保留上述不可识别部分。

## 4. 为什么真实反馈改变了，却没带来完整任务收益

### 4.1 任务要求没有通过可实现响应关系传给策略

模型能够在整个预测任务上直接移动，actor却只用实际任务回报加局部匹配罚学习。没有一项关系保证“模型提出的这次响应变化”属于当前策略在输入、执行滞后和预算下能完成的变化。

实际actor映射确实改变，末轮共同观测的动作差已核；但不同动作不等于实现了模型所承诺的后段响应。最终codesign三个seed均劣于uniform，成功0/24，不能拿真实更新发生过当作方法有效。

### 4.2 四个模块并未评价同一种任务后果

| 模块 | 代码实际评价的对象 |
|---|---|
| 在线MPC | 当前1秒预测窗口，并在窗口末端加入最终位置/速度罚 |
| 模型任务项 | 本批实际已经执行过的完整4秒命令序列 |
| W敏感度 | 当前1秒计划，随后保持末命令直到剩余任务终点 |
| PPO | 实际4秒过程中多次重规划、带探索噪声的执行回报 |

原terminal_cost不使用剩余时间，所以1秒窗口末端的目标罚不是4秒任务的真实终端条件。它可以作为NMPC启发式终端代理，但没有被推导为剩余任务价值。不能把这四种目标的导数统称为同一个“完整任务信用”。

短MPC问题为所有组共有，可能影响全组低成功率，不能单独解释codesign比uniform更差；候选额外使用模型持尾敏感度，又会受到这一代理偏差影响。增大预测时域也不是免费解法，必须保持计算比较与目标定义。

### 4.3 学习奖励依赖参考历史，但actor/critic没有看到相关信息

宏段开始时，程序根据起点和当时计划生成并缓存目标轨迹Q与W；逐步匹配奖励使用它们。actor与critic却仅见当前真实状态x、当前命令c和任务上下文。

剩余时间可推知宏段相位，不能说相位完全不可见；但是它不能一般地恢复宏段初态、参考记忆和当时计划。若两段历史到达相同可见输入、却带来不同参考目标，那么塑形回报存在状态混叠。

这不使动作概率记录或PPO比率失效。它会使带bootstrap的价值估计更难，并可能限制actor对不同参考要求作出不同反馈。日志没有reference-conditioned价值误差，不能把它指定为此次退化的唯一原因。

### 4.4 “C只做ID损失”不等于“已投影回真实响应”

proposal和calibration复用同一个Adam。当前C损失的任务系数归零，但优化器仍有A的历史动量。若一阶矩为\(m\)，C步仍含\(\beta_1m\)；默认\(\beta_1=0.9\)时四步之后旧一阶矩系数为\(0.9^4=0.6561\)。这个系数不是实际参数移动量或乐观误差的因果占比。

更根本的是，四次有限拟合本来就不是可实现集合上的投影，有限数据也不保证新MPC查询可靠。独立校准优化器可以消除这个混淆，却不能修复自由模型目标的偏置；不能把重置Adam作为整套方法的主要改法。

### 4.5 短段输出匹配不自动保持后续执行状态

真实对象中执行器状态a会影响下一步速度；模型用学得记忆m表达其影响，但匹配标签只包含位置、速度和资源。m可能学成充分表示，也可能没有；四步输出误差小不能证明其跨段延续正确。

这里m与a维数相同，现方案没有以降维收益证明隐藏真实状态的必要性。保留已可观测的执行器状态，或明确建立历史/记忆一致关系，是比调整输出权重更直接的表示修正。它不等于所有机器人都能直接观测完整执行状态。

## 5. 方法问题与实验不足分别裁决

| 判断 | 已有依据与可信边界 | 不应怎样解释 |
|---|---|---|
| 自由预测器同时追求拟合与降低自身任务成本，存在事实—目标冲突 | 源码与受限数学反例直接确认；真实实验的乐观模式与之吻合 | 不能说所有模型任务学习都错误 |
| 候选响应改变没有被动力学/策略一致性绑定 | 实现中先更新g，再有限PPO与软匹配；无已实现的约束关系 | 不能把有限更新等同内层已求解 |
| 任务后果/时间尺度不一致 | 源码直接确认，1秒/4秒/持尾/重规划不同 | 共有部分不能单独解释组间差 |
| 参考信息缺失、Adam跨目标状态延续 | 实现事实可核；影响大小未测 | 不能宣布PPO无效或将全部退化归于Adam |
| codesign在本预算下未胜uniform | 三seed、六个seed×任务格均更差，完整成功0/24 | 不外推为所有共同学习无效 |
| 各组学习充分性、强基线能力未建立 | 四组成功率都低，只有ordinary一次成功 | 不把uniform当成充分优化的最强方法 |
| 数据覆盖与泛化证据有限 | 8个固定评价条件、3训练seed，二维4秒全状态对象 | 不称24独立场景或机器人长程验证 |
| 随机学习与确定性部署分布有差异 | B批输入积分约0.866–0.871，确定性A/C约0.076–0.089；任务成本也明显不同 | 不是同条件方差测量，也不能自动认定探索噪声是唯一原因 |
| 精确因果份额不可识别 | 缺同批更新前后状态、参考条件价值误差和相关干预 | 不通过新加几个检查把未知变成已证 |

当前结果否定本配置新增任务度量的增量；它没有判定充分训练、不同可实现关系或正确任务表示下的所有方法。反过来，“实验还不足”也不能抹掉已经确认的目标语义问题。

## 6. 推荐的结构改法：在策略诱导的响应集合中设计

### 6.1 改变任务可以优化的对象

用h表示对实际执行足够的状态/历史。引入或复用动作条件动力学模型，并与真实策略组合：

\[
u=\pi_\theta(h,c,\kappa),\qquad
\widehat h^+=\widehat F_\psi(h,u),\qquad
\widehat R_{\psi,\theta}
=\operatorname{rollout}\!\left[\widehat F_\psi\circ\pi_\theta\right].
\]

\(\widehat F_\psi\)根据真实动作与后继状态学习，任务优化时固定其参数。任务更新进入\(\theta\)，通过动作与动力学改变响应；不能进入自由预测器参数、让相同反馈的未来自动变好看。

真实响应\(R_\theta\)仍以实际执行定义，\(\widehat R_{\psi,\theta}\)只是训练期可计算代理。若F是学得模型，它仍可能有误差，策略也可能利用误差；上述结构只消除“无行为变化、自由改写预测”的通道，不保证所有模型利用问题消失。

对于当前已知合成方程，可以使用精确F作为信息上界来理解结构，但所有对照必须获得相同信息。它不能冒称从有限数据学得的机器人模型。本轮不拟合新F、不运行该方案。

### 6.2 紧凑模型负责表达当前真实反馈，任务通过反馈改变其可表达性

供MPC在线使用的g仍保持紧凑，但它只根据当前策略实际响应及事实约束的预测误差学习。任务相关度量可以保留真实标签；直接的“让g自评任务更好”项退出事实预测器更新。

为保留共同设计目标，而非退回单向辨识，研究对象可以写为

\[
\mathcal E_{\mathcal G}(\theta;\mu)
=\inf_\phi\mathbb E_{\xi\sim\mu}
\!\left[d_{\mathcal T}\!\left(R_\theta(\xi),g_\phi(\xi)\right)\right],
\]

并研究在给定模型类别、在线预算与允许预测误差下，如何优化真实完整任务：

\[
\min_{\theta}
J_{\mathrm{real}}\!\left(\pi_\theta,\operatorname{MPC}_{g_{\phi^*(\theta)}}\right)
\quad\text{subject to}\quad
\mathcal E_{\mathcal G}(\theta;\mu)\le\varepsilon_{\rm plan}
\quad\text{及真实输入/任务要求}.
\]

其中\(\mu\)是每个设计阶段明确的起点与命令查询分布；变化后的规划访问分布还需要覆盖，不能假定所有期望已知。该式定义的是“任务有用且容易规划的实际反馈”，不是宣布有限Adam更新求得内层最优、约束已满足或算法已实现。也不以随意改变\(\varepsilon_{\rm plan}\)制造收益。

这样，**策略要学的是真实响应的性质；模型的容易预测来自行为被学得更合适，而不是模型被允许更乐观。** F可用于训练期信用与结构分析，部署仍由紧凑g上的MPC规划、RL策略执行，不要求在线展开完整F和actor。

### 6.3 若仍需显式目标响应，必须让它进入真实控制与可实现关系

期望响应T与当前事实预测P可以描述同一种运动，但在尚未实现时必须分清身份。可以把T作为策略明确可见的参考，或通过动力学与策略一致性产生教师；不能只把T自由优化好，再期待有限PPO默认兑现。

若T只是额外网络，仍可独立降低自己的成本，原问题原样存在。若仅删除原模型任务项而沿用其余结构，则接近已经失败的weighted_id，也不是完整解决方案。

当前优先采用策略诱导响应形式，把显式目标当其中受约束的表示或接口；不并行建设两个独立研究系统。

### 6.4 对齐任务后果与学习信息

短时域MPC应使用与剩余任务一致的终端价值或明确后续策略：

\[
J_N=\sum_{j=0}^{N-1}\ell_{\mathrm{task}}+
V_{\mathrm{remaining}}(h_N,\kappa_N).
\]

真正任务终点才使用原终端条件。V可以近似，但需明确它对应哪个实际后续控制器，不把保持末命令的价值当成实际重规划价值。

真实任务critic应保持实际任务含义；响应可预测性若作为辅助学习量，应有与其历史依赖一致的信用估计。若采用跟踪参考的架构，把所需参考误差/记忆显式提供给actor与相应critic，并向所有比较组公平开放。这里改变的是目标与状态定义，不是仅换GAE系数或增加网络深度。

对于当前对象，应优先保留可测的执行器状态；未来部分观测机器人再研究必要历史表征。任何新增状态或模型信息都必须同样提供给强对照，不能靠额外信息制造优势。

## 7. 为什么这不是已经确认的新算法

通过物理模型与策略组合传递信用已有[SVG](https://papers.nips.cc/paper/5796-learning-continuous-control-policies-by-stochastic-value-gradients)先例；动力学与策略一致性下的目标优化已有[constrained GPS](https://proceedings.mlr.press/v32/levine14.html)先例；可预测反馈与模型共训已有SPlaTES，响应塑形供MPC使用已有ReCo。参见[直接方案比较](../notes/method-reassessment-2026-10-19/alternatives-and-neighbors.md)。

因此，应建立一个强简单对照：**相同F、数据、策略容量、任务信息与MPC接口下的标准模型辅助PO＋纯监督响应辨识。** 如果它解释全部收益，就不再宣布一套独占的共同学习算法。候选潜在价值只能落在实际反馈的可规划结构、有限数据效率、预测可靠性或任务—计算取舍。

动作条件模型的可辨识性也不能省略：单个确定性策略只覆盖有限动作流形，低拟合误差不保证新动作方向的模型导数可信；策略版本ID也不能自动预测未见策略。本次保存的评价数据不足以完成这些新学习目标，当前不新增采样补齐。

## 8. 本轮作出的决定

1. 撤回“自由预测器直接降低自身任务代价，再靠有限PPO与校准兑现”的实现路线，不再靠增大拟合/匹配权重或增加更新次数维持它。
2. 保留MPC规划、RL执行及任务有用—真实可实现—紧凑可预测的共同目标；优先研究策略诱导响应的可行集合与事实预测。
