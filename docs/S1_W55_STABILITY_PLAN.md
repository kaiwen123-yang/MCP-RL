## 1. 当前判断与本轮完成目标

长期目标仍是同一世界地块的跨足、跨步、返程材料记忆辨识与协同控制。近期必须先取得原 Go2/TM02 的持续正常运动、合法材料贯穿和完整往返。增加存活时间、站住不动、数值求解可行和 GPU 局部加速，都不能代替这些目标。

W54 有 9 次不同版本原 E30、0 次通过；2 次控制器中断、3 次 body_fall、2 次 material_domain_exit、1 次非足接触、1 次完整 30 s 但未贯穿材料。没有合格内核，seed2 及 E60/E300/E600 未运行。F/r50 停在材料前；F/r51、r52 首次 z<.28 m 均在 4.880 s，真正材料施力分别始于 5.3196/5.3250 s。N/r48 最远 x=1.312010 m，有 12 次跨足地块重访，8.3568 s 躯干触地；没有完整去程/返程或材料记忆因果收益。

本次新发现改变了优先级：

1. **F 有可直接修复的官方已知缺陷。** MuJoCo 3.2.3 的平移 `mj_jacDot` 缺计算点移动项。r52 材料前 162 个摆足快照，用保存运动状态构成的中心差分运动学残差 RMS 从 2.5950 降到 .009986 m/s²；r51 为 2.5658→.009796。它解释了主要运动学不一致，但尚未经过修后闭环验证，不能承诺一次修完所有任务。
2. **N 的 E 虽然接线一致，支撑模型仍不完整。** 自由体 `J M^-1 S^T` 不代表其他脚承载时可用的制动能力。首次非足接触前的 243 个 E 激活 tick 中，169 个改动当前 >10 N 支撑腿。只守足底域的候选检查允许身体下坠；6.58 s 保存的全部 10 个候选都满足足域代理，却预测很低的机身。
3. **PANN 要独立审计，不能盲目解冻。** 真 plant 是解析 `ReferenceColumns`；网络权重固定但每地块 e/q 持续更新。当前使用 B ideal，而不是历史恢复偏快一倍的 noisy 权重。实际材料加载速率与训练采样路径有显著差异，需把本构误差、observer 采样误差、接触桥接和控制未使用状态分开。

本轮允许在三条既定线内进行有新证据的完整迭代；不是修一个小项、跑两次失败就停止。每次新物理身份必须对应具体模型或实现变化，不能原样重复负版本、参数网格或换 seed 追成功。

## 3. F：先修正确公式，再看真实执行

### 3.1 一次修全受影响的平移调用

基线是 `scripts/s1_w54_f_r52_backend.py:model_quantities`，冻结 plant 仍为 MuJoCo 3.2.3。依据官方 `de48f4178f971d945fc135afb42699b8ca6bec8e`，对固定于相应刚体的计算点，在世界坐标下使用：

`(Jdot_p v)_correct = (Jdot_p v)_3.2.3 + omega_body_world × v_point_world`。

实现为有明确适用版本的控制计算 helper 或等价局部 backport，并接通以下各处：

- 四足球心平移 Jdotv：使用该足所属刚体的角速度和球心世界速度。
- 全机器人 COM drift：逐连杆质心分别修正，再按质量平均；不能用一次 `omega_base × v_total_COM` 代替。
- 球底 rolling 约束：继承修正后的球心 Jdotv，再按现有世界固定 `r=-radius*n` 求 rolling 项。不要重新加入不属于当前几何点语义的向心项，也不要重复补一次平移缺项。
- base/foot 的角 Jacobian 导数不加此项。N 的运动学方向差分也不加。

当前 runtime 在控制前已有 `mj_forward`，没有证据是漏 kinematics/comPos/comVel。不能通过反复 forward、滤波、调 tracking gain 或放宽求解器容差替代这次修正。

### 3.2 必要验证围绕具体风险

## 4. N：把“减速一只脚”改为可支撑的全身动作

### 4.1 支撑约束进入 E 的响应模型

从 `experiments/terrain_memory/w54_e_native_r48.h`、`w54_e_core_r48.h` 及 Python 执行镜像出发，优先保持不含隐藏私有记忆的确定性执行映射。若当前支撑或因果材料状态影响输出，明确采用 `E(q,v,u_raw; support,z_material)`；附加输入在真实执行、native rollout 和 FD 中必须具有相同来源及更新语义，需要随预测演化的状态进入可独立克隆的转移，不能只藏在 Python 一侧。E 必须在真实 500 Hz、每个 native rollout 和每条 FD 扰动中同位置运行，之后仍是原 2 ms 位置输入 hold、5 kHz plant、PD60/5 及原限幅顺序。

用当前实测/当前预测支撑条件下的浮基联合投影替换自由体响应，推荐变量 `(qacc, tau, lambda_support)` 或其数学等价 Schur 消元：

- 同时满足全身动力学、支撑反力单边性、真实摩擦可行集、原输入和总力矩界及保持期间的可达界。
- 硬地当前承载脚使用实际接触几何和球足 rolling 语义；已进入材料的法向使用同一因果顺应状态/观测，不假设永久刚性平面。
- 触地前制动针对尚未承载且下降的脚。支撑和身体可实现性优先；期望落足速度不可达必须显式记录，不能让优化通过降低支撑腿力矩来掩饰制动成功。
- 不再把每脚 `sum(abs(H)*tau_max)` 当作全身同时可用的减速能力；所有脚共用同一组关节与浮基。

投影目标保持与原 raw 动作的接近，并报告可实现的足法向加速度/速度与身体支持余量。若引入状态、接触记忆或 warm-start 依赖，必须进入执行合同与转移、独立克隆；优先维持确定性无新增隐状态实现。真值材料 q 不得用来构造控制器可见状态。

同时生成显式的 support-aware 恢复候选或可行 warm-start，仍保持任务目标，必要时短时降低期望推进以稳住实际支撑。必须在同一个当前状态、同一 horizon、同一 E、同一检查与排序下重评新候选、恢复候选和 shifted nominal。不得只拒绝新候选后继续旧 unsafe policy，也不得强制安装未经过同样约束的“兜底”。

## 5. C：回答 PANN 是否适用，并做对下一步有用的 GPU 工作

### 5.1 复用本次实载审计，分离四个问题

读 `reviews/W54-review/pann.md`、`pann-audit.json` 和 `pann-replay-summary.json`。当前 `B_random1000--ideal` 权重 SHA 为 `743c6f3694b482a0b1b667f1d3a14d171269a1eb6b517eb3181e8042459563f7`。PANN 的冻结权重、每地块动态 e/q、PPO 权重及真实 TM02 参数是不同对象。

此次已完成 F/r52 的 3 个、N/r48 的 6 个预选地块，在 0.2 ms 与 2 ms 两个时钟的独立自由积分。同 0.2 ms PANN 最大单地块力误差分别约 .911/3.481 N，最大自由恢复差 .495/5.864 μm；Reference 自身 2 ms 端点路径相对原 0.2 ms 路径的峰值力差最高 7.472/45.269 N，包含边界与采样差异，不是纯步长误差。其中 N 的两个高速地块恢复偏差达到各自参考恢复峰尺度约 22.3%/18.9%，后续应重点核短时加载—恢复误差及其动作影响，不能称全部可忽略。九地块有限覆盖不支持优先大规模重训，也不代表全部新路径已验证。先使用这些已完成结果，不从头重复取证。扩展到原件中全部有相关加载/释放/跨足事件的独立世界地块，或修后自然产生的新路径，记录实际工作清单和覆盖增量。每条历史从 virgin 状态或可因果重建的状态开始；不能用真实 q teacher forcing 冒充部署积分。

## 7. 25 核与 96 GB GPU 的实际调度

先现场核具体配额与其他任务。本项目起始配额：N 最多 10 workers，F 最多 4 核，C/材料装配最多 8 核，系统及其他任务至少 3 核；总量不超过 25。F 小 QP 本身常只有一个求解线程，4 核是容纳记录/视频等的配额，不承诺自动吃满。数学库线程设 1，构建合计先 `-j6` 且计入共享 CPU 配额。

两条正式 N case 并行时保持首次 E30 已冻结 workers；如冻结为 10，则按 10+10+2+3 重新分配，C 缩小 CPU 装配或让出资源，不中途改变已运行身份的 workers。两条 F case 可以更轻；空余 CPU 供材料数据准备、已有结果分析及异步交付，不无依据生成重复物理任务。

记录真实有效物理区间交集、分段 CPU 核时/墙钟、native 求导/规划/记录开销、GPU 设备峰值与有效批量，区分初始化/编译/传输/热计算。W54 仅有 41.1324 s 有效双物理重叠，不能写成全程三线满载；显存分配量也不等于计算收益。资源调整基于这些实测，不设置额外满载 benchmark。
