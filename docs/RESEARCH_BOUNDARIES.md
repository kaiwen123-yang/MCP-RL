# 当前执行边界与必须保留的成果

2026-10-21。依据用户本轮直接要求更新；本页覆盖历史文档中已经过期的“下一步”和“PR不合并”指令。

## 当前授权和主线

- 用户已授权合并已完成、可核验的 PR #1 底座和证据。合并不表示旧辅助算法有效，也不自动授权训练或实机执行。
- 当前研究对象是复杂地形连续动作：跳跃、落地、姿态改变通过受限空间、楼梯等。研究后续动作需求如何改变前一个动作应学的实际反馈，以及 MPC 如何预测并利用这种变化。
- 用户已否定本轮提出的热负荷收窄方向；不继续把温度、热余量或电池模型作为当前主攻。
- 可继续定向阅读、核查公开多技能实现、读取已有数据、实现必要的合并修复与不训练的完整仿真准备。新场景必须先有明确任务语义与固定比较条件。
- 先不训练，不扩大训练，不上实机，不启动自动检测或长期后台作业。发现必要训练时先把具体任务、学习能力和预算讲清，不能从历史命令自行推导授权。

## 不再做什么

1. 不恢复 CV 或四秒 pathwise 辅助项作为默认主攻，不为它继续调权重、改任务或挑选有利检查点。
2. 不用增加路线长度、阶段标签、网络或损失项代替真实执行能力问题；不把“能运行、梯度非零、模型误差下降”当成整程研究增量。
3. 不按实验结果收窄门、抬高台阶、改变成功标准或限制强基线的合法减速/停顿/恢复来制造优势。
4. 不在技能交接处重置身体、接触、策略记忆或实际回报；如允许等待、稳定和重新接近，各组都有同等权限，耗时和资源计入整程。
5. 不把现有速度跟踪权重称为已有跳跃、低姿或楼梯技能；不靠新增技能编号伪装技能已学会。
6. 不把原模型对脚碰障碍的失败规则直接搬到楼梯；可承重地形与应避障碍必须按任务定义区分。姿态改变指真实可实现的机身/关节姿态，不改变刚性机身尺寸。
7. 不混用 HIM 与 robot_lab 的策略、观测、模型、时钟、PD和结果，不把社区移植等同原论文复现。
8. 不把机械工作、力矩平方积分当成电池电量或温度；不凭任意参数创造热衰减、疲劳等新瓶颈。

## 必须保留什么

- 27.32米原任务、成功条件、速度权限、全部成功和失败结果，作为完整回归基准；它已经参与开发，不再称全新留出测试。
- 冻结强策略＋充分MPC、几何跟随器、普通任务条件RL及旧辅助候选的源码、配置、结果和检查点来源。
- main 原有 HIM 路线 `src/go2_frozen` 与其脚本；PR robot_lab 路线隔离为 `src/go2_robot_lab`，任务学习仍为 `src/go2_learning`。
- 原始提交、源码哈希、失败批次身份、版本关系和物理/计算成本。历史证据不改写为当前结果。
- v2文献库、稳定MR编号及v1归档。定向新来源先作范围内阅读记录，不自动占用主库名额。
- 私有路径、第三方权重、原始高频数据与运行环境继续留在忽略目录；已公开的原创紧凑模型保持原身份。

## 后续判断依据

主要成果应回答：哪个真实反馈能力发生变化、MPC怎样利用、整程成功/时间/资源是否改善，以及强替代能否解释收益。
既不要求证明冻结控制器全局无解，也不以局部指标替代整程效果。每项可核验改动及时提交推送并核验远端；必要维护检查只保护结果身份与合并兼容性，不作为科研成果。
