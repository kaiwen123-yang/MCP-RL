## 实施的六个并行工作流

A. 材料：保留原PANN与M3，对整足观测条件下的能量/耗散势、释放恢复与重载响应重训；比较单模态同容量和少量恢复分支。已有零牵引边界/隐式Newton不是新功能。不给模型oracle网格状态标签冒充可部署辨识。

B. 状态与WM：M1已有世界坐标账本和懒执行恢复，新增可辨识性/不确定性约束的材料信念及执行器/FSM记忆；对照冻结与沿预测构型重算M/J/h、稳定多率积分、真实干预响应；检查完整反向是否一致。分别验收10k/50k等具体权重，禁止将旧节点失败泛化。独立比较自由想象与DMO式真实前向。

C. 步态/MPC：在少量可行接触序列内优化相位/时长、落点、触地速度、载荷曲线；材料状态和相关不确定性进入预测与可实现支撑约束。每个候选使用独立状态副本，同一地块多足作用不重复计算支撑。先证明各动作实际生效，再扩展维度。

D. WBC：比较当前r58、KV/STANCE式与PANN历史切线；将形变/加速度和本构相容写入变量/约束，区分首次触地、反弹、稳定承载、卸载。保留完整动力学、单边力、摩擦、总力矩及PD映射后的输入限制。

E. PPO/联合：保留已有真实时间GAE、raw/logp_raw、策略封存与KL回滚。新增混合事件/连续动作与跨足重载价值表征；完整输入包括机器人历史、任务命令、材料与执行状态。KL改为完整混合分布，控制器参数在同批PPO期间冻结；单独外层修改后重新采样，或作为采样动作纳入概率。真实PPO独立推进。短想象或DMO梯度只有在独立真实方向/幅值/执行效应检验通过时参与辅助；无可信时域时权重为零。冻结模型作actor更新，不能让奖励反向伪造更有利的物理模型。

F. 独立评测：维护数据分割、完整失败分母、视频事件对齐、接触点滑移、冲击、承载延迟、能耗、鲁棒/泛化及目标设备p99时延。评测流不参与挑参数；按起点/完整历史聚类统计，A/B不是种子，重复分支不是独立样本。

六条工作流可并行开发和分析，GPU重任务与物理worker按实测资源调度。先核可用CPU/内存/显存和其他项目占用，再采用2–3个互不依赖的GPU任务与4–6个物理槽等候选配置；没有实测吞吐证据不得盲目加并发。没有计算条件的任务继续做数据/代码/理论工作，不堵住其余支线。

## 判别实验与接受条件

- 先固定同一观测、任务奖励、动作权限与数据预算，再比较机制。新动作策略要与同能力无材料记忆策略比较。
- 材料比较：原PANN、M3、仅加载重训、释放/重载重训、共享/每足/打乱历史。
- 控制比较：固定步态、时序、时序+落点、再加触地速度/载荷；固定MPC比较WBC；固定WBC比较MPC；最后做交互组合。
- 学习比较：真实PPO、固定权重辅助、条件可信辅助、DMO式前向；区分局部导数错与长展开漂移。
- 留出完整材料参数族、加载历史、地图与命令组合，测试足印错位/接触噪声/延迟/扰动。低信号方向同时报告不可分辨比例和条件正确率。
- 目标设备完整链路测p50/p95/p99/最坏值与deadline miss；20ms MPC、2ms WBC只是现阶段待验证目标，服务器训练速度不作硬件结论。
- 筛选候选后使用多个独立种子；无有效性证据的候选保留负结果，不重复扩大训练掩盖问题。
