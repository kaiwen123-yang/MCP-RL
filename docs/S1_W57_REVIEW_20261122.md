## 3. 为什么 baseline 成立，研究收益仍然不清楚

### 3.1 新接口还没有一致胜过简单基线

r60相对r55，E600完成时间只提前A1.040s/B0.482s；归一化滑移代价增加0.317%/1.816%，峰值应变增加3.266%/4.467%。这不能写成统一性能提升。`slip_integral`是承重足水平速度按0.25m/s归一化后平方的时间积分，单位为秒，不是滑移距离。

r57屏蔽旧actor最后12维显式恢复预测，A/B仍通过E60；540维近期运动/受力历史仍在。它仅说明这个显式输入通道对当前冻结策略依赖较弱，不说明全部材料历史无用，更不是同权限重新训练的记忆盲策略。

### 3.2 材料的作用主要停在当前执行参考

现有法向参考使用`z_now + inverse(F_measured,h) - inverse(F_target,h)`。若逆响应在当前范围内近似`b(h)+F/k(h)`，共同历史偏移b会相消。这是解释假设，已有保存单点支持该通道可能很弱，但不能从一个点推广到全部事件。

更直接的源码事实是：`rollout_candidate`只有离线qualification调用，真实F的`replan`尚未消费它。**预测到材料内态变化，不等于规划器已经据此选择了不同未来。**

依据：[材料预测模块](../src/tm02/s1_material_prediction.py)、[当前WBC接线](../scripts/s1_w56_f_r58_backend.py)、[单点与隔离核验](../results/terrain_memory/simulation/tm-s1-go2-local-readiness-r12/w56/c/interface-qualification.json)。

### 3.3 本次新增：0.35s并非看不到所有下一跨足接触

从已发布r55 E300全部query-cell表筛选`same_lap_cross_foot`且精确查询/下一触地足印交集>0：

| 指标 | A | B |
| --- | ---: | ---: |
| 符合条件的query-cell行 | 146 | 138 |
| query→next-real-load中位/s | 0.1279 | 0.1611 |
| query→next-real-load最大/s | 0.2886 | 0.2978 |
| 落在0.35s内的比例 | 100% | 100% |
| 当前observer绝对q11中位 | 2.635647e−4 | 2.502698e−4 |
| 2ms自由恢复预测深度中位/μm | 9.113451 | 8.654723 |

这些是相关查询cell行，不是284次独立试验。材料历史来自r55 E300，不能冒充r60全时段分析。

必须区分“此刻查询到下一次触地”和“当前源加载到后续重访”。已存在的历史可以影响0.35s以内的下一接触；当前加载要为更远后果作打算则可能需要更长事件层。下一轮先使P1真正消费材料候选，不因单腿周期0.54s就先扩大所有horizon。跨圈约48s的查询残余已极弱，也说明原长往返适合稳定性回归，未必是最敏感的恢复记忆机制任务。

### 3.4 两个实施细节会直接影响下一轮解释

第一，当前候选用25ms一次材料积分，在线observer为10×0.2ms的已完成窗口，normal inverse为2ms。应以相同已存事件比较粗/细积分与历史效应量级。若离散误差大于所研究的记忆差异，不能把候选排名变化都解释为材料记忆。固定目标力再inverse→forward得到同一目标力，仅是内部一致性。

第二，新的59D timing head必须明确12个恢复量查询哪里、以哪个发布时间为基准、对应哪次待触地事件。旧actor的`t+0.2s`足位置和0.002/0.2/0.5s自由恢复查询不能未经说明直接称为未来受载预测。材料外、virgin、充分恢复与缺失也不能静默混成同一零值。

## 4. 本轮推进方式

[W57主计划](S1_W57_RESEARCH_PLAN.md)已把以下事项落实为执行要求：

1. **M材料估计**：先用M0保留当前接口；并行比较物理一致的测力状态校正M1。完整episode/事件族保留预测，不以只拟合当前力作为成功，不默认重训PANN。M1无益则采用M0继续P/R。
2. **P预测控制**：完成接触事件首因对齐、候选积分比较；私有材料状态真正进入候选评价、首动作和实际接触。先近未来已覆盖事件，远期层由真实source→target证据决定。
3. **R学习接口**：旧W44速度actor冻结，新head只学习±50ms交接请求，预测与执行使用同一个锁存请求；原支撑门保持。首批2048真实转移后，在有权限、有信号、credit正确、身份稳定的条件下同轮累计到4096/8192，不拿保留评估挑最好checkpoint。
4. **独立输入对照**：需要回答新策略是否使用材料预测时，独立训练同权限、同初始化和相同样本/优化预算的显式材料预测盲head。它仍共享合法当前接触、旧actor和原执行链，不能称整个系统无历史。
5. **联合**：先固定M与同一R1，做B/P/R/PR×A/B×短重访/充分恢复16个episode；条件式blind另4个。短任务不替代原资格；新控制身份各自原E30/E60，值得作为最终方法的版本再做自身E300/E600。

本轮不强求每个模块都必须提出一个新算法。可能的核心贡献是持久世界地块状态如何支持跨足决策；状态估计、规划入口和学习动作必须用各自对照证明必要性。标准PPO、timing residual、MPC+RL组合本身不足以构成新颖性结论。
