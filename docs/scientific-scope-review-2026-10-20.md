## 3. 为什么会反复感觉“抓小放大”

### 3.1 框架名称延续了，新增方法的研究对象却换了

原问题关心：完整任务需要什么响应，策略怎样真实实现，紧凑模型怎样可靠描述，MPC 怎样利用这些能力。当前第三组关心：事实模型与价值函数产生的动作方向，是否改善 PPO 的有限样本梯度估计。

两者可以有关联，但前者不会因为后者已写出就自然完成。当前 PR 的 f/g 仅拟合真实转移，纠正了旧方法允许预测器“自我乐观”的问题；新增目标集中于 PPO 的控制变量。它尚未建立显式塑造“任务有用且易于预测”的执行行为的共同设计机制。普通策略学习、模型再辨识和 MPC 的交替循环已经存在，不能把这些公共组件本身归为候选增量。

### 3.2 长程目标被阶段标签代替

当前任务是约6.321米的固定 L 形路线，顺序执行直行、转弯、过门、停止，状态和任务回报连续。这是实质整机进展。

但 nominal/narrow/wide 仅改变门宽和起始横向偏移；后续阶段需求没有改变。尚未展示哪一种前段局部合理行为会使后段付出较大代价，以及低层学习为什么能在同等信息与资源下改善这个取舍。长程的关键应是延迟后果和跨阶段依赖，不能仅用阶段数量或运行秒数定义。[固定任务源码](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/src/go2_frozen/task.py#L19-L62)

原参考跟随器已经完成且更快，不证明学习永远没价值，却要求研究解释“希望新增的具体能力是什么”。仅继续优化同一路线末端时间，容易逐步变成一个停稳控制工程问题。

### 3.3 每次负结果后的修复，默认继承了候选的研究地位

实现问题值得查清：优化器状态共享影响比较身份；终止语义影响实际优化目标；KL 提前停止影响实际更新量。此前修复和归因并非无用。

偏移发生在后续决策：发现公共问题，只能说明原理归因仍有限；并不能推出当前候选有正向潜力、修好就值得继续训练。若每次都按“发现问题—修复—再试原候选”推进，核心物理假设和最强替代方法就一直没有成为真正的决策依据。

### 3.4 “方法已经完成”混用了几个不同层次

公式明确、代码接通、优化器执行、整程成功、比强方法更好、形成论文贡献，是不同结果。目前前四项已有实质工作，后两项未成立。过去阶段报告常以“完整候选交付”开头，再在长文末尾限定未验证收益，容易把工程完成误读成科学问题接近完成。

训练底座也发生过变更：main 的二维任务曾接入 Tianshou，PR 的 Go2 学习器是自写 PyTorch clipped PPO。[PR训练器](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/src/go2_learning/learning.py#L123-L191)自写本身不构成错误，但前一底座的成熟性不能直接继承为新体系已具备有效学习量的证据；也无须为了修正叙述而再重建一套训练框架。

### 3.5 接续首页混合了多个“当前”

原 CURRENT_STATE 顶部正确记录已训练，后文“下一科学证据”仍写“本轮未训练”；README 首屏仍以10月19日冻结模型为最新阶段。main 与 PR 又使用不同策略、任务与预算。新对话容易从旧禁令或旧候选重新出发。

本轮将原 CURRENT_STATE 完整保存在[10月20历史快照](CURRENT_STATE_HISTORY_2026-10-20.md)，当前入口只保留最新事实、判断、执行边界和证据链接。整理文档解决接续混乱，不计为算法或实验进展。

## 4. PR 实际做成了什么，候选究竟改变什么

原生 TaskActor 在公开 robot_lab 策略上增加19维任务输入，全部策略参数可更新；新增输入的初始权重为零。执行链保留实际关节动作、PD 与接触仿真。完整真实 return 跨阶段传播，策略更新后用实际数据再辨识 f/g，再进入下一轮 MPC。[actor](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/src/go2_learning/policy.py#L21-L47) · [训练编排](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/src/go2_learning/runner.py#L338-L357)

第三组增加：

\[
\alpha\left[d^\top(\mu_\theta-\bar\mu)
-\rho_\theta d^\top(a-\bar\mu)\right].
\]

在文档明确的固定采样前信息和分布条件下，补偿项条件期望为零。它可能改善或恶化有限样本学习，不改变原 PPO surrogate 的期望目标，也不保证降方差。这不排除学习效率贡献，更不意味着两个有限样本训练过程必须相同。[方法与条件](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/docs/go2-adjoint-learning-method-2026-10-20.md#L215-L261)

动作方向只展开至下一个200毫秒命令边界，最长10个20毫秒微步；当前已选命令固定，续接命令来自已有计划，没有微分未来重规划。长程后果主要通过共同的价值函数 V 进入。短展开是合理的计算选择，但不能仅凭伴随链存在就声称解决了长程信用问题。[方向实现](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/src/go2_learning/learning.py#L48-L100)

直接文献关系也支持这种定位：[Q-Prop](https://arxiv.org/abs/1611.02247)的经典机制是利用 critic 展开构造控制变量；本轮只重核这项直接来源，不新增经典文献名额。[SPlaTES（RLC 2025）](https://nicoguertler.github.io/splates-pages/)研究可预测、任务相关的时延技能及长程规划；[ReCo（2026年10月预印本）](https://arxiv.org/abs/2610.01612)研究响应塑形、闭环辨识与策略感知 MPC。因此，控制变量、可预测技能、响应模型都已有直接近邻；实际贡献需要落在具体未解决的任务困难和可比较收益，不能靠组合名称确定。

## 6. 最新诊断能说明什么

**终止问题是公共实现的实质失配。** 实际任务在位置容差内连续停稳即可完成，公共评分仍计算固定4秒和精确路线余程。已保存25个终点决策中9个拒绝自己预测更早完成的跟随候选；只清零 V，没有停止全部完成后计费。宏步200毫秒端点还可能漏掉实际20毫秒检查中的速度峰。

**KL问题限制了实际学习量。** 24个学习轮次在原B状态上的解析KL均超过0.02，22轮仅接受一次actor更新。首轮普通和候选使用相同数据，其实际更新很接近，因此CV不是早停的必要原因。完成四轮不等于策略充分学习。

这些证据支持“公共体系存在影响比较解释的问题”，不支持“CV已有效但被掩盖”，也不能确定全部退化来自公共模型。停止当前投入是研究资源判断，不需要先把候选原理完全证伪。[综合诊断与原始证据入口](https://github.com/kaiwen123-yang/MCP-RL/blob/ac15c99e35c1b54d63f81a321ee4a5c4c09aa4e5/docs/go2-adjoint-diagnosis-2026-10-20.md)

## 7. 建议的下一阶段：围绕一项真实能力推进

建议保留的具体问题是：

> 在有限在线规划和学习预算下，后续阶段要求能否让RL学出不同且可预测的实际执行响应，MPC能否利用这种响应改善整程表现，并在未见过的阶段组合中保留收益？

这恢复了原问题中的任务价值、真实实现、可规划性三个条件，不预定答案为伴随、PINN、特殊网络或新优化器。学习效率可以是贡献，不要求改变理论最优策略集合。

### 7.1 下次主要设计交付应具体到一个相同前段、不同后续的任务关系

建议先考察同一段接近/转向/过门之后，后续要求是继续运动还是在指定区域停止。哪种速度、侧向运动或身体状态需要保留，由真实动力学和整程后果决定，不先把“慢、稳、误差小”写成一律更好的目标。

这是一项待检验物理假设，尚未证明当前Go2必须改变低层策略才能受益。它之所以比继续缩门或调奖励更适合当前主线，是因为它直接改变后续任务要求，而不是放大现有候选的某个优势。

下一任务设计只需少量自然的完整组合和一个预先留出的组合，明确各方法共同可见的未来任务信息、速度权限和预算。当前路线保留为回归与历史结果，不回写本次负结果。新增任务、参数及运行预算必须在新协议中明确，本轮没有实施。

### 7.2 公共修复作为有限的配套工作

使实际终止、模型预测完成和完成后评分表达同一任务；使KL更新规则与实际接受步、日志一致。必要时使用成熟实现核对，但不预设需要换整套框架。

这两件事的交付是“公共比较可解释、策略按声明机制学习”。不以继续增加KL表、V分区表、全部模型替换或新局部梯度探针作为研究成果，也不把修复后可能取得的时间改善直接归给新学习机制。

### 7.3 比较必须保留两个不同层次的强替代解释

| 比较 | 它可能推翻什么 |
|---|---|
| 冻结强反馈＋充分规划/合理续接价值，保留简单跟随器 | 改善可能只需高层规划，不需要新增反馈学习机制 |
| 普通任务条件RL＋事实辨识＋同样MPC，具有合理有效的更新 | 改善可能只来自公共任务信息和常规学习 |
| 一项明确的控制学习候选 | 只有额外改善整程、学习效率或计算取舍，才支持候选增量 |

第三行目前没有足够依据默认继续用CV。若将来仍选择CV，需要提出有依据、可判别的信用估计改进假设，说明规划方向相对普通价值/模型辅助方法可能提供的具体优势，并由固定比较检验；不要求在比较前已经证明该机制成立。若选择响应共同设计，需要通过真实策略改变响应；不能重新让事实预测器沿任务成本虚构改善。

不设冻结策略全局无解、二维先赢、54条后缀全部完成等前置门槛。交接解释只保留与所选物理假设直接相关的一两项量，嵌入完整任务比较；不另开漫长诊断支线。

### 7.4 继续与停止依据

继续依据随主张区分：若主张响应共同设计，需要展示实际反馈行为变化、规划对该变化的利用及整程改善；若主张学习效率，需要在同等任务表现下展示数据或总计算改善，不额外要求最终策略或规划行为不同。可预测性价值应体现在有限模型/在线预算下的决策效果，不能仅报告MSE更小。

若公共规划修复或普通任务条件RL已解释收益，就结束新增候选主张；若只有梯度、预测或局部交接量变化而没有整程价值，也停止该候选。保留底座和负结果。若出现稳定的实质增量，再开展直接近邻方法比较、更多组合与实机验证，而非现在同时扩展狗、臂、PINN和大规模并行训练。

## 8. 当前可执行边界

本轮更新的是研究判断与接续入口。PR保持Draft、未合并；当前没有新的训练、场景修改、服务器作业、自动检测或实机操作授权。下一阶段建议没有冒充已选定算法或已运行结果。

main 与 PR 两套历史结果保留身份。main 的 HIM/1秒规划/推扰任务结果，不能与 PR 的 robot_lab/4秒规划/无扰任务拼接；main约20毫秒的紧凑模型结果不能作为PR实时性证据。
