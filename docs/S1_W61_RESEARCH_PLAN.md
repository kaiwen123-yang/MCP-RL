## 1. 总体决定

**W59 已结束，固定其方法、结果和合格身份；W61 同时推进 A–F 六条研发线，先建立单模块因果证据，再尽快研究有依据的组件对，最后开展相同组件分别训练与共同训练的系统比较。**

本轮目标是形成可运行且有强对照的算法，直接解决材料适应、接触质量、有限算力规划、受限全身响应和高效学习之间的矛盾。已有日志/门控/修错是必要支撑，但不作为五个模块的论文主贡献。每条首选一个主实现；原地图每模块的另外两条保留研究，不要求一轮实现十五方向。

不把“所有五模块都成熟”设成第一组实验的前提。A/C 可先用冻结步态/WBC；B/D 可先用冻结 M1/MPC；E/F 先用冻结可行轨道库，不依赖新世界模型成功。所有已具条件的后继在同轮连续推进，不停在空目录、一次 probe 或下一份计划。

## 3. A 线：把 PANN 改成真正可以适应材料的模型

### 3.1 问题与模型

分开三个对象：材料身份 c、当前加载历史内态 z、几何/观测误差。c 表示材料族的低维可辨识差异，z 按世界 cell/材料区域保存加载、恢复和不可逆变化；不能将一次新观测造成的变化全解释为换材料。

采用条件自由能与耗散结构，例如 ψθ(ε,z;c)、Φθ*(ξ;c)，在已有物理结构内让 c 调制受约束低秩权重或正参数。应力由能量导数产生，内态按耗散结构推进；c 的在线更新使用短 support 历史，query 是后续独立加载路径。模量、松弛时间等可解释输出由明示参考状态的响应提取，不把 latent 分量直接改名成物理参数。

第一版只辨识由足底合力/压陷/速度/时间历史支持的低维参数或 latent；每个 cell 任意估许多参数会不可辨识。摩擦、接触几何和体材料参数分开，不能靠错误足印面积的补偿得到“正确材料”。对识别不足的方向输出不确定性或保守先验。

隐式/半隐式更新用于恢复/高刚度时间尺度；在线改变 c 会改变储能，需计入参数变化项、在明确窗口冻结 c，或给出有界更新与能量处理，不能用固定参数耗散结论直接宣称适配后整机稳定。

### 3.2 首批工作与比较

1. **A0 补测现有模型**：从原 50k blackbox/structured 权重，在原冻结 origins/输入/split 上评估 20/100/350/640/1300/2000 ms、接触事件、动作方向与梯度条件。原保留数据仅用于旧模型补证；新模型选择改用新开发集。结果写 W61，保留原 10k 负结果。
2. **A1 条件 PANN**：实现 c/z 分离、受约束条件权重、support/query 适配、有界响应空间更新；包含加载→卸载→驻留→同足/跨足重访。
3. **A2 一致执行 WM**：将刚体/高增益执行器做稳定的离散推进，构型相关 M/J/h 按预测状态更新；足位来自 FK(q)，材料内态、接触模式、控制器内部记忆按同一因果时间推进。只学习有明确物理作用点的残差，不独立生成相互矛盾的 q 与足位。

A0 与 A1/A2 同时做；A2 首先对线性 PD 子问题检查离散响应，再逐步加入构型/FK/模式一致性。梯度经过哪些 CPU、detached、离散与有限步求解路径逐项明确；没有实现的 backward 不声明存在。

直接对照包括冻结 PANN/M1、M3、普通参数估计、材料 embedding/条件黑箱、条件 PANN；HANO/强 RNN 做相同历史输入与训练预算比较。材料内态一致性与积分器应交叉消融，避免把新积分器收益全部记为新表示。执行 WM 比较原 structured、仅隐式驱动、再更新构型、再 FK 一致，并保留 blackbox 强对照。

### 3.3 数据、指标与完成条件

按材料与整条加载历史划分训练/开发/最终保留，不能随机拆相邻 tick。分别测试未见材料、已见材料的新加载速率/停留/顺序、跨足历史共享；oracle 参数只作明示上界，不送入部署 actor。新材料范围先由物理合法性和系统可观测范围确定并登记，不为制造收益随意放软地面。

指标包括整段力/回弹/恢复误差、局部切线、自由滚动有限率、守恒/耗散残差、识别校准、每次适配成本，以及固定控制器上的路线/冲击/滑移/能耗。可完成为有解释的负结果：如果低维参数无法从当前传感信息辨识，报告秩/后验与必要激励，不盲增网络。

非局部材料场、更多不可逆模式保留为后继；先用双压头/间距/顺序的强独立柱对照证明真实耦合作用，再扩展，不阻塞首版。

## 4. B 线：完整步态生成、真实相位反馈和可行切换

### 4.1 研究对象

轨道输出覆盖三维落脚位置、摆腿样条、触地法向速度、支撑力建立曲线、机身高度/姿态、接触窗口、周期与耦合。位置/速度/加速度来自同一时间参数化。以接触模式 χ、相位 φ、连续轨道坐标 z 与任务/材料条件 κ 表示受控轨道族 rχ(φ,z,κ)。

先用轨迹优化、现有成功数据和 continuation 生成可执行族，再学周期 decoder 与局部横向反馈。行进轨道在去平移/航向对称的坐标中定义，不要求世界坐标每周期回到原点。真实接触、已历时、计划相位分别记录；不能把 CPG 相位视为必然发生的触地。

首版采用 2–3 个确实可实现的模式图，保留多个连续轨道和有不同启动相位的过渡桥。模式/过渡可拒绝并回到冻结可行轨道，但最终必须报告拒绝率和任务推进；停止不动不是解决运动任务。未来动态/腾空步态另定任务合法性，不把 W59 的多足支撑习惯固化为所有研究的公理。

### 4.2 为什么这一线不等于已有“多步态选择”

11-gait/style CPG 工作已经通过两阶段 PPO 学样式和按地形选步态；APT-RL 已用优化数据训练 trot/bound decoder 与辅助动作；NMM 已研究轨道族与横向稳定。我们的候选贡献在于耗散材料状态条件下的全脚位/触地与承载过程、实际接触闭环、模式切换的可实现轨道及适配过程。若最后只实现一个 CPG selector，应按弱实现报告，不能完成本线主张。

NMM 的被动/弹性、输入秩和局部稳定条件不直接适用 Go2。先在固定 MPC/WBC 下估计局部返回映射与扰动逐周期衰减；证明成立范围、经验范围和失败范围分开。

### 4.3 首批实验

- **覆盖诊断**：保持旧 12-target 机制不变；用 raw ledger 细分 no-source、no-pair（同足/他足抢先、RR 缺失或晚到）和 pair-no-match（时间/几何/release）。检查 F01 入射相位/可达脚位。
- **新协议**：从预先定义的动态可达区域与初始相位范围抽取目标，冻结后不按候选成绩移动 cell。原路线、覆盖机会、合法机会中的材料响应、端到端性能四层同时记。
- **实现与内部消融**：固定低层，比较仅脚位/样条、真实相位反馈、两者结合、加材料身份、再加历史状态、轨道族与过渡。先短定向确认作用，再匹配预算的正式训练与冻结评价。
- **强比较**：固定/可切换轨道库、同接口的 CPG/style、拟议轨道族。LoComposition 的关节位置整栈作为系统级参照，不把底层不同的优势反推为本模块因果。PROMO 式偏好条件检验跟踪/能耗/接触的折中。

评估新材料×速度/路径×载荷/逐腿能力的组合，至少三个独立训练 seed（有学习的臂）；报告失败、冲击 p95/p99、off、周期/支撑、脚位、速度误差、滑移、CoT、转换中断、实际算力和完整视频。不要只统计成功回合的能耗。

## 5. C 线：GPU 批量规划与有限预算下的有效求解

### 5.1 主算法

保留接触拓扑多个分支，在每个分支中优化持续时间、落脚、身体/关节参考和接触力。GPU 并行的是“拓扑×材料场景×连续候选”，不是简单复制同一个不可用世界模型。每个拓扑维护自己的提议分布，禁止平均互斥接触模式。

固定拓扑内用稀疏 GN/SQP/DDP 或 QP/ADMM 做有限步精化，复用结构、分解、warm start 和预条件；先在已知刚体+冻结 M1 上运行，A 未完成不阻塞。随后加入材料历史的因果更新与统一信念下的风险聚合，不能从最乐观材料模型挑动作。

吸收 VR-MPPI 的二次提议与残差重要性修正，或 TRMPC 的分布信任域；改变 proposal 必须同步修权重。学习候选/预算分配、前馈或预条件器时，以实际有限 K 步输出和总墙钟成本为对象。收敛 KKT 导数可能消掉热启动的影响，不能替代有限步求解图。

“大范围”指有限预算内扩大有效模式/候选覆盖，不写成已保证全局最优。材料模型失真时扩大候选只会扩大模型利用，需同时看真实物理分支响应。

### 5.2 可完成的比较顺序

1. 在相同固定接触问题比较现有 CPU QP、标准有限步 warm-start 求解与稀疏 GPU 实现，检查首动作/全序列/约束残差和完整延迟。
2. 固定候选拓扑库与预测模型，比较 MPPI、VR-MPPI/选定 TRMPC、纯局部多初值与拟议采样+精化；分别做等候选数和等端到端墙钟预算。
3. 固定求解器，比较无材料历史、同足私有历史、跨足共享历史和材料后验场景；把参数适应收益与拓扑自由度收益分离。
4. 用新可行轨道/落脚接口扩大任务；B 暂未就绪时使用冻结轨道库，后续换 B 版本另记身份。

曲率、随机平滑附加样本、KKT 分解、CPU/GPU 搬运、同步、传感/网络全部计时。训练 batch 的有效候选/秒和单机器人循环 p50/p95/p99、deadline miss 是两套指标。Residual MPC 的千环境逻辑 100 Hz 不能当墙钟批量 100 Hz 引用；公开 CusADi 也不自动意味着有完整 PyTorch backward。

完成含真实闭环对照与失效样例，不只一个 GPU kernel benchmark。部署时可取小候选库+有限步修正/蒸馏 teacher；最终频率由目标设备全链测量，训练卡 96 GB 不是机载规格。

## 6. D 线：改变受约束全身闭环动力学

### 6.1 D0 定向数值诊断与 D1 同时做

用 w59-r3-5901-ppo-full-fallback-b-e60-0023 的失败前保存状态重建同一 WBC QP。记录尺度、活动约束、接触状态、原始/对偶残差、warm start 和预算；区分不可行与可行但未收敛。如果现有原件不足以复现，先明确缺失字段，在 W61 新运行加入必要求解前快照，不伪称已经精确复现。

同一配置最多一次确定性复现；有具体改动再比较，不能无依据调大迭代数或降低约束。D0 不占据整个 WBC 研究，也不阻塞其他五线。

### 6.2 D1 主算法

现有 18+12 维 QP、六行浮动基动力学、M/h/J/Jdot-v、滚动接触和执行器 hold 界保留。在当前支撑模式允许的可实现任务子空间内，设计自然任务惯量、允许的耦合、阻尼和前馈，减少强逆动力学补偿对模型误差的放大。

约化坐标随 q 改变时保留连接项；接触秩变化使用模式内 chart 与过渡处理，不假设变维基永远连续。全驱动 Natural Task-Space Decoupling 的定理不直接搬到欠驱动浮动基。

内模分为相位相关的周期误差与非周期载荷/驱动偏差。离线学习共享基，在线用预测误差和跟踪误差共同做有界适配；材料历史、冲击和电机误差不要全塞进一个无约束残差。非匹配基座扰动通过可用接触/任务调整应对，不能假设都可被关节扭矩直接抵消。

补偿作用于明确任务/广义力通道，再由同一个可行优化器执行，不能绕开总力矩和原位置输入映射。法向材料顺应/耗散、切向摩擦/滚动条件分别处理。储能包含材料时，接触功率为内部交换；外部供给、参考运动供能和松弛边界必须明确。

### 6.3 比较和理论目标

原 WBC、同约束的普通扰动观测/ESO 或 IMC 补偿、自然任务惯量版本、加混合内模版本，在相同固定步态/MPC/测量/权限下比较。预注册载荷、摩擦、驱动增益/偏置、延迟和脉冲扰动，衡量跟踪、耦合、恢复时间、冲击、滑移、饱和、输入平滑、QP 失败及延迟。

理论争取模式内局部 ISS/耗散和明确切换条件；经验闭环通过不改称全局鲁棒保证。第一版有完整对照后，与 B 的新轨道做 2×2 组件组合，重评轨道返回映射/过渡域，不能继承旧控制器下的稳定性证据。

## 7. E 线：真实事件学习与执行几何，条件引入模型梯度

### 7.1 首批实现应真正改变更新规则

策略联合选择接触模式 m、连续轨道变量 a、持续时间 Δ；critic、折扣和回报按实际事件持续时间定义。PPO/SPO 与新方法使用相同联合分布、critic 信息、观测、动作权限、初始化规则和有效样本预算。

首版以真实事件 score 梯度为可靠目标，把动作经冻结轨道/MPC/WBC/驱动产生的响应差异用于更新几何。概念形式：

H = F_joint + λE E[J_E^T W J_E] + λ0 I。

这里 J_E 是从策略参数到执行响应嵌入的局部 Jacobian/有明确预算的响应近似；F_joint 是完整混合策略的 Fisher。物理响应在给定模式、相同初态和共同随机数条件下只对连续变量与持续时间作局部求导；离散概率变化由模式枚举、完整 Fisher/score 与明示的概率响应嵌入处理，不能冒充跨接触切换的光滑导数。规定 W 为半正定、λE≥0、λ0>0。通过信任域自然梯度/约束步改变更新方向，不只是加一个接受 gate。

首版响应是冻结轨道/控制器可重算的名义时序、载荷、首段接触力和总命令，不是未观测的真实未来；用实际执行结果检验其有效域。归一化量纲、估计成本与响应噪声要进入设计。持续时间使用实际 elapsed 计折扣、运行代价按物理时间积分，请求时长与实际时长分别记录，防止仅改变决策频率就获得虚假奖励。

没有可信 WM 时 E 仍能训练。先在旧三维接口用保存状态/有限定向采样确认执行链与更新，再在冻结可行轨道库上实装混合接口；E/F 可以提供这个共同库，不必等待 B 的完整新算法。旧三维实验只支持局部更新诊断，不充当完整混合策略贡献。

### 7.2 第一轮固定预算比较

主要比较：PPO、SPO、E-score，各三个独立 seed，每头 8192 distinct real used，共 **73,728 条 planned used**。2048/4096 是预注册学习曲线/冻结检查节点，不据首个八状态均值正负停止某个种子。三 seed 是研究筛选规模，不能当最终充分统计功效或实机泛化证明。

统一的是采样协议、信息权限、配对场景随机数和预算；策略分叉后各臂采自己的 on-policy 数据，不能强行共用一份旧轨迹。相同 seed 的算法可用共同场景随机数降方差，不同 seed 使用独立探索流。批处理/GAE 切断、尾部 excluded、requested/observed/used/accepted 分开登记。

正式预算进入前冻结共同可执行的模式/连续/持续时间接口；算法无关的构建/安全/数据完整性资格可在短窗口内核验，不以收益符号筛选方法。物理/数值硬失败、非有限或约定 KL 约束允许拒绝具体更新/终止 run，保留失败结果和分母；修复产生新版本身份，不能反复换 seed 追成功。

若不能提供独立跨足/多模式接口，先交付明确限定的连续动作版本及其结果，并将混合研究标 blocked，不能将该弱版本冒称整条 E 完成。详细核和公平性见[学习设计](research/20261128-w59-review/w61_learning_design.md)。

### 7.3 关键修正与必要消融

在 AutoDL 实际 torch 构建验证旧高 32 位 seed 方案，保存原始噪声指纹；新 seed 使用完整混合或持久独立 RNG，训练/评价/collector 分流，恢复时保存 RNG 状态。这项定向验证解决已知风险，不扩大成与算法无关的测试工程。

三臂比较后，必须比较同一自然梯度更新器去掉执行几何的版本，否则胜过 PPO/SPO 不能归因于 J_E。首批没有证据时不同时加多个奖励修订、critic 特权和动作放大。优化墙钟、额外物理分支和响应估计成本纳入样本效率。

### 7.4 模型梯度作为有条件的后续算法

区分三种模型角色：只作 critic 想象目标、作候选排序、提供 pathwise 梯度。每种角色按需要的误差/事件/方向验证，不要求一刀切全通过才能用，也不因为短预测 loss 小就给长梯度。

可信局部模式内可加入连续 path 梯度；离散接触模式仍需 score/边界处理，连续动作影响未来模式概率的交叉信用不能丢。控制器 Jacobian、执行器 Jacobian 和动力学 Jacobian 是同一链式梯度因子，不能当三份独立回报梯度直接相加。

优先研究有 score 补偿的模型控制变量与可校准组合；未知偏差的 learned WM 不自动获得无偏性。有限 K 步控制器求导对应实际 K 步与其内部状态，不能偷用理想收敛解。模型用作 baseline 时，若 baseline 依赖动作，必须处理补偿，不能直接从 advantage 相减后声称无偏。

后续消融固定真实 used 预算，比较 score-only、控制变量、可信 path/mode 完整项与有意去掉交叉项；预算与准入由新协议预注册，不回填 W59 未运行 Diff 分支。

## 8. F 线：从第一天就做联合接口和可运行对照

### 8.1 当前即可交付

统一描述三种不同状态：物理状态/材料转移、observer belief、控制器内部记忆。接口含时间戳、坐标系、单位、接触 mode、历史来源、模型/控制版本、可用权限、不确定性与有效域。

执行响应算子条件化具体 MPC/WBC/驱动版本、参数和有限预算；它预测的是这个真实闭环。改控制器、延迟或执行器权限后旧响应模型/轨道稳定证据重新检查。公共接口先接冻结基线和共同轨道库，F 第一轮就能跑旧/新候选对照，不交空 schema 作为全部结果。

主联合问题为：**在固定部署计算和风险/任务约束下，减少未见材料×运动×能力组合上的适配阶段累计控制代价。** 同时控制速度/成功率，不能靠减速或停止降低冲击后称全面成功。

### 8.2 组合顺序

1. 单模块相对固定底层的实现与可信测量先成立；不要求每个模块单独正收益才允许预注册的 2×2 相互作用研究，阴性也可结束一个主张。
2. A+C：材料信念/历史与规划；做旧A旧C、新A旧C、旧A新C、新A新C的匹配 2×2。
3. B+D：轨道/触地与全身响应；同样保留 2×2，固定 A/C。
4. E 在固定组合上比较学习规则；再研究相同模块分别训练与共同训练，不让底层持续变化破坏 on-policy 身份。
5. 首个具条件的组件对立即推进，不等待另外几条全成熟；全系统结果再做 leave-one-component-out 与独立/联合训练对照。

共同适配的 query 必须来自当前适配候选的真实 rollout，或明确合法的 off-policy 估计。不能换动作/模型后仍使用旧 query next-state 充当新系统的真实结果。最初固定 support 采样策略，后续主动探测再额外处理 support 分布梯度。

### 8.3 首个真正共同训练的算法

首版先联合 A 的低秩材料适配映射/初始信念参数与 C 的状态条件提议、warm-start 或有限预算分配头；它们必须改变材料适配函数与实际候选生成/求解行为，不能只有几个代价权重网格。固定材料能量骨干、步态库、MPC/WBC结构、驱动权限与数据划分。首次证明的是这两个模块的共同适配，不冒称五模块已一起训练。

每个外层迭代执行：

1. 按固定 support 策略取得加载/运动历史 S，记录原件与可复位的物理/材料状态；比较候选使用相同 S、相同任务和可控随机数。
2. 用候选 A 适配头在 S 上执行预注册 K 步更新，得到本候选的材料信念；C 候选头据此生成提议，并执行实际有限步规划/控制。
3. 从匹配的初始状态分别运行当前正、负扰动候选的真实 query。失败也按共同规则计入目标和成本，不使用另一个候选的 next-state。
4. 将 support+query 累计任务代价、任务推进/风险条件、材料独立预测质量与总计算成本形成预注册外层目标；材料预测约束防止把有意失真的模型误称材料辨识。
5. 在标准化、受约束参数坐标中用反对称扰动的配对真实代价差更新 A+C。首版估计的是高斯平滑目标的黑箱方向，不声称无偏地穿过真实接触/规划器，也不把 learned-WM 梯度当真实导数。

外层方向数、有限适配步数、query长度、轮数与三个独立联合seed在一次开发成本测量后统一登记；全部比较使用相同总support/query曝光、真实候选执行量和适配/求解预算，分别报告采样与计算效率。至少比较：A/C独立训练、先A后C、同联合目标的交替块更新、同时共同更新。独立训练时A只优化材料校准、C使用明确的参考A；顺序与交替的顺序固定且公开。

这提供不依赖可信世界模型的可运行联合学习。随后在局部导数和有限K步求解链可信时，用真实目标检验解析/隐式梯度或控制变量能否降低外层方差与物理成本；改用这些估计器另列消融。再逐步开放 B/D/E 的参数，保留相同组件分别训练的对照。若首版只产出接口或固定权重拼接，F 尚未完成。

## 9. 统一实验协议：让结果回答实际问题

### 9.1 四个层次分别报告

| 层次 | 问题 | 实验 |
|---|---|---|
| 原任务回归 | 是否保持既有稳定能力 | 同身份 A/B 原资格，新身份逐 case 自取资格 |
| 机制辨识 | 历史是否可用、是否影响选择、是否改善执行 | 同当前状态不同加载过去；full/private/reset；合法足印与响应配对 |
| 能力扩展 | 新步态/材料适应/MPC/WBC是否解决新问题 | 预登记材料/路径/速度/扰动/能力任务及匹配强对照 |
| 部署泛化 | 是否以真实传感/延迟/设备工作 | 未见组合、端到端时延、部署路径，具备条件后才实机 |

不能把同一批开发调参场景再标最终 heldout。最终保留按材料与整条轨迹/任务组合划分；最终 seed 列表与评价随机数独立。三个训练 seed 与场景是统计单位，十二个同回合 cell 是嵌套观测。报告原始分布和区间，不承诺小样本必然显著。

冻结评价用预先登记的主 checkpoint（例如预算末节点）；中间节点报告学习曲线。模型选择只能用开发集，无法只选最好的 seed/工况。若达不到统计或实机目标，明确为初步研究结果。

### 9.2 视频、指标与失败分类

每个正式 run 保留同身份完整视频与高频日志，另外生成可跳转的相位片段；manifest 记录源视频真实 fps/PTS 与模拟时钟映射，不能仅写固定30fps并假定压缩片段等时。至少覆盖起步、材料入口、直行、换向、跨足重载、收尾、扰动与最差失败。

共同指标：任务成功/覆盖、速度误差、CoT/机械功、滑移、foot clearance、实际足序/占空/周期、off/承载建立、冲击分布、姿态/关节/总力矩、QP约束与失败、适配成本、有效样本/秒、全链延迟。电池能耗若没有测量不能用力矩平方或正机械功替代命名。

结果分通过、机制不达标、物理/材料失败、数值失败、存储/基础设施中断、运行中、未运行。技术中断保留真实已闭合样本；断开的 bootstrap 与正常终止分开，不能伪造任务终点。

## 10. 算力与并行：六研发线，六物理槽，按瓶颈组合

### 10.1 资源策略

25 vCPU/96 GB 显存是机器配置，启动前查实际可用 CPU/RAM/显存/磁盘和其他项目。六路总吞吐增益已有 W59 实测，若当前余量支持即可用六物理槽，不把两槽当永久上限；若 RAM/IO 无余量，先降低新准入而不是抢占其他项目。

双 collector campaign 原子取得两槽，六槽最多三个 campaign；单流评价占一槽，可混合装箱。native 材料 worker 与数学/求解线程都计入 CPU 配额。禁止六条研发线各自创建独立六槽池。共享调度器与租约由 F 的唯一整合者管理，当前其他项目任务不归它终止。

同时推进的典型组合：

| 资源池 | 可并行工作 | 准入依据 |
|---|---|---|
| 物理六槽 | 三个双 collector；或两 campaign + 两个冻结评价 | 总有效吞吐、每流推进、RAM、IO、其他项目余量 |
| GPU 批量池 | A 材料/WM、C 候选/求解、E 小网络更新 | 实测显存与计算重叠，不以占满显存为目标 |
| CPU 开发/保存状态 | B 轨道、D 数值/理论、F 评价/整合 | 显式预算与有限 workers，不抢物理关键线程 |
| 上传与交付 | 原件分块、hash/远端核验 | 磁盘余量和IO优先级，异步不阻塞已闭合采样 |

先读现场已有吞吐，不强制重新跑一堆无关容量测试。若任务混合变化使资源风险具体出现，用有限窗口测总有效吞吐和峰值；不要只有 GPU 利用率截图。

#### 2026-11-28 的冻结长回合动态调度

E 线以每个训练头自己的 8,192 distinct real used 回执和冻结权重 SHA256 为释放条件。该头的 A/B × short/recovered × U1/U2 共八条未见材料长回合独立进入现有共享池。九个正式头给出 72 条，三个 E-Fisher 消融头给出 24 条。48 条 short 各 168 物理秒，48 条 recovered 各 288 物理秒。原路线 A/B 的 E30 各自启动，只有同模型、同 case 的 E30 通过才释放相应 E60。零策略参照与 2,048/4,096/8,192 学习曲线都按原协议单计。

训练双 collector 原子占两个物理槽，冻结评测每条占一个，所有线路合计上限六槽。新评测有余量时可独立填满六槽。只有一个空槽且队首是资源可行的双 collector 时，为它凑齐下一槽。准入使用 cgroup CPU/RAM、GPU 余量、I/O 压力和在途原件的磁盘额度。每条物理任务有唯一租约。完整视频随原控制和物理日志保留，上传在物理租约释放后进行。正式评测沿用原 native evaluator 与归一化、材料、路线、扰动、时长和终止规则。

#### 每个头的连续采样与独立成片（2026-11-28）

一个头完成 256 个 distinct real used 的更新后，下一批使用该头刚发布的 checkpoint、独立 RNG 和 A/B 两条原始轨迹。实际双槽每批归还并重新申请。已取得训练位置的头可一直接续到 8,192，出现规定终局时封存该身份。其他就绪头在位置可用时开始。正式九头优先，新消融头可在正式头均占位或闭合后使用空出的训练位置。2,048、4,096 和 8,192 的曲线评价读固定权重，8,192 的终评也随每个头独立释放。每个版本仅按一份科学更新与去重事件清单计数。

原任务与长回合在原 native evaluator 封存轨迹、关闭 actor 流后写出对应的物理回执。相同 case 的 E30 物理资格释放 E60，完整编码由独立渲染 worker 按 GPU 余量和 I/O 负载执行。物理租约归还时刻、开始/结束渲染时刻、帧数、PTS 和原件摘要分别记录；曲线两条轨迹均保留。在源轨迹仍供渲染、资格追溯或训练/恢复读取时继续保持在线。

跨 collector 材料测时在原 E 采样器、M1、MPC/WBC 与 0.2 ms 物理链上使用独立 A/B 进程，CPU 与融合 GPU 对照使用同一原子双槽、同一算力分组和相应冻结策略。入口开销、凑批等待、H2D/D2H、GPU 同步、控制、实际物理终止和完整合法事件均计入。生产选用通过净吞吐、尾延迟与动作/轨迹一致性比较的后端。当前实测前缀选用 CPU，具体原件和后续量测随实验封存更新。

### 10.2 加速有价值的路径

W61 将已有 hybrid observer 做成按 batch/队列选择 CPU/GPU 的后端，在同输入核验基础上测一次完整闭环与生产吞吐。它不是 W59 热替换；等价仅证明同输入数值，不证明新标签与真实 plant 状态一致。

训练 GPU 批量模型和规划，机载部署使用实际可获得设备的模型规模/候选数/固定步数。250–500 Hz WBC、50–100 Hz MPC 只能作为待核的设计范围；未经目标硬件全链测量不作为已达指标。控制周期的计算截止与后台实验的墙钟截止完全不同。
