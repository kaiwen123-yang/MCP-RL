# 联合动力学分解与独立 PANN 实验的必要理论纠正

日期：2026-11-26。本文件仅审查给定设计及已读材料报告，不扩展检索，不修改活动仓库。主报告 `material.md` 的可辨识性部分已同步纠正。

## 1. 联合分解可以成立，但要明确六个边界

待审模型：

\[
M(q)\dot v+h(q,v)
=S^\mathsf T\tau_{\rm act}
+\sum_iJ_i^\mathsf T\lambda_i
+J_{\rm ext}^\mathsf Tf_{\rm ext}.
\]

### 1.1 右端各项必须按物理作用互斥

上述方程是合法的分解形式，本身不保证数据能唯一识别每一项。必须定义：

- \(\tau_{\rm act}\) 是实际作用于关节的净执行器力矩；传动摩擦、驱动延迟等若已包括在它里面，就不要再在 \(h\) 或另一个残差头中重复计入。
- \(\lambda_i\) 是该接触区域传给机器人的一次作用。PANN 需要接触几何、边界条件和内状态，才能积分得到它；一个能量网络单独不能确定接触力。
- \(f_{\rm ext}\) 只包含未被 \(\lambda_i\) 覆盖的外部作用。若它是不受约束的任意网络残差，就可能吸收任意材料/执行器误差，破坏归因。

若物理引擎仍对同一软地面区域施加原生法向反力，PANN 不得再施加一份法向力。切向摩擦由哪个模型负责也要明确。WBC/MPC 把接触力作为优化变量时，需施加相应材料/接触一致性条件，不能一边自由优化力，一边在仿真后处理阶段替换为另一个力而仍认为预测一致。

Jacobian、力/力矩和速度应采用功率共轭的同一坐标约定；\(v\) 是广义速度，不应在含四元数时直接写成 \(\dot q\)。无需为这点改变算法，但实现接口必须一致。

### 1.2 “关节状态”和“世界 cell 状态”正确，但有模型适用域

执行器状态随对应硬件/关节保存，不能随足端换落点重置。为避免符号混淆，建议分别写 \(z^{\rm act}\)（执行器动态状态）、\(\theta^{\rm act}\)（执行器参数）、\(c\)（材料参数）、\(\xi\)（材料历史状态）。

材料状态绑定世界 cell，适用于当前固定基底、独立材料柱的近似。若后续引入明显侧向流动、材料搬运或跨柱应力传播，世界空间位置不再天然等于同一物质点，应增加材料坐标/输运关系。现有懒恢复的等价性也依赖独立柱假设。

卸载时应推进零外部载荷下的恢复，不能直接把 \(\xi\) 清零，也不能把“足未接触”误写成固定零应变。多足读写同一 cell 需要一致的世界状态，候选预测只能操作各自克隆的状态，不能修改真实环境状态。

### 1.3 因果 observer 与 generative actuator 的信息集合要分开

observer 可以使用时间戳 \(\le t\) 且实际已经到达的遥测。离线双向平滑结果、未来电流或未来触地标签不能进入部署输入。当前时间戳不等于已经收到，还应考虑传感和通信延迟。

用于候选预测的执行器模型最好明确输出两项：

\[
(z_{k+1}^{\rm act},\tau_k^{\rm act})
=\mathcal A(z_k^{\rm act},u_{\le k},q_k,v_k,V_k,T_k;\theta^{\rm act}).
\]

未来 \(q_k,v_k\) 来自该候选的动力学推进；未来电压和温度需要预测、显式冻结或有界假设，不能读取真实未来序列。存在命令延迟时，只写当前 \(u_k\) 而不保存命令队列并不构成完整动力学模型。

接触可通过预测的关节运动、传动负载状态反馈影响电机输出；不能为了“分离”而禁止真实的负载依赖。但模型不得把 PANN 接触作用直接藏入一个额外等效外力矩再加一次。需要用自由空间/已知负载等可归因数据约束这种分解。

### 1.4 浮动基方程能帮助分离，但不能唯一恢复多足力

未驱动基座行满足选择矩阵的执行器块为零，因此给出净外部 wrench 的约束。这是一个独立于关节执行器力矩的有用信息源，但其有效性依赖质量/惯量、姿态、加速度、接触位置和外力模型。

同一个净 wrench 通常对应多种单足力分配；因此“有浮动基六维方程”不等于“每个 cell 的材料参数都可识别”。若任意未知 \(f_{\rm ext}\) 同时存在，净接触 wrench 也不能直接从这些方程唯一分离。第一阶段实验应固定为无附加外力或使用独立可测外力，随后才研究有界外力干扰。

### 1.5 冻结材料参数是合理预测约定，不是完整自适应闭环保证

每个候选内部固定 \(c\)，允许 \(\xi\) 按物理规律演化，是清晰而可实现的第一版。若未来要预测“走几步后学到材料并改变控制”，需显式建模未来 belief update；不能把冻结参数 rollout 同时称为已实现的未来学习规划。

候选材料可以从当前后验采样，但同一候选的固定未知材料样本不应每个预测时间步独立重采样，否则人为制造了物性抖动。物理参数变化模型是另一项扩展。

### 1.6 历史重放＋记录 ΔE 仍不是通过能量门槛

在可得窗口上重放是正确的候选参数检查，但短窗口起点的 \(\xi_0\) 若未知，不能声称已经恢复完整历史。需要联合估计/保持初态不确定性，或说明已从可验证的完全恢复状态开始。

储能差应使用相同物理时刻和状态定义，并对材料体积积分：

\[
\Delta E_{\rm est}
=\sum_j V_j\Big[\psi(\hat\varepsilon_j^+,\hat\xi_j^+;c_j^+)
-\psi(\hat\varepsilon_j^-,\hat\xi_j^-;c_j^-)\Big].
\]

这里只比较模型的估计版本，不修改真实地面状态；应力/能量单位、合成缩放和体积权重必须一致。若执行器储能状态或参数也更新，应另记其模型储能变化。

**日志中记下非零 \(\Delta E_{\rm est}\) 只是诊断，不是通过被动性/稳定性验证。** 真要声称整体能量性质，需要明确允许的切换储能、相应供给率或可证明的预算条件。仅降低拟合残差、逐模型耗散非负或把力平滑一下都不充分。

## 2. 原材料报告已修正的可辨识性措辞

原稿有两个容易导致过度解释的地方，已直接补入 `material.md`：

1. 原观测函数包含未知 \(\xi_0\)，但 Schur 补只消去执行器参数。现在 nuisance \(\eta\) 同时包括未知材料初态、执行器初态/参数以及必要的几何/传感偏置。
2. 带先验精度的 Schur 补现在只称为“先验条件下的后验局部曲率近似”，并增加无先验的数据敏感度：

\[
F_{c\mid\eta}^{\rm data}
=J_c^\mathsf T(I-J_\eta J_\eta^\dagger)J_c.
\]

该式假定测量噪声协方差已正确白化，参数已按尺度归一化；数值伪逆阈值及扰动敏感性应报告。局部 Jacobian 谱诊断的是**当前模型、参数点、协议和接触模式附近的一阶区分能力**，不是全局结构可辨识性证明。

有限差分会受步长、积分容差、噪声和接触模式切换影响；自动微分也不消除模型错误或模式不可微。矩阵满秩在适当正则条件下可支持局部结论，但一次数值满秩没有证明这些条件；秩亏也不能排除高阶可辨识性。神经材料 embedding 的坐标旋转/缩放/置换等价性要固定或按预测等价类评价。

先验可以收缩不确定性，却没有添加测量。数据本身无法区分两个材料时，应该明确结论由先验选择。重复使用重叠滑动窗口时，也不能把同一观测当成独立新证据反复更新后验。

## 3. 独立 PANN 的最小跨因素矩阵

先采用**八个条件格子的材料台/等价仿真测试**，全部方法复用同一批数据。目的是发现方法是否有明确价值，不在这一轮同时遍历步态、机器人速度、地形、多个 RL 算法和所有材料参数。

| 因素 | 水平 0 | 水平 1 | 解决的归因问题 |
|---|---|---|---|
| M：材料迁移 | 训练材料族内、未见材料 ID/参数组合 | 预先留出的本构形状或时间尺度族 | 是参数插值还是能处理模型失配？ |
| H：历史初态 | 可验证的充分恢复初态 | 预载后进入支持窗口，初态未知 | 是材料适配，还是偷用了真内状态？ |
| P：支持协议 | 单一速度的压入 | 两种速度＋保持＋卸载/再加载 | 改进来自辨识机制还是只是更多激励？ |

采用 \(M\times H\times P=2\times2\times2\) 完整交叉；每类 M 最少预先选择两个材料 ID，因此只需 **16 段短的支持＋查询数据**就可运行首轮。两个 ID 只是最小重复，不能据此宣称广泛材料泛化。

两个 P 水平匹配观测样本数、总支持时间和允许的最大压入范围，记录实际机械功/载荷差异。每个材料使用同一段预先固定的留出查询协议，包含未用于适配的速度或恢复间隔；查询数据不参与调阈值和参数发布。

最小方法集合：

| 方法 | 用途 |
|---|---|
| 固定原 PANN | 测跨材料适配的必要性 |
| 预先固定形式的低维黏弹模型＋MAP | 判断经典辨识是否已经足够 |
| 条件 PANN＋普通小维适配 | 排除“只要有 embedding 就能提升” |
| 条件 PANN＋本文受约束适配 | 主方法 |
| 真材料＋真内态 oracle | 仅作误差下界，不是可部署竞争方法 |

第一阶段可让两个条件 PANN 方法共享同一已训练材料族，仅比较更新机制，避免表示容量变化和适配改造同时发生。只有机制确实有效，才增加一次“共享训练 vs support/query 元训练”的对照；不需要为八格分别训练八个大模型。

最小主要指标为留出合力预测误差、恢复/重载峰值误差、错误自信/更新拒绝情况、Newton 失败率、能量/切换储能残差以及适配 P99 时延。参数误差只在合成真参数具有可辨识意义时报告。比较应使用配对材料/协议/噪声；训练型方法的少量随机种子结果不能替代跨材料重复。

### 3.1 再用一个四格试验检查执行器—材料混淆

八格独立材料试验不含机器人执行器误差，因此还需一个针对联合接口的 **2×2 小对照**，而不是把执行器扰动再乘进全部八格：

|  | 执行器标定条件 A0 | 执行器条件改变 A1 |
|---|---|---|
| 同一材料 C0 | 参照 | 材料估计不应把纯执行器变化当成地面变化 |
| 不同材料 C1 | 应识别可见的地面差异 | 检验两者同时变化时是否仍可归因 |

固定同一个信息较充分的协议和历史初始化方式；A1 首轮只选一种已知执行器变化，例如延迟或增益变化，避免一次混合多个未知因素。所有候选只使用因果部署观测，台架力传感/真力矩只用于评估归因与 oracle 诊断。未知附加体外力先关闭或独立测量。

通过条件不仅是总运动残差下降，还包括：在 C0、A1 中材料预测应保持合理；在 C1、A0 中应能表达材料改变；每部分的独立验证误差不能由另一部分抵消。若总误差小而归因错误，则该接口尚不能作为自适应材料主张的证据。

### 3.2 本轮停止条件

若普通条件适配或经典 MAP 在相同时延/观测预算下已达到同等效果，先报告这个结论，不扩大复杂模型。若只有 oracle 内态下才有提升，先处理历史状态估计；若材料随执行器扰动漂移，先修正联合分解。上述八格＋四格中没有明确有效机制前，不把整个机器人 PPO、步态和 MPC 同时重训来掩盖来源。
