# 步态—WBC 接口最终审查（2026-11-26）

本审查仅分析主代理提供的设计草稿及本轮已读步态材料，没有新增检索、没有训练或修改仓库控制代码。以下是设计条件与逻辑检查，尚未构成实现验证或稳定性证明。

## 一、总判断

草稿方向合理：把已存在的非线性浮动基 M、h、J 作为基础，把新的研究对象放在执行器—接触模式—材料响应的闭环协同；HIM 的响应表示不能代替经典 IMC 的稳定性条件；浮动六自由度不能随意反演；机器人主动行走不能被笼统描述成无条件被动。

需要补齐五个关键条件，才能使提案自洽：

1. WBC 中的力矩必须区分“已实际作用的电机力矩”和“本周期发出的命令”。有执行器状态和延迟时，二者不能共用一个自由变量 τ。
2. 软地法向材料关系不能与同一方向的刚性零接触速度/加速度约束同时硬施加。
3. 接触事件可以改变 observer 的坐标、模型和置信度，但不应一律清空执行器动态记忆；材料 world-cell 状态应连续继承并按物理模型更新。
4. 步态论文的独立收益需要在固定 WBC、相同动作权限和相同事件回调频率下证明；新的 WBC 与新的 gait 同时上线只能首先证明联合效果。
5. 有限步恢复、相位同步和误差储能是三个不同命题。学习分类器的高分、CPG 的收敛、控制器的参考连续性，都不能单独证明机器人恢复可行。

## 二、WBC 动力学和执行器变量必须对应真实对象

建议先统一记号：

\[
M(q)\dot v+h(q,v)=S^\top\tau_m+J_c(q)^\top\lambda+d,
\]

其中 \(\tau_m\) 是电机实际输出的关节力矩；命令使用另一个记号 \(u\)。执行器隐状态 \(a\) 满足：

\[
a_{t+1}=f_a(a_t,u_{t-d:t},q_t,v_t),\qquad
\tau_{m,t}=g_a(a_t,u_{t-d:t},q_t,v_t).
\]

如果 WBC 优化 \(\dot v,\lambda,\tau_m\)，必须有执行器可实现性约束，将 \(\tau_m\) 与 \(a_t,u\)、历史命令、饱和及速率限制关联。否则优化器实际上拥有一个不存在的“瞬时理想力矩执行器”。可选实现为：同时优化 \(u\) 与预测 \(\tau_m\)，或先得到期望机械力矩再经有界执行器逆映射，并将不可实现残差返回上层。后一方案的实际残差必须纳入分析与日志。

若命令存在非零 delay，本周期的 \(u_t\) 可能无法改变本周期 \(\tau_{m,t}\)。应明确预测时点，使用已作用力矩估计当前加速度，使用动作队列预测新命令生效时的状态；不能把未来可实现的力矩直接写进当前动力学等式。实时推理速度快也不会消除物理延迟。

HIM 表示、NeuralActuator、PANN 和扰动 observer 应有分工：执行器模型解释命令到力矩的响应；材料模型解释足端法向作用；observer 解释剩余可观测误差。若三个模型都学同一净加速度残差，再叠加补偿，会重复抵消同一个误差。需要通过消融和残差闭环日志核验，而不是靠模块命名区分。

## 三、材料接触约束：避免软接触与刚性接触相互矛盾

对于固定地表、以向下压入为正的法向形变量 \(\delta_i\)，材料模型可写为：

\[
\lambda_{n,i}^{+}=F_\theta(\delta_i^{+},\dot\delta_i^{+},z_i^{+}),\qquad
z_i^{+}=G_\theta(z_i,\delta_i,\dot\delta_i,\Delta t).
\]

下一步形变量必须由同一足端运动预测产生，不能成为与 q/dq/qddot 无关的额外自由量。若已允许法向形变，不能同时对该法向硬施加 \(J\dot v+\dot Jv=0\)。切向可以根据粘着/滑动条件分别使用 no-slip 或摩擦关系；“足接触”不自动等于三向无滑移刚性约束。

约束最低要求包括法向单边作用、没有接触时无法凭空产生地面支撑、摩擦与力矩/速度边界，以及材料状态的物理允许域。加载和卸载的不同关系可以来自同一含记忆的材料模型，不必人为切成两个互不一致的网络。

材料关系若非线性隐式，整体已不是原来的普通 QP。若采用逐次线性化或固定少量迭代，应报告材料关系残差、动力学残差、约束松弛和实际闭环结果；不能把数值线性化近似称作精确隐式求解。必要时只将可信的局部线性化放入快速 WBC，将较长时域材料演化留给 MPC。

还应选择一致的冲击模型：如果接触力已经通过柔性压缩在若干仿真步内积分，就不能再无条件附加一次理想刚性 impact 速度跳变，否则可能重复计算冲量/耗散。若某些刚性碰撞确需混合跳变，应清楚声明它与柔性接触的切换条件。

## 四、经典 IMC 的可实现边界

“名义模型+低通逆+误差反馈”的表述需要限定被逆对象和不可逆部分。纯延迟的精确逆需要预见未来；非最小相位零点的直接逆会产生不稳定。单纯在形式逆后接低通滤波器，不会自动解决这两个问题。

建议只对可稳定、因果、proper 逆的局部执行器/接触响应部分设计 \(Q_\sigma\)，保留延迟、非最小相位及不可观测部分在预测器或参考整形中。各接触模式使用不同模型和带宽，但切换瞬间应约束命令连续性与积分/滤波器状态映射。模式误判、模型误差和延迟范围都进入条件分析。

机器人浮动基位姿不应被直接放入“全部可逆输出”集合。对可补偿扰动，既要看结构子空间，也要看执行器、接触摩擦、单边力和时序约束。仅投影到 \(\operatorname{range}[S^\top,J_c^\top]\) 不足以断言可实现；该线性子空间忽略了力矩饱和与摩擦锥。

更明确的接口是当前可实现广义力集合：

\[
\mathcal F_\sigma=\{S^\top\tau_m+J_c^\top\lambda:
\text{执行器状态、接触模式及全部物理约束成立}\}.
\]

结构不可控、饱和受限、接触尚未承载、延迟未到生效时点，是不同不可实现原因。WBC 应回传原因、剩余可实现 wrench/力矩余量、时间窗口和置信度，而非只回传一个“QP失败”布尔值。上层才知道应降速、延长支撑、改相位还是重选落足。

## 五、接触模式、observer 和 world-cell 状态如何衔接

| 物理/估计状态 | WBC 的主要约束与关注点 | 给 gait/MPC 的信息 |
|---|---|---|
| 飞行 | 该足 λ=0；执行器/摆腿运动可实现性 | 预计触地分布、剩余摆腿时间、摆腿可达域 |
| 初触/接触不确定 | 抑制将低置信接触当完整支撑；检测异常冲击 | 接触概率、时间区间、冲击/估计残差 |
| 加载 | 材料压缩与力建立关系；限制冲击/饱和 | 承载建立分布、可用法向力增长区间 |
| 承载 | 可实现力/摩擦/力矩与材料状态一致 | 支撑余量、滑移风险、允许卸载时间 |
| 卸载/预离地 | 限制残余承载时强制抬腿；保持参考连续 | 可离地窗口、残余负载、预计足端状态 |

这些是接口分工，不能把新增几种状态名称当作新 WBC 理论。项目已有 confirmed/loadbearing 逻辑继续作为实现资产。

Observer 的切换应使用模式相关映射 \(\hat x^+=R_{\sigma^-\to\sigma^+}(\hat x^-,y)\)，必要时扩大协方差或暂时降低高频残差补偿。未验证 impact 的真实跳变形式之前，不应默认“全部 reset”。执行器迟滞、摩擦或热状态通常跨接触持续存在；盲目清空 RNN/history 会丢掉正要利用的状态。

材料 world-cell 状态不被 observer reset 删除，但仍需按实际加载、卸载和时间恢复继续推进；“保留历史”不等于把状态冻结。重复访问 cell 时要使用当前置信度和定位关联误差。已有 lazy recovery 机制无需重复包装为贡献。

## 六、phase ≠ touchdown ≠ actual bearing：提交与确认协议

步态相位定义的是参考节律；touchdown 表示发生接触；bearing 表示已经形成可用支撑。三者应分别记录和传递。较高接触概率或四足接触数量，都不能替代力矩受限下的支撑能力。

建议每个新计划都带 `plan_id / issue_time / intended_apply_time / observation_time`。gait 发送相位变化、接触时间窗口和摆腿参考；MPC 发送一致的机身/力参考；WBC 用当前实际模式与可实现性检查返回 accepted/projected/rejected 及原因。执行的 plan_id 与实际动作时间写日志。异步更新时不能使用新 gait 的 swing 状态配旧 MPC 的 stance force，同时又保留旧 WBC 接触约束。

真实事件改变后，WBC 的实际接触估计优先于名义相位；但修正不应造成关节目标、足轨迹或扭矩无界跳变。所有比较方法应使用相同的参考连续化和保护投影。如果保护层接管完成大部分恢复，必须记录接管比例、施加修正及接管前后的动作，不能把保护层能力全部归给新 gait。

## 七、怎样证明“本体感觉 gait 模块本身有贡献”

### 7.1 主实验先固定低层

第一组独立步态实验固定原有稳定 WBC/MPC/PD 及其参数、状态估计、接触确认、动作投影与保底策略。PANN/NeuralActuator 若用于 gait 的独立主对照，应统一关闭或给所有方法相同冻结模型，不让新 gait 独占更强状态估计。

新增 gait 接口的兼容性修改可做，但必须同时给予全部对照。标准固定 gait 是回归参照；真正证明算法新意的是相同 16 维权限的 actor、事件/力反馈 CPG 和其他强基线。增加动作维度本身是能力扩展，不能用它证明事件模型更好。

明确对齐：传感器及历史长度、真实可部署 estimator、事件回调频率、允许 phase correction 的时点、输出范围/变化率、摆腿和落足权限、低层计算预算、保护规则、训练互动数据量。模型额外训练与推理成本单列报告。若新方法在 500 Hz 回调修相位，对照也必须能使用相同回调与同等有界修正权限，不能只允许对照在 50 Hz 改名义 gait。

本体感觉版本不输入真实地形高度、材料系数、负载/故障 ID 或执行器 delay。足端力/电流若是实机实际可测量通道，可以使用，但必须对照一致；若只能由 observer 估计，所有方法使用同一估计结果及置信度。

### 7.2 联合实验用因子设计定位增益

| 组合 | 意义 |
|---|---|
| G0 + W0 | 同权限常规 gait 与现有 WBC |
| G1 + W0 | 新 gait 是否独立改善 |
| G0 + W1 | 新 WBC 单独带来的改善 |
| G1 + W1 | 联合效果与交互作用 |

其中 G0 必须包含一个具有相同动作权限的强 actor，不能只有固定 trot。如果 G1 只在 W1 下改善，可以形成有价值的联合论文，但“步态独立贡献”尚未成立。也不能简单把两个单独收益相加当联合效果；应分析交互项和失败类型变化。

新步态可能要求低层当前做不到的参考。应先测参考可跟踪范围，避免因低层执行能力缺失而错误否定 gait；同时不能为 G1 特别调 WBC 而保持 G0 的旧低层参数。

## 八、有限步恢复证据的定义与边界

恢复起点应在预设扰动或接触执行偏差发生时确定，不能只挑已经成功接住的 touchdown 后开始计时。事件计数使用相同定义和去抖规则，多个近同时接触如何算一步预先固定，避免接触抖动增加“已恢复步数”。

终端恢复集合至少覆盖姿态、速度误差、扭矩余量、脚滑、接触状态与执行器/材料隐状态置信范围，并要求随后一段窗口继续完成目标运动。站住不倒不自动等于恢复到行走。若状态在 H 次接触事件内到达集合但随后马上失稳，也不能计成功。

没有接触事件发生或机器人停止前进时，不能无限等待后宣布“还没到 H 步”。应有明确的物理试验观察窗口及失败标准。这是任务评价口径，和不设置后台训练墙钟完成时间是不同问题。

理论上的 H-step recoverability 需要在指定状态域、误差界与约束下存在一条可执行控制序列；学习分类器只有统计预测作用。验证可采用配对扰动相位/强度网格、留出延迟变化、重复实机测试与置信区间；实验估计的恢复域应标为“已测试区域”，不能直接等同真实最大 viability kernel。

重要否定条件：同权限 G0 已获得同等恢复率；收益只能在 oracle delay/material 输入下出现；新方法主要靠高频保护接管；恢复以更多过载、冲击或停止不动为代价；新方法只有与 W1 一起使用才有效。不同情况分别决定独立步态或联合算法论断是否成立。

## 九、能量、冲击与条件混合稳定性

### 9.1 储能论断的合理形式

主动步行持续消耗执行器能量，不能把从“地面接触端口”看到的局部耗散推成全系统无条件被动。若研究材料储能，按上述压缩正方向，进入地面的法向机械功率为 \(\lambda_n\dot\delta\)；卸载允许释放之前储存的能量，不能要求每瞬间接触功率非负。

若研究误差/增量储能 \(S_\sigma\)，变化参考会产生 \(\partial S/\partial r\cdot\dot r\) 等供能项，必须明确保留。电气输入功率、机械力矩功率与参考端口功率应分别定义，不能在一个物理总能量平衡里重复计算。模式切换还需验证 \(S_{\sigma^+}(x^+)-S_{\sigma^-}(x^-)\) 的跳变界，不能只给每个连续模式内的下降不等式。

条件 hybrid ISS 可以作为拟研究目标，但至少要写明：模式识别/估计误差界、执行器和材料参数范围、求解误差、参考变化范围、接触切换/非 Zeno 条件、初始可行域和必要的接触可控性。若这些界没有在目标场景成立，就不应宣布已得到机器人混合 ISS 保证。

### 9.2 实验指标不能掩盖主动功率与冲击

至少分别报告：电池功率/电能（如果实机可测）、各关节正机械功、负机械功、绝对机械功以及峰值/持续力矩。\(\sum_j\max(\tau_j\dot q_j,0)\)、\(\max(\sum_j\tau_j\dot q_j,0)\) 与 \(\sum_j|\tau_j\dot q_j|\) 不等价，不能混用后统一称真实耗电；是否跨电机能量回收需按硬件能力处理。

接触冲击报告统一采样率/滤波下的峰值、加载速率、接触窗口冲量、机身加速度及足滑。仿真步长或力传感滤波不同会改变峰值，不能在不同带宽下比较冲击改善。材料更软造成峰值下降，也可能伴随更长支撑滞后、更大形变和更多能耗，须共同评价。

CoT 只在有有效位移和稳定统计窗口时有清晰含义；停走、跌倒、低速区间另外报告任务能量和失败率。全 episode 结果与成功条件下结果并列，不能排掉高能耗失败样本后宣布同时更省能、更鲁棒。

## 十、建议主报告使用的表述

“我们拟研究一个执行器与材料响应一致的混合 WBC，并向步态/MPC 显式反馈当前可实现支撑与接触建立时间。步态模块学习真实事件驱动的相位响应和有限步恢复策略。先在固定低层上验证步态独立收益，再通过 gait×WBC 因子实验检验联合效果。理论目标限于具有明确误差、参考和切换条件的混合稳定性或增量储能结论；当前设计尚未形成这些保证。”

这一表述符合现有证据，不把已有 M/h/J、接触状态机、学习表征或材料历史重新包装成新控制理论，也保留了后续通过扎实机制和实机实验形成独立创新的空间。
