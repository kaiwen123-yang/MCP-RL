# MPC 与 WBC：扩大到算法内部的独立研究设计

日期：2026-11-26，Asia/Shanghai。性质：文献方法审读与新研究设计，不是新实验结果。这里的候选名称只用于讨论，不宣称首创或已证明。

本轮不再由 NeuralActuator、早触故障或当前三维动作权限决定研究上限。目标是让优化器和全身控制器各自拥有可独立比较的方法、理论问题、实现和实机证据。既有模块中的非线性刚体动力学、接触 Jacobian、力矩限制不能重新计作创新。

## 2. MPC候选一：混合接触空间上的全局搜索与局部求精

### 2.1 完整优化对象

决策不再局限于接触力QP，改为联合决策

\[
\zeta=(m_{0:K},\Delta t_{0:K},p^{foot}_{0:K},r_{0:H},u_{0:H-1}),
\]

其中m是接触拓扑，时间间隔为正，足点受地形几何限制，r含躯干/质心/关节参考，u为实际驱动命令。预测状态包含机器人、材料记忆与必要执行器状态。不是每个周期都自由优化全部量：保持相同数学问题，用不同层级控制点压缩维度。

### 2.2 求解器本身的改造

1. **拓扑分组搜索。** GPU批量展开多个接触程序与多个材料假设。每类保持自己的可行精英和局部连续分布，不将互斥接触模式的动作做简单平均。
2. **结构化局部模型。** 对同一接触程序构建稀疏线性化/二次化，处理接触内状态的隐式导数；在可信的固定模式段进行GN/SQP/DDP求精。模式改变重新建局部模型，不假装整个混合系统处处光滑。
3. **残差驱动的分布更新。** 吸收VR-MPPI，但把近似对象设为“给定拓扑、给定模型的可实现闭环代价”，按完整非线性rollout的残差校正局部预测；KL/熵限制控制分布坍缩。每个接触分支明确目标参考分布p0与实际提议q；自适应分配后保留重要性修正log p0−log q，并处理变量变换Jacobian。材料场景按同一信念聚合风险，不能从最乐观的一个材料假设挑动作。
4. **计算分配也成为决策。** 在探索新拓扑、细化当前轨迹、增加材料场景、验证约束之间分配下一批计算。依据已观测的单位时间可行改进与场景分歧安排预算，并保留最低探索量；这是待研究的调度准则，不称全局最优保证。
5. **多率执行。** GPU提供较大候选集合与先验，CPU/部署端负责最后的稀疏精化和高频反馈。端到端延迟含数据传输、材料预测、求解、WBC及命令下发。

### 2.3 独立贡献应落在什么位置

“GPU+MPPI+DDP”不足以区分已有工作。可检验的主张是：在具有材料记忆和接触拓扑变化的同一非凸问题上，**拓扑保留的分布更新及闭环可实现曲率，能在固定端到端预算内找到更多有效运动模式，并降低局部精化的无效计算**。

必须比较纯SQP/DDP、多初值DDP、MPPI/DIAL、VR-MPPI、信赖域MPPI、简单串联采样→DDP及新分配法。分开等时间、等rollout和等硬件三种比较。实时性看部署设备上的p99与超期率，任务表现看约束违反、能耗和动态行为质量。

## 3. MPC候选二：材料与能力信念下的风险/信息协同规划

此方向不以更快求同一个名义最优解为核心，而是改变决策问题。维护材料族、材料记忆及逐腿能力的结构化信念b；离散材料类别可用粒子，类内参数用低维连续近似，避免所有未知量笛卡尔积枚举。

\[
\min_\zeta\;\mathbb E_b[J(\zeta)]
+\beta\operatorname{CVaR}_{\alpha}(L_{fail}(\zeta))
-\eta\,I(\vartheta;Y_{future}\mid\zeta,b),
\]

并满足输入、几何和支撑可行约束。信息项表示动作怎样改善将来的材料/能力判断；必须通过可获得传感器的观测模型计算，不能把未来真参数注入规划器。可先使用有限候选的预期后验下降，再研究更完整的信念传播。

**具体算法问题：**接触时长、加载幅度和左右足落点同时影响移动性能与材料可辨识性；要识别哪些探测动作值得做、在何种风险预算下做，以及信息何时应改变步态。与LLA-MPPI的单一模型选择相比，保留多假设和动作信息价值；与普通风险MPPI相比，包含材料的历史记忆及可选接触结构。

比较时匹配总风险水平与任务速度，禁止靠站住或走得很慢获得“更稳”。核心指标是突变后的累计任务代价、适配样本量、未见材料/能力组合中的尾风险，以及是否真正选择了不同而有益的动作。CVaR估计不是硬约束证明；分布鲁棒结论需要明确歧义集合覆盖假设。

## 4. MPC候选三：学习优化器与可部署的预测前馈

把求解器的初值、局部度量/预条件器、终端价值和迭代分配作为可训练对象，目标是**有限迭代后的实际闭环表现**，而不是仅拟合离线最优动作。

训练样本覆盖速度、转向、地形、材料、负载、执行器能力和传感延迟。网络给出多个接触模式候选、控制点、稀疏预条件结构和终端代价；固定少量结构化优化步骤后，使用独立真实模拟轨迹评估。学习初值、预条件器和有限步调度时，对实际执行的K步求解过程求导，或采用score/黑箱外层优化；收敛最优解的KKT隐式导数通常消掉这些算法路径的影响，不能替代有限步导数。热启动误差、求解残差及约束残差共同约束训练，不能靠减少约束取得更短延迟。

前馈需要进入完整预测：计划力→材料变形/加载过程→关节参考/扭矩→驱动动态→实际接触作用。对可逆、稳定部分做逆补偿；纯延迟通过提前规划处理，不做非因果逆。预条件器、迭代与精度可在部署前编译/蒸馏，模型适配以低维参数更新为主。

最近邻是学习热启动、可微MPC、μMPC、MPC蒸馏与BMPC等。差异必须是接触模式和材料状态变化时的泛化、真实求解次数下降及可行性保持，而不只是“神经网络输出初值”。这是与候选一可以共享实现、但能独立立项的优化器学习课题。

## 5. WBC候选一：接触约束下的自然任务动力学与可实现解耦

### 5.1 从真实浮动基系统出发

\[
M(q)\dot v+h(q,v)=S^T\tau_{act}+J_c^T\lambda+d.
\]

已存在的M、h、J不是新内容。需要改的是：怎样选择闭环任务惯量，哪些任务能解耦，如何保持接触力与执行器能力的可实现性。

在当前刚性约束的切空间取N，得到约化惯量M_N=N^TMN、驱动映射B_N=N^TS^T；柔性法向接触保留材料状态，不同时施加刚性零法向加速度。一般B_N不是满行秩。因此不能直接套用全驱动逆动力学，也不能对不可控任务写任意解耦目标。约化动力学还必须保留N随状态变化产生的连接项（包括Ṅ贡献），不能只替换M就沿用原能量恒等式。

### 5.2 新设计

从可控任务子空间的自然任务惯量出发，保留对角块，按接触、地形和逐腿能力选择可实现的非对角耦合。WBC优化的不只是任务误差权重，还包括**任务间允许耦合、阻尼与可实现前馈**。固定秩模式内可使用连续基变换和秩感知调节；秩或维数改变时采用不同局部chart与显式过渡/跳变条件，或固定环境维数的松弛表述，不能要求一个变维N跨事件始终连续。

物理QP/小型SQP同时求加速度、接触力和命令增量；未驱动基座动力学严格保留，扭矩/摩擦/功率约束进入同一问题。目标可以包含任务误差、偏离自然惯量的代价、力变化和实现残差。先研究局部固定模式的部分解耦，再分析模式切换的能量与误差变化。

### 5.3 独立研究假设

在同等跟踪速度与约束下，**保持自然惯量结构并仅实现可行解耦**，比固定单位惯量反馈线性化或固定任务权重WBC降低对接触模型误差和外力估计延迟的敏感性，同时保持多任务能力。

对照现有QP-WBC、层级逆动力学、被动任务控制、FND的适用子问题、柔性接触WBC。验证躯干扰动/摆腿/承重的交叉耦合、力冲击、扰动放大、执行器饱和、平均与最坏延迟。理论目标是有界模型误差下的局部ISS/耗散界和切换条件；不是无条件全局稳定。

## 6. WBC候选二：相位相容的学习内模与复合自适应控制

用户的“混合内膜”按“混合内模”理解，但三个概念分开：HIM是历史编码的显式/隐式表征；经典IMC是模型误差反馈结构；内模原则是对参考/扰动生成器的动态再现。本方向利用它们可用的部分，不把名称等同。

控制器内状态包含：运动相位/参考生成器、可解释低维动力学参数、历史特征和有限维扰动生成器。周期成分用相位条件基函数或可适配振子表示；非周期残差用有界历史特征表示。模型误差的瞬时跟踪信号与窗口预测误差共同更新低维系数，离线训练共享基，在线只更新可负担的少量参数。

控制律的核心是**前馈、误差动力学与可行力分配共同设计**。已知参考加速度、材料加载路径与估计执行器能力生成前馈；反馈负责剩余误差；WBC对不可匹配的基座外扰通过可用接触力和躯干参考响应，不假设都可由关节力矩直接抵消。

与简单ESO叠加的差别：内模学习周期结构与状态依赖，并且它的更新由控制误差几何和可实现性共同约束。要研究模型辨识与轨迹跟踪的复合适配律、跨接触模式参数共享，以及参数误差怎样进入闭环误差界。

比较HIM特征+固定WBC、经典IMC-WBC、ESO/WB-DRC、只做参数适配、只有学习前馈和完整方法。若收益仅来自更大网络或更多观测，不成立。未知周期扰动、负载变化、单腿衰弱及非周期推扰应分开测试。

## 7. WBC候选三：材料储能、接触功率与任务能力联合控制

此方向改的是控制器允许的能量流与力分配，而非额外附一个安全缩放系数。将机械误差储能、材料内部储能及必要的控制器储能组成V。对于行走，参考和执行器本来就供能，因此采用带供给率的目标

\[
\dot V\le -\alpha\|e_{\perp}\|^2 + P_{ref}+P_{ext}+\sigma,
\]

并显式计算接触事件及参数更新带来的储能变化。σ必须具有预先规定的幅值/累计预算，并报告实际使用量。材料储能加入系统后，足端接触功率是机器人与材料之间的内部交换，不能再全量算入P_ext；外部端口和参考供给单独定义。e_perp是轨道横向误差；不能要求运动相位也收缩到同一时钟。材料卸载可能返还能量，压密/滞回可能耗散；两者影响下一次落脚的力与速度约束。

在一次约束优化中共同决定接触力、局部阻抗、任务推进率与功率分配，使相同电机能力被用于更有价值的身体/摆腿任务。约束冲突要有明确优先级和松弛代价，不能用被截断的任务掩盖失败。

与CBF-tank、变阻抗控制和传统passive WBC相比，要检验的是**混合柔性接触中的能量再分配与任务推进相容性**。需要证明的范围包括固定模式储能不等式、切换供给/跳变界、饱和时的可行条件。实机比较电气能耗、正负机械功、恢复时间、任务速度与接触峰值，不能只靠能量tank停止运动来获胜。

## 8. 选型与并行关系

- MPC首选候选一做求解器主线，候选三研究有限预算部署；候选二独立研究适配/主动探测，不应在第一版把三种机制全部混成不可解释的大系统。
- WBC首选候选一做动力学结构，候选二做自适应误差动力学。候选三与材料记忆和步态能效结合，拥有独立问题和实验。
- 同时建立共用任务集，但单模块证据先通过固定其他模块的直接比较形成。联合系统再考察能力增益和交互项。
- 当前S1可以提供初始数据、控制基线与回退；步态设计空间、材料族和任务范围向前扩展。不存在“旧三个参数没有收益，所以下一轮也只能改三个参数”的限制。
