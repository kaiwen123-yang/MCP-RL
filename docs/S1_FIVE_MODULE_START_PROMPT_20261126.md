## 四、六工作包并行推进

### A 材料

条件势保持结构约束；材料身份、历史初态、执行器/测量 nuisance 分开。先做 8 格材料适配小矩阵和额外 4 格归因，不展开海量全因子训练。对照经典参数 MAP、普通条件 PANN、受观测约束适配。数据局部信息与先验后验曲率分别报告。参数更新记录储能变化并检查状态转换；不要把能量记账称为被动性保证。

### B 步态

先固定估计器、MPC、WBC、PD 和保底逻辑。所有主对照使用相同 16 维动作、事件回调频率和投影；比较实际 touchdown/承载建立/liftoff、过渡与恢复、能耗、冲击和饱和。相位改变保持参考连续，不能用更高控制权限赢过基线。同步名义相位、实际接触、承载图和视频。

### C MPC

先用已知模型隔离求解器贡献。比较 CPU 与 GPU 的同模型、同约束、同精度和同端到端时间。候选×场景×多起点批处理，触地附近细化，少量精修。带状态时间戳、模型版本和有效窗口；发布时对齐实际已发动作，从当前状态重新展开/精修并检查可行性，不只更新元数据。

### D WBC

区分 HIM 表征与经典 IMC 控制结构。只逆稳定、因果且 proper 的部分，不逆纯延迟或不稳定零点。柔性法向材料相容不能同时施加该方向刚性零加速度约束；接触冲量只计算一次。返回可实现支撑余量、时间窗口和拒绝原因。固定参考下对比现有 WBC、KV/STANCE、IMC 与扰动观测控制。

### E 学习

首先做 frozen actor 闭环导数与估计器成本实验。控制器/执行器/动力学导数是一条链，不能重复相乘或作为三个完整 actor 梯度相加。保留独立 HF value anchor。

PPO 必须明确概率架构：上游 raw 请求、下游执行器作为环境时复用 old logp 必须固定执行映射；若 solver 输出是策略分布参数，则重建对应 likelihood。Conditional CV 首版限 fixed-θ/fresh-batch 单次估计，独立校准系数与门控，有限 K 修正；不要声称多 epoch PPO、Adam 或 KL 回滚后的最终更新无偏。

### F 执行器与集成

审计真实可用遥测与时间戳。固定官方 NeuralActuator 代码版本 541a93aac4368e73883e86a51f31a7add6bde059，只借鉴经核验接口。先自由空间/已知负载，再材料×执行器 4 格交叉。对照简单延迟/摩擦、历史黑盒与可分解生成模型。若简单模型已足够，不强制加大神经网络。
