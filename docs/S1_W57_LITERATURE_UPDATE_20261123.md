# W57 文献复核与 W58 实验映射（2026-11-23）

审查基点：`fd4ede8d46572d638b736d4538f4d9946326265d`；本文件给出文献复核和下一阶段设计依据，不报告新实验。此前 `e2d3892` 中的机制证据继续有效。检索以2025–2026为重点，保留直接影响运动质量和对照设计的较早论文。仅依据作者全文、出版社与作者仓库；不报告未核实的中科院分区。没有据定向检索宣称新颖性已经穷尽。

## 1. 本轮最重要的判断

1. “MPC＋RL”“接触时序学习”“从历史估计软地面性质”都已有明确近邻。待证明的贡献应落在同一世界地块的可恢复材料内态、动作条件预测和跨足/重访效益，并解释其超过当前接触反馈、近期本体历史和通用timing优化的原因。
2. 不建议因为论文新就替换目前成功的F控制链。先完成已经实施的M/P/R对照，再由具体首因决定改动。
3. 估计误差下降、候选排序改变、动作确实生效、任务改善是四层不同结果。应分别出证据，不能用一个替代另一个。
4. 形成更好步态的学习先验有价值，但周期/对称性不是所有地面通用目标。稳定地直行、转弯和短重访应分段评价；材料扰动下必要的不对称应保留解释。

## 2. 八项主要工作与阅读范围

### 2.1 Learning to adapt through bio-inspired gait strategies for versatile quadruped locomotion

- **出版**：Nature Machine Intelligence 7,1141–1153，2025-07-11，DOI 10.1038/s42256-025-01065-z。
- **一手来源**：[Nature](https://www.nature.com/articles/s42256-025-01065-z)、[作者公开全文v3](https://arxiv.org/html/2412.09440v3)、[官方代码与数据](https://github.com/ihcr/learning_to_adapt)。
- **已读**：公开全文的方法、指标、讨论与数据/代码可用性；出版社检索全文核对出版身份。
- **具体内容**：步态选择、调度器与运动策略分层；综合CoT、力矩使用、机械功和接触跟踪，另分析步周期CV。它的gait procedural memory是调度已知步态的结构，不是被踩地块的材料历史。
- **本项目映射**：已有稳定F之后，报告真实接触表、周期CV、功率/力矩分布与地面区间；不要只看无跌倒或回报。先借评价，不急着增加八步态选择器。

### 2.2 Residual MPC: Blending Reinforcement Learning with GPU-Parallelized Model Predictive Control

- **出版**：IEEE Transactions on Robotics 42:3469–3488，2026-08-07，DOI 10.1109/TRO.2026.3721669；前期公开全文为2025预印本。
- **一手来源**：[IEEE正式出版记录](https://ieeexplore.ieee.org/abstract/document/11644391/media)、[作者公开全文](https://arxiv.org/html/2510.12717v1)、[作者出版列表](https://seungwoo-hong.github.io/publications/)。
- **已读**：作者公开全文中的残差混合、训练、三类对照、GPU计时及运动行为分析；IEEE正式出版元数据已核实。
- **具体内容**：MIT Humanoid，kinodynamic MPC控制先验与残差联合训练；动作表示/混合方式影响学习。相同奖励等条件下比较MPC、残差、端到端策略。文中明确，100Hz是控制频率；1000环境每仿真步墙钟约0.5s，闭环MPC训练仍比普通RL贵。
- **本项目映射**：先确认新timing head的零动作行为、动作权限和其相对原F的偏离；用同任务、同预算对照，分开样本效率与墙钟吞吐。本文不是对本项目完整MPC上GPU的现成速度保证。
- **代码边界**：未确认完整Residual MPC实验训练代码；CusADi开源不等于整篇实验公开。

### 2.3 RL-Augmented MPC for Non-Gaited Legged and Hybrid Locomotion

- **出版**：2026；作者仓库列RA-L DOI 10.1109/LRA.2026.3675839。
- **一手来源**：[全文](https://arxiv.org/html/2603.10878v1)、[官方AugMPC](https://github.com/AndrePatri/AugMPC)。
- **已读**：接触注入、动作/观察、MPC状态回路、软件架构和结论。
- **具体内容**：SAC策略发出twist和每足flight injection；未来相位被写入MPC，并将其位置/长度纳入观察。注入节点前移更灵敏，但留给求解器的可行调整时间更短。它的模型未施加关节力矩限制，不能照搬这种约束边界。
- **本项目映射**：W57的请求→接收→实际交接和计划/执行同源是必要的。若PR弱于P/R，应检查R训练时P0和组合时P1的请求分布、基准时距与mask，而非直接认定材料无用。先区分冻结模块组合与真正联合再训练。
- **计算边界**：作者多实例吞吐来自具体CPU/GPU仿真架构；不能直接变成本项目25核服务器的吞吐预期。

### 2.4 Load-bearing Assessment for Safe Locomotion of Quadruped Robots on Collapsing Terrain

- **出版**：RA-L接收2025-10-09；2025公开全文。
- **一手来源**：[全文](https://arxiv.org/html/2510.21369v1)。
- **已读**：GRF包络、轨迹优化/MPC、探测状态机与实机实验。
- **具体内容**：根据整步预计GRF包络确定探测载荷，同时让其余三腿保持支撑；在Aliengo上评估塌陷平台/石块。
- **本项目映射**：材料预测应对准将发生的接触和载荷，而非一个与获选动作无关的恢复数。未来材料响应与支撑可行性需要共同解释；它为动作相关接触需求提供范例。
- **边界**：慢速探测/承载能力不同于TM02恢复记忆；不建议为S1另加探测动作作为当前前置条件。

### 2.5 Terrain-Adaptive Quadrupedal Locomotion Using Model Predictive Control With Impedance Control and SINDy Model Enhancement

- **出版**：International Journal of Robust and Nonlinear Control，2026-08-14，DOI 10.1002/rnc.70700。
- **一手来源**：[出版社全文](https://onlinelibrary.wiley.com/doi/full/10.1002/rnc.70700)。
- **已读**：接触/阻抗/导纳控制、SINDy作用位置、适应范围说明与实验范围。
- **具体内容**：在线更新的是接触状态、阻抗/导纳参数及参考偏移；SINDy模型离线学习后冻结，摩擦参数也固定。作者明确限定“地形自适应”指接触控制而非在线更新预测模型。实验为PyBullet。
- **本项目映射**：这是本轮新增的直接近邻。M1校正更准、WBC接触更好和P1未来材料决策的贡献必须分开；若当前收益来自反馈补偿，应准确命名，不冒称前瞻材料规划收益。
- **边界**：不能拿此文声称的改善比例当Go2预期，也不据仿真稳定性论证实机或未来全时域保证。

### 2.6 Imitating and Finetuning Model Predictive Control for Robust and Symmetric Quadrupedal Locomotion

## 3. W57 新证据改变了下一步重点

本节是依据仓库证据提出的研究设计，不是上述论文已证明本项目有效。

### 3.1 G：处理摆动末端早触反弹，准确限定问题

W57对四份旧基线完整E600的高频普查，将1047次小幅失载归为计划落地前4.4–13.2ms的摆动早触后反弹；confirmed bearing loss为0。因此G应定位首次实际碰撞后的参考接管、速度连续性和载荷建立，不能把这些事件改写成已确认承重后的支撑丢失。主要指标是早触—反弹发生率、触地速度、冲量、接触时序误差与原任务表现。相关来源：[完整事件普查](../results/terrain_memory/simulation/tm-s1-go2-local-readiness-r12/w57/p/full-force-off-summary.json)。

Nature MI与IFM提供运动质量评价维度；Wiley的接触反馈框架提示区分接触控制收益与未来材料预测收益。G的控制修改要由本项目实际事件决定，不能直接照搬其他机器人的增益或接触阈值。材料段、刚地段、转向分别报告，避免全程平均掩盖真实变化。

### 3.2 M2：将释放后跨足重载作为独立预测目标

M1短期整体预测改善不能覆盖其释放后重载误差增加。M2应以完整事件族划分开发/保留数据，将20.2ms短期与释放→目标重载预测分别评分；按真实卸载时间、足印重合度与原有材料残余分层。数据应包含同足重载、跨足重访与充分恢复，而不只选有利于某个校正器的片段。

使用真实未来加载作为共同输入的离线比较，属于条件预测检验；部署时仍只能使用已发布候选预测，不能泄漏将来真实测力。选择M2需要在目标事件上的保留误差支持，M1或M0仍作为对照；不要求新校正器必须被采用。来源：[分事件误差](../results/terrain_memory/simulation/tm-s1-go2-local-readiness-r12/w57/m/error-by-event.json)、[保存规划与长事件对照](../results/terrain_memory/simulation/tm-s1-go2-local-readiness-r12/w57/p/saved-planning-summary.json)。

### 3.3 P2：隔离材料历史、几何可用性与通用等待

W57已经接通在线候选，但当前材料私有历史干预没有产生获选排序改变；低频事件层的时序候选还会改变未来落点XY。因此，改变了动作不能自动归为材料记忆收益。下一阶段在相同几何、相同候选集合与相同硬界下比较完整历史、私有历史盲版本及固定等待控制，明确每种变化的来源。

P2预测必须绑定源加载和目标重载事件、实际地块/足印及候选载荷。完整历史与私有历史干预使用同一个当前支撑状态，不重置真实plant、共同observer或当前接触足的完整足印。Load-bearing Assessment提供动作相关未来载荷的范例；AugMPC支持显式记录未来相位及实际执行，但两者都不替本项目证明材料历史有效。

## 4. 任务、对照与联合学习的判定

### 4.1 先用物理曝光定义机制任务

短重访任务根据实际足印交集、源加载—目标重载间隔、残余材料状态与合法支撑定义。身体穿越次数和同一地块被另一足重载次数分别报告。允许依据基线轨迹修正反向足印错开，但所有控制器共享同一任务，且在查看方法间胜负之前冻结任务合同。

每个预声明的接触对都进入账本，未重合、无有效历史、失败和未运行不能事后从分母消失。新任务用于机制识别，原路线继续作为独立资格。不能以“P2胜出”判断任务是否构造正确。

### 4.2 首批最小有信息矩阵

在同一个合格G和选定M下，采用四组：当前共同基线、P2私有历史盲版本、P2完整历史版本、冻结固定等待版本。与短重访/充分恢复两种条件及A/B配对，形成首批16个机制episode。具体身份和运行预算以W58主计划为准，不借旧身份原任务资格。

P2 full与blind具备相同候选权限、几何、目标定义和时间预算，差别限于声明的私有历史输入/预测。固定等待量在开发集按预声明方法确定，测试前冻结，不能看完测试结果再挑。当前共同基线保留其原有权限，作为工程参考；因果比较主要在同权限P2组之间进行。

完整报告路线耗时、策略主动等待、速度、滑移、机械功与任务失败。充分恢复条件所需的准备时间单独记录。历史策略可以选择等待，但要支付共同时间代价；若固定等待或通用慢走就能获得同样收益，应按实际机制报告。所有策略在同一任务内具有相同的最大等待权限，不能让材料策略独享更宽预算。

### 4.3 先完成W57，再按信号推进新学习

W57已有full/blind训练与冻结评价应按其既定身份自然收尾；以真实样本和checkpoint账本区分两个策略、已用于更新与未用于更新的转移，不把合计样本量写成一个策略的训练量。

只有材料预测对选择产生可测影响、选择改变了实际接触、且同权限对照支持收益，才继续W58的新full/blind学习和联合训练。若不满足，优先处理已定位的估计、候选目标、任务曝光或执行权限问题；其他已就绪工作线继续推进。扩样本量不能代替修正无作用的接口。

### 4.4 将冻结组合、单模块贡献与联合增益分开

同一个R1从P0接到P1/P2属于冻结模块组合。应核查请求基准、可见未来相位、mask和实际动作分布；组合变差可能来自接口分布改变，不能直接归为材料记忆无效。后续联合再训练使用独立身份和匹配对照，不能与冻结组合混算。

对代价J越低越好的指标，报告J_B、J_P、J_R、J_PR和配对差值；可另列交互量J_PR−J_P−J_R+J_B。负交互量只表示在该指标和该标度上超过简单加和的改善，少量case不能据此宣称统计显著。成功率、任务时间和滑移分别保留，不事后挑综合权重制造优势。

## 5. 计算资源与阅读边界

W58按主计划默认三槽，只有现场实测证明总吞吐提升且CPU、内存、I/O和其他项目余量允许时，才扩到4–6槽。论文中的大规模并行来自特定模型、求解器及仿真批次结构，不能由96GB容量直接推出本项目的加速比例。依据实际物理秒/墙钟、完成episode吞吐、CPU核时、GPU端到端批次时延和I/O使用选择并发；不更改正在运行任务的冻结身份。

本文八篇中，Nature MI、Residual MPC作者版本、AugMPC、Load-bearing Assessment、Wiley和IFM已阅读与本问题有关的正文方法/实验部分。Terramechanics-Aware与MILD仅核实官方摘要与出版身份。未取得全文的工作不能用来断言其不存在某种持久地块、恢复历史或消融设计；也未将本次定向检索当作完整新颖性证明。
