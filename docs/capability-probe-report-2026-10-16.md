# MATLAB与Simulink：反馈能力、输入资源和规划利用的第一轮判别

日期：2026-10-16。用户授权先在本机MATLAB/Simulink测试。本轮完成已知模型上的经典控制机制实验，不训练RL；原科学问题和MPC规划、RL执行的目标结构保持。

## 1. 结论先行

这轮比此前“解析接口已经完成全部控制”的小试向前推进了一步：**已构造并核验一个单高层命令无法直接覆盖的低层反馈变化方向，且能算出这一变化要付出的输入代价。**同样看起来能实现的响应变化，有的需要规划暂时降低前进命令，有的即使不前进也超过纠偏能力。

同时，实际任务结果没有支持“共同学习已经成功”。本轮没有RL；扩展的经典反馈族在三个评价任务中成本较低，但用到了额外非线性自由度和更多设计候选；较强反馈在一个任务中产生实际饱和。重新规划相对命令回放降低了饱和，却未在每个任务中降低成本。这给下一步明确了需要学习和优化的物理取舍，而不是提前宣布新算法优势。

MATLAB与原生Simulink完整在线闭环均运行完毕，两组各60次实际MPC求解，状态一致性最大差8.89e-16。此处的Simulink高层是在线计算，区别于以前只回放高层命令的低层验证。模型已经在本机MATLAB/Simulink打开。

## 2. 测试什么，为什么选这个对象

对象有两个执行器、一个高层速度命令。两个执行器共同推动前进，力的差异同时用于抑制内部偏转。位置、偏转、两个速度和两个执行器力共6个状态；执行器有0.1s滞后，实际输入限额1.8。所有组获得相同全状态和参考预览，未知未来扰动。

低层把前进需求f和纠偏需求g分配为u1=f+g、u2=f−g。状态相关反馈项为

\[
g=-k_p\sin q-\left(k_d+\theta\frac{q^2}{q_0^2+q^2}\right)r.
\]

当kp/kd固定时，新增θ项不改变原点线性化，却能改变有限偏转下的反馈。它是经典非线性阻尼，**不是RL，也不是我们发明的控制律**；这里用它检验未来学习是否真的有物理自由度，而不只是修改一个预测标签。

在相同状态下，改变标量命令只能沿[1,1]改变动作，θ沿[1,−1]改变动作。不能仅凭这两个瞬时方向不同就宣布完整任务不可替代，因此又给冻结低层增加了0.02s一次的高频命令MPC对照。

完整对象、局部稳定条件、饱和适配等价边界及耗散恒等式见[理论推导](../notes/capability-probe-2026-10-16/theory.md)。[冻结协议](../notes/capability-probe-2026-10-16/protocol.md)列出设计集、评价集、计算设置及实现修正。

## 3. 得到的实质机制证据

精确的当拍输入条件是

\[
\max(|f+g|,|f-g|)=|f|+|g|\le1.8.
\]

在同一个状态q=0.2、r=0.6、v=0.6，固定kp=3、kd=0.5、命令c=0.8时：

| 非线性阻尼θ | 前进需求绝对值 | 纠偏需求绝对值 | 合计输入需求 | 判定 |
|---:|---:|---:|---:|---|
| 0 | 0.7200 | 0.8960 | 1.6160 | 当前命令可实现 |
| 1 | 0.7200 | 1.2800 | 2.0000 | 当前命令不行；把c降至[0.3867,0.7333]内可避免限幅 |
| 3 | 0.7200 | 2.0480 | 2.7680 | 单独纠偏已超过1.8，任何标量命令都无法避免限幅 |

这正是“任务希望的反馈变化”和“真实执行可付出的资源”必须共同决定的地方。只让响应模型与策略参数同步变化，三种都可以形式上配对；加入资源实现条件后，接受、调整规划命令、拒绝过激反馈三种决定才分开。

另取θ=1、c=0.6，新动作约为[−1.1600,1.4000]，实际可不饱和执行。冻结θ=0的低层即使允许全部实数命令及饱和，两输入差幅也不超过1.7920，新动作差幅为2.5600，无法复现。扫描20001个命令的最小动作差0.543058，与解析下界吻合。这是**同状态下的动作非等价**；有限时间任务最优性仍未由它证明。

固定kp=3、kd=0.5、同一命令的三组探针还显示：对称无扰动初态下轨迹严格相同；有初始偏转时响应及输入需求不同。前者检查不变子空间上的实现一致性，同线性化的依据是三阶项解析展开，而不是靠这条零偏转轨迹辨识出来。

## 4. 完整任务比较

6秒任务包含连续速度切换、偏转扰动和执行器状态延续。MPC用当前真实6状态重规划，预测1.2秒；每次3轮×64候选CEM，所有标准组一致。18个反馈在两个设计任务上比较；线性子族6点选出[3,1.5,0]，扩展族18点选出[6,1.5,8]。这只是声明网格内的经典选点，不是连续全局最优或学习收敛。

主比较两组kp也不同，因此不能把其成本差全归因于“同线性化下增加θ”。扩展族还使用更多候选，设计成本单列。固定kp/kd的机制探针与主任务比较承担不同证据角色。

下表为未用于选点的三个评价场景，成本越小越好：

| 实际执行方式 | case3反向扰动 | case4执行器不对称 | case5持续扰动 | 三场景平均 |
|---|---:|---:|---:|---:|
| 选定线性反馈＋当前响应MPC | 1.66197 | 1.47089 | 2.05180 | 1.72822 |
| 选定扩展反馈＋当前响应MPC | 1.43758 | 1.40888 | 1.74100 | 1.52915 |
| 冻结线性反馈＋5倍频率命令重规划 | 1.54522 | 1.38666 | 1.87452 | 1.60213 |
| 扩展反馈＋回放线性组命令（归因诊断） | 1.38751 | 1.33456 | 1.76624 | 1.49610 |

扩展反馈相对线性组的三场景平均成本下降约11.52%，但这不是RL收益，也不是同设计搜索预算的胜利。高频命令组使用5倍MPC调用，case4比扩展反馈标准MPC更好；本次有限CEM的平均表现仍未追平，不足以否定所有强命令适配。未来仍按0.1s命令块预测，高频组并非在所有0.02s未来命令序列上全局优化。

**成本必须与实际饱和一起看：**

| 组别 | case3饱和比例 | case4饱和比例 | case5饱和比例 |
|---|---:|---:|---:|
| 线性反馈＋当前MPC | 0 | 0 | 0 |
| 扩展反馈＋当前MPC | 2.33% | 0 | 0 |
| 线性反馈＋高频命令MPC | 0 | 0 | 0 |
| 扩展反馈＋回放旧命令 | 5.33% | 2.33% | 1.00% |

case3扩展反馈限幅前最大需求2.12124，高于1.8；实际输入被物理限幅，没有突破1.8。该组有一次重规划未找到满足名义约束的样本，之后采用协议中的最小罚分候选。未知扰动发生后，名义预测可行并不保证真实执行不饱和。

重新规划相对回放命令减少了三场景的饱和，但case3/4成本更高。回放诊断没有承担“预测限幅前输入不超限”的规划要求，其成本更低伴随更大饱和，不能据成本单项认定MPC无用。反过来，饱和减少也不能自动称为完整任务严格优势；这里得到的是成本与响应实现之间的取舍。

全部评价轨迹在0.02s记录点均没有超过|q|=0.35。此为采样统计，不是连续时间硬安全证明。仅三个确定性场景，不做伪随机种子显著性，也不称最终盲测。

## 5. Simulink不是命令回放

[构建源码](../matlab/capability/buildCapabilityModel.m)用原生连续Integrator、六个Fcn微分方程、实际Saturation和采样保持构成物理对象。离散控制器块每0.02秒读取真实状态，每0.1秒实际调用MPC；命令和计划在仿真中生成。物理积分为ode4、0.005秒，与MATLAB的RK4子步一致。

| 核验 | 线性选定组 | 扩展选定组 |
|---|---:|---:|
| 实际在线MPC调用 | 60 | 60 |
| 控制器调用（含终点） | 301 | 301 |
| MATLAB—Simulink状态最大差 | 6.66e−16 | 8.88e−16 |
| 实际输入最大差 | 1.22e−15 | 1.33e−15 |
| 命令最大差 | 3.33e−16 | 2.78e−16 |
| 扰动与采样时刻差 | 0 | 0 |

这验证了当前对象/采样/算法在两个实现中的一致性，不是模型真实物理准确性、机器人性能或实时性认证。MATLAB中标准组单次6秒仿真的求解合计约0.16–0.17秒，高频组约0.81–0.91秒，是本机测量，不能外推NX或硬实时截止时间。[核验JSON](../notes/capability-probe-2026-10-16/simulink-check.json)

## 6. 下一步应怎样接到RL，而不重回解析替代

本轮找到的明确学习对象是：**高层低维命令不能直接指定的内部反馈行为，以及它对瞬态响应和输入占用的影响。**未来RL应学习状态/历史相关的差模反馈或其更一般对应物，不能只学这一个经典θ常数后便称为新能力。

收尾时项目已新增[用户确认的算法交接要求](research-handoff-control-rl-coupling-2026-10-16.md)。保持它的优先级：**不再追加网格、换对象或启动训练，下一份交付应为具体联合算法与理论稿。**本轮结果用于该稿中的物理关系和不训练见证。

下一顺序：

1. 明确对象类、已知结构与必须交互学习的反馈函数；给出“段内输出＋真实输入需求/扰动恢复”的共享描述，以及可从数据计算的估计式。不能再仅以预测MSE判断可实现性。
2. 写出一批PPO数据到规划需求、实现关系估计、策略/模型共同更新和能力发布的完整伪代码；明确ratio、advantage、停止梯度、约束处理和额外预算。与同结构普通共同训练及直接近邻逐步比较。
3. 复用现有固定状态/数据，形成一次无需训练的决策差异见证，并完成至少一条与该机制直接相关的有限步/误差条件推导。先解释为什么某项反馈变化应被接受、改向或拒绝，再由更新后的模型说明MPC如何使用它。仅加奖励项或调用一般QP不构成贡献。

是否恢复小规模训练须遵守用户后续指令；本轮不自行进入。保留本轮最佳经典反馈和强命令适配作为未来基线，而不是用较弱基线制造学习优势。

输入资源条件在本轮已知模型中能精确计算，但未知执行动态/部分观测下怎样获得可信且不空洞的关系还没解决。此次没有证明RL必要，没有SPlaTES/ReCo方法级胜负，也没有把本轮经典反馈升级为论文主算法。它完成的是进入学习前的非退化方向与资源因果检查。
