## 2. 已定位的机制与优先级

### 2.1 执行链不是当前首要矛盾

已保存窗口中 32 个可比较计划的未来 20 ms 与真实执行高度一致：base 位置最大误差约 2.30e-8 m、关节角约 1.52e-7 rad。所查最终评价动作无 QP 失败或投影修正；500 Hz 出发记录没有 PD 请求裁切迹象。全部 34 个保存完整计划本身就在预测后退，其中两个终端计划没有未来实际执行可比。此结论只覆盖本轮驻留状态及已保存窗口，不保证未来换支撑/材料接触也一致。

不再无证据重做 QP、重接 PD、调整材料硬边界或提高力矩上限。先解释求解结果和目标。

### 2.2 λ=1 的物理意义依赖成本尺度

r32 的新 epoch 重置确实有效。问题是运动阶段原件中 H 的特征值约 1.00065476–1.00202382，单位正则约占对角的 99.855%–99.935%。当前 Effort 在 Stand 使用 `(u-u_ref)/.02`，运动时使用 `.02*tau`；按 PD60 和 176 节点平均，其直接控制曲率约从 1.136 变为 6.545e-4，相差约 1736 倍。这个量级关系有实际矩阵佐证，但尚不是“调低 λ 一定会走”的因果证明。

最终 E30 出发段 A/B 的 1374/1372 次 accepted 都只用一次 backward；实际 chosen-alpha 的 `cost_surprise` 全部小于 .5，中位约 .236。`lambda_after` 只为 1 或 2，没有 .5。因此不能承诺增加相同迭代会自动降低阻尼，也不能把代理预计下降当 native 真下降。

### 2.3 原生下降主要降低了什么

A 末计划约 66.45% 成本来自 `MaterialSupportHeight`，一次局部改善约 97.6% 也来自该项，Gait 改善约 1.25e-9。这个残差在 `r11_moving_body_support` 下刚地也启用，名字不代表材料加载。早期约 4 秒计划主要是 Position 成本；不能用末端分项代表整个回合。

现有证据支持“优化改善与实际前进脱节”，尚不能证明目标的全局最优就是驻留。没有已评分的高质量前进候选时，不能把搜索不足和目标权衡混为一谈。

### 2.4 候选保留需正确，但不是当前主因

旧保存输入暴露过 best nominal 优于 incumbent 却未部署。最终 E30 出发段仅 A 3 次/B 4 次复用涉及更好已算候选，最大成本差约 3.79e-10/9.54e-10。作为候选管理完整性修正，不据此解释全部驻留，不为这个微小差异重跑 W43。

## 3. 先完成一个有界的机制判别，随后只冻结一种主机制

这是直接服务控制改动的科学比较，不是新建 smoke/mock、纯 MPC/刚地/E30 准入链。复用 W43 两次 E30 的四个真实保存问题：A/B 各取 `r32-search-call000221`（origin 4.00 s）与 `r32-search-call001517`（29.92 s），并连接当时输入的 incumbent/参考 packet。晚段选 1517 是因为其输入 A plan1380 / B plan1378 的完整矩阵已发布；1516 的更早输入矩阵不完整。首次 outbound 2.002 s 没有完整已发布 search/accepted 上下文，不列入精确输入组。对当前状态、时间、参考、目标、约束和原生前向保持一致，比较下面三种明确不同的运动方向来源。

| 方向 | 具体改动 | 回答的问题 |
|---|---|---|
| **S：尺度匹配的局部求解，默认主候选** | 保留 r31 soft derivative/native forward，把绝对 `lambda*I` 改为有量纲依据的正则尺度；实际完整重算约束 Riccati、原生线搜索 | 单位阻尼是否遮蔽了本来可用的局部运动方向？ |
| **N：同尺度下的 native 局部方向对照** | 与 S 共用同一预声明 D、退化下界、初始 mu、预算和目标，仅在这些保存问题用 native 接触前向的 FD 构造局部方向；不重新按 N 导数定义另一套尺度 | 主要限制是否来自当前平滑代理方向与原生下降不一致？ |

当前 r32 结果保留为历史基准，不重跑历史完整回合。四个问题可以分给两条 CPU 分析流。每个 S/N 调用最多 5 次 regularization attempt（首次 + 最多 4 次重试）；每次成功 backward 后最多 10 个 alpha rollout。nominal 的反馈倍率筛选另有 10 次 native rollout，FD 子调用也单列，不能把每问题总计算量写成 10 或 50。

保存输入必须恢复可获得的 state、time、userdata、任务参数/权重、完整 policy/reference/K/H 及实际步态上下文。缺失的私有历史明确列出；可在统一新建的问题上下文中比较，但不能冒称原历史的等价 replay。若不能完整恢复历史上下文，须在同一重建快照补一次当前 r32 局部基准，再比较 S/N/P；不能拿不同上下文的历史数值当尺度改动的因果对照。对照共享同一个初始化快照，不允许各方法使用不同目标或 warm context。

### 3.1 S 的实现原则

使用与局部曲率同尺度的正则度量，例如 `H_reg = Q_uu + mu * D`，其中 D 是由当前问题的正半定残差 Gauss–Newton 控制曲率构造的正对角尺度，退化方向的下界按该问题/动作的特征尺度定义。这里的 D 是 Hessian 量纲的矩阵，不能混同某些 LM 文献中其平方根 D。具体公式、均值归一化、零曲率处理及单位必须先写进 spec；不能随手把 1 改成一个未经解释的常数，也不能用绝对下界 1 把原问题重新引入。

新问题依然重置无量纲 mu/rate 和 stopped 状态；同问题内部适配依据真实 native 可行性/下降。保留原 min/max 的对应数值含义或明确记录新量纲映射。若选状态正则而非控制正则，必须完整推导它对 H/Qux/反馈/价值递推的影响，不混搭旧式。

每次真正重算 r30 的 k/K、活动约束行、Vx/Vxx/dV 和 qp2 解；部署 H 也必须是本次实际使用的度量。绝不在保存 H 上减 λ 再求逆，伪称新完整 Riccati。最初保持每问题一次成功名义改进，避免把尺度变化和额外迭代预算同时当成一个因果因素。若后续增加同问题精修，作为明确配置变体记录成本与预算。

不下调原 native 接受要求，不把 soft 预期下降改写成真实下降，不人工把 surprise 乘一个经验常数以触发降阻尼。保留有限失败、当前问题有效 incumbent 和明确无可部署候选错误。

### 3.2 比较与选择规则

每种方向逐个问题记录 `(native trunk violation, native J)`、所有分项、预测 base Δx/vx、足端高度/法向力/离接触、动作/PD请求、真实/代理下降、k/K/H尺度、候选来源、耗时与评价次数。优先级仍是原可行性和成本排序；不为了显示向前而强选成本更差或原约束不满足的策略。四例逐例报告，不能凭某一例微小正位移宣称起步或稳定；选择只表示获得进入真实双流的局部依据。

- 若 S 已得到原生更优且具有有效运动的候选，选择 S 作为 S5-r33 主机制，N/P 留作判别证据，不同时塞入在线控制器。
- 若 S 未兑现、N 或 P 提供了明确更好的可部署运动候选，按该证据选择对应一种机制，先写清 r33 spec/成本/导数/候选身份及预算，再进入双流。两流使用同一种冻结机制，不将不同历史父点上的不同控制器伪装成干净因果对照。
- 若所有有限候选仍驻留或前进候选成本更差，输出各项真实代价，不自动扩大原样 PPO 训练。明确区分 proposal 质量不足与目标偏好，形成一个有证据的参考/目标修改版本后再训练；不默默同时改奖励、步态、时域、动作权限和物理。当前任务能力仍不成立，负结果必须交付。

这个分支是研究结果的真实边界，不是因运行时长到点停止。不能在算法没有实质变化时给 r32 改名后继续 512 条，把它当本轮推进。

### 3.3 所有机制共享的策略保留规则

维护本问题中已真实 native 评分且可部署的完整策略集合，包含 incumbent、最佳 nominal、实际线搜索/结构候选。只有完整的 actions/times/reference/K/H/feedback scaling 与原评分相同才可安装；均值、插值、局部精修后的新对象必须重新 rollout。保持原 trunk `(v,J)` 比较规则与失效语义；无有效候选不吞错。最好的已评分候选不能因精修失败而被一个成本更高的旧策略替换。原始候选管理差异单列，不能冒充主要运动收益。
