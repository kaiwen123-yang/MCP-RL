# 第一轮阅读路线

目标是先读懂几种不同的融合机制，再从 100 篇目录向外展开。每篇首先回答“学什么、优化什么、何时运行、证据支持什么”，不要求第一遍推完全部证明。

## 阅读顺序

| 顺序 | 文献 | 第一遍重点 | 读完应能说清 |
|---|---|---|---|
| 1 | MR004 · Synthesis of MPC and RL | 比较、分类和讨论章节 | MPC 的角色、学习接口与梯度路径是不同维度 |
| 2 | MR029 · AC4MPC | 算法结构、理论结论与车辆实验 | Actor 初值与 Critic 终端价值分别解决什么 |
| 3 | MR008 · Data-Driven Economic NMPC | 参数化 MPC 与 RL 的理论联系 | 为什么模型不准时仍可能通过代价学习改善控制，以及结论的条件 |
| 4 | MR022 → MR026 · TD-MPC → TD-MPC2 | 方法、规划与训练循环、消融 | 学习模型、策略、价值和在线规划如何互相影响 |
| 5 | DMPO、Learning to Optimize in MPC | 学习对象、候选更新和实际计时 | 学习优化器与学习控制策略有什么不同 |
| 6 | Safe RL Using Robust MPC、Predictive Safety Filter | 不确定性、可行性、保证条件 | 性能改进与约束保证分别需要什么证据 |

前四组已有 [初读笔记](../README.md#第一轮初读笔记)。第五、六组是接下来的阅读方向，尚未在本仓库完成专项笔记。

## 每篇先完成一张小表

| 问题 | 应记录的内容 |
|---|---|
| 原问题 | 作者试图解决的主要困难 |
| 学习量 | 网络／参数的输入、输出和学习目标 |
| 优化量 | MPC 决策变量、模型、时域及目标 |
| 训练 | 数据来源、谁运行、谁更新、是否穿过求解器反传 |
| 部署 | 运行的模块、动作接口、是否继续学习 |
| 理论 | 结论类型及关键假设，精确解还是有限求解 |
| 证据 | 支持主张的实验、对照与消融 |
| 边界 | 作者明确局限、作者未来工作、自己的推断分开 |

## 第一轮的学习检查

读完后，尝试不用论文原图，自己解释下列三件事：

1. 相同的网络输出，为什么放在模型、终端代价或动作残差三个位置会产生不同控制问题？
2. 如果融合方法更好，怎样判断收益来自长期价值、初值、模型还是额外计算？
3. 哪条理论结论依赖理想假设，实际实验只验证了其中哪些条件？

能回答这些问题之后，再从失效机制中选择通用测试。当前没有指定必须采用哪个平台、网络或求解器。
