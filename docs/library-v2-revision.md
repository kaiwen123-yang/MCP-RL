# 文献库 v2 修订说明

修订日期：2026-10-13。当前主库见 [100 篇索引](../literature/INDEX.md)，结构化元数据见 [papers.json](../literature/papers.json)。

## 为什么重建主清单

v1 以方法基础为中心，但较早论文占比过高，不能充分回答近三年 MPC–RL 方法如何继续发展的需求。本轮把主清单调整为近期研究优先，同时保留有具体机制用途的少量经典。当前阶段仍是先理解方法与理论、再做聚焦的通用仿真、最后选择机器人应用；实机实验不是选篇前提，也未提前锁定机械臂、机器狗或某种融合架构。

创新的判断以重要问题和证据为中心：既可以提出新问题，也可以承接已有方法，解决其仍未处理的模型误差、长期价值、约束保证、泛化或计算问题。模块的新组合、单个指标的小幅变化和“之前有人做过”都不能单独决定研究价值。

## 年份和版本如何解释

近期 90 篇按正式刊会的卷期或会议年份统计：**2024 年 27 篇、2025 年 33 篇、2026 年 30 篇**。这一统计不代表 90 篇都首次公开于这三年。

`year` 记录正式发表年；`first_public_year` 和 `earliest_verified_public_year` 记录目前查到的早期公开证据，`version_note` 说明预印本、在线版、会议版或期刊扩展关系。首稿字段为 `null` 或尚未单独核实时，只表示版本史没有全面查清，不能据此认定没有前稿。已查明的 2023 年较晚预印本、2024 年正式发表论文可以保留，但必须如实标出早期版本；不能用较晚卷期年份把旧方法包装成全新研究。

例如 MR024 CACTO-SL 的 arXiv 首稿为 2023-12-17，正式论文为 L4DC 2024。主库按 2024 年计数，同时保留 [arXiv 版本记录](https://arxiv.org/abs/2312.10666)。本轮已剔除不适合近期主线的早年首稿晚刊条目；仍可能存在尚未识别的更早版本，不能声称版本追溯已全部完成。

10 篇经典单独放在索引底部，每篇有 `classic_reason`，分别支撑约束 MPC、迭代学习 MPC、经济 NMPC 与 RL、TD-MPC、概率模型规划、预测安全过滤、信息论 MPC、可微 MPC、Guided Policy Search 和 MPC-Net 等具体机制。经典名额不是按作者声望或发表年限自动授予。

## 主题、来源和证据边界

近期论文按八个研究接口组织：综述与统一框架，MPC 与 RL 的理论联系，策略与长期价值辅助规划，学习模型与不确定性，安全约束与稳定性，采样优化与实时计算，可微 MPC 与结构化策略，以及规划教师与分层学习。这是仓库的阅读导航，不是作者原始分类，也不是八个已确定的研究方向。每篇都有具体选篇理由；必要相邻方法与直接 MPC–RL 方法需按其实际接口区分。

书目使用正式出版社、会议论文集、DOI 或 Crossref 等来源核对，并记录核验入口。期刊的 **2025 年中科院升级版大类分区来自公开转录交叉核对，仍待官方复核**；这里不把公开转录表述为官方认证。会议按照正式会议来源核验，不套用期刊分区。

当前阅读状态保留为 **5 篇初读、95 篇书目与相关性筛选**。初读已有原创方法导读，但不表示逐条证明复核、全面精读或复现完成；所有条目的复现状态仍为 `not_started`。选篇理由与条目数量都不能作为研究结论的证据。

2026-10-13 已回读核验 Zotero 主库100条、v2选篇笔记100条、本地PDF覆盖89/100；历史库100条及原有笔记、附件保留。全文取得不等于精读；此处不表示云端附件同步已完成。

尚缺全文的编号：MR025, MR078, MR103, MR105, MR106, MR108, MR112, MR113, MR115, MR156, MR160。缺全文不等于论文未开放；部分公开下载端点本次未成功。

## 公开数据与兼容性

新版公开 JSON 使用 `schema_version: 2.0`，按字段白名单生成，只包含书目、公开来源、版本史、选篇理由、分区来源和阅读状态。`reading_note` 始终按仓库根目录相对路径解析；归档 JSON 也保留这一明确语义。RIS 和 Markdown 索引与当前 100 个稳定编号对应，不包含本地文件、账户或应用内部标识。
