## 1. 最终要解决的具体问题

**面向重复踩踏的四足机器人地面记忆辨识与跨步协同控制。**

机器人踩过的软地面会改变，抬脚后也不会立即回到初始状态。前腿怎样加载、后腿是否重叠落足、隔多久再次踩上去，以及返程是否沿原足迹走，都会影响后来能否获得足够支撑。

研究问题是：**在材料状态不可直接测量、跨腿共享且持续恢复的条件下，如何辨识同一地块的接触历史，并根据未来支撑需求安排现在的加载、落点和重访时间，使整程任务更可靠、更有效率？**

首版只研究具有可测恢复时间的黏弹性地层与可控材料样件。先把加载—卸载—离足恢复—再次加载这一机制做实；暂不同时引入泥地吸附、颗粒流动、破坏、渗流等全部过程。不得假定预先踩踏一定有利，踩踏也可能使后续支撑变差。

### 一个主机制，三个候选贡献

| 候选贡献 | 必须实现的机制 | 必须回答的实验问题 |
|---|---|---|
| 1. 跨足共享的地面记忆辨识 | 在世界坐标中维护地块内变量；PINN 学习受物理约束的加载、卸载和自由恢复关系，换腿和离足不清零 | 与充分辨识的经典本构、同信息历史网络相比，能否预测未见的完整加载/重访历史及后续支撑？ |
| 2. 未来支撑需求约束当前踩踏 | MPC 联合考虑当前加载、落点重叠和重访间隔；把后续足所需支撑映射回当前动作 | 同样能感知地面时，主动改变当前动作能否改善未来接触和整程结果？ |
| 3. 超出 MPC 时域的重访价值 | RL 学习与未来地块重访相关的终端价值，显式利用跨步/返程关系 | 在相同在线计算预算下，是否优于普通终端价值及延长时域/按重访事件规划的 MPC？ |

三个贡献是待验证假设，不能仅按 PINN、MPC、RL 三个模块各写一个“创新点”。前人已有软地面适应、材料记忆模型和 RL–MPC 组合；创新判断落在上述具体机制及证据上。若经典本构或充分规划已经解决问题，必须保留这个结果，再修正同一科学问题的实现。

### 模型与控制之间的关系

地块 j 的内部状态记为 z_j；当前加载动作 a 包含足端力/位移轨迹、作用位置和持续时间。加载算子 L 和离足恢复算子 R 形成后续接触前的状态：

```text
z_j(next contact) = R(theta, revisit interval, L(theta, z_j, current loading))
```

MPC 要求未来足所需的**力—时间轨迹**属于这一状态下材料能够实现的支撑集合，同时满足机器人动力学、足端运动和材料变形关系。不能把所有材料记忆简化成一个静态最大支撑力，不能让计划接触力与仿真实际反力来自互不相容的两套模型。

离足时继续按零外载等实际边界条件求解材料恢复；“无接触”不等于“压入位移强行归零”。地块状态跨不同腿、转弯和返程保留。只在独立实验回合之间按既定方式准备初始材料状态。

### 4.3 固定数据和训练预算

| 项目 | 本轮固定量 |
|---|---|
| 独立训练历史 | 100 条，每条 100 个时间增量；ideal/noisy 共用底层应变路径 |
| 训练采样与生成 | 沿用原三次样条、结点范围和 dt∈[0.03,0.07] s，不筛选“容易”的加载历史 |
| 噪声 | noisy 应力各分量标准差 1.5 MPa；每条路径固定独立噪声，所有初始化复用 |
| 训练 | 2 条件 × 25 初始化 × 20,000 次完整数据集更新；共 50 个新模型、1,000,000 次模型更新 |
| 优化与选模 | 原 Adam 和学习率日程；每条件只按最终训练损失选一个模型 |
| 新留出路径 | 20 条，每条 250 个增量，dt=0.05 s；所有模型共享 |
| 已知困难路径 | 复用第一轮原数组，只作为已知诊断，不再称新盲测 |

训练 seed 24015000–24015099，噪声 seed 24017000–24017099，新评价 seed 24016000–24016019 已写入配置。训练前固定生成协议、种子并保存实际数组；不根据评价误差改变路径、初始化、网络或超参数。评价始终使用无噪参考响应，包括 noisy 训练模型。参考隐变量只用于数据生成和结果分析，不进入训练标签、尺度估计或部署状态。

多序列实现必须保持物理与优化含义：

- 每条独立准备的历史分别设 q0=h0=c0=0；路径内部不清零、不截断为互不相关的片段。R2 的已知初始状态不等于解决了真实地块未知初态辨识。
- **先在每条路径内部计算应变率，再汇总全训练集的归一化范围。** 不能拼平所有路径后做差分，不能按微批重新计算尺度；旧模型始终使用原权重附带的旧尺度。
- 每条 100 步历史保持完整反向传播。可按 5 个初始化、10 条路径一组处理；累计完全部 100 条路径并正确求平均后，只做 **一次 Adam 更新**。不能把 10 个微批误算成 10 次优化更新，也不能重复除以批量大小。
- 分组大小可按显存调整，完整历史长度、实际训练数据和总更新预算不变。保存所有初始化的最终模型、优化器与 20,000 点损失记录，不能只保存选中的两个模型。

### 4.4 新旧模型在相同留出历史上比较

复用第一轮全部 50 个冻结模型；每个评价时使用自己的原训练尺度。本轮新 50 个模型按各自完整训练集尺度预测。两组在同一套 20 条新路径上自由积分：

- 旧 50 × 新 20 路径 = **1,000 次完整预测**；
- 新 50 × 同 20 路径 = **1,000 次完整预测**；
- 新 50 × 第一轮已知困难路径 = **50 次完整预测**。

因此新增 2,000 次留出路径预测和 50 次已知路径预测；物理上仍是 **20 个新加载工况**，不能写成 2,000 个独立工况。原 50 次旧路径结果直接引用，不重跑旧训练。

主要比较每条路径、每个模型的 **MPa 单位 MAE/RMSE、逐分量误差、静水与偏应力误差**；对选中模型给出 20 条路径配对误差变化、中位数、90% 分位数及最差路径，同时展示全部初始化分布和真实失败。原 NRMSE 的分母是各自训练应力半范围，新数据改变分母，所以不能直接横向比较。若额外给归一化指标，另用一个对新旧、ideal/noisy 一致且公开的固定尺度。

报告训练/评价体积应变等不变量范围及范围内外误差，解释改进是否与覆盖变化一致；不把单变量范围重叠当成充分状态覆盖。只有查看结果后得出的解释，明确写为结果分析，不回头修改留出协议。统计以完整路径和初始化两个维度呈现，不把相邻时间点当成独立样本；无需为此搭建统计框架。

### 4.5 同协议重访：新增 24 条，复用原 36 条

## 5. S：在完整机器人任务中验证本课题机制

### SuperMimic 的借鉴落点

TM07：[SuperMimic 固定 v1](https://arxiv.org/abs/2610.28480)、[作者项目页](https://supermimic.github.io/)。原文用共享可微世界模型、多步想象和终端 critic 支持人形动作跟踪；它不是本文的未知黏弹地面模型，也没有证明持续软地状态下的跨足决策。

借鉴其模型服务决策的思路，保留本项目的解析机器人动力学，只学习材料闭合关系：

| 原文启发 | 本课题具体落点 | 执行时机 |
|---|---|---|
| 共享模型，多步自由展开 | 同一材料网络服务各地块；地块各自保留状态；先做完整重访推演 | R2 迁移先评价，出现明确漂移再设计多步训练改进 |
| 通过模型评价动作后果 | 比较当前加载/时间/落点候选对后续支撑的影响 | 材料候选排序之后，S 中接入真实接触约束 |
| 短时展开加终端价值 | 终端项依赖可能重访的地块状态和剩余任务；与无价值、普通 critic、长/事件时域 MPC 比较 | S 的第三机制 |
| 模型与行为交替改进 | 用当前规划器实际产生的材料历史补充学习数据，留出整段未见任务 | S 中有耦合任务和明确数据需求之后 |

R1 的随机刚体外扰轨迹不提供材料变形与恢复标签，不能充当上述材料训练数据。共享权重也不意味着共享/清空地块状态。原文已知仿真 context 不能转成实际方法可直接读取的真实材料内变量。

先用采样 MPC 前向比较候选，不假定采样 argmin、接触切换或整个物理仿真可微。若以后采用代理模型梯度，只在明确可微的材料/连续动作路径内使用；critic 用固定的回报/TD 目标学习，不能让 actor/critic 互相抬高数值。不得直接照搬原文时间步数、效率倍数或人形大数据训练规模来声称本项目收益。

不新增“先完整复现 SuperMimic”的阶段。它是当前主线的机制参考；原方法复现结果、后续多步改进和整机控制收益分别给出。

### 先落实一个持续材料状态的任务

首个主任务为 **硬地起步 → 软地走廊 → 端部停留/转向 → 原区域返程**。路程、允许时间、指令和判定条件写入场景配置；所有方法允许相同的减速、等待和落点调整。完整往返结束前不重置地面，不把去程和返程拆成互不影响的 episode。

先复用冻结 R1 的机器人与控制底座，再完成 Go2 移植。固定 2.4 Hz 与 adaptive 均保留；不得只选明显较弱的固定 1.3 Hz 来证明新方法有效。软地采用具有独立内部状态的材料区域和明确接触面积/足迹映射；世界坐标中的重叠足迹共享状态。离足后的区域继续恢复，不能用每步随机刚度或普通高度场冒充材料记忆。

环境的参考本构与学习模型分开，评价使用未见参数和未见完整加载历史。至少包括可辨识的非线性/多时间尺度参考材料，避免训练网络和环境使用同一个可直接拷贝的函数而形成虚假优势。先用真实材料状态可见的 oracle 对照确定决策价值上限；该信息仅限 oracle，不能进入实际方法或普通基线。

### 按依赖接入三个机制

1. **持续地块状态与 PINN。** 解析机器人刚体动力学保持不变；神经网络只学习必要的材料闭合关系。用加载平衡、状态演化、恢复边界和耗散关系约束可见接触历史；评估未见重访间隔下的未来反力/变形。若内部变量不能唯一辨识，以可观测的未来支撑预测为依据，不声称获得唯一真实隐变量。
2. **跨步协同 MPC。** 在同一优化问题中传播当前加载对后续接触的影响，联合接触力/位移相容、落点重叠和重访时间。先通过有界候选落点/时序或事件展开实现，不立刻重写一个通用混合整数规划平台。
3. **长期重访价值 RL。** 固定已验证的接触执行接口，以未来可能重访的地块状态及关系为输入学习超出 MPC 时域的价值，并作为规划终端项。奖励围绕完整任务完成、耗时、能耗和支撑失败；不加入“奖励像论文机制”的人工标签。

### 必须有的强对照与消融

各组使用相同可获得信息、训练数据预算、评价任务和动作权限。在线耗时、离线训练量分别报告；更长规划必须纳入匹配在线预算的比较。

| 对照或消融 | 排除的替代解释 |
|---|---|
| 冻结的固定 2.4 Hz / adaptive 控制底座 | 新方法是否仅靠高步频获得表面收益 |
| 充分辨识的标准线性固体/广义 Maxwell 等经典材料模型 + 同一 MPC | 是否只是故意选择了过弱的材料基线 |
| 同等历史和空间信息的普通神经材料模型 + 同一 MPC | PINN 的物理约束是否有实际增益 |
| 同等历史/地块记忆输入的 RL 控制基线 | 是否只是提供了更多观测信息 |
| 完整状态估计 + 不传播当前动作对未来地块影响的规划 | 跨步协同机制是否比被动适应有效 |
| 去掉长期 RL 价值；普通终端 critic；更长/重访事件 MPC | 结构化长期价值是否优于充分规划或普通价值学习 |
| 完整方法与真实地块状态 oracle | 识别误差和决策局限分别造成多少损失 |

上述是围绕三个假设的科研实验，不增加无关工程测试。先完成固定规模的整程比较；学习方法首轮使用 3 个独立训练 seed，每个预定场景每个 seed 评价 20 个完整未见回合，对照共用对应任务 seed。这是首次整程研究预算，不能用更小片段替代，也不自动演变成无上限搜索。训练步数在开始前依据复现底座和实际算力写入配置；需加量时基于真实学习曲线的未收敛证据决定。

### 三份核心仿真成果

- **记忆证据：** 相同外观/相近瞬时形变下，不同加载历史是否产生不同后续支撑；模型是否预测到这一差异。按完整历史留出，不随机打散时间点泄漏未来。
- **机制证据：** 恢复时间、可用足迹重叠和重访间隔变化时，最优策略如何变化；何时等待有利，何时换点有利，何时策略与普通控制等效。不得预设踩实一定提高支撑。
- **整程证据：** 往返成功率、完成时间、能耗、峰值沉陷/支撑失配、在线计算时间及连续视频。失败回合与条件全部进入结果；准确率或材料损失下降不能替代机器人任务收益。

成果放入 `results/terrain_memory/simulation/` 与 `outputs/terrain_memory/simulation/`。根据负结果修改同一问题的模型/控制机制；不得通过换题、堆网络、扩写文档绕开核心结果。
