### 2.3 三个需要区分的问题

**已确认的任务阻塞：触地/受载运动超出了原材料域。** H=.05 m、|主应变|≤.02，对应法向压入尺度1 mm。这是本构使用域退出，不是已证明自然地形塌陷。dev07首次材料反力7.3702秒，到最后积分状态7.3716秒仅1.4 ms；下一越域边界步为7.3718秒。一次500Hz控制保持为2 ms，2Hz高层Actor更不能在这段冲击内临时修正；必须提前改变可执行触地运动。其他七条不能一概归为首次接触同一事件。

**源码已显示几何/参考不一致，因果贡献尚待执行端核对。** 固定作者[quadruped.h](https://github.com/johnzhang3/mujoco_mpc/blob/e00c47a5adb9856af2e0f24231bb3a60d5be23c4/mjpc/tasks/quadruped/quadruped.h)使用kFootRadius=.020 m；项目原模型[元数据](../results/terrain_memory/simulation/tm-s1-contact-execution-20261026/development-v1-seed4/rigid-T1R-resolved.json)中四足球半径均为.022 m，模型映射保留了该几何。作者[步态残差](https://github.com/johnzhang3/mujoco_mpc/blob/e00c47a5adb9856af2e0f24231bb3a60d5be23c4/mjpc/tasks/quadruped/quadruped.cc)用floor+kFootRadius+step作为足心参考；旧补丁未显示对这个常数的对应修正。因此末摆参考趋近的足底可能是−2 mm，已大于1 mm材料域。注意step=0时旧Gait残差关闭，不能声称整个支撑相都硬要求−2 mm；R9执行指纹未逐项列出该头文件，应在实际编译源确认，不把源码推导当作已完成的二进制反演或唯一根因证明。

**触地轨迹与预测器不适配，不能靠水平cap穷举解决。** 作者StepHeight为截断余弦。在2 Hz、duty=.45、amplitude=.03 m下，摆动时长.275秒，未截断连续参考的末端法向斜率幅值为pi*.03/.275≈.343 m/s，并不是零速落地；这只是参考导数，不是实测足速。R9实测峰值约.92–1.43 m/s还包括真实跟踪和机体运动。MPC内部始终预测原生地面，plant却使用有状态材料反力。模型、触地目标和反馈共同作用，当前资料未隔离唯一原因；不能断言只修半径或只平滑参考必定成功。

静态量级进一步排除错误方向：原参数给出E_eq=9KG/(3K+G)=750 MPa，完整均匀足印的平衡k=gamma*E_eq*A/H=375000 N/m。两足均分重量时约74.59 N/足，对应约.199 mm平衡压入。瞬时K=1500/G=1000 MPa时E0≈2454.55 MPa、k0≈1.227e6 N/m，1 mm的弹性力量级约1227 N，与现有冲击峰值量级相近。这里假设完整足印、自由侧向和冻结/松弛内变量两端情形，不是动态承载保证，也不能据此宣布积分正确；但不支持“材料在域内根本托不住Go2”。

### 3.2 N：触地前减速必须进入优化问题

在同一个MPC中加入材料区近接触的法向运动目标，先保持原2 Hz、duty=.45及3 cm峰值抬脚高度，改变下降末段形状而非继续扫描水平cap。可用分段五次曲线或具有零端点速度/加速度的升降参考；需连续衔接当前相位，不在每次重规划重置摆动进程。初始研究不另换crawl或减速到改变原任务期限。

仅画出一条平滑期望曲线不够：优化代价必须评价预测的真实足底法向速度、近地间隙/压入和机体支撑后果，覆盖实际可能接触的区域，不能只在名义step!=0时起作用。代价的量纲、归一化、作用区间与权重应在实际resolved配置中明确，依据原1 mm域、控制保持时间及已有可行支撑尺度设计，不照搬另一材料论文的8 cm/s。

这是软目标/预测约束设计，不得称为已证明的硬安全保证。实际plant始终保留原材料域退出。最终动作仍由MPC统一优化并经原PD执行；禁止求解后另加足力、关节补偿或目标滤波来掩盖预测—执行差异。

优先从.25 m/s名义完整任务开始；只有修改后的轨迹支持需要界定速度可行域时，才按.215、.18顺序使用其他固定cap。不要把R10再次执行成五固定速度加三波形。

### 3.3 C：必要时允许局部接触预测改变，不冻结错误刚地假设

若G/N完整任务仍显示明显法向接触预测失配，则在同一执行批次内采用**一个**明确的短时法向接触近似，而不是停止后再索要下一轮提示。它可以是基于当前因果估计的局部力—位移关系及切线，但须明确哪些状态被冻结、有效时域和遗漏的记忆效应。不得用真实材料q/e偷偷给正式控制器提供oracle信息。

候选力由候选足运动重新计算，不能将当前外力原样复制到所有候选。近似的单边接触与切向受力关系须明示；真值TM02不变。若预测模型使用持久材料状态，则每条rollout和有限差分分支都必须持有独立状态，状态转移与导数包含对应传播；userdata不是自动的优化状态。若采用冻结局部近似，则诚实称短视执行模型，不称已完成跨事件材料MPC。

每条转移必须来自S4 MPC+真实材料+Go2，MPC服务/模型与PANN编译实例跨rollout持久化；不能用快控制器、伪plant或模型想象代替本闭环采样。rollout片段不重置物理/材料。真实成功后可终止训练episode，不用后续静站凑样本；真正物理/材料失效及任务固有60秒截止终止，普通片段边界bootstrap真实后继，技术预算中断单列。

## 6. 计算预算与长实验的现实边界

新R10物理campaign墙钟硬上限48小时，从第一次R10物理积分开始，包含暂停、开发、训练及评价；实现/构建和发布传输另记。最多3环境并发、每个2 solver workers，现有fy-5080 SSH/tmux和环境，不新开付费资源。

预留核心正式评价不少于max(6小时，实测剩余核心评价成本×1.2)。条件600秒优先从额外剩余预算中安排，不能挤掉21+3核心评价。用真实完整episode计时，不新增microbenchmark轮；PANN观察/私有预测、MPC、物理、训练更新和记录分别统计，重叠计时不相加冒充独占总成本。

R8项目规划p50约224–252 ms，p95约320–347 ms，逻辑周期20 ms全部超时；名义300秒墙钟3679.95秒。R9八条episode墙钟之和856.3291秒/物理61.2944秒≈13.97倍，但这是包含并发共享的episode之和，不是campaign实际经过时间。仅凭这些数据不能宣布NX实时或保证48小时完成49152转移。

2 Hz只降低高层动作次数，不减少底层50 Hz求解。4096个完整.5秒转移约2048秒物理时间，六流合计约12288秒；提前终止的最后转移可能短于.5秒，应按真实物理秒结算。当前成本下先建立真实小规模联合基线，后续再依据实际瓶颈考虑动作参数化/预测压缩、蒸馏或离策略学习，不在本轮同时更换算法和平台。

## 7. 怎样判断有进展，而不是只是日志更长

**执行层：** 是否同一版本真正穿过材料、转向返回并保持；触地前实际法向速度、最大压入、实际GRF/冲量、关节饱和和完整任务是否改善。只降低峰值但仍失败不能称整程可用；反之没有新稳定性定理也不妨碍承认实测整程成功。

**信息层：** 独立PANN恢复特征是否在实际可比条件下准确、有非零幅值，并影响真正应用的cap；记录未来查询足印是否已经访问、占空比和作用次数。大多数查询都是virgin而全零时，不能将无收益简单归因于PPO欠训练。评测屏蔽输入只做依赖诊断，公平“无PANN算法”对照必须重新训练RAW组。

**机制层：** 将真实接触段与世界地块对应，记录前足离足→后足加载的唯一事件、面积交叠、卸载间隔、重载前e/q及可观测反力差；真值内变量只作评价。长达300/600秒不等于记忆持续同样久，远距离返程可能早已恢复，跨腿短间隔才可能是主要作用窗口。不能调慢真值恢复来制造长记忆。

**任务层：** 三组完成率/首次完成时间/后续保持完整列出；能量、时间、滑移等只在双方完成配对中作性能比较，失败任务提前结束的低功耗不是节能。三seed和确定性yaw条件只是初步覆盖，不是随机材料总体可靠性统计。响应预测、改变动作、提高整程表现分别结论。

完成联合基础后，优先回答材料信息是否提供可被动作利用的收益，再推进持久状态辨识、跨事件规划和长期价值；强横向对照包括经典本构+因果估计器、同信息历史/RNN策略、普通PPO、计算预算匹配规划。若充分基线同样有效，应接受，不先预定必须胜出。
