# 地面记忆与跨步协同：固定问题和执行计划

用户于 **2026-10-21** 确定本课题。执行约定见根目录 [AGENTS.md](../AGENTS.md)。本文件规定研究对象、实验顺序和成果，不作为每日状态记录。**2026-10-23 的当前执行阶段为第 4 节 R2；第 3 节明确 R1 冻结范围。**

## 1. 最终要解决的具体问题

**面向重复踩踏的四足机器人地面记忆辨识与跨步协同控制。**

机器人踩过的软地面会改变，抬脚后也不会立即回到初始状态。前腿怎样加载、后腿是否重叠落足、隔多久再次踩上去，以及返程是否沿原足迹走，都会影响后来能否获得足够支撑。

研究问题是：**在材料状态不可直接测量、跨腿共享且持续恢复的条件下，如何辨识同一地块的接触历史，并根据未来支撑需求安排现在的加载、落点和重访时间，使整程任务更可靠、更有效率？**

首版只研究具有可测恢复时间的黏弹性地层与可控材料样件。先把加载—卸载—离足恢复—再次加载这一机制做实；暂不同时引入泥地吸附、颗粒流动、破坏、渗流等全部过程。不得假定预先踩踏一定有利，踩踏也可能使后续支撑变差。

### 一个主机制，三个候选贡献

| 候选贡献 | 必须实现的机制 | 必须回答的实验问题 |
|---|---|---|
| 1. 跨足共享的地面记忆辨识 | 在世界坐标中维护地块内变量；PINN 学习受物理约束的加载、卸载和自由恢复关系，换腿和离足不清零 | 与充分辨识的经典本构、同信息历史网络相比，能否预测未见的完整加载/重访历史及后续支撑？ |
| 2. 未来支撑需求约束当前踩踏 | MPC 联合考虑当前加载、落点重叠和重访间隔；把后续足所需支撑映射回当前动作 | 同样能感知地面时，主动改变当前动作能否改善未来接触和整程结果？ |
| 3. 超出 MPC 时域的重访价值 | RL 学习与未来地块重访相关的终端价值，显式利用跨步/返程关系 | 在相同在线计算预算下，是否优于普通终端价值及延长时域/按重访事件规划的 MPC？ |

三个贡献是待验证假设，不能仅按 PINN、MPC、RL 三个模块各写一个“创新点”。前人已有软地面适应、材料记忆模型和 RL–MPC 组合；创新判断落在上述具体机制及证据上。若经典本构或充分规划已经解决问题，必须保留这个结果，再修正同一科学问题的实现。

### 模型与控制之间的关系

地块 j 的内部状态记为 z_j；当前加载动作 a 包含足端力/位移轨迹、作用位置和持续时间。加载算子 L 和离足恢复算子 R 形成后续接触前的状态：

```text
z_j(next contact) = R(theta, revisit interval, L(theta, z_j, current loading))
```

MPC 要求未来足所需的**力—时间轨迹**属于这一状态下材料能够实现的支撑集合，同时满足机器人动力学、足端运动和材料变形关系。不能把所有材料记忆简化成一个静态最大支撑力，不能让计划接触力与仿真实际反力来自互不相容的两套模型。

离足时继续按零外载等实际边界条件求解材料恢复；“无接触”不等于“压入位移强行归零”。地块状态跨不同腿、转弯和返程保留。只在独立实验回合之间按既定方式准备初始材料状态。

每臂固定初始化 **0、1、2、3、4**；ideal 一组，noisy 三套独立观测噪声，每套五初始化，共 **60 个研究模型**。A 的 ideal 五个和 noise0 五个旧模型直接复用，因此**新训练 50 个**。不为了包含旧 noisy seed10 改初始化名单；全 25 初始化选中的旧模型继续作为历史结果，不能混进五初始化口径。

每模型 20,000 次完整数据集平均梯度 Adam 更新。A/C 每次使用 100 条，B 每次使用 1,000 条；微批只分摊显存，不单独更新，不截断历史。固定更新次数下，B 每次工作量约为 A/C 的十倍；新训练数据/梯度工作量约相当于 230 个原 100×100 模型，即第二轮 50 模型的 **4.6 倍**。这不是等计算量算法比较；需报告真实时间、数据遍历量和显存，不能将 4.6 倍直接当作墙钟时间预测。A/C 观察增量数相同，但 A 的原随机时钟与 C 的恢复历史固定 5 s 不同，也不能称采样过程完全相同。

**C 的完整历史固定如下。** 20 条单轴压缩、15 条体积压缩、15 条纯剪切；每条 5 s，dt=0.05 s。预载由 0→0.1 s 达峰、保持到 0.3 s、0.4 s 卸为零；自由恢复 2/2.5/3/3.5/4 s；随后以同一 0.4 s 包络施加探针；余下保持零外载到 5 s。预载分量峰值均匀取 0.75–5.5 MPa、探针 0.75–4.5 MPa，种子与分配规则写在配置。峰值是应力分量幅值，不是三模式相等的张量范数。参考应力控制求解给出实际应变/应力，训练只读取这些可观测量；零外载时不钳制应变。

**配对与尺度固定。** A/B 共用的 100 条、A/C 共用的 50 条，必须精确共享时间、应变、无噪应力和同噪声实现的数组。噪声仍为每分量 1.5 MPa 高斯噪声，恢复段也加噪，不把零载标签偷偷改成无噪；每套噪声由五初始化共享。所有臂、三个噪声实现固定复用第二轮各条件全部 norm 字段；不按新数据重估、不用评价数组和 q 推导尺度、不裁剪超出归一化范围的数值。三套噪声是有限敏感性比较，不是十五套独立噪声数据。

### 4.4 已知历史诊断：直接区分材料响应与边界求解

第二轮的 20 条随机留出与原 12 条重访均已被查看，现在明确称为已知诊断。对全部 60 个研究模型比较完整响应，已存在且完全相同的预测直接复用。

对每条原重访参考历史，执行两种完整重放：

1. 输入参考应变历史，模型独立演化自己的 q，预测应力；不注入参考中间状态。
2. 输入原应力命令，模型独立演化自己的 q，预测应变；无载阶段求解自由恢复。

前者的误差直接检查这段可观测轨迹上的本构响应；后者还包含逆问题条件和模型自身轨迹偏离的影响。不能仅凭二者差异就宣布 Newton 有 bug，也不能靠降低数值残差掩盖错误的物理响应。结合恢复/重载曲线及零态局部恢复量解释，保留两种边界下的实际失败。

这些诊断用于解释最终固定实验，不用于修改本轮评价集或选模。不能在看到诊断后再添加新的 loss、网络、局部 q 标签或重训预算。

### SuperMimic 的借鉴落点

### 先落实一个持续材料状态的任务

首个主任务为 **硬地起步 → 软地走廊 → 端部停留/转向 → 原区域返程**。路程、允许时间、指令和判定条件写入场景配置；所有方法允许相同的减速、等待和落点调整。完整往返结束前不重置地面，不把去程和返程拆成互不影响的 episode。

先复用冻结 R1 的机器人与控制底座，再完成 Go2 移植。固定 2.4 Hz 与 adaptive 均保留；不得只选明显较弱的固定 1.3 Hz 来证明新方法有效。软地采用具有独立内部状态的材料区域和明确接触面积/足迹映射；世界坐标中的重叠足迹共享状态。离足后的区域继续恢复，不能用每步随机刚度或普通高度场冒充材料记忆。

环境的参考本构与学习模型分开，评价使用未见参数和未见完整加载历史。至少包括可辨识的非线性/多时间尺度参考材料，避免训练网络和环境使用同一个可直接拷贝的函数而形成虚假优势。先用真实材料状态可见的 oracle 对照确定决策价值上限；该信息仅限 oracle，不能进入实际方法或普通基线。

### 按依赖接入三个机制

1. **持续地块状态与 PINN。** 解析机器人刚体动力学保持不变；神经网络只学习必要的材料闭合关系。用加载平衡、状态演化、恢复边界和耗散关系约束可见接触历史；评估未见重访间隔下的未来反力/变形。若内部变量不能唯一辨识，以可观测的未来支撑预测为依据，不声称获得唯一真实隐变量。
2. **跨步协同 MPC。** 在同一优化问题中传播当前加载对后续接触的影响，联合接触力/位移相容、落点重叠和重访时间。先通过有界候选落点/时序或事件展开实现，不立刻重写一个通用混合整数规划平台。
3. **长期重访价值 RL。** 固定已验证的接触执行接口，以未来可能重访的地块状态及关系为输入学习超出 MPC 时域的价值，并作为规划终端项。奖励围绕完整任务完成、耗时、能耗和支撑失败；不加入“奖励像论文机制”的人工标签。

### 必须有的强对照与消融

各组使用相同可获得信息、训练数据预算、评价任务和动作权限。在线耗时、离线训练量分别报告；更长规划必须纳入匹配在线预算的比较。

| 对照或消融 | 排除的替代解释 |
|---|---|
| 冻结的固定 2.4 Hz / adaptive 控制底座 | 新方法是否仅靠高步频获得表面收益 |
| 充分辨识的标准线性固体/广义 Maxwell 等经典材料模型 + 同一 MPC | 是否只是故意选择了过弱的材料基线 |
| 同等历史和空间信息的普通神经材料模型 + 同一 MPC | PINN 的物理约束是否有实际增益 |
| 同等历史/地块记忆输入的 RL 控制基线 | 是否只是提供了更多观测信息 |
| 完整状态估计 + 不传播当前动作对未来地块影响的规划 | 跨步协同机制是否比被动适应有效 |

| 完整方法与真实地块状态 oracle | 识别误差和决策局限分别造成多少损失 |

### 三份核心仿真成果

- **记忆证据：** 相同外观/相近瞬时形变下，不同加载历史是否产生不同后续支撑；模型是否预测到这一差异。按完整历史留出，不随机打散时间点泄漏未来。
- **机制证据：** 恢复时间、可用足迹重叠和重访间隔变化时，最优策略如何变化；何时等待有利，何时换点有利，何时策略与普通控制等效。不得预设踩实一定提高支撑。
- **整程证据：** 往返成功率、完成时间、能耗、峰值沉陷/支撑失配、在线计算时间及连续视频。失败回合与条件全部进入结果；准确率或材料损失下降不能替代机器人任务收益。

成果放入 `results/terrain_memory/simulation/` 与 `outputs/terrain_memory/simulation/`。根据负结果修改同一问题的模型/控制机制；不得通过换题、堆网络、扩写文档绕开核心结果。
