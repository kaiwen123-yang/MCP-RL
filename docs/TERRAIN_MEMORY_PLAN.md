## 1. 最终问题与一个主机制

**面向重复踩踏的四足机器人地面记忆辨识与跨步协同控制。**

当前踩踏改变世界固定地块的内部状态，离足后继续恢复，后腿或返程再接触时的支撑因此变化。研究：**在材料状态不能直接测量、观测间断和在线计算有限的条件下，如何辨识这种变化，并安排当前加载、落点和接触时序，改善完整任务？**

首版从有可测恢复过程的黏弹性材料及可控样件开始，不把它自动解释为湿草、沙、雪或泥。加载可能改善也可能恶化后续支撑，不能事先给“踩实有利”奖励。

| 候选贡献 | 拟实现的机制 | 必须排除的替代解释 |
|---|---|---|
| 物理约束的跨足记忆辨识 | 接触观测修正地块状态，离足按物理规律传播；材料参数与当前状态分开，跨腿共享 | 充分辨识的经典本构＋估计器、同信息历史网络是否已经解决问题 |
| 跨接触事件 MPC | 当前加载通过材料状态影响后续接触；近期细时序、远期相关事件形成可执行计划 | 是否只靠更长时域、更大计算量或增加动作权限 |
| 面向重访后果的强化学习 | PPO Actor 选择接触意图，Critic 学习同一闭环的远期价值；研究重访后果的延迟信用分配 | 同信息普通/循环 PPO、普通 Critic 和充分事件规划是否已经足够 |

用户于 2026-10-24 明确希望“一个科学问题、核心新机制和三项方法贡献”，并要求在 S0 阶段考虑 Go2＋NX 部署。相似论文用于具体横向比较，不能只凭关键词相似否定，也不能仅拼接 PINN、MPC、RL 名称就声称创新。理论目标可研究任务相关的记忆截断、估计/价值误差与决策损失；目前没有已证实新定理或完整新算法。

R2 实际基座是自由能/耗散势 PANN，不把原论文已有的热力学结构当本项目新贡献。保留解析机器人动力学，只学习必要的材料闭合关系。材料响应、候选选择和整机任务收益分别评价。

## 4. R2：第三轮结论和冻结边界

完整已执行协议保存在 [本轮原计划](https://github.com/kaiwen123-yang/MCP-RL/blob/7b74c709052ed310af52d4e33a6e690e2e9152d5/docs/TERRAIN_MEMORY_PLAN.md)、[r2-memory-study.json](../experiments/tm02/r2-memory-study.json)和现有运行脚本中。它们供独立复跑，不再是当前启动任务。[统一索引](../results/terrain_memory/reproduction/material/tm02-memory-study-20261023/index.json)与 [Release](https://github.com/kaiwen123-yang/MCP-RL/releases/tag/tm02-memory-study-evidence-20261023)保存原始结果；不改写历史索引的阶段字段。

### 4.1 已做成什么

三臂 A=100 随机、B=1,000 随机、C=50 随机+50 恢复历史；每单元五初始化、三套 noisy 观测噪声，60 模型中 50 新训练、10 复用。每模型 20,000 次完整数据集梯度更新，B 每次覆盖全部 1,000 条历史。按各臂各噪声单元最终训练损失选出的 12 模型完成全部 8,400 次新预测，积分失败为零。

600 个固定物理工况对应 700 条完整参考历史；2,640 次已知诊断来自 60×(20 随机+12 重访的两种边界重放)，并非 2,640 个独立物理工况。共有 45 个 noisy 模型，不是 45 套独立观测噪声。训练数组配对、旧归一化、整历史反传、部署移除辅助 RNN、自由恢复与双边界推演已落实；没有发现需要推翻本轮结论的核心实现错误。

| ideal 全历史 RMSE 均值 | A 随机 100 | B 随机 1,000 | C 混合 100 |
|---|---:|---:|---:|
| F1 随机，应力 / MPa | 0.05164 | 0.04739 | 0.06858 |
| F2 变速，应力 / MPa | 0.05364 | 0.04719 | 0.06376 |
| F3 松弛，应力 / MPa | 0.07028 | 0.07196 | 0.07066 |
| F4 蠕变恢复，应变 ×10⁻⁶ | 7.676 | 5.598 | 9.281 |
| F5 压剪循环，应变 ×10⁻⁶ | 9.792 | 7.064 | 12.027 |
| F6 重访，应变 ×10⁻⁶ | 12.918 | 9.325 | 16.238 |

B ideal 的五家族均值改善，F4–6 约改善 27%–28%；F1/F2 最差路径和 F3 均值/最差值却变差。C ideal 六家族均值均差于 A，但 F3 最差值较小，不能说每个指标都退步。完整均值、中位数、尾部和逐工况配对见 [家族结果](../results/terrain_memory/reproduction/material/tm02-memory-study-20261023/final/family-model-summary.csv)。B 使用更多计算，不是等计算量优越性证据。

### 4.2 没做成什么，以及为何不再机械扩量

全部 45 个 noisy 模型的零态局部体积恢复时间为 **0.601994–0.639048 s**，参考为 **1.2 s**；偏量为 **0.514553–0.542220 s**，参考为 **0.952381 s**。这是物理零态势函数导数得到的局部量，不是全程常数时间模型。A/B/C 与独立噪声重复均未消除恢复偏快，不能再只归因于选 seed 或数据少。

C noisy 在 F2/F3 有平均误差收益，但三个噪声实现的 F6 恢复段 RMSE 中位数均变差；B/C 的恢复积分绝对误差中位数均变差。给参考应变预测应力的双边界诊断同样存在 noisy 偏差，不能只归因于逆求解器。当前证据不证明 RNN 或某个 loss 是唯一病因；也不证明所有信息性激励都无效，仅说明这次固定 50/50 设计没有解决目标问题。

F6 参考为 **60 strict early、40 近似平局、0 strict late**，12 主模型也都如此，always-early 的真实遗憾为零。B ideal 峰值压缩相对误差中位数/最差为 **1.216%/2.065%**；B noisy 为约 **14.23%–14.30%/23.65%–23.76%**。满分强排序可以与严重幅值偏差共存，因此不能据此宣称历史规划、MPC 或 RL 有收益。

### 4.3 可冻结的材料域与未覆盖内容

可复用 A ideal seed0 和 B ideal seed0，后者作为较强材料预测器；B 三个 noisy seed0 作为已知偏差对照。实际支持来自固定 Table 1、已知 virgin 初态和完整前史下的离散执行工况，不能升格为整个连续区间的保证：

- F4：单轴峰值 1/2/3/4/6 MPa，保持 0.1/0.5/1/2/5 s，斜坡 0.05/0.1/0.2/0.5 s，零应力恢复 20 s；B ideal 峰值压缩误差中位数/最差 1.588%/2.228%。
- F5：2–6 MPa 法向压剪、剪压比 0.25/0.5、0.5 s 周期、5/20 循环与 5 s 恢复；对应峰值误差 0.679%/2.010%。F6 的完整重访响应见上述结果。
- 明确困难条件：F2 满幅、四倍速度的最差 B ideal RMSE 为 0.28437 MPa；F3 三轴各 −0.02、保持 20 s 的最差为 1.19476 MPa。不能只用中位数隐藏这些条件。

原文所有三种训练方案、作者随机数组/原代码、各图原数值、未知材料/未知初态和实测噪声均未完整复现。准确名称是**所选原方法的有界重实现基线，加三轮项目适用性实验**。下一步接触尺度与边界仍须实际计算；不能把已有材料预测叫作软地通行。

### 4.4 第三轮结束时的论文借鉴（已落实到 S0）

1. **相容接触与真正动作后果。** [TM06 §III-A 式 11b](https://arxiv.org/html/2604.12006v1)将平足法向力与面积、应力联系；[TM09 §3–5/7.4](https://arxiv.org/html/2610.05550v1)启发同前史候选、响应差和实际决策结果分开评价。S0 据此实现真实 N/mm/J/s、完整后足/返程约束与 constant/myopic 对照；不移植泥地全部触变吸力机制或另建世界模型。
2. **部署一致的材料积分训练，留作有任务需求后的唯一候选对照。** [TM02 §4.1 式 18–19](https://arxiv.org/html/2401.14270v1)原本已有 integration training；[TM08 §4.2 式 30–31/附录 C](https://arxiv.org/html/2609.03645v1)提供隐式状态/边界联解与 backward adjoint 思路。若整机任务证明 noisy 的相关误差确实阻碍决策，可固定数据、噪声和势函数结构，比较辅助 RNN 与直接物理积分训练。当前不执行第四轮训练；这不是新发明，也不能先断言必定修复。TM08 使用对偶耗散势且其噪声涉及位移空间求导，不能直接抄残差或套正则到现有应力标签噪声。

新核到近邻 [Robust bipedal locomotion on flowable slopes via foot-driven terrain manipulation，2026-07](https://arxiv.org/abs/2607.11855)通过足部结构调控颗粒地形响应。此次只核到原始摘要，未据全文排除重合。它足以提醒“主动改变地面帮助行走”不是空白；本项目贡献须落到同一地块跨腿/返程持续恢复以及未来支撑反约束当前决策，仍以 S1 实验为准。

4. **接触执行与上层同时改变，缺少独立对照。** 首轮的 `stance_torque` 是材料反演目标加额外 `Jᵀ PD`，仅随 C2/C3/C4 启用；它没有复现 STANCE 的联合 WBOpt 接触约束。C3 采用近段 0.02s、远段 0.1s 的混合步长；“两个重访”只限制记录条数，尚不是已验证的事件离散算法。保留历史 C 标签，但不以名称代替方法证据。
5. **总应变差分不等于实际撞击速度。** 19 个实际加载的 TM02 回合最大分量应变率为 18.746–99.558/s，旧 R2 700 条历史采样最大值为 0.227082/s；两者不是连续有效域保证。已核 TM02 C0 seed0 的最大值 70.9725085935832/s，精确发生在 5.5834s：足底滑出 patch45/49，极小剩余接触面积归零，独立材料柱瞬时转为零载边界。此时足端 vz≈−0.0535m/s。这不能直接解释为真实高速冲击或扩训到 100/s 的依据；其他回合不自动归入同一原因。该回合 5.9954s 的主应变超 0.02 仍是有效模型域退出，不能抹掉。

#### 5.5.1 一个修正版，两个明确的执行改动

**第一，补齐实际接触模式。** 所有“名义支撑、实际未支撑”的足都要有接近/重接触运动控制，包括初始站立、尚未摆腿和中途失接触。从实际/持续参考的p/v/a接续，接触丢失立即使旧GRF失效；每足每周期的运动/支撑控制有明确所有者，日志与实际关节命令一致。初始已建立支撑沿用原初始化；失接触后的再加载不能以has_swung为前提。保留原时钟、速度计算、加载时长与滤波，不增加独立恢复控制器。

**第二，在原sampler内表达接触可用性和加载限制。** 现有非自适应sampler的候选rollout与首步力提取共用相同约束函数，加入逐足逐预测时刻的加载上限：

```text
0 <= Fz <= alpha * grf_max
abs(Fx), abs(Fy) <= mu * Fz
actual/unavailable contact: F = 0
```

沿用原grf_max、摩擦近似和成本。未来alpha从既有触地预测及固定loading_duration计算，不将当前接触mask冻结到整个时域。优化器因此能在同一预测中考虑合力和力矩后果。**删除T1末端的额外grfs*alpha与剩余力均分，不新增分配QP、全WBC或另一MPC平台。**

50Hz求解之间，500Hz低层保持上次已求出的四足力`f_hold`，用同一约束函数计算`f_cmd=project(current_contact,current_alpha,f_hold)`。真实失接触的脚置0并转运动控制；其余脚不增加补偿；再接触也受同一加载上限约束。**不要用变化后的mask重新调用旧compute_first_stage_grfs计算mg/n，否则会隐式重新均分。** 下一个原50Hz周期再重新优化。

突发失接触会使原期望合力/力矩暂时不可实现；记录同一时点的Σ(f_cmd−f_hold)、Σr×(f_cmd−f_hold)，不宣称瞬时保持六维wrench。GRF命令与−Jᵀf项一致且只计一次，另记运动/惯性/偏置及最终关节命令。沿用原执行器限幅并报告实际饱和，不能把足力约束当作完整全身力矩可行性证明。

T1→T1R冻结共同摆腿补项、接近速度公式、材料查询、参考滤波、增益与加载时长；保持同一nonadaptive后端和原采样预算。不得同时回调旧摆腿、换MPC、改材料或搜索增益，否则无法回答这次具体修复是否有效。

### 5.6 后续三个算法贡献的接口现在就固定

- **PANN辨识：**输入真实可获得的载荷/足端运动/机器人状态，输出地块状态、材料编码与预测不确定性；接触修正、离足预测、跨腿共享。训练可借鉴TM08的可测力/位移和部署一致积分，经典本构＋估计器和同信息历史网络必须对照。
- **MPC：**输入机器人状态、相关地块状态和接触意图，输出相容的身体/足端/接触力计划；保持真实动力学与执行器限制。事件状态压缩要与延长时域及计算预算比较。
- **PPO Actor–Critic：**Actor输出与S1相同的有限接触意图，Critic评价剩余任务并提供MPC终端价值；从一开始在“Actor→MPC→机器人”同一闭环训练。只学价值函数不能叫改进PPO。候选创新是利用同起点接触分支辅助重访价值/信用分配，模型反事实有偏差，不能直接当真实无偏优势；普通/循环PPO、普通Critic与充分事件MPC是必要对照。

新增训练须由整机中的真实控制瓶颈触发，本轮S1训练预算仍为0。后续算法正式实验至少包含充分辨识经典模型、同信息历史网络、普通RL和真状态参考；训练真值只用于明确的监督/oracle，部署Actor和终端Critic不读不可获得的真实材料内变量；若训练另设特权Critic，不能直接把它作为实机MPC终端价值。现有R1/R2是组件基座，第二轮B1仍是刚地/KV8000局部执行参照；当前先处理第三轮暴露的接触执行缺口。TM02可行任务与材料历史决策收益均未成立，控制修复本身不冒充三项算法贡献。

## 6. H：最终实机，不把部署问题全部推迟到这里

目标为用户明确的Go2＋NX。现在固定控制链、观测来源和时间预算，设备详细配置在可访问时据实记录。S1形成稳定且可解释的整程结果后，先标定材料加载/卸载/恢复及测量误差，再做跨足重访和完整往返；真实慢恢复参数必须有数据依据。

分开控制器实际使用的传感与只用于评价的参考测量。比较使用相同材料准备、恢复与试验顺序规则，保留整程视频/力学记录。现场操作者启动/结束，保留原生限位、限流和急停；没有现场条件时继续已授权仿真，不把硬件记作完成。
