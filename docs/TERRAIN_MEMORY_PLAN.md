- **从开始阅读任务起计时，最多4h，包含构建、运行、分析和推送。** 3.5h开始收尾；目标提前完成就提前结束。

- 默认只读AGENTS和本页，再定位相关函数/错误窗口。大日志留文件，终端只输出关键错误和结果，不把完整数组、反复diff、旧总索引灌进上下文。
- 一次真实失败已经能回答的问题不重复验证。正常构建和针对性真实运行继续做，不新建单元/mock/冒烟/导入/形状测试、通用防御层、审查报告或独立性能基准。
- 版本关系用正常Git commit、配置名、checkpoint路径记录。已有程序顺手产生的摘要可保留，不新增全量hash/资产遍历/重新下载复核任务；仅在具体传输损坏或文件拿错时定点检查。
- 窗口末只更新顶部6行：做了什么、实际结果、还卡哪里、下次唯一动作、文件/checkpoint位置。详细结果沿用正常运行输出，不再写第二份交接包。

## 4. 首次学习的最小约束

候选能正确站立、动作实际生效并真实加载材料，就允许W2/W3；无需先完整通过E30/E60。首次两流使用nominal，分别独立保存，不等待未启动流，不扩大初态/seed矩阵。

256是当前首次更新任务的样本目标，不是新的物理实验次数限制。普通rollout更新不重置环境；**若本窗口明确在首次256或墙钟截止结束，应在末条进入buffer/GAE前标外部截断，使用真实末观测bootstrap；真实物理失败terminal优先。** 外部截断不额外加失败/超时奖惩。

更新后正常保存checkpoint和计数；窗口未满256则保存已有有效尾buffer。无需另开恢复演习或参数重载对照；下一次真正续训时正常加载即可。无完整环境快照时新开物理会话，保留实际边界和训练计数；缺失末观测的数据如实标缺失，不伪造连续状态。

早期训练用于解决实际接线问题，不宣称收敛或PANN收益。控制器改版时分清版本、保留旧样本；最终正式比较从预声明种子开始，不混用开发结果。
