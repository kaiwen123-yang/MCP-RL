## 1. 最终要解决的具体问题

**面向重复踩踏的四足机器人地面记忆辨识与跨步协同控制。**

机器人踩过的软地面会改变，抬脚后也不会立即回到初始状态。前腿怎样加载、后腿是否重叠落足、隔多久再次踩上去，以及返程是否沿原足迹走，都会影响后来能否获得足够支撑。

研究问题是：**在材料状态不可直接测量、跨腿共享且持续恢复的条件下，如何辨识同一地块的接触历史，并根据未来支撑需求安排现在的加载、落点和重访时间，使整程任务更可靠、更有效率？**

首版只研究具有可测恢复时间的黏弹性地层与可控材料样件。先把加载—卸载—离足恢复—再次加载这一机制做实；暂不同时引入泥地吸附、颗粒流动、破坏、渗流等全部过程。不得假定预先踩踏一定有利，踩踏也可能使后续支撑变差。

### 一个主机制，三个候选贡献

| 候选贡献 | 必须实现的机制 | 必须回答的实验问题 |
|---|---|---|
| 1. 跨足共享的地面记忆辨识 | 在世界坐标中维护地块内变量；PINN 学习受物理约束的加载、卸载和自由恢复关系，换腿和离足不清零 | 与充分辨识的经典本构、同信息历史网络相比，能否预测未见的完整加载/重访历史及后续支撑？ |
| 2. 未来支撑需求约束当前踩踏 | MPC 联合考虑当前加载、落点重叠和重访间隔；把后续足所需支撑映射回当前动作 | 同样能感知地面时，主动改变当前动作能否改善未来接触和整程结果？ |
| 3. 超出 MPC 时域的重访价值 | RL 学习与未来地块重访相关的终端价值，显式利用跨步/返程关系 | 在相同在线计算预算下，是否优于普通终端价值及延长时域/按重访事件规划的 MPC？ |

三个贡献是待验证假设，不能仅按 PINN、MPC、RL 三个模块各写一个“创新点”。前人已有软地面适应、材料记忆模型和 RL–MPC 组合；创新判断落在上述具体机制及证据上。若经典本构或充分规划已经解决问题，必须保留这个结果，再修正同一科学问题的实现。

### 模型与控制之间的关系

地块 j 的内部状态记为 z_j；当前加载动作 a 包含足端力/位移轨迹、作用位置和持续时间。加载算子 L 和离足恢复算子 R 形成后续接触前的状态：

```text
z_j(next contact) = R(theta, revisit interval, L(theta, z_j, current loading))
```

MPC 要求未来足所需的**力—时间轨迹**属于这一状态下材料能够实现的支撑集合，同时满足机器人动力学、足端运动和材料变形关系。不能把所有材料记忆简化成一个静态最大支撑力，不能让计划接触力与仿真实际反力来自互不相容的两套模型。

离足时继续按零外载等实际边界条件求解材料恢复；“无接触”不等于“压入位移强行归零”。地块状态跨不同腿、转弯和返程保留。只在独立实验回合之间按既定方式准备初始材料状态。

### 4.1 已做成什么

三臂 A=100 随机、B=1,000 随机、C=50 随机+50 恢复历史；每单元五初始化、三套 noisy 观测噪声，60 模型中 50 新训练、10 复用。每模型 20,000 次完整数据集梯度更新，B 每次覆盖全部 1,000 条历史。按各臂各噪声单元最终训练损失选出的 12 模型完成全部 8,400 次新预测，积分失败为零。

600 个固定物理工况对应 700 条完整参考历史；2,640 次已知诊断来自 60×(20 随机+12 重访的两种边界重放)，并非 2,640 个独立物理工况。共有 45 个 noisy 模型，不是 45 套独立观测噪声。训练数组配对、旧归一化、整历史反传、部署移除辅助 RNN、自由恢复与双边界推演已落实；没有发现需要推翻本轮结论的核心实现错误。

|---|---:|---:|---:|
| F1 随机，应力 / MPa | 0.05164 | 0.04739 | 0.06858 |
| F2 变速，应力 / MPa | 0.05364 | 0.04719 | 0.06376 |
| F3 松弛，应力 / MPa | 0.07028 | 0.07196 | 0.07066 |

B ideal 的五家族均值改善，F4–6 约改善 27%–28%；F1/F2 最差路径和 F3 均值/最差值却变差。C ideal 六家族均值均差于 A，但 F3 最差值较小，不能说每个指标都退步。完整均值、中位数、尾部和逐工况配对见 [家族结果](../results/terrain_memory/reproduction/material/tm02-memory-study-20261023/final/family-model-summary.csv)。B 使用更多计算，不是等计算量优越性证据。

### 4.2 没做成什么，以及为何不再机械扩量

全部 45 个 noisy 模型的零态局部体积恢复时间为 **0.601994–0.639048 s**，参考为 **1.2 s**；偏量为 **0.514553–0.542220 s**，参考为 **0.952381 s**。这是物理零态势函数导数得到的局部量，不是全程常数时间模型。A/B/C 与独立噪声重复均未消除恢复偏快，不能再只归因于选 seed 或数据少。

C noisy 在 F2/F3 有平均误差收益，但三个噪声实现的 F6 恢复段 RMSE 中位数均变差；B/C 的恢复积分绝对误差中位数均变差。给参考应变预测应力的双边界诊断同样存在 noisy 偏差，不能只归因于逆求解器。当前证据不证明 RNN 或某个 loss 是唯一病因；也不证明所有信息性激励都无效，仅说明这次固定 50/50 设计没有解决目标问题。

F6 参考为 **60 strict early、40 近似平局、0 strict late**，12 主模型也都如此，always-early 的真实遗憾为零。B ideal 峰值压缩相对误差中位数/最差为 **1.216%/2.065%**；B noisy 为约 **14.23%–14.30%/23.65%–23.76%**。满分强排序可以与严重幅值偏差共存，因此不能据此宣称历史规划、MPC 或 RL 有收益。

### 4.4 本次论文借鉴只落实两个机制

1. **相容接触与真正动作后果。** [TM06 §III-A 式 11b](https://arxiv.org/html/2604.12006v1)将平足法向力与面积、应力联系；[TM09 §3–5/7.4](https://arxiv.org/html/2610.05550v1)启发同前史候选、响应差和实际决策结果分开评价。S0 据此实现真实 N/mm/J/s、完整后足/返程约束与 constant/myopic 对照；不移植泥地全部触变吸力机制或另建世界模型。
2. **部署一致的材料积分训练，留作有任务需求后的唯一候选对照。** [TM02 §4.1 式 18–19](https://arxiv.org/html/2401.14270v1)原本已有 integration training；[TM08 §4.2 式 30–31/附录 C](https://arxiv.org/html/2609.03645v1)提供隐式状态/边界联解与 backward adjoint 思路。若 S0 证明任务价值且 noisy 的相关误差仍阻碍决策，可固定数据、噪声和势函数结构，比较辅助 RNN 与直接物理积分训练。当前不执行第四轮训练；这不是新发明，也不能先断言必定修复。TM08 使用对偶耗散势且其噪声涉及位移空间求导，不能直接抄残差或套正则到现有应力标签噪声。

新核到近邻 [Robust bipedal locomotion on flowable slopes via foot-driven terrain manipulation，2026-07](https://arxiv.org/abs/2607.11855)通过足部结构调控颗粒地形响应。此次只核到原始摘要，未据全文排除重合。它足以提醒“主动改变地面帮助行走”不是空白；本项目贡献须落到同一地块跨腿/返程持续恢复以及未来支撑反约束当前决策，仍以 S1 实验为准。

**要回答的科学问题。** 在公开的接触几何、实际载荷和同一后足/返程要求下，当前落点、加载时机和等待是否产生可利用的未来支撑差异？解析参考已知道完整材料状态，先给出这组任务的收益上限；再看 ideal/noisy 的误差是否影响选择。该装置由机架承载，允许双足同时零载，不承担自由机器人的重力平衡，不能提前声称四足步态或通行成功。

**先说明物理尺度。** 原 Table 1 的 K_eq=500、G_eq=300 MPa，对应 E_eq=9KG/(3K+G)=750 MPa。示例 100 N、4 cm²、2 cm 厚度，仅有约 6.7 μm 平衡压入；这不是已测机器人参数，也不能直接当作明显沉陷软地。S0 固定两块自由侧面、均匀压缩的材料样件 P/Q：有效面积 A=0.001 m²、厚度 H=0.05 m、中心间距 0.1 m。原尺度 γ=1 作对照；γ=0.025 是明确的合成软化假设，50/100/150 N 对应原模型 2/4/6 MPa，平衡压入约 0.133/0.267/0.400 mm。原尺度同载荷为 3.33/6.67/10 μm。不能改参数使收益变大，也不将合成样件称为泥、沙、雪的已辨识材料。

同比缩放 ψ*=γψ、φ*=γφ。若直接修改参考参数，K/G/η/**a_MPa** 都乘 γ，b/o 不变，否则会改变非线性黏度的 σ_ov/a。推荐复用未改权重/norm，在等效原应力 σ*/γ 下求同一应变和状态轨迹，再将物理应力、能量密度和耗散同比换算；这只是声明的模型变换，不是新材料实测泛化。

**接触必须相容。** 压缩取 ε11<0，δ=−H ε11，N=−A σ11×10⁶；其余应力分量为零。S0 给非负法向力，由材料求压入与内状态，不能同时另给独立接触位移。离足外应力为零、材料继续恢复；gap≥0、N≥0、gap×N=0。机械功按真实 N·dδ 计算，与样件体积内 σ:dε 相容；正向接触功不叫整机电耗。所有限制按完整时程判定：N≤150 N、材料压入≤1 mm、最大主应变绝对值≤0.02、足端水平/垂直速度≤0.5/0.1 m/s。1 mm 不是包含抬脚的执行器总行程；相对未变形表面的飞行高度为 11 mm，允许表面位移范围内净空至少 10 mm；接近和交接各留 0.25 s，实际抬/降各至少 0.12 s，横移按真实距离和速度完成。无法实现的候选保留失败，不截断位移或另加刚地力使之成功。

**固定 72 工况。** γ∈{1,0.025} × 前史加载地块∈{P,Q} × 前史窗口后额外间隔∈{0.1,1,5}s × 后足 P/返程 Q 的载荷对∈{(50,150),(100,100),(150,50)}N × 后足窗口后返程间隔∈{0.5,3}s。该网格是机制覆盖，不能叫 72 次 iid 随机样本。

每个工况从两地块 virgin 状态开始，前足先在指定地块完成 100 N、1 s 前史窗口，之后为固定前史间隔。当前前足从中点接近候选地块，再完成 100 N、1 s 当前窗口；0.25 s 交接后，后足在 P 完成 1 s 规定载荷；经过返程间隔，前足返回 Q 完成 1 s 规定载荷。最后追加 2 s 零载恢复供曲线观察，不计任务完成时间或目标。前史、后足、返程用 early 包络；当前动作有 **P/Q × early/late × 等待 0/0.5/1.5 s，共 12 候选**。early 在窗口 0.1 s 达峰、保持至 0.4 s、0.5 s 卸零；late 整体平移 0.5 s。当前两种包络峰值均 100 N、冲量均 40 N·s；等待真实延迟全部后续事件。

前史的额外间隔并非总恢复时间，early 窗口后半段已经零载；必须保存各接触开始、卸载、等待和返程的全局时刻。前史末尾零载时允许前足抬离、回中点，随后按给定接近时间运动。当前足到返程足的移动也保留连续轨迹，不瞬移。每个真实地块的材料历史覆盖整个时间轴，在另一个地块受载时仍继续恢复。现有积分入口每次默认从 q=0 起步，不能按每足接触分段后直接拼接；优先为每地块构造完整应力数组并整体积分，或显式传递状态。

**七个材料预测器和同一任务的实际后果。** 使用连续解析参考；仅在规划时每次接触重置的解析参考消融；A ideal seed0；B ideal seed0；B noise0/1/2 各 seed0。每个学习模型用完整可观测前史自由建立自己的状态，不读真实 q。所有方法选定的候选都在持续记忆的解析参考环境评价，可复用已经算过的真轨迹；reset 模型不能重置真实环境。当前 noisy 是训练标签噪声形成的模型误差对照，不冒充部署传感器噪声实验。

### 5.3 S1：持续材料状态的完整机器人任务

首个主任务为 **硬地起步 → 软地走廊 → 端部停留/转向 → 原区域返程**。路程、允许时间、指令和判定条件写入场景配置；所有方法允许相同的减速、等待和落点调整。完整往返结束前不重置地面，不把去程和返程拆成互不影响的 episode。

先复用冻结 R1 的机器人与控制底座，再完成 Go2 移植。固定 2.4 Hz 与 adaptive 均保留；不得只选明显较弱的固定 1.3 Hz 来证明新方法有效。软地采用具有独立内部状态的材料区域和明确接触面积/足迹映射；世界坐标中的重叠足迹共享状态。离足后的区域继续恢复，不能用每步随机刚度或普通高度场冒充材料记忆。

环境的参考本构与学习模型分开，评价使用未见参数和未见完整加载历史。至少包括可辨识的非线性/多时间尺度参考材料，避免训练网络和环境使用同一个可直接拷贝的函数而形成虚假优势。S0 的机架任务不提供整机收益证据；整机仍需用真实材料状态可见的 oracle 对照确定任务价值上限；真实状态信息仅限 oracle，不能进入实际方法或普通基线。整机接触使用法向压入与自由侧面应力的混合边界，由同一材料关系产生唯一反力；不能让刚地和材料模型各输出一套支撑力。

### 5.4 按依赖接入三个机制

1. **持续地块状态与 PINN。** 解析机器人刚体动力学保持不变；神经网络只学习必要的材料闭合关系。用加载平衡、状态演化、恢复边界和耗散关系约束可见接触历史；评估未见重访间隔下的未来反力/变形。若内部变量不能唯一辨识，以可观测的未来支撑预测为依据，不声称获得唯一真实隐变量。
2. **跨步协同 MPC。** 在同一优化问题中传播当前加载对后续接触的影响，联合接触力/位移相容、落点重叠和重访时间。先通过有界候选落点/时序或事件展开实现，不立刻重写一个通用混合整数规划平台。
3. **长期重访价值 RL。** 固定已验证的接触执行接口，以未来可能重访的地块状态及关系为输入学习超出 MPC 时域的价值，并作为规划终端项。奖励围绕完整任务完成、耗时、能耗和支撑失败；不加入“奖励像论文机制”的人工标签。

### 5.5 整机强对照与消融

各组使用相同可获得信息、训练数据预算、评价任务和动作权限。在线耗时、离线训练量分别报告；更长规划必须纳入匹配在线预算的比较。

| 对照或消融 | 排除的替代解释 |
|---|---|
| 冻结的固定 2.4 Hz / adaptive 控制底座 | 新方法是否仅靠高步频获得表面收益 |
| 充分辨识的标准线性固体/广义 Maxwell 等经典材料模型 + 同一 MPC | 是否只是故意选择了过弱的材料基线 |
| 同等历史和空间信息的普通神经材料模型 + 同一 MPC | PINN 的物理约束是否有实际增益 |
| 同等历史/地块记忆输入的 RL 控制基线 | 是否只是提供了更多观测信息 |
| 完整状态估计 + 不传播当前动作对未来地块影响的规划 | 跨步协同机制是否比被动适应有效 |

### 5.6 三份核心整机仿真成果

- **记忆证据：** 相同外观/相近瞬时形变下，不同加载历史是否产生不同后续支撑；模型是否预测到这一差异。按完整历史留出，不随机打散时间点泄漏未来。
- **机制证据：** 恢复时间、可用足迹重叠和重访间隔变化时，最优策略如何变化；何时等待有利，何时换点有利，何时策略与普通控制等效。不得预设踩实一定提高支撑。
- **整程证据：** 往返成功率、完成时间、能耗、峰值沉陷/支撑失配、在线计算时间及连续视频。失败回合与条件全部进入结果；准确率或材料损失下降不能替代机器人任务收益。

成果放入 `results/terrain_memory/simulation/` 与 `outputs/terrain_memory/simulation/`。根据负结果修改同一问题的模型/控制机制；不得通过换题、堆网络、扩写文档绕开核心结果。
