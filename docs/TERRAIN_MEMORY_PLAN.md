## 1. 最终问题与一个主机制

**面向重复踩踏的四足机器人地面记忆辨识与跨步协同控制。**

当前踩踏改变世界固定地块的内部状态，离足后继续恢复，后腿或返程再接触时的支撑因此变化。研究：**在材料状态不能直接测量、观测间断和在线计算有限的条件下，如何辨识这种变化，并安排当前加载、落点和接触时序，改善完整任务？**

首版从有可测恢复过程的黏弹性材料及可控样件开始，不把它自动解释为湿草、沙、雪或泥。加载可能改善也可能恶化后续支撑，不能事先给“踩实有利”奖励。

| 候选贡献 | 拟实现的机制 | 必须排除的替代解释 |
|---|---|---|
| 物理约束的跨足记忆辨识 | 接触观测修正地块状态，离足按物理规律传播；材料参数与当前状态分开，跨腿共享 | 充分辨识的经典本构＋估计器、同信息历史网络是否已经解决问题 |
| 跨接触事件 MPC | 当前加载通过材料状态影响后续接触；近期细时序、远期相关事件形成可执行计划 | 是否只靠更长时域、更大计算量或增加动作权限 |
| 面向重访后果的强化学习 | PPO Actor 选择接触意图，Critic 学习同一闭环的远期价值；研究重访后果的延迟信用分配 | 同信息普通/循环 PPO、普通 Critic 和充分事件规划是否已经足够 |

## 4. R2：第三轮结论和冻结边界

完整已执行协议保存在 [本轮原计划](https://github.com/kaiwen123-yang/MCP-RL/blob/7b74c709052ed310af52d4e33a6e690e2e9152d5/docs/TERRAIN_MEMORY_PLAN.md)、[r2-memory-study.json](../experiments/tm02/r2-memory-study.json)和现有运行脚本中。它们供独立复跑，不再是当前启动任务。[统一索引](../results/terrain_memory/reproduction/material/tm02-memory-study-20261023/index.json)与 [Release](https://github.com/kaiwen123-yang/MCP-RL/releases/tag/tm02-memory-study-evidence-20261023)保存原始结果；不改写历史索引的阶段字段。

### 4.1 已做成什么

三臂 A=100 随机、B=1,000 随机、C=50 随机+50 恢复历史；每单元五初始化、三套 noisy 观测噪声，60 模型中 50 新训练、10 复用。每模型 20,000 次完整数据集梯度更新，B 每次覆盖全部 1,000 条历史。按各臂各噪声单元最终训练损失选出的 12 模型完成全部 8,400 次新预测，积分失败为零。

600 个固定物理工况对应 700 条完整参考历史；2,640 次已知诊断来自 60×(20 随机+12 重访的两种边界重放)，并非 2,640 个独立物理工况。共有 45 个 noisy 模型，不是 45 套独立观测噪声。训练数组配对、旧归一化、整历史反传、部署移除辅助 RNN、自由恢复与双边界推演已落实；没有发现需要推翻本轮结论的核心实现错误。

| ideal 全历史 RMSE 均值 | A 随机 100 | B 随机 1,000 | C 混合 100 |
|---|---:|---:|---:|
| F1 随机，应力 / MPa | 0.05164 | 0.04739 | 0.06858 |
| F2 变速，应力 / MPa | 0.05364 | 0.04719 | 0.06376 |
| F3 松弛，应力 / MPa | 0.07028 | 0.07196 | 0.07066 |
| F4 蠕变恢复，应变 ×10⁻⁶ | 7.676 | 5.598 | 9.281 |
| F5 压剪循环，应变 ×10⁻⁶ | 9.792 | 7.064 | 12.027 |
| F6 重访，应变 ×10⁻⁶ | 12.918 | 9.325 | 16.238 |

B ideal 的五家族均值改善，F4–6 约改善 27%–28%；F1/F2 最差路径和 F3 均值/最差值却变差。C ideal 六家族均值均差于 A，但 F3 最差值较小，不能说每个指标都退步。完整均值、中位数、尾部和逐工况配对见 [家族结果](../results/terrain_memory/reproduction/material/tm02-memory-study-20261023/final/family-model-summary.csv)。B 使用更多计算，不是等计算量优越性证据。

### 4.2 没做成什么，以及为何不再机械扩量

全部 45 个 noisy 模型的零态局部体积恢复时间为 **0.601994–0.639048 s**，参考为 **1.2 s**；偏量为 **0.514553–0.542220 s**，参考为 **0.952381 s**。这是物理零态势函数导数得到的局部量，不是全程常数时间模型。A/B/C 与独立噪声重复均未消除恢复偏快，不能再只归因于选 seed 或数据少。

C noisy 在 F2/F3 有平均误差收益，但三个噪声实现的 F6 恢复段 RMSE 中位数均变差；B/C 的恢复积分绝对误差中位数均变差。给参考应变预测应力的双边界诊断同样存在 noisy 偏差，不能只归因于逆求解器。当前证据不证明 RNN 或某个 loss 是唯一病因；也不证明所有信息性激励都无效，仅说明这次固定 50/50 设计没有解决目标问题。

F6 参考为 **60 strict early、40 近似平局、0 strict late**，12 主模型也都如此，always-early 的真实遗憾为零。B ideal 峰值压缩相对误差中位数/最差为 **1.216%/2.065%**；B noisy 为约 **14.23%–14.30%/23.65%–23.76%**。满分强排序可以与严重幅值偏差共存，因此不能据此宣称历史规划、MPC 或 RL 有收益。

可复用 A ideal seed0 和 B ideal seed0，后者作为较强材料预测器；B 三个 noisy seed0 作为已知偏差对照。实际支持来自固定 Table 1、已知 virgin 初态和完整前史下的离散执行工况，不能升格为整个连续区间的保证：

- F4：单轴峰值 1/2/3/4/6 MPa，保持 0.1/0.5/1/2/5 s，斜坡 0.05/0.1/0.2/0.5 s，零应力恢复 20 s；B ideal 峰值压缩误差中位数/最差 1.588%/2.228%。
- F5：2–6 MPa 法向压剪、剪压比 0.25/0.5、0.5 s 周期、5/20 循环与 5 s 恢复；对应峰值误差 0.679%/2.010%。F6 的完整重访响应见上述结果。

### 4.4 第三轮结束时的论文借鉴（已落实到 S0）

1. **相容接触与真正动作后果。** [TM06 §III-A 式 11b](https://arxiv.org/html/2604.12006v1)将平足法向力与面积、应力联系；[TM09 §3–5/7.4](https://arxiv.org/html/2610.05550v1)启发同前史候选、响应差和实际决策结果分开评价。S0 据此实现真实 N/mm/J/s、完整后足/返程约束与 constant/myopic 对照；不移植泥地全部触变吸力机制或另建世界模型。
2. **部署一致的材料积分训练，留作有任务需求后的唯一候选对照。** [TM02 §4.1 式 18–19](https://arxiv.org/html/2401.14270v1)原本已有 integration training；[TM08 §4.2 式 30–31/附录 C](https://arxiv.org/html/2609.03645v1)提供隐式状态/边界联解与 backward adjoint 思路。若整机任务证明 noisy 的相关误差确实阻碍决策，可固定数据、噪声和势函数结构，比较辅助 RNN 与直接物理积分训练。当前不执行第四轮训练；这不是新发明，也不能先断言必定修复。TM08 使用对偶耗散势且其噪声涉及位移空间求导，不能直接抄残差或套正则到现有应力标签噪声。

新核到近邻 [Robust bipedal locomotion on flowable slopes via foot-driven terrain manipulation，2026-07](https://arxiv.org/abs/2607.11855)通过足部结构调控颗粒地形响应。此次只核到原始摘要，未据全文排除重合。它足以提醒“主动改变地面帮助行走”不是空白；本项目贡献须落到同一地块跨腿/返程持续恢复以及未来支撑反约束当前决策，仍以 S1 实验为准。

2. **预测没有接续真实摆腿。** `s1_planner.py` 将当前足位置同时作为新的起摆点与落点，清空等待状态，再叠加摆腿弧；也没有复用实际下层 MPC 的力计划。已发布刚地 C2 seed0 在 2.8s 作出的计划，对 2.98s 的 roll 预测为 −0.782945rad，实际为 −0.083159rad，相差 40.1°；高度差 29.681mm。比较处于下一次重规划之前，时间已对齐。
3. **不可区分候选被枚举顺序选中。** 上述回合五次有效决策都选 −4cm，其中四次不同偏移的最小成本完全相同。3.0s 时全部 12 候选在同一 0.14s 公共前缀被拒绝、成本逐值相同。不能将其解释为 12 个不同真实未来动作均物理不可行。保留真实约束，修预测和候选定义，不通过放宽 IK 残差、选择已知无效解或隐藏回退使结果变好。
4. **接触执行与上层同时改变，缺少独立对照。** 首轮的 `stance_torque` 是材料反演目标加额外 `Jᵀ PD`，仅随 C2/C3/C4 启用；它没有复现 STANCE 的联合 WBOpt 接触约束。C3 采用近段 0.02s、远段 0.1s 的混合步长；“两个重访”只限制记录条数，尚不是已验证的事件离散算法。保留历史 C 标签，但不以名称代替方法证据。
5. **总应变差分不等于实际撞击速度。** 19 个实际加载的 TM02 回合最大分量应变率为 18.746–99.558/s，旧 R2 700 条历史采样最大值为 0.227082/s；两者不是连续有效域保证。已核 TM02 C0 seed0 的最大值 70.9725085935832/s，精确发生在 5.5834s：足底滑出 patch45/49，极小剩余接触面积归零，独立材料柱瞬时转为零载边界。此时足端 vz≈−0.0535m/s。这不能直接解释为真实高速冲击或扩训到 100/s 的依据；其他回合不自动归入同一原因。该回合 5.9954s 的主应变超 0.02 仍是有效模型域退出，不能抹掉。
6. **现有重访量不能直接读成残余记忆证据。** reload 的 e/q 在新载荷施加后记录；应新增加载前、加载后的状态和实际事件唯一编号。旧“预测覆盖”允许滚动窗口重复匹配，也包括同腿重访，不能当全部真实跨腿事件的召回率。

已有 MPC 核心在 71,012 次稳态调用中只有 1 次超过 20ms，各回合 P95 为 1.085–1.359ms。TM02 C3 上层 P95 为 1.497s；C4 去掉各 seed 首次材料调用后，246 次上层调用 P50/P95 为 1.223/10.789s，155 次超过 0.2s。主要新增计算瓶颈在上层/材料展开。包含物理仿真的总耗时不能直接判定控制实时性；上述是运行服务器计时，**NX 未测**。

#### 5.10.2 冻结 PANN 的独立观察与具体特征

使用 R2 `B_random1000--ideal`、seed0 及原归一化；权重路径和 SHA256 在新配置中固定。本轮不重训 PANN，不给 Actor 真实材料内变量 q/e 或未来实际反力。真实 ReferenceColumns 与观察器 LearnedColumns 必须持有各自状态；无 PANN 组不得沿用旧代码 `predictor=ground` 的别名。

三个时钟明确分开：

| 环节 | 实际推进/决策间隔 | 约定 |
|---|---:|---|
| Go2 plant＋真实 ReferenceColumns | .0002 s | 原项目物理步、真实力学连续推进 |
| 独立 PANN 观察器 | .002 s | 使用真实累计 dt 与允许观测；不是每个 .0002 s 步都推进 .002 s |
| PPO Actor | .5 s，2 Hz | 读当前已更新到该时刻的观察/预测，保持所选高层 cap |

观察器在观测时间 t 到达后，用 t−last_observation_time 更新至 t；t=0 保持 virgin，不提前推进未来。2 ms 采样相对 .2 ms 真值是明确近似；已观测的窗口内接触事件可按时间分段处理，不读取真实 q 修正。Actor 不工作时观察器仍持续推进离足恢复。

第一版每足只用**三个带符号自由恢复下陷特征**：

1. 从最近一个已经完成的 S3 名义计划，按绝对时间 **t+.20 s** 取预测 qpos，独立 FK 得到四个世界足印。记录计划起点与查询时刻；不用真实未来运动，也不先用尚未选出的 Actor 动作重规划形成同一步循环依赖。
2. 在观察器**私有副本**为四个足印取得面积权重和查询柱并集；未访问 soft 列用已声明的 virgin。先创建全部查询列，再取并集，避免数组身份变化。
3. 从当前估计 e_hat/q_hat 以零法向外载、自由横向边界、原 .002 s 积分器连续推进 250 步，保存第 **1/100/250** 步，分别为假设无再加载后 **2/200/500 ms**。可沿现有 API `law.step(e_hat,q_hat,zeros(n),.002,zeros(n,bool))`，四足共享一次并集 rollout。
4. 每足按面积加权 **−H·e_hat[:,0]**，再除 .001 m 归一化，保留正负号。当前受载 e 是约束总应变，不能直接叫“当前自由表面”；不增加额外压缩探测、不另建候选控制搜索。
5. rigid/跨边界足印用公共 mask 与零材料特征。公共查询位置/mask 给两 PPO 组，RAW 组的 12 个预测通道置零以匹配网络输入维数。查询不改变真值或持久观察器状态。

上述预测是**条件零载恢复**，不是保证未来没有脚踩上去。只在后续确实未再加载的可比窗口评价相应恢复误差；出现新接触另记，不能把条件不同的真实变化一概当模型预测误差。真实 Ground、observer 与 query clone 的稀疏列创建顺序可能不同，比较必须按世界网格 key(ix,iy) 匹配，不能按数组行号；只有真值确实未加载的地块才用已声明的 virgin 参考。500 Hz 观察与每次 250 步私有预测均计入本轮真实成本，不承诺其可在 NX 实时执行。

训练在首次满足完整原路线＋连续 2 s 终点稳定时可成功结束，不让成功后的 Stand 占满后续采样。物理失败、材料/模型域失效及任务本身 60 s 截止均为真正终止，bootstrap=0；普通 PPO rollout 片段边界不终止、对真实后继 bootstrap。技术性预算中断不得伪装成物理失败。正式评价仍必须观察完整 60/300 s。

#### 5.10.4 一套固定奖励与实际收益

两学习组奖励相同，由**实际执行结果**计算，训练开始后不按正式成绩调权，不奖励 PANN 预测值或预定“踩实有益”：

`r = 5·Δroute_fraction − dt/60 − I²·dt/60 − .1·S²·dt/60 − .01·Δa_applied² + 10·success − 10·failure − 5·timeout`

- Δroute_fraction：去/返程每个实际物理步沿当前 leg 方向的有符号进展，总尺度 6 m，跨 phase 分段，没有阶段切换赠分；保留后退的负进展。
- I²：实际加载 soft 足的正下陷/ .001 m 的平方均值，按转移内实际时间积分；没有加载足时为 0，不用预测下陷代替。
- S²：实际 Fz>1 N 的加载足切向速度/.25 m/s 的平方均值，按时间积分。
- Δa_applied：仅平移阶段真正应用 cap 的归一化变化；不罚固定阶段无效 requested 动作。
- success 只由原完整任务/原 2 s 稳定触发；failure 分别标出物理、材料域或观察器失败；timeout 只在未完成达到 60 s 截止触发，不重复当普通 failure 扣分。能量、峰值力、饱和等另作实际指标，不临时添奖励项。

这套奖励和小动作空间用于建立首个可执行基础。若最优策略接近恒定最高速、PANN 不改变动作或反而变差，这是本轮要揭示的结果，不为制造差异扩大动作权限或改材料。

#### 5.10.5 直接推进一个完整实验 campaign

**A．薄适配与实际材料整程：最多 8 次非训练物理启动。** 每次直接按原 60 s mission 完整执行，提前失败保留完整失败轨迹；不另开短驻足、小型诊断/冒烟轮。依据完整记录修正足底/受力/时钟等具体实现问题。在至少一个允许速度意图下完成材料整程，说明冻结执行器有可用域后，再投入策略训练。若真实材料域/接触执行仍不成立，保留具体负例和阻塞，不修改真值或恢复旧 T1 装作联合成功。

**B．六条真实 PPO 训练流。** 两组×seed0/1/2，从零各以 **4,096 高层转移**为首目标，预算允许时**共同扩到 8,192**，总硬上限 **49,152**。按同一 256 步倍数保存共同 checkpoint，平衡分配时间；不能先把一组训练完才给另一组剩余预算。到不了首目标就报告实际共同量，不能写“训练完成 4096”。只记录必要 transition/episode 数据、学习曲线、模型和材料摘要，不在每个训练步保存全部 MPC 预测数组。

每条训练转移 .5 s，但固定阶段动作可能无效；分别统计总转移、有效动作转移、物理秒、MPC 调用、episode/reset/失败数。采样量不是动作有效性，也不是独立成功次数。三 seed 只能初步观察学习离散性，不是论文级广泛材料统计。

**C．冻结后 21 条原任务。** FIXED_S3 在 nominal/yaw±5°各一条，两个学习组各 3 seed×3 初态，共 **21×60 s**。使用标准确定性 Actor 均值；冻结实际源码/配置/二进制/权重，三组同真值、同底层与同评价。名义开发固定组结果仅在原样同版且事先明确身份时复用一次，不能重复计启动；学习组不能看正式成绩挑 checkpoint。

原路线为初始 2 s Stand→3 m 去程→实际转向 π→返程→原连续 2 s 终点稳定；原任务远端不新增停稳。终点位置半径 .15 m、线速度≤.05 m/s、角速度≤.1 rad/s、roll/pitch≤.15 rad、四足接触，以及原关节/力矩/跌倒判据不变。首次完成时间与后续保持分开，**提前完成也观察到 60 s**。

**D．立即安排三条连续长任务。** 三组均用 nominal，其中 PPO 两组**预先固定 seed0**，共 **3×300 s**；该组 nominal60 s 完整观察成立就开始，不等待所有短任务满分。若这条名义任务失败，保留对应长任务未满足启动条件，不换最好 seed。其余组可行的长任务继续。

每条连续五次 0↔3 m，两端按原条件稳定 2 s 再转向，≤270 s 完成路线，继续记录到 300 s，最终原连续 2 s 稳定；末 30 s 所有超限和更早中断照实报告。圈间不重置材料、机器人、策略/控制历史或初始规划，不拼接不同 run。训练只见原单往返、评价五往返属于延长执行与重访覆盖，不自动等于未知地形泛化。

**预算合计：非训练物理启动最多 32＝8 开发＋21 原任务＋3 长任务，训练启动单独计数。** 不为好看追加正式修订或混入其他控制器的最好成绩。完整组不优于固定/RAW 也交付全部同版结果。

#### 5.10.6 计算预算必须按真实闭环兑现

物理 campaign **墙钟硬上限 48 h**，从第一次新物理启动起，包含适配、训练、正式评价与中途暂停；实现/构建和发布传输耗时另记。预留正式评价时间至少 **6 h**，并按完整 episode 实测成本保留 **max(6 h，预计剩余评价成本×1.2)**。最多 3 个并发环境、每个 2 solver workers，复用当前资源，不新开付费算力。

R8 单条 300 s 已需约 61 min；加入材料/PANN 只可能改变实际成本，不能把旧吞吐当保证。10,000 个 .5 s Actor 转移对应 5,000 s 物理时间，按 R8 单流量级已约 17–18 h，尚未计 PANN；2 Hz 高层动作不减少底层 50 Hz MPC 求解。用最初真实完整训练 episode 分项计时、调整剩余分配，**不另外开 microbenchmark 轮**。

若当前预算只能支持共同较少样本，就用同额 checkpoint 评价并准确标注欠训练；如连完整评价也无法完成，保留实际预算中断和未执行项，不假称 21＋3 已做完。不以百万步、长队列或巨大日志作为成果。持续推进全部可行工作，只在成果交付、具体无法解除的阻塞或预算实际耗尽时结束，不在每个失败后等用户下一句启动词。

#### 5.10.7 本轮成果和下一次判断

必须交付可运行接线与真训练权重、逐 seed 学习曲线、三组同版整程表、全程正负视频、高率物理/材料/PANN 记录及实际耗时。开发/正式保存 500 Hz 状态/命令/力矩、.2 ms 真实反力与接触及必要预测；训练用紧凑记录和选定完整任务视频，不逐步落盘所有未来轨迹。

三层判断分别写清：

1. **执行闭合：** 同一实现是否能完成真实材料原任务和连续 300 s，末段稳定与重访历史是否保留？
2. **信息作用：** PANN 条件恢复特征是否在实际条件下有效，是否使请求/应用速度出现有意义变化？掩蔽特征的离线动作差可辅助说明依赖，不能冒充重新训练的公平性能消融。
3. **任务收益：** 相比固定/RAW，完整任务成功、时间、下陷/滑移/能量及跨足/返程响应怎样变化？若无收益，先判断物理场景是否提供了可行动的记忆差异、速度接口是否足够、训练是否充分，再决定后续贡献；不在当前批次无限扩张。

稳定联合版本之后，才按第 5.11 节进入持久状态辨识/跨事件规划/长期价值研究。R9 本身不宣称三项新方法或未知材料泛化，也不把这套速度策略当最终接触意图算法。

源码/紧凑结果推 GitHub，大数组、权重、视频从执行端直接上 Release，单资产<2 GiB、按连续时间/数据流分片，**只分文件不重置任务**。核对最终 commit 和资产 URL/size/digest 后结束；**不在用户电脑下载、复制、镜像、压缩或再次归档**。不新增审查报告、状态日报、接续文档、通用 fallback 或小型单元/mock/冒烟/导入/形状测试。

### 5.11 先完成联合基础版本，再逐项研究三项贡献

用户明确的顺序仍然成立：**先稳定联合执行，再研究机制创新。**

1. **MPC 执行器已经建立。** R8-S3 在指定刚地原任务与长任务成立并冻结，不再把无限驻足修补或全边缘条件完美当主任务。
2. **当前 R9：接材料、冻结 PANN、训练标准 PPO。** 第 5.10 节固定了受控材料、独立观察、速度 cap、小规模真实闭环训练和三组原/长任务。网络被加载、策略输出、完整任务改善分别证明。
3. **联合稳定后再找有实效的改进。** 先用真实加载/恢复与动作记录判断记忆是否可辨识、是否跨接触事件持续、是否能被允许动作利用；根据失败证据决定下一项方法，而不是同时改 PANN、PPO 和 MPC。
4. **最终研究贡献仍围绕同一个科学问题。** 分别推进跨足状态辨识、跨接触事件规划、长期信用分配；与同信息的经典本构/估计器、历史网络/循环策略、普通 PPO 及计算预算匹配的规划器比较。模块组合、长视频或扩大样本量不自动构成创新。

若后续让 iLQG 直接优化持久材料状态，每条候选/有限差分分支必须独立传播该状态并具有相应导数；userdata 或外力回调不会自动做到。这是后续高级方法的要求，不应阻止当前层级式联合基础。首版普通 Critic 用于 PPO 自身训练，是否作为 MPC 终端值以后由实验决定。

### 5.12 Go2＋NX 部署架构与可观测性

最终结构：观测/定位→机器人及世界地块状态估计→PANN材料预测与RL接触意图→MPC→明确的关节跟踪→Go2；是否增加MPC终端价值由后续实验决定。服务器训练；首版NX在线进行推理、状态估计和必要的低维参数适应，不在行走控制线程训练PPO。在线更新地块状态不等于更新网络权重。

观测清单在S1接口中明确：编码器/IMU、经核实的接触力信息、足端运动学和世界位置是候选输入；真实q、真实恢复时间和未来GRF只属仿真参考。力字段存在不证明其精度；足垫形变、机身估计误差与材料形变需要分清。固定位置样件可用于初始实机研究，不能把已知样件位置当任意场景定位已解决。

NX型号、内存、功耗、传感器、固件和低层接口以实际设备记录。最终接触控制采用明确的低层控制所有权，仅发送Sport速度指令不能证明自己的接触MPC被执行。R9 不启用硬件或另开 NX 计时。后续轻量化阶段，若有实际 NX，先在不连接电机时重放真实负载测量；当前保留未测，不伪造实时结论。

物理状态恢复后的材料参数知识可能仍可长期使用，两者分别表述。真正的长期价值必须有持续影响与实际任务证据，不凭长视频或多步数认定。
