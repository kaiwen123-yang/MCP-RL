- 非足小越界持续主导：依据预测—执行误差与真实cost分解处理可行性余量/约束，不能盲目加权。

下一阶段结果不足时仍如实记录，不由“累计12个r24更新”直接宣判算法失败；但同cap无限续训也不是默认。材料记忆的跨足/返程收益、未见材料泛化与NX实时/真机仍是后续研究，尚未证明。
