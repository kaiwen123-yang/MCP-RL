# 响应—策略共同学习：实际接入、微型学习与否证结果

2026-10-15。主线不变：在输入受限、有扰动和复杂执行动态的系统上，共同设计任务有用、实际可实现、适合在线规划的闭环响应与执行策略；结构为MPC规划、RL执行。

**本轮结论：独立算法和真实工程链路已实现，冻结小规模比较已完成，但尚未证明共同学习机制具有可靠增益，也未形成三个已成立的论文创新点。** 这一结果不能被包装成“已超过SPlaTES/ReCo”。目前更有力的证据是：当前“自由神经反馈＋平均残差＋soft-QP”的实现未能稳定满足输入响应阈值，而本对象上的经典反馈已经十分有效。软松弛、估计方差、响应失配和训练不足尚未被分别排除。继续扩大训练或直接上机器人没有当前结果支撑。

## 1. 本轮确实做了什么

- 独立定义可训练执行策略θ、紧凑响应η、任务目标、实际响应/输入残差及联合更新；不依赖SPlaTES的互信息目标。
- 调用SPlaTES采用的官方LayeredRL原始CEMPlanner、BlackboxPlanner、CEM、Predictor、Hierarchy和Level。每批真实执行800物理步，高层每10低层步规划，Hierarchy.learn确实触发联合更新。
- 使用1505参数完整动作网络和4参数非线性响应模型；神经策略没有叠加经典残差。原版SPlaTES的互信息学习和低层TD-MPC2未运行，因此是实际组件接入，不是完整原论文复现。
- 实现黑箱CEM下合法的两组score梯度及小约束近端QP，51个数学数值检查通过，最大原始—对偶间隙4.996e-15。
- 运行3个训练种子、6个学习/调参比较组，增加预先锁定的4候选经典反馈对照；没有GPU大规模训练。
- 导出真实学习权重，在MATLAB和实际Simulink状态反馈中重新计算动作，核验轨迹及实现残差公式。

## 2. 核心控制关系与算法

实际对象为

\[
\dot p=v,\quad \dot v=a-\sin p-0.2v-0.1v|v|+w,\qquad
0.12\dot a=-a+\operatorname{sat}_{1.2}(u).
\]

低层观察实际x=[p,v,a]及高层命令c，由网络产生完整u；不读取任务目标、虚拟参考、η或真实扰动。MPC用响应状态z=[r,s,q]预测，其中r'=s，s'=q，q'=jη(z,c)。η决定频率、阻尼、执行响应带宽及速度相关系数，既影响规划结果，也影响希望策略实现的响应。每个宏段用实际状态初始化预测，物理执行器状态持续演化。

若标称系统严格实现该响应，所需输入为

\[
u_{nom}=\sin r+0.2s+0.1s|s|+q
+0.12\{\cos r\,s+(0.2+0.2|s|)q+j_\eta\}.
\]

本轮将真实任务成本最小化，并分别约束

\[
E[q_1]\le 0.0002,\quad q_1=\operatorname{mean}[(p-r)^2+0.05(v-s)^2],
\]
\[
E[q_2]\le 0.03,\quad q_2=\operatorname{mean}[(u-u_{nom})^2].
\]

q2反映响应所需输入与实际策略输入之间的差异，不是实际输入越界率，也不是鲁棒可实现性的充要条件。外扰纠偏可能合理地产生输入偏差；不能只凭q2超标就断言该控制任务物理不可实现。

CEM的排序/有限迭代不被假装成可微KKT最优解。训练期先采ξ~N(μ,σ²I)，η=T(ξ)。对任务和两项残差分别估计：actor使用实际pre-tanh动作score乘cost-to-go；μ使用完整episode成本乘(ξ−μ)/σ²。当前动作与设计样本固定后计算score，baseline来自上一批。随后共同求解

\[
\min_{d,s\ge0}\ \widehat g^Td+\frac{1}{2\alpha}d^TMd+\rho\mathbf1^Ts,
\qquad \widehat G+Ad\le s,
\]

其中d同时包含θ和μ的变化。两个约束的对偶QP用box face枚举求解，若KKT失败则不应用更新。超出信赖半径时缩小α重解。**这是soft-slack更新；求解成功不表示s=0，也不表示真实执行约束满足。**

θ确实发生变化，T诊断明确冻结θ。因此程序不是只用RL调4个MPC参数。但“真的共同改变了两者”与“这种改变值得做”是两个不同问题，后者由下面的结果判断。

## 3. 公平比较与实际结果

五主组J/B/F/I/T具有相同1505参数actor、4参数响应、观测、输入权限、MPC配置、32000步主训练和最终测试。全部共享4096条真实teacher数据、600次监督更新和12800步公共任务预训练。B每批也更新两个块；T冻结的是公共任务预训练actor。I拥有同一真实任务成本，但本轮未声称它已达到独立策略的最优收敛性能。

F+为四个固定响应各自训练一个完整40批actor，再选择训练好的pair；主训练量是J的4倍，明确单列。它仍是4候选集内的强对照，不是连续全域最优。经典C使用四组事前锁定的backstepping增益，分别辨识同族模型，再验证选择；使用相同物理任务和测试实例，无神经网络训练，结构上利用已知标称物理。

所有学习组的q1平均值均低于0.0002，J的q1均值约1.52e-5；但J的输入响应误差明显超过0.03。**小的位置/速度预测误差足以掩盖输入实现不匹配。** 原因与控制改进的关系仍需分析，不能把这一现象直接升级为一个新理论。

最终选择在验证集先检查平均q1/q2和名义规划可行性，没有可行候选就明确标false。J仅一个种子通过验证均值筛选，冻结测试时三个种子的平均q2又都超过阈值（第三个为0.03036，略超）。这暴露的是当前soft约束和有限数据的限制，不是有效安全保证。

### 事后交叉组合：确实耦合，但没有证明有益

再交换J与T的actor和响应，只运行两个非对角组合，不重训也不重跑原对角。定义交互差Δ=Jactor/Jresponse−Jactor/Tresponse−Tactor/Jresponse+Tactor/Tresponse。任务交互差在三个种子分别为+0.0000523、−0.0087800、−0.0028260；只有2/3为负。负交互表示组合影响不能写成两个单独影响的简单相加，不能替代绝对任务收益或可实现性。J的q2在三个种子均比T差，新增交叉组合的q2也均超过0.03。

同一个81点实际状态/命令网格上，J与T的实际动作RMS差为0.5280、0.4256、0.3270。因此这批探针排除了“仅参数重排，实际反馈函数没变”；它同时说明共同学习改变了执行行为，但尚未证明这种改变有用。[交叉诊断完整数据](../notes/learning-pilot-2026-10-15/results/cross-diagnostic.json)独立标为事后分析。

## 4. 理论结论到底到了哪里

已推导而且可核验的是：

1. 对声明的随机设计问题，联合score在固定支持、可积且可交换求导与积分等条件下成立；没有忽略规划命令随响应变化的影响。
2. 近端QP与低维对偶等价；数值检查包括奇异/零约束梯度、独立原始求解和无活跃约束时joint=block。
3. 若约束值、梯度误差分别有界ε0、ε1，约束梯度Lipschitz常数为L，且更新半径≤δ，则
   \[
   G(p+d)\le\widehat G+\widehat a^Td+\epsilon_0+\epsilon_1\delta+L\delta^2/2.
   \]
   加足此裕量且无松弛时才能推出真实期望约束可行。当前训练没有认证这些界，不能宣称满足该条件。
4. 同一最终策略/响应可行集合下，共同优化与完全充分嵌套优化的全局最优值相等；可争取的是有限资源求解和约束处理收益。

以上基本score、凸对偶、下降引理与同集合最优值等式是继承的数学工具，不能直接作为三个原创定理。对自由神经反馈，上一轮经典backstepping的鲁棒证书不自动成立。

正式seed11/J的100步冻结轨迹已用MATLAB和实际Simulink闭环重算。神经动作来自各自当前物理状态，没有播放动作记录；高层命令和扰动回放。跨Python状态最大差1.1921e-7、动作最大差2.3842e-7，MATLAB与Simulink相同。独立重算q1/q2也一致，其中该episode q2=0.10605，确实超0.03。

[MATLAB/Simulink证据](../notes/learning-pilot-2026-10-15/matlab-simulink-check.md)验证了数值一致性和公式实现，不是全域安全、机器人可行性或高层MPC独立复现。

每个MPC宏步在0.2秒执行周期下运行，低层0.02秒调用小网络。此次没有在Orin NX上计时，也没有完整机器人负载测试，因此没有实时部署保证。NX继续只作为后续部署载体，不由本次CPU运行速度决定科学问题。

## 6. 三个创新点应怎样落实，而不是怎样命名

| 拟贡献 | 已落实的具体内容 | 尚缺的实质增量 |
|---|---|---|
| 任务有用且输入可实现的闭环响应表示 | 显式执行器状态、响应预测、标称必要输入、实测输出/输入残差 | 需要真正限制可学习反馈与响应的实现关系；平均残差和解析逆动力学本身不足以形成原创贡献 |
| 响应与策略的联合求解机制 | 两类合法score、同批共同QP、同变量分块对照和只调模型诊断 | 当前未胜充分对照；需证明/实证说明实现结构如何改变可达更新方向、估计效率或有限预算性能，不能仅把两个参数块拼进QP |
| 共同学习与在线MPC相连的控制结论 | 局部期望可行性条件、经典原型鲁棒界、数字实现核验 | 尚缺对学习反馈成立的误差传播、输入裕量和规划可行性结论，不能将经典证书移植给自由网络 |

相对SPlaTES，模型与技能共同学习本来就存在；相对ReCo，让规划理解已训练策略也本来就存在；相对MR-ARL，可变最优参考及适应实现也本来就存在。我们的候选增量仍是输入受限和执行器记忆下任务驱动的实现关系、共同更新及其控制结论。本轮完成了可运行检验，**没有证明已解决这些论文未解决的问题**。近邻证据与版本范围见[算法文档第8节](../notes/learning-pilot-2026-10-15/algorithm-theory.md)。

## 7. 下一步的研究决定

保留已确定的科学问题与MPC规划/RL执行结构；暂不将当前“自由MLP＋平均实现残差＋通用近端QP”定稿为论文主算法，不扩到大规模机器人训练。

先研究一个具体缺口：当规划要求响应改变时，哪些策略变化能在输入限制下真正实现它，同时保留已有反馈能力？所需对象是响应变化与策略变化之间的控制实现关系，而不只是训练后再测一次MSE。若这一关系无法比经典响应整定和独立策略辨识提供更强结论或可重复收益，就不将该机制列为创新。

随后仍使用现有同容量B、强固定F+和经典C作判别。不能通过加大网络、放宽输入、延长只有J的预算或更换测试种子挽救结论。T-RO继续作为研究目标，当前证据还不支持将这版算法组织为投稿主结果。
