## 已确认的科学问题和结构

在输入受限、存在扰动和复杂执行动态的机器人上，共同设计“对任务有用、实际能够实现、适合在线优化”的闭环动力学与反馈策略，使规划性能和真实执行性能一起提高。

- **结构：MPC规划、RL执行。** 实际完整任务回报更新反馈；事实响应描述当前执行能力并供MPC使用。尚未实现的期望响应不能冒充当前事实预测。本轮候选改变学习信用估计，不重新启用自由模型目标。
- **首篇范围：**连续多阶段长程任务中的交接状态、规划与实际反馈的协同及后续任务代价；先围绕无外部扰动的“直行—转弯—过门—停止”讨论，不能重新把扰动恢复当主线。评价完整任务成功率、时间和资源取舍，不把局部误差、非零梯度或软件流程完成替代主结果。
- **控制理论的角色：**组织可学习的反馈/响应关系，帮助学习什么、怎样学或怎样可靠预测；不预设只做安全投影或解析控制后的微小残差。
