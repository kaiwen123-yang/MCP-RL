## 已确认的科学问题

在输入受限、存在扰动和复杂执行动态的机器人上，共同设计对任务有用、实际能够实现、适合在线优化的闭环响应与反馈策略，使规划与真实执行一起改善。第一篇的具体范围见下方“首篇”，不要求每个开发任务都施加外扰。

- **结构：MPC规划、RL执行。** 完整任务指导真实反馈学习，事实模型描述实际能力，MPC利用该能力决策。事实预测不能通过降低自己的任务成本虚构改善。
- **首篇：长程多阶段任务。** 关注前段留下的状态如何影响后段，以及有限学习/在线预算下的整程取舍。扰动是可选测试条件，不是主问题；四个阶段标签本身也不等于已经验证长程困难。
- **控制理论的作用：**帮助决定学什么、怎样学、怎样可靠预测；不能由解析控制完成主体任务而把其收益归给RL。
- **研发载体：**Go2整机仿真优先，二维用于推导/诊断，Piper H留作后续候选。不要求二维先赢，不要求冻结策略全局无解。
- **研究标准：**允许继承已有理论和优化器，实际任务、样本效率或计算取舍的改善可以有价值。SPlaTES/ReCo是直接近邻；原版SPlaTES完整性能复现尚未完成。T-RO是目标，尚非可投稿性结论。

依据：[原主线](mainline-in-plain-language-2026-10-15.md)、[控制帮助学习](control-informed-coupling-2026-10-16.md)、[Go2研发顺序](go2-research-transition-2026-10-19.md)、[10月20主线审查](research-direction-audit-2026-10-20.md)。

## 下一阶段建议，尚未实施

主要问题应重新落到：**后续任务要求怎样改变前段应学的实际反馈，MPC怎样预测并利用这一变化，在同等资源下改善完整任务。** 当前三个Go2开发条件只改门宽/起始偏移，尚未检验不同后续需求或未见阶段组合。

建议下一主要设计交付围绕一项相同前段、不同后续要求的自然任务关系，例如通过后继续运动或进入停止区；明确一项真实响应取舍、同信息强对照和整程判据，再决定候选机制。保留当前路线为回归例，不改写旧负结果。任务族/留出组合与预算须在新协议中预先固定，本轮没有修改场景。

公共终止语义、保持时间尺度和KL执行约束作为有限的底座修复，与该任务/机制设计配套；不能再把修复本身变成主要科研目标。第三组不默认沿用CV，也不默认加入PINN。公平比较保留充分规划的冻结反馈、普通任务条件RL＋辨识，以及一个能解释具体能力变化的候选。

继续依据是整程表现或达到同等表现所需数据/计算的实质改善；若公共规划或普通学习解释全部收益，或只有局部误差改善，就关闭具体候选的增量主张。不把54条后缀、全局冻结无解或二维先赢设为入场门槛。详细理由见[本轮审查](scientific-scope-review-2026-10-20.md)。
