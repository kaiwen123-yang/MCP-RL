# 保存批次上的KL早停诊断

日期：2026-10-20。数据仅来自优化器状态隔离后的干净r2，包含3个seed、普通/伴随两组、各4轮，共24轮。只读已有B批与更新前后checkpoint，重算actor前向、Gaussian概率与保存的Adam矩；**没有optimizer.step、模型拟合、策略采样或物理仿真，没有试探其他超参数。**

结论是：**这24轮的KL超限主要是实际动作分布均值变化超过公共阈值，不是仅由估计噪声误触发，也不是CV才产生的现象。** 22轮实际只更新actor一次；另外两轮是seed11普通组第3/4轮，各更新两次。24轮全部提前停止，合计接受26次actor更新；4 epoch原本提供2016个minibatch位置。后者是可检查的位置数，不是应当无条件执行的更新数量。

## 真正越界的是哪一部分

对同一批已保存的旧策略状态，计算原始12维Gaussian的解析
\(D_{\mathrm{KL}}(\pi_{\mathrm{old}}\Vert\pi_{\mathrm{post}})\)：

\[
D_{\mathrm{KL}}
=\sum_{i=1}^{12}
\underbrace{\frac{(\mu_{old,i}-\mu_{post,i})^2}{2\sigma_{post,i}^2}}_{\text{均值部分}}
+
\underbrace{\log\frac{\sigma_{post,i}}{\sigma_{old,i}}
+\frac{\sigma_{old,i}^2}{2\sigma_{post,i}^2}-\frac12}_{\text{方差部分}}.
\]

| 判别量 | 实际结果 |
|---|---|
| 全B状态平均解析KL超过0.02 | 24/24轮 |
| 全B平均解析KL范围 | 0.020472–0.117143 |
| 重算停止位置的解析KL范围 | 0.020021–0.109928，全部超过0.02 |
| 重算停止位置的原估计KL范围 | 0.023854–0.111467，全部超过0.02 |
| 方差变化对总KL的最大比例 | \(4.03\times10^{-7}\)，约0.0000403% |
| 每关节均值变化RMS，原始动作单位 | 0.005856–0.014009 |
| 每关节均值变化RMS/旧标准差 | 0.0584–0.1397 |

这里的解析KL是对固定状态上Gaussian分布的精确表达式，随后在已保存状态上取平均；不是总体状态分布的无误差估计，也不是经过动作裁剪之后的物理动作KL。

初始原始动作标准差为\(\exp(-2.3)=0.100259\)。方差近似不变时，12维总KL=0.02对应的平均每关节均值RMS约为0.005788。这个动作变化量不大，但12个维度的KL相加，足以触及公共阈值。现有实现求的是12维联合KL，不能拿单关节平均KL与0.02直接比较。

阶段分解显示，这个变化并不只集中于过门或停止：24轮按已有样本数加权的解析KL均值，直行为0.05462、转弯0.05566、过门0.05145、停止0.03959。各轮分解见[stage_kl.csv](stage_kl.csv)，12个动作维度分解见[joint_kl.csv](joint_kl.csv)。这些是同一批数据的描述，不是独立新场景统计。

## CV是不是首步即停的原因

三个seed的第1轮，普通组和候选组的B批关键字段逐tensor完全相同，初始actor也相同，因此这一轮具有直接的同数据比较意义：

| seed | 普通/候选的全B解析KL | 两组post均值RMS差 | 该差/各自old→post变化RMS |
|---|---|---:|---:|
| 11 | 0.0708533 / 0.0708532 | \(7.8734\times10^{-6}\) | 约0.07227% |
| 23 | 0.1171320 / 0.1171427 | \(4.8863\times10^{-6}\) | 约0.03488% |
| 37 | 0.0552967 / 0.0552965 | \(5.0414\times10^{-6}\) | 约0.05238% |

两组post均值最大绝对差分别为\(3.7432\times10^{-5}\)、\(3.6955\times10^{-5}\)、\(4.5300\times10^{-5}\)。实际首步行为变化几乎相同；因此本次“第一次更新就触发后续早停”主要由两组共有的PPO、actor和分布尺度关系决定，不能归咎为CV特有的不稳定。

后续轮次的策略、Adam历史和访问状态已经分化，只能作描述比较，不能把两组后续KL之差全部因果归于CV。[paired_arms.csv](paired_arms.csv)明确区分首轮同B比较与后续非同轨迹比较。

## 为什么clip和梯度限幅没有阻止这一步

原更新器在每次minibatch更新**之前**检查KL。首个minibatch仍使用旧策略，重算估计KL为0；随后允许一次Adam更新。下一minibatch发现已经越界，才停止后续actor更新，并不撤销刚完成的那一步。

PPO的ratio clip约束surrogate的局部计算，不保证这次优化器更新后的联合Gaussian KL必小于0.02。首步开始时ratio为1，尚未进入裁剪区。`max_grad_norm=0.5`限制梯度范数，也不是动作分布的信赖域约束；Adam还会用一、二阶矩重新缩放各参数。

保存权重显示，例如seed11普通组第1轮，输入层和输出层参数变化RMS约为预设学习率\(3\times10^{-5}\)，大量参数同时变化。对22个单步轮，使用已保存Adam矩按原Adam代数公式计算该步变化，与前后权重实际差的最大逐元素残差为\(2.37\times10^{-7}\)，与浮点舍入量级相符。该核对没有执行优化器更新。[parameter_changes.csv](parameter_changes.csv)、[saved_adam_delta_check.csv](saved_adam_delta_check.csv)保留分层结果。

这些证据支持“实际公共更新尺度相对当前联合动作分布的KL阈值偏大”。没有运行任何替代配置，因此不将原因份额进一步拆成学习率、标准差、奖励尺度、网络结构各占多少，也不宣称某项调参已经有效。

## 停止位置和日志身份

从`seed+71`开始，逐轮按原逻辑消费4次`randperm(5250)`，可以恢复minibatch顺序。KL提前停止不跳出value训练epoch，因此不会减少这些随机排列。

- 22个只更新一次的轮次：前后checkpoint直接给出唯一实际actor变化，重算第1 epoch第2 minibatch的首次拒绝检查。
- 两个更新两次的轮次：根据已记录更新数定位第1 epoch第3 minibatch的最终停止位置，并以保存的post actor重算该位置；**没有中间checkpoint，未重建前两次更新之间的策略或完整检查序列**。
- `record.json`中的`approx_kl`是第4 epoch最后一个minibatch的值，不是触发停止时的值。按恢复顺序重算最后记录，最大差为\(2.64\times10^{-6}\)。

一个具体例子是seed23普通组第4轮：末尾记录为0.017448，低于0.02；首次拒绝位置估计KL为0.023854，解析KL为0.020021。不能根据末尾数值反推该轮没有达到早停条件。该轮接近边界，动作采样噪声会影响超限幅度，但全B解析KL仍为0.020472，不能将全部24轮现象解释成噪声假警报。

用保存的旧均值和前checkpoint标准差重算旧log probability，最大差\(2.86\times10^{-6}\)。批量重新运行旧actor与采集时singleton算术存在轻微舍入差：旧均值最大差\(8.58\times10^{-6}\)，旧log probability最大差\(2.69\times10^{-4}\)。未发现把执行后裁剪动作当Gaussian样本、错载旧actor或错用minibatch顺序的证据。
