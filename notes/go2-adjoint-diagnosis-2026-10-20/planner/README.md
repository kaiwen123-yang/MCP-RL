# 保存状态上的规划归因

本诊断不生成物理轨迹、不更新权重、不改生产控制器或参数。用原检查点、原CEM随机流及逐个保存的实际宏边界状态，重放原决策；先核对原命令，再固定其768个候选，替换已有模型/价值组件重评分。数据仍是之前完成的固定小试。

选择此前已经报告的seed11三个末轮实例：伴随nominal、普通nominal、冻结narrow；另保留伴随nominal与冻结narrow的第3轮对照。437个实际宏决策的首命令最大绝对差为4.36e-7，预测总成本最大差为1.01e-4。原始full48已经是原planner使用的float32输入，不要求重建完整MuJoCo接触状态。这里核对的是原神经规划计算，不是物理续跑。

每条轨迹在距目标0.35米内的实际决策中等距选最多5个点，合计25个；每个点使用原3轮CEM已搜索的768候选，全部替换都使用同一个候选池、原前一命令及任务记忆，不重新搜索以提高替代方案成绩。

## 关键区分

- 去掉V，25/25点仍选原赢家；将V换成上一轮检查点，25/25点也不变。
- 原赢家与几何跟随候选在25/25点都预测任务已完成，因此终端V已经按原实现置零。
- 仅替换为上一轮g，第四轮的三个实例15/15点赢家改变。冻结组actor未变化且没有CV，因此这一模型—评分失配不需要CV或actor更新才会出现。
- 有9/25点，当前g自己预测几何跟随候选更早完成，但原目标仍拒绝它。这是原候选内部的目标排序问题，不是替代模型的物理效果结果。

## 一个完整的评分例子

seed11伴随组第4轮nominal，在实际14.8秒：距目标约0.0766米、平面速度0.0433米/秒，停稳计时已开始0.08秒。

| 当前g下同一候选池 | 原选中候选 | 几何跟随候选 |
|---|---:|---:|
| 首次预测完成还需/s | 2.0 | 1.0 |
| 原生产评分，越低越好 | 5.3909 | 10.0128 |
| 固定4秒时间项 | 4.0 | 4.0 |
| 终端参考余程惩罚 | 0.0 | 5.8115 |
| 已预测完成后的运行代价 | 2.6019 | 3.0609 |
| 终端价值贡献 | 0.0 | 0.0 |
| 4秒末端预测y/m，实际目标3.6m | 3.7174 | 3.5822 |

跟随候选虽然被预测为1秒后已经满足任务完成，却因4秒后仍落在精确路线终点前约1.8厘米，继续被`20 × remaining_reference_time`惩罚。原选中候选在4秒末端越过路线终点，余程惩罚为0。真实任务允许0.22米位置容差并要求连续1秒停稳，二者不是相同的终止目标。

这一差异被当前g与上一轮g的预测变化放大：换旧g后，同一状态、同一跟随候选的预测末端约为3.751米，余程惩罚消失，固定池选择回到跟随候选。不能据此宣布旧g真实续跑更快；对伴随/普通组，旧g还对应旧actor。冻结组的固定actor对照使“公共g更新能够改变排序”更直接。

## 公共目标的具体不一致

`score_trajectory`在20个固定宏步各加0.2秒，时间项对候选恒为4秒。预测完成后，任务记忆吸收于complete，但机器人状态仍继续传播，几何、命令和终端余程仍计分；只有V被归零。因此“更早完成”本身既不减少固定时间项，也不消除完成之后的虚拟代价。

这不是说参考余程项始终错误或模型一定不准。它说明在原停止容差附近，这个连续代理目标没有与真实终止事件一致。当前目标会对很小的预测终点偏移敏感，g的事实回归改动就可能改变末段命令偏好。

真实已执行的0.2秒后继仍用于独立误差描述。三个第四轮实例在0.35米区域内，当前g的平均位置误差约0.010–0.011米，平均速度向量误差约0.085–0.091米/秒。位置平均误差不大，速度误差却与0.12米/秒停稳门槛处于同一量级；更不能从整体48维拟合损失推断4秒终点或连续保持预测可靠。上一轮g并非每个短时误差指标都更好，所以不把结论写成“新g所有预测都变坏”。
