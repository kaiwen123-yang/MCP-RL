# MR157 · A view on learning robust goal-conditioned value functions: Interplay between RL and MPC

## 全文结构与真正贡献

§2 从 MDP、Bellman 关系讲到 actor-critic 和 HER；§3 从 LQR 解释 MPC 的有限时域与终端价值；§4 区分“独立训练价值后辅助 MPC”与“MPC 整体作为策略/价值参数化”；§5 提出场景式鲁棒训练加目标条件化价值的组合；§6 用双倒立摆、随机线性系统和 CSTR 验证；附录包含 LQR 推导、模型、计算成本与软件实现。

作者把 RL 看成离线获得全局长期价值，把 MPC 看成利用模型、约束和当前状态在线构造局部价值。本文不是说这两类方法只能承担这些角色，而是选取一个可操作的接口视角（p.2—14）。

离线用给定不确定模型构造**每步分支的 MDP**，学习跨场景平均的目标条件化价值，SAC 配合 HER；部署用受约束的短时域场景 MPC，末端取 Q(s, μ_actor(s))。在线场景可少于离线，作者采用首步分支、后续固定各分支参数，以控制计算增长（p.14—19）。这不是任意未知环境下无需模型的鲁棒保证。

## 重要理论与安全边界

场景式目标是列举场景的平均表现，约束在列举场景内处理；不能把它等同覆盖连续真实不确定集的一般最坏情形保证。最终式30使用软状态约束。§5.4 明确把 Lyapunov 结构、稳定性等与该特定架构结合留待未来工作（p.20），不能因摘要写 safe 就报出闭环安全定理。

式32用 Jensen 不等式把传统成本与高斯目标奖励联系起来；它不能单独证明非凸有限预算求解器一定优于另一个控制器。作者自己的附录 A 还指出折扣趋近零会使控制趋近零，对开环不稳定系统会出问题，因此正文有关 LQR 稳定性的概括必须带齐折扣及系统条件（p.23、32）。

## 实验应该怎样读

- 双倒立摆实验**没有 RL 和模型不确定性**，目的是隔离高斯形目标奖励。三个 MPC 目标不同，expert 还含动作平滑惩罚，不能把全部差异归因于“用了 RL”（p.20—22）。
- 线性实验有 2/4/8/16/32 维，每维十个随机系统、每系统十个初态。32维另训练十个 RL，各 50 万步；actor 与 critic 各超过 9 万参数（p.23—24、33）。
- CSTR 的无约束 RL 本来就没被告知状态约束；加入 MPC 后约束表现改善，应以这个信息差为比较前提。作者报告的是目标附近时间与软化越界指标，不是严格零越界定理（p.25—27）。
- 全部实验运行于 Apple M3 Pro、18 GB RAM。RL 使用 do-mpc 模拟器、CleanRL 和 L4CasADi。平滑 swish 激活对在线优化有帮助，作者明确不当作一般超参数建议（p.36—37）。

## 与“价值是否适合求解器”的直接关系

附录 B.1（p.33—34）已经测试把学习价值在目标附近做 Taylor 近似以降低在线成本；快速版本计算时间接近普通 MPC、性能损失小，但作者明确指出初态不能离目标太远，或需增加预测时域。**因此“把神经价值局部二次化用于 MPC 加速”已经有直接先例**，不能直接作为新创新。

作者明确的未解问题是：真实环境分布可能不在给定不确定模型的覆盖内；给 RL 回放加入真实数据可以更新全局价值，但 MPC 的内部模型仍可能错，二者怎样相互配合尚未解决（p.28、35）。阅读者进一步推断：在近似价值、局部线性/二次化和有限次优化共同存在时，是否能判断一次规划对实际回报的净收益，是值得继续核查的更窄问题。该推断仍须与 BMPC、TD-M(PC)²、AC4MPC 及已有近似 MPC 理论排重，本文不足以建立它的新颖性。
