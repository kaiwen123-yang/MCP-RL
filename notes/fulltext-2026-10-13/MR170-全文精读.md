## 科学问题与机制

传统 Model Predictive Shielding（MPS）用备份策略保证动作执行后的状态仍能安全恢复，但“刹停或退回”可能阻碍任务进展，甚至把策略训练限制在不良的探索区域。本文的问题是：**当必须介入时，能否找到既保持可恢复性又有利于长期任务回报的动作，并使 RL 从这些动作中学习？** 这比“再加一个安全模块”具体：它针对介入动作的任务无关性及其对训练数据分布的影响。

系统是完全状态可观测、确定性转移和确定性奖励的 MDP。已知备份策略 `πbackup` 与 `isRec`：后者前向模拟若干步，验证能否安全到达安全平衡。接受学习策略动作的条件是其后继状态可恢复；否则调用局部恢复规划，失败则仍使用原备份策略（p.4–6，图1）。

恢复规划式(2)最大化

\[
\sum_{i=0}^{n-1}\gamma^iR(s_i,a_i)+\gamma^nQ_{\hat\pi}(s_n,a_n),
\]

同时强制预测状态 `s0,…,sn` 全部可恢复。只执行规划第一步，再滚动重算。短期回报使介入不只是刹车，末端 Q 帮助有限时域区分短期相近、远期不同的方案（图2的水洼例子）。安全性来自可恢复集合的保持，**不来自 Q 网络准确，也不来自 TD3 收敛**。

Algorithm 1 对触发介入的原学习动作加入高负奖励、空后继的记录，再加入实际安全恢复动作的真实转移。TD3 随后从混合 replay buffer 更新，因而既受到介入惩罚，也得到能推进任务的恢复经验。这是文中“规划器和策略协同”的具体信息路径；并非单独显式行为克隆损失。Algorithm 2–3 用 MCTS/UCB、随机动作分支及可恢复性筛选实现 `planRec`（p.19）。

## 理论：读到了什么，以及哪里尚不能照搬

恢复遗憾 RR（p.5）是 shield 实际访问分布下，只有介入状态才计入的 `V*(s)−Q*(s,πbackup(s))` 的期望。它不是整条学习曲线的累积 regret，也不等于完整策略全局最优性或神经策略安全性的收敛定理。

Theorem A.1（p.16）的三个版本比主文的简化说法更具体：

1. 末端 Q 与 Q* 一致误差不超过 ε，且采样预算 m 趋于无穷时，RR 为 `O(ε γ^n)`。
2. `S×A` 紧、Q 连续、每步奖励绝对有界，给出 `O(γ^n)`。
3. Q、Q* Lipschitz，单步状态位移有界、初始状态集和动作集有界，给出 `O(n γ^n)`。

证明主链为 Lemma A.2 的 `V*−Q* ≤ 2Bγ^n+ε_m`，其中 B 是 n 步可达末端上的价值误差上界、ε_m 是规划目标优化误差；两次替换末端 Q 产生 `2Bγ^n`。第一种情形直接令 B≤ε；第二种由紧性、连续性和几何级数得到统一有界；第三种用 Lipschitz 与三角不等式把误差增长限为距离/时域的线性项，再对折扣访问分布求和（p.16–19）。

**读者核验发现，保留为待澄清问题：**

- p.16–17 用“真实无限时域最优动作序列”与受 `isRec` 约束的 `planRec` 比较，并使用 `J_Q(a_plan)≥J_Q(a*)−ε_m`。这一步需要比较序列在同一可行集合内。主文 RR 使用未明确限制的 V*/Q*；即使理解为安全最优，安全可行也不必等于“能被特定备份策略恢复”。因此需明确 Q* 是哪个受限 MDP 的最优值，或增加最优轨迹保留在备份可恢复集合内的条件。不能仅凭本文文字宣告对任意安全最优策略的差距指数归零。
- 作者把 ε_m 定义成全状态上的 supremum，并直接将概率完备/渐近最优解释为其几乎必然趋零。这比固定起点的逐点渐近最优更强；本文未在这里证明统一收敛。Algorithm 2–3 的固定分支随机采样也未单独给出渐进扩宽等足以覆盖连续动作最优点的证明。
- p.17 的 ε_m/ε 符号及引理编号存在局部不一致；p.18 三角不等式文字省略 n 而后续公式使用 `n d_T`。这些是阅读时需校正的排版/表述问题，不能代替对关键可行域问题的澄清。
- 安全归纳需要初始状态可恢复、`isRec` 声音性和备份闭合性；正文以 MPS 框架说明，未在本文重新证明其所有实现条件。引用 [9]、[40]、[41] 的原证明尚未外部核读。

因此 proof_status 为“证明全文已读；有条件链与可行域疑问待核”，不标记 verified。

## 实验与信息、计算成本

13 个仿真基准：5 个静态，4 个动态障碍任务各配双积分器/差速驱动。动态任务给学习器本体位置速度等状态，并显式提供门或障碍当前角度（p.21）；规划器使用精确确定性转移，不是从视觉或有噪测量中估计环境。

主比较为 MPS、REVEL、CPO、PPO-Lag、TD3。REVEL 仅在静态环境比较，因为动态环境的白盒最坏情形模型难以建立。PSRL 方法表1报告每回合 shield 次数，其他方法报告违规次数，二者不可当作同一数值指标直接排胜负。动态环境训练 200,000 步、每回合最多500步；五个独立随机种子，每10,000步测试10回合，表中取最后测试结果。静态环境训练预算依任务为100,000–400,000步。负奖励设得足以使穿越障碍不获正总回报；作者也指出某些软约束基线因此选择同时远离障碍和目标。

视觉核对表1–2、图3–5：动态 double-gates+（DI）是明显收益例，DMPS return `13.0±0.6`，MPS `−0.9±0.1`；shield 为 `24.2±6.4` 对 `239.8±16.3`。但并非所有静态任务或所有基线都被超越：mount-car 的 MPS return 更高，obstacle2 的 CPO/PPO-Lag return 更高；安全承诺必须另外比较。图3–4是五种子1σ带，不是经验证分布下的置信区间。

作者报告约100次节点扩张、分支10、时域5，每次介入规划平均约0.4秒；Python单线程实现，每次实验一CPU线程、一GPU。理论预算无穷与这套有限计算设置明显不同。附录图7以“到深度H成功探索10个状态所需扩张数”为代理，H=2–9显示近指数增长；它不是完整运行时扩展定律。图8显示 H=9 比 H=5 早期学习快，最终相近，H=1明显差；这只在 double-gates+（DI）验证。

主文汇总数字（p.2、p.8）与表1逐任务记录的聚合口径未完全交代，本笔记保留逐任务原数，不把“76%减少／29%提高”等摘要汇总作为重新核算过的统一效果。

## 读者推断：可以承接的最小实质推进

有意义的承接对象是**有限计算与不完全模型下，保持可恢复性的任务友好介入是否仍可得到可解释、可检验的性能保证**。已有 DMPS 并未自动消除这条路线的研究价值，但单纯替换网络或加大 MCTS 预算也不足以构成实质推进。

一个小而明确的理论推进候选是：先将 comparator 明确定义为同一可恢复域中的最优策略，给出有限预算优化误差、末端价值误差及可恢复域保守性三者分离的界；再考虑带误差集的模型下哪些项可估计。这是读者提出的待研究问题，未声称已得到定理，也未确认为最终方向。

后续有判别力的检验应匹配环境交互量、转移查询量、在线规划时限与安全判定信息，分别比较原MPS、无Q末端的任务恢复规划、完整DMPS；不应只把换了奖励或获得额外障碍状态后的改进归于方法。证伪条件包括：控制这些信息和计算后，恢复回报优势消失；有限预算扩展中更深时域反而因搜索不足退化；或带模型误差的可恢复判定产生真实违规。任何一个成立都应收窄对应结论，不能靠换机器人平台回避。
