# MR153 · Warm-starting active-set solvers using graph neural networks

覆盖：PMLR 2026正式16页附件文字全读，包括DAQP算法附录及参考文献；p.8—9原页核对图4/5、表2。没有独立重跑或审计DAQP实现。

机制：将正定QP的H、A、f、b转为图，监督学习约束是否活动，用预测活动集初始化DAQP；后续仍由标准dual active-set solver收敛。因此不准确预测主要影响计算成本，不能直接等同策略不安全，前提是求解器有时间完成。是监督学习加速优化的相邻工作，不是RL算法（p.2—6）。

条件：同尺寸实例H/A固定，f/b仿射变化；不同尺寸使用新的矩阵。GNN允许尺寸转移，但并非已经展示任意动态结构/病态度迁移。预测耗时与求解耗时分别报告，MLP前向约快一个数量级（p.7—8）。

MPC例：预测H=50，控制H=5或50，比较主要是cold-start，不能自动说优于充分利用上一时刻解的常规warm-start。H=50的中位迭代数由13变19，90分位由94降78.7，平均减少1.6；说明长尾、均值、中位改善不同，应计入图网络推理成本而非只看预测准确率（p.9—10）。

作者明确展望：其他问题类、更小训练实例到大尺寸泛化、先预测活动约束数再预测具体约束的多步方法（p.10）；p.5保留任务专用图层设计。

可承接推进：在闭环时变QP中，让学习热启动选择关注总延迟尾部及活动集变化，并与上一解、cold-start和简单MLP同预算比较。若能解释并降低“预测大多正确却让关键少数求解更慢”的失效，可属于有意义的推进。仅换更大的GNN或减少平均迭代不足以证明研究价值；现有实时认证求解器和学习warm-start必须继续对照。
