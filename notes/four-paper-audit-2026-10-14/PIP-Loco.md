## 2. PIP-Loco 实际做了什么

PIP-Loco 已有实质性的策略—模型相互依赖。内部模型生成的未来信息进入 expert actor，而内部模型中的克隆策略又学习这个 expert actor。由此形成训练中的相互影响。其部署另用采样 MPC，根据学得的动力学、奖励和终端价值直接选关节动作。

因此，准确的结构是：**训练中学会利用预测的 RL actor，并训练可供规划的内部模型；部署时以规划器替代 expert actor 的直接动作选择。** 它不是“上层 MPC 只调速度，底层冻结 PPO 执行”的结构，也不是全部训练阶段都在运行部署 MPC。

### 训练接口与损失（p.2–4，Fig.2）

| 部件 | 输入／输出 | 数据与优化依据 |
|---|---|---|
| expert actor `πe` | 当前本体观测、估计速度、Dreamer 输出 → 12 维关节角偏移 | PPO，任务奖励包括速度、姿态、高度等；另加 barrier-inspired 平滑奖励 |
| privileged critic `Ve` | 当前观测及仿真器额外信息 → 价值 | PPO critic；额外信息包括地形、外力、真实线速度 |
| 速度估计器 `vϕ` | 观测历史 → 线速度估计 | 与仿真真值的 MSE |
| 动力学 `dθ` | 观测／可选 latent／动作 → 下一观测 | 监督 MSE，真实训练转移来自 expert actor |
| 奖励模型 `rθ` | 观测／可选 latent／动作 → 奖励 | 监督 MSE |
| Dreamer 策略 `πθ` | 观测／可选 latent → 关节角偏移 | 模仿 expert actor 的行为克隆 |
| Dreamer 价值 `Vθ` | 观测／可选 latent → 终端价值 | 监督拟合 privileged critic |
| 可选 encoder `αθ` | 历史观测 → latent | 借鉴 HIM 的对比学习 |

正文给出了这些损失的类型，但没有完整列出全部监督项权重、梯度截断、网络尺寸和更新调度。因此“共依赖”可以确认，“所有参数沿一个端到端任务目标共同反传”不能据本文确认。

三种 Dreamer 的差异（p.3–4）：

- **NLM**：`d(o,a)` 预测下一观测；用克隆策略递归生成 H 步未来观测，将它们作为 actor 的额外输入。部署选用这一种。
- **PLM**：用历史 latent、速度估计与当前观测／动作预测未来，并在 rollout 中更新历史相关量。
- **FLM**：进一步编码 PLM 的未来和过去信息；论文设置历史长度与 dreaming horizon 相同。

这里的 `o` 包含关节量、投影重力、速度指令、上一动作等可观测量，不能直接当作完整物理 Markov 状态。训练 privileged critic 的值也未必能由部署观测唯一重建。

### 部署接口、决策变量与成本（p.4–5，式(3)、Algorithm 1）

优化变量包含 H 步关节动作及一组在时域内保持不变的 twist 指令。若每步动作是 12 维，则有效动作变量规模约为 `12H+3`；论文式中末端动作索引与内循环有一个端点记号差异，不将该记号当额外已实现决策变量。

对每个候选，当前观测中的速度指令分量被候选 twist 替换，之后用 `dθ(o,a)` 递推。目标为 H 步折扣学习奖励加学习终端价值。动作最终是关节角偏移，加 nominal position 后进入执行链；正文描述其送入 actuator network 生成力矩。具体实机低层伺服与时序未展开，不可把训练 actuator network 直接解释为实机也运行完全相同网络。

Algorithm 1 混合克隆策略轨迹和高斯采样轨迹，按约束评价筛选，再根据高回报精英拟合高斯、动量更新，最后从该分布取首动作。训练时的 expert actor 并不是部署时始终执行的固定低层策略。

“无限时域”来自终端价值近似剩余回报，实际在线优化 H=10。它不是显式计算无限步，也没有证明近似价值等于最优无限时域价值。

## 4. 理论实际建立到了哪里

全文提供 POMDP 表述、内部模型定义、有限时域优化式与算法；没有定理、引理或附录证明闭环稳定性、递归可行性、真实系统约束满足、优化收敛或 joint learning 单调改善。

下面是阅读者根据具体算法得到的边界，而不是作者明确承认的全部限制：

1. 式(3)写逐时刻约束，Algorithm 1 实际累积折扣约束值 `Cj` 后和 `b` 比较。正文没有说明两者一般等价所需的符号、权重与阈值设计。
2. 可行样本拟合成高斯后再次取样，最后的新样本并不自动保持可行；算法没有明确精英为空时的后备安排。这限制了从算法直接推出硬约束保证的可能性。
3. 目标 twist 被优化变量替换，学习奖励也依据替换后的观测评价。原始目标 twist 在算法输入中出现，但正文没有清楚展开其偏离成本或范围。因而安全／稳定改善有可能部分来自降低任务难度。
4. 训练 critic 有特权信息，部署价值只由有限观测拟合。对于历史混叠或不同隐环境产生相同观测的情形，需要额外条件才能解释为可靠的终端价值。

这些问题说明下一项研究需要加强什么，并不否定本文已展示的机器人能力。也不能仅靠修正其中一个伪代码细节构造新的完整论文。

## 6. 对当前 joint-response 草案的直接重评

审计对象：[当前研究草案](../../docs/joint-response-learning-proposal-2026-10-14.md)。

| 草案内容 | 相对 PIP-Loco 的判断 |
|---|---|
| 候选未来输入条件下的多步模型 | PIP 已有动作条件 `d(o,a)`，不能作为泛化贡献 |
| 模型和策略在训练中互相影响 | PIP 已有 model→future features→actor、actor→cloned policy→future features 的真实依赖 |
| 高层命令的闭环响应模型，低层 RL 保持执行 | 与 PIP 的动作级部署规划存在明确结构差异，但其他前人已有，不能仅据这一篇建立新颖性 |
| 在 MPC 实际闭环任务中训练低层 RL | PIP 明确未做，值得研究；但原则属于 model-based policy iteration 的常见方向，需要与其他三篇及相关方法继续对比 |
| 更新策略后重新拟合响应模型 | 是必要的模型维护安排；本身不是新耦合原理 |
| 当前策略数据、旧数据管理、成对验收 | 可以提高有效性与复现性，仍是实现与评估安排，尚未定义独立创新 |
| 当前条件 latent、模型误差界与约束收紧 | 只有给出具体学习／控制机制及新的适用条件，才可能构成方法贡献 |

**当前草案确实形成了能运行的闭环组织方式，但相对文献的新耦合尚未被定义到足够具体。** 交替更新不自动等于拼装；同时训练也不自动等于创新。关键在于每个部件的优化条件是否由其他部件的真实作用改变，以及这种改变解决了哪种已知局限。

草案中“固定当前模型和 MPC，在完整任务中 PPO 更新策略，再重辨识”本质上仍是一个分块迭代方案。它可以作为朴素联合训练强基线。若最终算法与该流程没有进一步差别，就不应把它包装为新的融合原理。

## 7. 两个可具体推导的机制候选

以下是待对比和推导的研究者构想，不是已经确认的新贡献。它们需要与 ReCo、SPlaTES 和决策导向模型学习交叉核查。

### 候选 A：用规划的实际敏感方向共同塑造响应与预测

定义低层策略在候选命令 `C` 下的实际响应 `Rθ(h,C)`，预测器为 `Gφ(h,C)`，MPC 决定 `C*φ`。当前草案只有一般 MSE 和全任务奖励，尚未说明什么响应差异值得消除。

可以研究一个具体准则：让预测器重点拟合会改变计划排序或使约束变紧的响应分量；同时让低层策略在这些分量上降低执行变化，而保留能够提高任务进度的差异。规划问题的伴随量／约束乘子可给出一组有物理意义的方向和权重。

这样模型和策略响应同一任务相关敏感性，而不只是分别追求 MSE 小和奖励高。需要推导的是：在什么正则条件下，该局部敏感性能够近似真实任务改善；约束模式改变、接触切换和模型错误时如何失效。为保证内容实质，必须超过“加一项加权损失”，并与简单固定权重共训比较。

低层策略梯度必须来自真实仿真执行的回报、似然比估计或经过核验的可微动力学。已折入旧策略的 `Gφ` 不提供新策略参数的真实导数；把 `∂G/∂θ` 直接当作已知是不成立的。

### 候选 B：对策略更新的响应变化建模，使旧经验可有条件复用

草案目前每轮更新后重新采集／拟合，可能付出很大代价。一个具体研究对象是：由 `θold→θnew` 引起的响应差 `ΔR(h,C)`，能否由少量配对执行预测，并在限定更新范围内修正旧模型和旧数据。

这要求在同一初始历史／环境条件、同一候选命令下，比较新旧策略，避免把环境差异当成策略变化。可用多步响应误差而非参数距离定义更新约束。模型学习与策略更新因此通过可复用响应范围发生双向约束。

应争取的是响应变化界、数据复用误差及最终计划表现之间的关系。若只是加 policy ID、减小 PPO step 或使用小 buffer，就没有超过已有做法。配对采样自身也有成本；只有它减少了总训练与模型重拟合代价，才值得采用。

## 8. 紧凑闭环响应为什么可能节约计算，也可能更贵

紧凑模型可以把低层执行的 K 个步长压缩成一个宏观命令步。在推理时，若直接预测任务状态及必要的段内约束量，就可能避免每个候选都显式展开 K 次低层网络和全关节状态。这是合理的计算动机。

但至少有三项代价不能忽略：

- **获取标签**：B 个初态、Q 条候选命令、H 个宏观步、每步 K 次低层执行，约需 `B×Q×H×K` 次仿真状态更新与策略推理。复制环境状态、控制器记忆、执行器滤波和接触状态也要完整。
- **加入 MPC 的训练**：每个环境的完整任务 rollout 都调用 planner，新增开销取决于候选数、优化轮数和模型 horizon。不能只报告响应网络训练时间。
- **信息压缩**：若只预测机体速度，足端撞击、关节限位、接触丢失可能被隐藏；为了支持这些约束增加段内统计或多分支预测后，原有速度优势可能消失。

一个可检查的在线预算是

`T_total = T_state/history + T_encoder + T_planner + T_feedback + T_constraint/check + T_communication`。

对采样 planner，模型评价规模约为 `N_iter × N_candidate × H_macro`，其串行深度通常仍含 `N_iter × H_macro`。一次性整段预测可减少 rollout 深度，但会增加输入／输出、跨时域一致性和可变时域问题；其优越性应测量，不能先写结论。

最合理的首版计算假设是：低层部署策略直接推理，MPC 在较慢任务频率调用 compact response；训练中计入全部 planner 查询和仿真分支。是否机载可行必须在用户实际设备、目标周期和完整链路上验证。本轮没有依据给出可承诺的毫秒数或训练小时数。

## 9. 当前证据支持的结论

PIP-Loco 已经完成“内部模型与 RL 共依赖训练＋部署 MPC”的完整机器人方法，证明该组合具有工程可行性与实验价值；它也主动承认训练成本和 planner 分布失配。它没有建立联合学习、近似模型规划及真实约束的理论闭环。

我们可以承接这些限制形成完整研究，但目前三项拟贡献仍缺一个明确、可推导、能改变模型和策略更新方式的中心机制。下一步应先选择并写出这个机制的数学对象和优化关系，再由四篇原文比较判断其增量；不能把更多模块、更多数据或交替训练次数当作创新。
